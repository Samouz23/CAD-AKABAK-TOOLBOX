ABEC 3.5.3 (vs ABEC 3.4)

Version 3.5 completes the sub-domain-modeling. Driving and connecting of subdomains can be done in any configuration, see chapter Subdomains and the example: \ABEC3 - Examples\ABEC3 Examples\BEM\2D\Horn.

Dim=2D has been improved further. Normals point now as they should and Pressure_Points are correctly implemented in case of IB.

Note, that NUC=true by default even if it is not specified in section Control_Solver. With low density meshes there is danger of giving wrong results, for example at low frequency analysis. In these cases it is better to specify NUC=false in section Control_Solver.

Baffle section got improved.

Parameter Mirror= is working correctly now.

ABEC 3.4.1 (vs ABEC 3.3)

The new version provides a method to compensate the Non-Uniqueness Problem.

The boundary element analysis has been extended to Dim=2D, see also examples at /BEM/Rooms/*2D

The new version provides new sections for convenient specification of acoustic boundaries for the Boundary Element Part:

Baffle, Duct and Transition.

An interface for importing GiD-mesh-files has been added.

Collada-mesh-file supports grouping, see example /BEM/Rooms/Room-Hex.

CAD-Import Tags can also be a string, as explained in chapter Mesh-File-Tags.

SVG-file import driver (Inkscape and sPlan) for Dim=2D modeling.

Pressure point distribution by mesh-file, see at Pressure_Points.


!!! Functioning of parameter Position= has been updated. See note at chapter Compatibility of Parameters.

ABEC 3 (vs ABEC 2)

ABEC3 got a substantial refurbishing of the code base, which we call refactoring. A new layout of the code-base was designed in order to provide a comfortable home for all the new features of the long, long wish-list... Refactoring is painful because all has to be taken apart and re-wired, hopefully avoiding bugs. The advantage is that development and maintaining of the code is more manageable and future proof.

ABEC3 supports storing the state of the solver. After opening, observation can commence directly. See chapter Result Files.

ABEC3 can access mesh-files, which provide a powerful link to 3D-CAD programs.

ABEC3 exists as 32bit and as 64bit version. The latter allows to allocate memory beyond 2GByte.

ABECs parallel-processing has been extended also to the observation stage.

ABEC3 got an update on the GUI, which is more standard conform.

ABEC3-scripts can be parameterized.

ABEC3 has a Direct Sound mode.

ABEC3 provides the "Measured Radiator", see at Def_MeasRadiator.

ABEC3 provides a direct link to Klippels' laser scanner data-files, which can be uses as driving boundaries, see VibFile.

Finally there are many smaller features added and completed and issues solved.

Compatibility

Compatibility to ABEC2 scripts is almost 100%. Some identifiers were changed but ABEC3 still understands depreciated ones.

More important to note is that LE-Scripts and Data-Files are handled differently in ABEC3, see Compatibility of Parameters.
