ABEC Professional needs a Release Code in order to enable saving Result Files. The demo-version does not save Result Files and there is no need of a Release Code.

Running ABEC Professional without a Release Code still allows to load Result Files and to perform observations. However, re-solving the Boundary Element part will delete the previous Result File. A warning is issued for this particular case.

Any Release Code is unique and enables ABEC only on a particular computer.

Temporary Release Code

After purchasing you should have received an email with a temporary Release Code, in order to bridge the time between purchasing and arrival of the letter with the USB-key (see below).

In order to enter the temporary Release Code go to menu Help > Release Code, which opens the dialog:

Steps

  1. Open the dialog at menu Help > Release Code.
  2. Paste the Release Code in second field.
  3. Click on Ok in order to save the code.

USB Key

The USB-Key is mailed to you or to your company after purchasing ABEC.

The USB-Key conveniently generates the Release Code after connecting to a USB-port of your computer and after opening the dialog at menu Help > Release Code...:

Steps

  1. Open the dialog at menu Help > Release Code.
  2. Fit the USB-Key to a USB plug of your computer.
  3. After some seconds a green light should be shown.
  4. Click on Ok in order to save the code.

Note that you need your USB-Key only for installation or when you change the computer or parts of it. Keep the key at a safe place or return it to the administrator.

Release Code without USB

It is also possible to obtain a permanent Release Code from R&D-Team without using the USB-Key. This might be necessary for special licenses or computers without an USB connection. In order to receive such a Release Code, send us your machine identifier as reported in the dialog:

a) Steps for Inquiring Release Code

  1. Open the dialog at menu Help > Release Code.
  2. Click bottom Email...
  3. Send email to info@randteam.de.

b) Steps for Acknowledging Release Code

Eventually we respond with the Release Code for you.

  1. Open the dialog at menu Help > Release Code.
  2. Paste the Release Code into the second field.
  3. Click on Ok in order to save the code.

Notes

Once installed, there is no need for connecting the USB-Key.

However, keep the key at a save place in case ABEC will ask for a new Release Code. This may happen only in three cases:

  1. Installing on a new machine.
  2. After larger modifications to your computer.
  3. Erasing of .../All users/ABEC.ini, a file which stores the Release Code.

In any of these cases, start ABEC and proceed as listed above.
