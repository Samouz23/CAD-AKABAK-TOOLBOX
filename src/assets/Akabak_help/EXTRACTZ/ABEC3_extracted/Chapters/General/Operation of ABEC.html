Operation of ABEC

Home

Operating of ABEC is simple regarding the complexity of the issue.

Because ABEC is a simulation program you expect numerical results. These are displayed by ABEC in form of field-plots or spectral curves, such as the sound pressure response or the response of the excursion of the voice coil and so on.

In order to calculate these response functions ABEC need to know details of the observation, i.e. what exactly you want to see. For example the sound pressure at a certain spatial point or the driving point impedance of a network, etc. In ABEC this information is specified in so called observation scripts.

Naturally we need to specify the device - the structure, which produce sound and which provide boundary conditions. Here ABEC offers a range of Operation Modes.

The Boundary Element Mode calculates sound fields satisfying boundary conditions. This means we have to specify the geometry of these boundaries. Typically this is done at the so-called solving script or BE-script. The Boundary Element Mode needs to go through a solving stage before we can go and observe its parameters.

The Direct Sound Mode is straightforward and allows the calculation of the response of pressure point sources without taking into account boundaries. Naturally these scripts are simpler than those of the BE-Scripts. Also, in the Direct Sound Mode there is no solving involved and we can observe directly.

The Lumped Element Mode calculates networks of dedicated two-, four- and multi-poles. There can be electric-, mechanic- and acoustic components. Also abstract filter transfer functions are supported.

It is possible to setup pure Lumped Element projects. For example for analyzing equivalent circuits.

You can use Lumped Element Networks together with the Boundary Element and Direct Sound Mode. In Boundary Element Mode ABEC provides full coupling between the BE- and LE-domains [9].

The Lumped Element is part of the observation stage. This means also that you can alter the LE-script without the need of re-solving of the BE-script.

From Scratch

For example, if you want to analyse a closed loudspeaker box in a room you would need the Boundary Element Mode possibly linked with a Lumped Element Network. The BE will calculate diffraction and reflection of the cabinet and the room-acoustics. The LE may be used to model the electro-acoustic device and the interior of the speaker cabinet.

New Project

The first step is to issue menu Project/New Project, which opens the File-Dialog for saving.

It is wise to provide a dedicated folder for a project, which you can create on the fly with the help of the File-Dialog.

Enter a name for the project and press Save.

Adding Scripts

The next step is to add scripts to the project. Of course this implies that you have these already available.

Because we use the Boundary Element engine of ABEC we need a solving script. This is usually the largest script and often time-consuming to set up. However, basically the solving script is simple because its sections are only there to describe the geometry of the structure, which provides the boundaries to the field. If you enter the geometry manually it is best to draw a sketch first. First enter all vertices of the planes (Nodes). Then you switch on Views/Nodes, which helps to identify the Nodes. Then assemble the Elements. If you use CAD and tools like GMESH, best is to make a temporary section Elements, which shows all triangles of the mesh-file. Then select the plane in order to learn their Tag number, which you use to disperse triangles over a range of Elements sections.

Because, in our example, we want to use coupling to a Lumped Element Network, we need to also create such a script and register it with the project. Coupling happens through the parameter DrvGroup=, which is part of driving Elements in the BE-script and related components in the LE-script.

Finally, we compose observation scripts and register them with the project. The observation scripts for Field Analysis describe the size and shape of the observation grid where ABEC calculates and displays the sound pressure. The observation script for spectra lists sections for microphone positions and network observation parameters.
