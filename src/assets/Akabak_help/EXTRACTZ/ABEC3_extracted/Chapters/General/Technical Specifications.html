Hardware Requirement

In general ABEC assumes modern PC-hardware, fit for a standard MS-Windows 7+ system.

Recommended is an amply equipped computer with many CPUs and lots of memory, because ABEC makes extensively use of parallel processing. However, with each used thread also the memory allocation goes up, which should be available.

On 32bit-systems memory is limited to a maximum of 2GByte per process. If you simulate large structures on multiple CPUs it is recommended to run the 64bit version of ABEC. Of course, this assumes a 64bit OS-system with plenty of memory.

It is hard to give reliable prediction of memory consumption. In fact the best measurement-tool is ABEC itself. Run ABEC with different mesh-distributions and frequency ranges and observe Windows' Task-Manager/Performance board. Note, regarding memory consumption the free and commercial version of ABEC are similar.

ABEC 3D-viewer runs OpenGL. Make sure your graphic-card is up-to-date. Typically this is OK for 32bit systems, however, some older graphic-cards may not have a proper 64bit driver.

OS Requirements

ABEC should run on all versions of MS-Windows 8 and 7. There is available a 32bit and a 64bit version. The installation is organized automatically by the installer.

Other Software

For swift working you also need some further software-tools as explained in chapter Modules.

Installing

Installing is straightforward. Open the install application and follow the instructions. The installer installs automatically the correct bit-version of ABEC (32/64bit). Examples are very important, and are part of the installation.

User Documentation

The basic user documentation is available as Help. If you are new to ABEC, simply press F1 and enjoy the reading!
