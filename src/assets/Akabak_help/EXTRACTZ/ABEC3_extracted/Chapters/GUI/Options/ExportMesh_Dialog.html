The Export-Mesh Dialog opens via menu Options/Export Mesh....

This tool converts the current boundary element mesh to a mesh-file. Typically the exported file represents the starting point for creating a more refined CAD draft. In order to do so there are versatile software-tools in order to refine and transform the mesh, for example:

MeshLab

GMESH

File Format

Select the file-format of the output.

STL stands for Stereo Lithography. It is commonly used for feeding 3D-printers. See Wikipedia. The STL-format is very basic. It consists only of coordinates of vertices of triangles.

File Output

Multiple Files creates files for each section of the solving script. The file-name is produced automatically according to formula:

Filename = Name of File + Section Name + .Extension

Name of File is given by the File Dialog after pressing the button Save As (see below). Section Name is the name of a script section (make sure section-names are unique). Extension depends on the file-type.

Single Files exports all items into a single file.

Elements

All exports elements as are specified in the script, regardless of desktop-settings.

Visible Only exports only elements, which are switched visible by desktop-settings.

Symmetry

All exports the complete structure.

Part Only exports only the original part without the mirrored parts.

Save, Save As

Creates the mesh and finally saves it to a single or multiple files.

Save As will call the File Dialog in order to provide a filename.

Save will use an already specified filename.
