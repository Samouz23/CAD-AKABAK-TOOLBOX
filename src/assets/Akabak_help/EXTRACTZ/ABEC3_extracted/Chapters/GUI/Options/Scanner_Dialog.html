The Scanner Dialog opens via menu Options/Scanner....

This tool helps to manipulate and transform data-files from Klippels Laser Scanner, which are going to be used at section VibFile.

Import

On page Import specify a text-file as has been exported by Klippels' Laser Scanner Software. If such a file is currently registered with the project and selected then its content is loaded directly. Alternatively, you can load such a file (see button Import).




Geometry

On page Geometry specify an optional mask, which is used to remove superfluous elements.

For example, on the right hand side you see at the top a complete scan. Because the scan is always circular there might be elements which need to be removed. The bottom picture shows the same mesh but masked by an oval, which erases all elements outside this shape.

Shape of Outer Mask

Shape specifies the shape of the mask. All elements within this mask will be maintained.

Diameter, Width, Height is the size of the mask.

Preserve Height at Mask Edge. If checked then coordinates of the elements at the cutting edge are maintained. Otherwise elements at the edge may be stretched in order to be at zero height.

Export

Button Export starts the transformation from a Klippel laser scanner data-format to a GMESH-file format (*.msh). The GMESH-file format is documented at [17].

Manual Entry of Result Filename. If checked then specify a filename for the export-file. Otherwise the filename from the Import-stage is used, however with a different extension (*.msh).
