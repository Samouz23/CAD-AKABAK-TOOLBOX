Fields

Home

The menu Fields belongs to the observation stage.

Start Calculation

Start the calculation of field-analysis as specified in the Observation Files with section BE_Field.

Field calculations are also controlled from the desktop with the help of page Ob-Field.

Abort Calculation

Stops the calculation of field observation. There will be not output.

Show Field

After calculation of checked frequencies ABEC renders the result as field-plots inside the 3D-Viewer on page Drawing. The frequency can be selected on page Ob-Field.

Level Legend

The Level Legend for contour plots can be enabled at Miscellaneous/Level Legend of page Views.

Only Meshing

This function only distributes the calculation points and calculates the mesh for the display. In order to see the mesh you need to select its plane.
