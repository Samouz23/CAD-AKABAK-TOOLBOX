The solving-menu provides functions for solving the Helmholtz Integral of the Boundary Element Analysis.

Start Solving

Starts the solving process, which goes through several steps until the flag Solved appears in the status line. Progress information is given on the Solving Page.

Abort Solving

Stops the solving process and clears all result-databases. Termination may take a while.

Saving Result File

Manually saving results from solving stage of the Boundary Element Analysis to a Result File.

Normally results are stored directly after solving is completed. However, this command is there if for whatever reasons automatic saving fails.

Only Meshing

This function performs only the meshing-part of the solving process. It is very useful for checking the mesh-density. All result-databases are cleared.

Calculate Fields after Solving

If checked then ABEC proceeds with the calculation of fields directly after solving. It simulates a click on menu Fields/Start Calculation.

Calculate Spectra after Solving

If checked then ABEC proceeds with the calculation of spectrum-calculations directly after solving. It simulates a click on menu Spectra/Start Calculation.
