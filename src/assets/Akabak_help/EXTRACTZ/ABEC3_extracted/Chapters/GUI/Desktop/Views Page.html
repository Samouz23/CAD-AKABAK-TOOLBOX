Views Page

Home » Desktop

The View-Page lets you switch on and off items in the 3D-Viewer.

Structure

- Original Elements shows elements as specified, otherwise the mesh is rendered, if available.

- Normals displays a little stub in the center of Boundary Element planes. The length of the stub can be adjusted with the track-bar at the bottom.

- Driving Directions displays a little stub in the center of driven Boundary Elements The length of the stub can be adjusted with the track-bar at the bottom. See also parameter Direction=.

- Nodes shows indices at all Nodes.

- Element Indices displays the index of the elements.

- IB Mirrors displays the mirror mesh-elements if radiation is from an Infinite Baffle (needs meshing first).

- Symmetries displays the complete structure if Sym= is specified.

- Wire Frame shows the structure transparent.

Observation

- Field Nodes displays all Nodes used to build the observation planes for Field Analysis.

- Field Wires shows the observation planes transparent.

- Original Field Planes shows observation planes as entered. Otherwise the mesh is rendered.

- Field showing all field-planes.

- Spectrum Hints show little dots and arcs of Spectral Analysis.

Selection

- Calculations displays additional information on selected element.

- Node Numbers displays node indices of selected element.

- Dimensions displays the coordinates of the vertices of selected element.

Miscellaneous

- Project Info renders the name of the project in the 3D-Viewer.

- Frequency Info renders currently selected frequency of Field-section.

- Coordinate Axis displays axis of the coordinate system.

- Axis Probe displays a little coordinate system at bottom left.

- Level Legend display a list with contour levels used for selected Field-item
