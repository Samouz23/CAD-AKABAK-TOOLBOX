After menu Solving/Start Solving, the Solving Page reports messages from the solver of the Boundary Element Analysis.

If an error occurs a red flagged icon is placed on the tab of the page.

The solving process starts with menu Solving/Start Solving. Typically solving is time consuming and ends automatically. Solved successfully is reported and the Statusbar of the desktop displays Solved. Then observations can take place.

The process can be stopped at any time via menu Solving/Abort Solving. The termination may take a while until all sub-threads are cleared.

Meshing

In this step ABEC calculates the size of the Boundary Elements so each element satisfies the frequency criterion as specified in the solving script at MeshFrequency= or EdgeLength=.

Please note, currently the meshing is not sub-threaded. Termination of this stage can be achieved with pressing the ESC-key.

Acoustic Constants

This line reports parameters of the domain medium, which can be specified in section Control_Solver of the solving script or see at Acoustic Parameters.

Solving

Num domains are the number of independent un-coupled BE-domains. For example, a simple sealed loudspeaker cabinet with interior and exterior domain should report two BE-domains, because there is no acoustic coupling between the interior and exterior domain with a sealed enclosure.

Num elements reports the total number of elements meshed.

Num global freedoms are the number of unknowns of the main-system matrix to be solved. If there is only one sub-domain then Num global freedoms = Num elements otherwise it is equal to the number of interface elements.

Num frequencies are the number of frequencies as specified at section Control_Solver of the solving script.

Calculating Volumes reports the calculated volumina of each interior sub-domain and the total. The values should be regarded approximate as they are based on the triangulisation of the object. The volumina are not used internally. However, the values are also useful for checking the quality of the model. For example, negative values for a volume typically indicate miss-aligned normals or over-lapping elements.

Calculating Free Terms are special parameters of the solving of the Helmholtz Integral. For you as a user of the program the Free Terms can be used as an indicator for the quality of the mesh. Typically, its values should be approx 1/2. Strong deviations from this value may indicate problems with the normals or overlapping elements. However, there are also cases where Free Terms may vary strongly, for example for elements at open edges. The calculation of the Free Terms is single threaded.

Solving for frequencies. In this processing-stage the Helmholtz Integral Equation is solved for each frequency. All available CPUs are used in parallel processing. Because of this there is an increase of memory allocation, which may cause an Out of Memory error for large models. In this case you can try to limit the number of CPUs in menu Options/Preferences.

Solved Successfully

When this line is output the solving stage is finished and you can proceed to observation-calculations.
