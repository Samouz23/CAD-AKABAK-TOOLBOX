Drawing Page

On this page the structure is rendered in the 3D-viewer. The projection can be controlled with the help of the mouse and keyboard. For this the viewer should have focus (click into it). There is a dedicated main-menu Drawing. On the side there is a list of buttons for quick access. This list can be aligned differently with the help of menu Options/Preferences/Desktop.

Mouse

Rotation

Left-click and drag. Press CTRL-key for rotation on a finer grid. If the rotation mode is ArcBall then the mouse movement is mapped on the surface of a virtual sphere, which rotates. If the rotation mode is Euler then rotation is about the coordinate axis. In this case the horizontal movement rotates about the vertical axis. The vertical axis can be selected in the menu Drawing/XYZ-Axis Upwards, respectively.

Shifting

Wheel- or middle-click and drag. The structure is panned until the mouse button is released.

Zooming

Rotate the mouse-wheel for zooming the view in and out of the structure.

Keyboard

The structure can be moved with the LEFT/RIGHT and UP/DOWN keys. Increase the step with simultaneously pressing the CTRL-key. The HOME-key rests the default values. The END-key yields maximum clipping.

Use menu Drawing/Set Keyboard To... to select, whether the keys rotate, shift, zoom or clip the structure.

Alternatively simply type

    R   Rotation mode
    S   Shifting mode
    Z   Zooming mode
    C   Clipping mode

Note, for the quick-keys to work the drawing should have input-focus.

For example: Press "R" and then the LEFT-key in order to rotate to the left. Press "C" and then the END-key in order to set the clipping to maximum. And so on.
