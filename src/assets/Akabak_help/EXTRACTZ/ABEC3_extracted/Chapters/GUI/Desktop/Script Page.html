After loading scripts, the interpreter makes use of this pane for outputting information, warnings and errors. If an error occurs a red flagged icon is placed on the tab of the page.

Scripts are loaded after menu Project/Open Project or after menu Project/Add Files. Scripts are automatically re-loaded and interpreted if they have been modified by the external editor, see Updating Files.

Simply click on a header to expand the embedded lines of information.
