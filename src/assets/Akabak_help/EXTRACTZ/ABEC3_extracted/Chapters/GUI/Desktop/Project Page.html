At the top of the Project Page the folder and project-name is reported. Note, if the project-name is "Project.abec" then ABEC shows the the name of the hosting folder instead.


The list of the Project Page lets you register files, which are used in the Project.

Note, embedded files should not be registered here, see parameter File=.

Boundary Element Script

Provide the so-called Solving Script if in Boundary Element Mode. See Add Solving Script.

Direct Sound Script

For Direct Sound Analysis add the Direct Sound Script.

Currently, the Boundary Element and the Direct Sound modes are mutual exclusive.

Lumped Element Script

If observations are driven (coupled) to a Lumped Element Network then add the LE-Script here.

It is also possible to perform only Lumped Element Analysis. In this case there would be no BE-Script and no Direct Sound Script. For LE-Analysis only, you need only the LE-Script and an Observation Script with spectral definitions. See Spectral Observation Scripts.

Observation Scripts

Observation Scripts declare what, where and how you want to view results. Typically Observation Scripts are organized so that Field and Spectral specifications are in dedicated scripts.

There can be multiple observation scripts. Each may have one or more embedded files, see File=.
