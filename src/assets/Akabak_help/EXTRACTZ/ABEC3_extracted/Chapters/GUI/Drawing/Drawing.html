Home

Menu for controlling the 3D-viewer.

The 3D-viewer can be controlled with the help of the mouse and with the keyboard as explained in chapter Drawing-Page.

Set Keyboard To...

These menu items select, whether the LEFT/RIGHT and UP/DOWN and HOME and END keys lets you rotate, shift, zoom or clip the structure.

Alternatively simply type

    R   Rotation mode
    S   Shifting mode
    Z   Zooming mode
    C   Clipping mode

Resetting

Restores the default settings for rotation, shifting, zooming and clipping.

Alternatively, press the HOME-key.

ArcBall

If the rotation mode is ArcBall then the mouse movement is mapped on the surface of a virtual sphere, which rotates. Use preferences to have ArcBall rotation by default for any project. See menu Options/Preferences/Graphics.

Euler

If the rotation mode is Euler then rotation is about the coordinate axis. In this case the horizontal movement rotates about the vertical axis. The vertical axis can be selected in the menu ZYX-Axis Upwards, respectively. Use preferences to have Euler rotation by default for any project. See also menu Options/Preferences/Graphics.

Axis Upwards

Use this feature to quickly rotate the structure with one of the axis pointing upwards.

Secondly this setting controls also the rotation axis for Euler-Rotation.

Copy as Picture

Copies the current view of the 3D-Viewer onto the clipboard as a bitmap. The bitmap-format can be selected via menu Options/Preferences/Graphics.

Save as Picture

This function allows to save the current view of the 3D-Viewer as a bitmap. The bitmap-format can eventually be selected in the file-dialog at "Save as Type".
