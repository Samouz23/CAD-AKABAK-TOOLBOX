Menu for editing features.

Note, that ABEC performs only the processing of script-, data-, and mesh-files. For editing of these files you may need to install further Modules.

Edit Script

Edit Script opens the selected file of the Project Tree-List in an external text-editor.

There is no functional relation to the external text-editor. Or, in other words, you can also open the script manually in the external application.

However, after editing and saving of the script in the external editor, ABEC will reload the script as explained in Updating Files.

File Alias

Select a script in the Project Tree-List and issue Edit/Edit Alias, for editing the File Alias of the selected file. See Edit File Alias Dialog
