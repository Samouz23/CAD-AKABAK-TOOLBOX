A File Alias is used for convenience in order to avoid handling of file-names in the scripts. A File Alias is used in the solving and observation scripts at sections, which need access to external data. For example

  WallImpedance "Damping Wall"
    DataFileAlias=Z1
    RefElements="wall"
    Type=Impedance
    Normalized

In this example section WallImpedance accesses impedance-values in a file with file-alias Z1.


The actual file together with its alias need to be registered with the project.

The file-alias should be unique within the project.

The File Alias Dialog opens eventually during Add Data File, Add Mesh File, Add Vib File, or via menu Edit/Edit File Alias.

In the Project Tree-List the File Alias is reported behind the file-name.
