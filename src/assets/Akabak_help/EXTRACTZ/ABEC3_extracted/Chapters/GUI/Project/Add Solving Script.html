Add Solving Script

Home » Project

Add Solving Script registers the solving-script with the project. The solving script enables the Boundary Element Analysis otherwise ABEC performs Direct Sound Analysis.

There can be only a single solving script per project. However, the main-script can have embedded scripts.

First select the Solving Script header in the tree-list at the Project page. Then issue menu Project/Add Solving Script. In the File Dialog select the file and press OK.

Adding a solving script clears all calculation databases. A warning will be issued. The script and all its embedded scripts get interpreted immediately. Warnings and errors are reported on page Solving. Solving frequencies for Field calculations are reported at page Ob-Fields.

If the script takes reference to data-files via DataFileAlias=, MeshFileAlias= etc. these data-files need to be registered as well, see Add Data-Files.
