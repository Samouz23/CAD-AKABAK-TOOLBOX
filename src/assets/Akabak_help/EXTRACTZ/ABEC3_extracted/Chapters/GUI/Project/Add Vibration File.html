Add Vibration File

Home » Project

Add Vib File registers a vibrational-file with the project. All vibrational-files, which are used in scripts, need to be registered.

Scripts refer to the vib-files with the help of an alias. This alias can be specified at section VibFile in the scripts. For example:

  VibFile "Vib"
    VibFileAlias=Vib
    ...

First select the file-name of the Vib-File in the opening File-Dialog.

Sub-sequentially the File-Alias-Dialog opens, where you can provide the alias.
