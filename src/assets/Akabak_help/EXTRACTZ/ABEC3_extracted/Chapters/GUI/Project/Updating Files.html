Updating Files

Home » Project

ABEC co-operates with other Modules, which file-output it reads.

ABEC loads these files automatically if they have been modified by another application, which can be the Text-Editor, VACS or a Meshing Tool.

Modifications to registered files are monitored by ABEC and eventually reloaded automatically.

As soon as the ABEC-application gets activated, say by clicking somewhere on its desktop or by using ALT-TAB, it compares the time-stamp of the script or data-file. If out-of-date, ABEC reloads the file and immediately performs the interpretation.

If one of the embedded scripts gets updated then the whole branch will be re-loaded.
