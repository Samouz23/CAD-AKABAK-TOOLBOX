Add Mesh File

Home » Project

Add Mesh File registers a mesh-file with the project. All mesh-files, which are referenced with the help of MeshFileAlias= in solving and observation scripts need to be registered.

Mesh-Files typically provide coordinates, planes and positions as explained in chapter Mesh-Files.

First select the file-name of the Mesh-File in the opening File-Dialog.

Sub-sequentially the File-Alias-Dialog opens where you can provide the alias.
