Add Direct Sound Script

Home » Project

Add Direct Sound Script registers a Direct Sound-script with the project. The Direct Sound script enables the Direct Sound Analysis.

There can be only a single Direct Sound script per project. However, the main-script can have embedded scripts.

First select the Direct Sound Script header in the tree-list at the Project page. Then issue menu Project/Add Direct Sound Script. In the File Dialog select the file and press OK.

Adding a Direct Sound script clears all calculation databases. The script and all its embedded scripts get interpreted immediately. Warnings and errors are reported on page Scripts.

If the script takes reference to data-files via DataFileAlias=, MeshFileAlias= etc. these data-files need to be registered as well, see Add Data-Files.
