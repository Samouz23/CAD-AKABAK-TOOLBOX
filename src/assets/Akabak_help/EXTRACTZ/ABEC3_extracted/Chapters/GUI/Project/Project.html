New Project

Start a new project. All data are cleared. In the file-dialog enter the name of the project. After pressing OK in the File-Dialog an empty project-file will be created (*.abec).



Each project should reside in an individual folder. The reason for this is that Result Files are stored in a sub-folder, and there can be many files making a project as demonstrated in the above screen-shot.

Note, the File-Dialog provides a little button at the top right, which lets you create a folder on the fly.

Note, if you call the project "Project.abec" then labels of the desktop refer to the folder-name instead.

After the project-file has been created the next step is to add scripts and data-files to the project, see at "Add (files)" below.

Open Project

Open an existing ABEC project. In the File-Dialog select an *.abec file and press OK.

If Result Files are present they will be loaded, otherwise registered scripts are interpreted.

All data-files are loaded.

Finally the structure will be displayed.

If Result Files are available observation can be calculated right away otherwise the system has to be solved in Boundary Element Mode.

A Recent File List can be found on page Project. Click on one of the items of this list to directly open the related ABEC-project.

Drag and Drop of *.abec-files from Windows File-Explorer also directly opens the project.

ABEC.exe can be started with an *.abec-file as parameter, which opens the project directly at start of ABEC.

Add (Files)

In ABEC all parameters are input with the help of scripts, mesh-files, wall-impedance-curves, driving-values, etc. You need to register all these files as explained in Add (Files).

Reopen file

Enforces the selected file to be re-loaded and interpreted. Normally you would not need this function as ABEC does this automatically if it receives input-focus, i.e. if the application gets selected with the mouse or with the ALT+TAB-key, and only if a file has been modified, see Updating Files.

Remove File

Un-registers the selected file from the project.

File Explorer

Calls the Window File-Explorer at the projects' folder.

Exit

Terminates ABEC, which may delay during solving or calculation because all threads need to be closed first.
