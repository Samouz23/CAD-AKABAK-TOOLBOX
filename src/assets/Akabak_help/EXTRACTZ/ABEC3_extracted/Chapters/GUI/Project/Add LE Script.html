Add LE-Script registers a script for Lumped Element Analysis with the project.

The Lumped Element Network of this script is used to drive the Boundary Element Structure or the Direct Sound Sources at observation stage. Hence, you can alter the LE-Script without the need to re-solve the BE-part.

The coupling to the Boundary Element or Direct Sound domains is via Driving Groups.

If a LE-Script is registered, it will form the default driving for all observations, unless you declared a section Driving_Values in an observation script. In the latter case the LE-Script is ignored for this script and fixed values of section Driving_Values are used.

There can be only a single LE-Script for a project.
