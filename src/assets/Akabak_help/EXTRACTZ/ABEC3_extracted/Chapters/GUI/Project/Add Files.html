In ABEC all parameters are input with the help of simple text-files (scripts). Additionally data-files can provide external meshes, wall-impedances, driving-values, etc.

Project/Add (files)... lets you register these files. It works together with the tree-list on page Project. First select a header in the tree and then issue Add Solving Script, Add Observation Scripts and so on.


Registered files will be monitored and updated if changed, see at Updating Files.




Scripts can embed further scripts, see File=. Embedded scripts should not be registered with the project.

Use Project/Remove File in order to un-register a script or data-file. The file will not be deleted.
