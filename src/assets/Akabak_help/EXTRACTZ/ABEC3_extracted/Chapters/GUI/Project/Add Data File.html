Add Data File

Add Data File registers a data-file with the project. All data-files, which are used in solving and observation scripts, need to be registered.

Scripts refer to the data-file with the help of an alias. This alias can be specified at various sections in the scripts, see DataFileAlias=.

For example:

  WallImpedance "Damping Wall"
    DataFileAlias=Z1
    ...

Data-Files typically provide impedance spectra for the section Wall_Impedance, driving values for section Driving_Values, impedance and SPL values for Def_MeasRadiator and directivity data for the Pressure_Box.

The format and generation of the file is explained in Spectrum Data-Files.


During adding the data-file to the project, i.e. at registration, this alias has to be specified as well.

First select the file-name of the Data-File in the opening File-Dialog.

Sub-sequentially the File-Alias-Dialog opens, where you can provide an alias.
