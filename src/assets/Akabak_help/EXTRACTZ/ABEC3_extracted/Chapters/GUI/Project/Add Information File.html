Add Information File

Home » Project

Optionally, you can provide an Information File, which may contain annotations of the project, such as drawings, specifications, etc.

The Information File is rendered at the Information page.

The Information File should be a plain text-file or formatted in form of Rich Text Format (*.rtf), which most word-processors can create. Such RTF offer rich formatting features and can embed pictures such as bitmaps.

First select the Information File header in the tree-list at the Project page. Then issue menu Project/Add Info-File. In the File Dialog select a *.rtf or *.txt file and press OK.
