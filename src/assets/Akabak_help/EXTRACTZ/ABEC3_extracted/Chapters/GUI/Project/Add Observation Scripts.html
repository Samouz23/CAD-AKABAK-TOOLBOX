Add Observation Scripts

Home » Project

Add Observation Scripts registers observation scripts with the project. There can be multiple scripts. Typically there are distinct observation scripts for field- and spectrum-analysis.

First select the Observation Scripts header in the tree-list at the Project page. Then issue menu Project/Add Observation Scripts. In the File Dialog select one or multiple files and press OK.

Observation Scripts can embed further scripts, see File=. Embedded scripts should not be registered with the project.

The scripts will be interpreted and current calculations reset.

If scripts takes reference to data-files via DataFileAlias= or MeshFileAlias= these data-files need to be registered as well, see Add Data-Files.

If any of the Observation Scripts is driven by a Lumped Element Script then the LE-Script needs to be registered as well. See Adding LE-Script.
