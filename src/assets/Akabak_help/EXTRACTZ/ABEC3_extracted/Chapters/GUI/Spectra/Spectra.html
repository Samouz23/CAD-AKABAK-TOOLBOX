The menu Spectrum belongs to the observation stage.

Start Calculation

Start the calculation of spectra as specified in the Observation Files with sections BE_Spectrum, Radiation_Impedance and LE_Spectrum.

Tree-List

The tree-list on page Ob-Spectrum shows all available spectral specifications of all registered observation scripts. Only checked entries will be calculated.

Abort Calculation

Stops the calculation of spectral observation. There will be not output.

Show Spectra

This function re-renders the current result-database. The output medium can be selected with the help of menu Spectra/Output Ways. Note, normally the result is output directly after calculation.

Output Ways

The spectral result curves are rendered as binary VACS-Import-Files. This format can be directly read by VACS. Technical documentation about the format of these files can be found on the web-site http://www.randteam.de.

In order to display spectral result files with VACS you need to install VACS or VacsViewer.

VACS Automatic

In this mode ABEC will send data directly to VACS via the COM Interface Technique. If necessary, VACS or VacsViewer will be opened directly prior to calculation. The curves will be displayed immediately after the calculation has been finished.

Clipboard

This setting will copy data to the clipboard from where you can paste the spectra into a running VACS application. VACS will not be opened automatically. After the spectrum-calculation has finished, select the VACS-application and there issue menu Edit/Paste.

File

In this mode ABEC will render spectral results into a file at

  <ABEC-Project Folder>/Results/VacsSpectrum.vips

Eventually this file can be imported into VACS.
