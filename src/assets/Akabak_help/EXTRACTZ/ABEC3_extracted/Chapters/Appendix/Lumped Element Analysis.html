Lumped Element Analysis

Home

The Lumped Element Analysis (LE) calculates flows and potentials of a network of components, such as resistors, capacitors, etc. In ABEC this analysis is extended to the mechanical and acoustical domain, where you have components, such as the Driver and Waveguide component.

Basically the LE solver assumes Voltage, Force and Pressure as potentials and Current, Velocity and Volume-Velocity as flows. The product of potential and flow yield the power

P  =  1/2·pot·flow'

with assuming peak-values, and flow’ means conjugate complex.

Because it is easier to model the mechanical domain with the help of the mobility analogy, the LE-Analyzer provides also special components and observation modes for the case where the force is regarded as a flow and the velocity as a potential. See chapter LE-Mobility Analysis.


The LE-Network is specified in a dedicated LE-Script as a text-file.

As a first step this file needs to be registered with the project at LE Scripts in the project tree-list, see Adding Lumped Element Script. Then all observation scripts, which do not have a section Driving_Values will couple to the Lumped Element Network by default.

The LE-Analysis is part of the observation stage. Changing the LE-Script will maintain the solving stage, which means that only the related observations need to be re-calculated.


The LE-Analysis is assuming a certain System, Network and Component hierarchy.

Observation

Use LE_Spectrum-Sections in order to observe parameters of the LE-Networks, such as voltage, current, pressures, excursion etc. For example, in order to get a curve of the electrical driving point impedance of System with name "S1" specify:

  LE_Spectrum  "Drv Point Impedance"
    AnalysisType=Impedance
    System="S1"
    ID=101

Coupling LE and BE

Coupling to the Boundary Element part is established with the help of parameter DrvGroup=, which exists on both sides, ie at the BE and at the LE part. In the BE-part DrvGroup= is used to mark a "driving-channel", i.e. at the solving-stage there are no driving values yet. In the LE-part DrvGroup= is also used. Here DrvGroup= is used at network-components in order to exchange diaphragm-dimensions, radiation-impedance and driving-values values with elements of the BE-part.

Fully coupled means that on the one hand side the driving values for the Boundary Element analysis are taken from network-parameters of the LE-simulation, for example the velocity of a driver-diaphragm. On the other hand, the LE implements radiation impedance elements, which are calculated during solving of the radiation-field. The implementation of the Boundary Element method is done in such a way that changes to the LE-network do not make necessary a resolving of the Helmholtz Integral. The effect of this is that calculations are fast as long as the acoustic structure is not altered. A detailed paper is available at [9]

The LE-Analysis is fully coupled to the Boundary Element Analysis. However, it is also possible to make simulations only with the LE-network or together with Direct Sound Analysis.
