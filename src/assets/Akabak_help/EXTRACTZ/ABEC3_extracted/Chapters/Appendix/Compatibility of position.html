Compatibility of Position

Home

Components, such as Diaphragm etc need to be positioned.

There are several ways of specification. One makes use of a positioning-triangle as explained at parameter Position=.


In versions of ABEC <= 3.3.3 there is a bug, which ignored the rotation of the component. It did not matter which position P2 had, the diaphragm was always aligned with the principal axis.


From version >= 3.3.4 of ABEC, P2 controls also the axial rotation.

In the first example P2 is at the same "height" than P1, which yields no axial rotation of the Diaphragm. In the second example P2 is at the top corner, which makes the Diaphragm to adjust its position accordingly.

As before P3 has a degree of freedom. It only controls inclination.


Old scripts may need adjustment. For example if your current specification is similar to the bottom picture then you might consider to specify another coordinate in section Nodes, which is at P2 in the above picture, and use this new coordinate at parameter Position=.

Alternatively you can provide axial rotation with the help of sub-parameter Rot= of parameter Position=, for example:

Diaphragm  "CF"
  ...
  RefNodes="NF"
  Position=3000,3003,3004  Rot=0
 
Diaphragm  "CF"
  ...
  RefNodes="NF"
  Position=3000,3003,3004  Rot=-45

In the above example the position triangle yields a mismatch of the Diaphragm-baffle. Rot=-45 brings it back into place.


Scripts, which use mesh-files at parameter Position= may also need adjustment. In most cases best is to provide sub-parameter Rot= as explained in the above example.
