LE-Scripts and Data-Files

The biggest change versus ABEC2 concerns the handling of data-files. In ABEC3 all data-files and LE-scripts need to be registered with the project, before you can access the data or couple to it in any script. The previous embedding of data-files and LE-scripts is not supported any more and and an error message is displayed. For example, in ABEC2 an observation script, which coupled to a LE-script typically had a line like this

  File_LE="LEScript.txt"

In ABEC3 this has changed. There can be only a single LE-script for all observations. This LE-script need to be registered with the project, see at Add LE-Script. If an observation script has Driving_Value sections then constant driving is assumed (for this particular observation script). If an observation script is void of Driving_Value sections then ABEC assumes coupling to an existing LE-Script.


Likewise, the embedding command "File_Data=" of ABEC2 is replaced by the new alias schema. For example, if you want to attach an impedance-spectrum to WallImpedance, you simply specify

  WallImpedance
    DataFileAlias=Imp1
    ...

Also here you need to register the data-file with the project and provide an alias for this file. In the above example the alias is "Imp1".


More on aliases and registering data-files and LE-scripts see at Add Data File and at Add LE-scripts.
