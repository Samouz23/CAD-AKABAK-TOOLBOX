As outlined at section Filter there are several ways of specification for the transfer-functions. In particular there are two rational transfer-functions:

H(s) = H1(s)·H2(s)

H1(s) is a rational transfer function where the coefficients ai= and bi= are specified explicitly. If no ai= and bi= are specified then H1(s) = 1.

H2(s) is also a rational transfer function. However, coefficients of H2(s) are internally calculated from a family of standard filter alignments and its transforms. H2(s) is instigated if parameter Order= is given. Otherwise H2(s) = 1. This type of specification is explained here.

See also Filter-examples.


Specification possibilities:

    Filter  'Any Name'
      f0=
      v0=
      t0=
      z0=
      { b0=...;  b1=...;  ...;
        a0=...;  a1=...;  ...; }
      { General formula }
  
    
    Order=
    <Alignment Type>
    <Transformation Type>
    Ripple=
    Param=
    Bandwidth=
    d=
    Q=

For the standard-filter-alignment we need parameters on the right hand side. Not all. Some parameters depend on others. Further we need the filter-frequency f0=. All others are optional.

Order=

A transfer-function with a standard-alignment is only created if the parameter Order > 0. Order is the degree of the denominator-polynom of the rational transfer function, i.e. of the low-pass-version of the filter-function. See parameter Order= for details.

Alignment

The transfer function with a standard-alignment is created from a low-pass function. This means first the low-pass coefficients are calculated and then transformed into other forms, for example a high-pass.

The type of low-pass is specified by simply stating the name of the alignment. See chapter Alignment Types.

Transformation

By default a low-pass is created. The type of transformation is specified by stating the name of the transformation, see chapter Transformation Type.

Ripple=

For low-pass type = CH (Chebychev) Ripple= is the level of the amplitude deviations.

For low-pass type = LR (Linkwitz Riley) this value is the ripple of the BU-LR compromise cross-over filter (LR with Ripple=0dB, BU with Ripple=3dB), see Literature [20].

For low-pass of other types Ripple= is ignored.

Param=

For low-pass type = BT (Butterworth-Thomson), Param= is the transition parameter between BU and BE alignments, (BU with Param=0, BE with Param=1).

For low-pass of other types Param= is ignored.

d= and Q=

For low-pass type = Block and if Order = 2 then d= or Q=, respectively, control the resonance.

For low-pass of other types and orders d= and Q= are ignored.
