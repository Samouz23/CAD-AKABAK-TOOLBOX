Data Files - Spectrum - Def_MeasRadiator

Home » Data Files - Spectrum

The Def_MeasRadiator defines a radiating lumped element based on measurements. Here we have two specifications of DataFileAlias= because Def_MeasRadiator needs an impedance-file and a sound pressure-file. For Def_MeasRadiator the type of data is derived from the Import Control Settings. These settings are part of the file as exported by VACS and are documented in the help-system of VACS at Import Control Settings.

For example the definition in the Lumped Element Script is

  Def_MeasRadiator  'Tweeter'
    DataFileAlias='Imp_Tweeter'
    DataFileAlias='SPL_Tweeter'
    DataDistance=1m,1m
    DataDriving=1V

The data-file should have basic Import Control Settings in order to be able interpreting the dataset. For example the impedance data-file could look like this:



  Data_Domain=Frequency
  Data_Format=Complex
  Data_LevelType=Impedance10
    98.5719             4.91222           0.479163
   101.099              4.90695           0.47749
   103.69               4.8745            0.425568
   ...

Data_Domain=Frequency indicates a frequency abscissa, which forms the first column of numbers. Data_Format=Complex specifies that the second column is the real-part and the third column the imaginary part. Data_LevelType=Impedance10 is used to indicate that these data are forming an impedance-spectrum.




  Data_Domain=Frequency
  Data_Format=LeveldB_Phase
  Data_LevelType=SoundPressure
   100            -30.2386            -163.612
   102.556        -22.9868            -129.838
   105.177        -15.9197             -63.1628
   ...

The sound pressure file has a different number-format than the file for impedance data (not necessarily but here for demonstration purpose). Data_Format=LeveldB_Phase specifies the second column to be level-dB and the third column hosts phase-values in degree. Because of Data_LevelType=SoundPressure we know that the level is to be read as SPL-values.
