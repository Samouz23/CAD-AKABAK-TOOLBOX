Mesh-File-Tags

Home

Mesh-files are a list of planes, typically triangles, which can be linked to Elements- and Field-sections and can be used to position components such as the Diaphragm or Shell.

However, often we do not want to use all triangles of a mesh-file. For example, we may want to structure a script and assign certain planes to one Elements-section and others to a second section and so on.

This filtering can be done with so-called Tags of the mesh-file. As there are different formats there are also different types of Tags.

Number Tags

If you select an element a Tag-number will be reported. This Tag is part of the mesh-file. Its generation depends on the application, which exports the mesh-file. Simple formats, such as STL, provide no special Tags. Here the Tag is the index of the triangle.

GMSH

In GMESH, conveniently, all triangles of a CAD-item are assigned a common Tag. The index starts with 1, 2, 3,... For example, all elements of the right wall of the box have a different Tag than those of the left wall.

Collada

Collada-files, which originate from Sketchup, contain triangles. Here the Tag-number is the index of a triangle within a group starting with 1, 2, 3, ...

String Tags

The mesh-file may support strings as Tags. This is typically the name of a group in the CAD-system.

GMSH

On importing from CAD into GMESH you open the first CAD-file, assign a Physical Group to all the imported surfaces. Then hide this Physical Group in GMSH. In the next step you merge the next CAD-file into the GMSH-project. Assign the next Physical Group to all the visible surfaces (there is a window selection tool that will ignore the hidden Physical Groups for this so that you do not have to select them one by one), hide the new Physical Group, and so on ...

For meshing you just unhide all Physical Groups and perform the meshing. Many things are easier with Physical Groups as you can define individual mesh sizes or mesh-types for different Physical Groups etc. (thanks to Eric V. for this report).

Eventually you would save the mesh-file in GMSH and register it with the ABEC project. You can then use the names of the Physical Groups as Tags.

Collada

Collada-files, which originate from Sketchup, can have string-Tags. For this to work, you need to organize CAD-items into groups and then provide names to it.

SVG

Inkscape lets you assign String-Tags with the help of Object Properties/ID, either to the drawing object or to the group (SVG is for Dim=2D).

Include    Exclude

In ABEC-scripts Tags can be filtered with the help of Include and Exclude, where both follow each other in a line. Behind Include we list all Tags to be part of this line and behind Exclude we list all Tags which to ignore. All separated by blanks, tabs or comma (but semi-colon).

Typing "All" includes or excludes all triangles, respectively.

Tags can be Number-Tags or String-Tags. If a String-Tag contains blanks it should be quoted.

For Number-Tags you can also specify a range with the help of two or three dots. For example 100...115 means you want to include/exclude all mesh-elements with Tags ranging from 100 to 115. It is also possible to omit the first or last index, which then means open-end. For example ...100 means to include/exclude all mesh-elements up to Tag 100.

Example Number Tags

  Elements "Mesh1"
    Subdomain=1
    101  MeshFileAlias=M1  Include All   Exclude 10 12  100...115  16
    102  MeshFileAlias=M2  Include 1000...
    ...
  Elements "Mesh1"
    Subdomain=1
    MeshFileAlias=M
    RefNodes=N
    101  Mesh  Include All   Exclude 1, 2, 3
    102  1001  1002  1003   //Node indices
    ...
  Diaphragm  "D1"
    Subdomain=1
    Position= MeshFileAlias=M  Include=111  SwapNormal
    ...
  Field  "F1"
    ...
    MeshFileAlias=M
    101  Mesh  Include 100
    ...

Example String-Tags

  Elements "Hall-Elements"
    MeshFileAlias=M
    101  Mesh Include  "Hall"  Exclude 128 129

  Elements "Stage-Elements"
    MeshFileAlias=M
    101  Mesh Include "Stage"

  ...
  Field
    ...
    MeshFileAlias=M
    101  Mesh Include  "ObHall"  "ObStage"
    ...
