Single argument functions

    Sqr(z)           square of z
    Sqrt(z)          square root of z
    Exp(z)           exponential function
    Ln(z)            natural logarithm
    Log(x)           logarithm to base ten
    Sin(z)           sine
    Cos(z)           cosine
    Tan(z)           tangent
    Cot(z)           cotangent
    Sinh(z)          hyperbolic sine
    Cosh(z)          hyperbolic cosine
    Tanh(z)          hyperbolic tangent
    Coth(z)          hyperbolic cotangent
    ArcSin(z)        arcus sine
    ArcCos(z)        arcus cosine
    ArcTan(z)        arcus tangent
    ArcCot(z)        arcus cotangent
    ArcCosh(z)       hyperbolic arcus cosine
    ArcSinh(z)       hyperbolic arcus sine
    ArcTanh(z)       hyperbolic arcus tangent
    ArcCoth(z)       hyperbolic arcus cotangent
    Sinc(z)          sinc(z) = sin(z)/z
    Rad(z)           radian of z: Rad(z) = π/180·z (for converting angles from degrees to radians)
    Deg(z)           degree of z: Deg(z) = 180/π·z (for converting angles from radians to degrees)
    Abs(z)           absolute value
    Signum(z)        signum = 1 if z = 0 and z/|z| otherwise
    Sign(x)          sign = 0 if x = 0 and x/|x| otherwise
    Dirac(x)         delta function. Dirac = 1 if x = 0 otherwise Dirac = 0.

Multiple argument functions

    ArcTan4(x1, x2)	 arcus tangent in four quadrants.
                     ArcTan4 = ArcTan(x1/x2).
                     If there is only a single argument then
                     ArcTan4(z) = ArcTan4(Im(z)/Re(z)).

    if(z0, z1, z2)   Result = z1 if z0 <> (0,0)
                     otherwise Result = z2.
