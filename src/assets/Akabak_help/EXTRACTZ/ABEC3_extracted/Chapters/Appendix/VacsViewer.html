VACS stands for Visualising Acoustics, a software package that has been developed to simplify visualising, processing and storing acoustical data, notably of transfer-functions.

With VACS it is easy to compare measurements, simulations and calculations from different origins. Once imported, a variety of processing tools allows for transformations and calculations.



ABECs calculation of spectrum-curves makes use of the interface of VACS, which allows for receiving and displaying data. After calculation results are packed and send to VACS, which performs the rendering.

On recalculation, curves will be updated in VACS. In order that ABEC can link the right curves each observation should get its unique ID=.

By default ABEC transmits spectral data to VACS automatically. However, it is possible to select alternative Output Ways, see menu Spectra/Output Ways.


VACS can also be used to create Data-Files, which can be used with WallImpedance, Driving_Values, Pressure_Box and Def_MeasRadiator. See also at Spectrum Data-Files.

VacsViewer

VacsViewer is essentially the same application as VACS but does not allow for saving VACS-project-files. VacsViewer is free of charge and readily available from our dedicated web-site: www.vacsviewer.com
