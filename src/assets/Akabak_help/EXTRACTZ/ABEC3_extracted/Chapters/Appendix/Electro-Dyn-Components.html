Electro Dynamic Components

Example for a model for an electro-dynamic transducer with individual components and RadImp and Enclosure attached.

Ze and Zms are the frequency dependent impedances of the voice-coil and the mechanical elements Mms, Cms and Rms, respectively. BL is the force-factor or conversion factor of the electro-dynamic motor. The mechano-acoustical coupling is provided by the front- and rear-sides of the diaphragm. See chapter Lumped Element Diaphragms.


The following script is an example for the model used by Def_Driver. System S1 is modeled with the help of basic lumped elements. System S2 is for comparison. This example is LE-only, i.e. it is not coupled to a Boundary Element Analysis.


  // Common parameters of the driver
  Def_Const
    {  Reo=10;        fre=10e3;     ExpoRe=0.7;
       Leo=50e-6;     ExpoLe=0.6;
       Bl=10;
       Mms = 1.2e-3;  Rms = 1.7;    Cms = 33e-6;
       dD = 50e-3;    // 50mm
       SD = pi*sqr(dD/2);
    }

  // Definition only used for the second System 'S2' for comparison
  Def_Driver  'Drv1'
    dD={dD}
    Re={Reo}   fre={fre}    ExpoRe={ExpoRe}
    Le={Leo}   ExpoLe={ExpoLe}
    Bl={Bl}
    Mms={Mms}  Rms={Rms}  Cms={Cms}


  // S1 is a transducer, which is modeled with the help of individual elements
  System  'S1'

    // Voice-coil
    Impedance  'Ze'
      Node=1=2
      Z={ Re_f = Reo*(1.0 + f/fre)^ExpoRe;
          wLe = w*Leo;      hh = sqr(wLe/Reo);
          r = (ExpoLe*hh + 1.0)/(hh + 1.0);
          Le_f = wLe^r;
          Ze = Re_f + j*Le_f; }

    // Motor
    Gyrator 'G1'
      Node=2=0=3=4
      Bl={Bl}

    // Mechanical part.
    Impedance  'Zms'
      Node=3=5
      Z={ Zms = Rms + jw*Mms + 1/(jw*Cms) }

    // Rear side with enclosure
    Coupler  'SD_r'
      Node=4=0=8
      dD={dD}

    Enclosure  'Vb'
      Node=8
      Vb=0.3L Lb=3cm

    // Front side with radiation
    Coupler  'SD_f'
      Node=5=0=7
      dD={dD}

    // Radiation impedance
    RadImp 'RI1'
      Node=7
      dD={dD}


  // S2 models the transducer with the help of a compact component
  System 'S2'

    Driver  Def='Drv1'
      Node=1=0=7=8

    Enclosure  'E1'
      Node=8
      Vb=0.3L  Lb=3cm

    // Radiation impedance
    RadImp 'RI2'
      Node=7
      dD={dD}
