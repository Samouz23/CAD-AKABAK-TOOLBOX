Delay= or DrvDelay= allows to add time-delay to the driving-value according to

z2 = z1·exp(-jω·Delay)

assuming positive temporal time convention z(t) = z·exp(jωt)

Example

A most simple example is to investigate the response of a point source defined in section Pressure_Points at an observation point at 1m distance.

The time-impulse response of the Direct Sound Analysis of the pressure response can be obtained with the help of VACS using its Processing/Fourier Response feature.

The blue impulse is without additional delay. The approx 3ms delay stems from the traveling time of the sound of 1m distance. t = d/c with d distance between microphone and point source and c speed of sound.

The red curve features additional Delay=2ms.

The associated observation script is


  Driving_Values
    DrvType=Pressure
    Value=1.0
    101   DrvGroup=1001   Weight=1.0   Delay=2ms


  Nodes "PPoint"
    Scale=1mm
    1001     0     0    0

  Nodes "Spectrum"
    Scale=1mm
    1001     1000     0    0


  Pressure_Points
    DrvGroup=1001
    RefNodes=PPoint
    101  1001  Weight=1.0

  Control_Spectrum
    Name="Point Source"
    f1=0;  f2=20kHz;
    NumFrequencies=1024;  Abscissa=lin;


  BE_Spectrum
    PlotType=Curves
    GraphHeader="SPL"
    BodeType=LeveldB;  Range=50
    RefNodes="Spectrum"
    101   1001        ID=101
