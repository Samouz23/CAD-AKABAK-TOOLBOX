The Boundary Element and Direct Sound Analysis make extensive use of geometrical data. ABEC has two different schema to provide geometric information for planes:

  1. Nodes and Elements
  2. CAD drafts via Mesh-files

Nodes and Elements is an elegant schema in order to provide 3D-geometry manually in a manageable form. The schema always consists of two related sections:

  1. Nodes
  2. Elements or Field

Nodes

Nodes are lists of coordinates, which form points in space. Each point has a unique name in form of an integer. For example:

  Nodes   "N"
    Scale=1mm
    1001      0.0      0.0        0.0
    1002    302.5      0.0        0.0
    1003    302.5    205.0        0.0
    ...

Each line represents one point (node). The first column is the index or "name" of the node. It follows the coordinates, in the above example, Cartesian x-, y- and z-values in mm.

Elements and Field

Elements form the Boundary Elements or planes for visualization of fields. The individual planes are assumed to be flat and can have currently three or four vertices, ie triangles or quadrilaturals.

For specification, elements are listed as arrays of node-indices, which are assumed to be specified in one of the Node-lists (see above). For example:

  Elements "E1"
    RefNodes="N"
    ...
    101   1001  1002  1003  1004
    102   1011  1012  1013
    ...

or

  Field "F1"
    RefNodes="N"
    ...
    101   1001  1002  1003  1004
    102   1011  1012  1013
    ...

Each line represents one plane. The first column is the index or "name" of the plane. It follows the array of node-names as given by the referenced Nodes-section (RefNodes=).

For Boundary Elements the order of node-indices matter as explained in Normal and Volumes.



If you enter Nodes and Elements manually it is of advantage to make a sketch of the structure.

Best is to type all nodes first. In ABEC you can enable Views/Structure/Nodes, which displays all available nodes.

In a second step you specify all planes of the Elements- or Field-sections.
