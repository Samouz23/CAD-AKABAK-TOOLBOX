Planes

Planes are the major building components of the 3D-Boundary Element Method.

Planes are also used to position components in 3D, such as the Diaphragm, Shell, Duct, VibFile, Baffle and the Infinite Baffle.

Planes are also used at generating observation points, for example at section Field and at section BE_Spectrum.

There are two ways of inputting planes

  1. Nodes and Elements
  2. CAD and Mesh-Files

Nodes and Elements

See also chapter Nodes and Elements.

Here we specify a plane with the help of an ordered list of points, which form the vertices of the plane. These points are called Nodes. The order should be such that the normal points according to the right hand rule. For example the above plane should be specified by node-indices in the following order:

1001  1002  1003  1004

For BEM-Elements the normal should point into the domain as explained in chapter Normals and Volumes.


Planes are also used to give position and direction. In this case the first point of the list is the position and the other two form a triangle of any size. The normal of this triangle yields the direction of the component. See also at parameter Position=.


Before we can construct a plane, we need a list of coordinates, which are specified in sections named Nodes. Each node of a section should have a unique name, which is simply an index-number.

Finally we can assemble a plane, simply by listing the node index-numbers. For a triangle there are three such indices and for a quadrilateral there are four.

For example

  Nodes "N"
    //       x       y       z
    1001     0.0     0.0     0.0
    1002    10.0mm   0.0     0.0
    1003     0.0    10.0mm   0.0
    ...

We can use these nodes to form a boundary element in form of a triangle

  Elements "E1"
     Subdomain=1
     RefNodes=N
     //     Node   Node   Node
     101    1001   1002   1003
     ...

or to position, for example, a Diaphragm component

  Diaphragm  "D1"
     Subdomain=1
     RefNodes=N
     Position=1001  1002  1003
     ...

CAD and Mesh-Files

See also chapter Mesh-files.

Planes for BEM, positioning and for fields can be imported from 3D-CAD-applications. Best results are obtained if an intermediate meshing-tool is used. A meshing-tool can read typical CAD-files, performs meshing and eventually exports so-called mesh-files. The content and structure of these mesh-files are similar to the above Nodes & Element approach.

The CAD drawing should be as simple as possible. It should contain only faces relevant to the acoustic problem.

The meshing-tool should create a mesh as coarse as possible. Just complex enough that the boundaries are represented. Note, that ABEC will mesh further based on the imported mesh and according to the frequency criterion, see chapter Meshing. In general, ABEC can refine the mesh but cannot simplify the mesh.

The meshing-tool generates so called Tags, which are names of planes in form of simple integer-numbers. With the help of these Tags we can organize mesh-file-elements in our script. See chapter Mesh-File-Tags.

Example Boundary Elements

  Elements "Horn-Baffle"
    SubDomain=3
    MeshfileAlias=Mb
    101 Mesh include 11 13 14 17 18 20
    102  2001 2002 2003 2004 RefNodes=N

The above shows a section from Solving.txt of example \BEM\Loudspeakers\ABEC21 Sealed Mesh-Files.

Line starting with 101 creates boundary elements from a mesh-file with alias=Mb. Only planes with Tag numbers from the set [11 13 14 17 18 20] are used. The actual mesh-file is assumed to be registered with the project at "Mesh-Files".

Line starting with 102 defines a plane, which is not part of the mesh-file but specified by Nodes & Elements.

The mesh-file with alias=Mb has been derived from a STEP-file, which originally was drafted in a CAD-program. Here we used the meshing-tool GMESH.

Example Positioning

Planes are also used to provide positioning and direction for components, such as used at Diaphragm.

In the CAD-program we provide these planes as part of the drawing. These planes are typically little boxes as shown in the draft on the right hand side. Eventually one of the planes of the box will form the control-plane.

  Diaphragm  "Drv1 cone front"
    ...
    Position= MeshFileAlias=Mb Include 28  Rot=-22.5
    ...

Here the Position= parameter takes reference to a mesh-file with alias=Mb. The control-plane will be assembled from all mesh-file elements with Tag=28. The mounting point P1 is the center-point of this plane. The first triangle of this set will provide P2 and P3. In this example, we had to manually adjust axial rotation by -22.5 deg.
