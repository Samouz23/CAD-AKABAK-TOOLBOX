Modules of ABEC

Home

ABEC as an application provides the calculation-engine for the Boundary and Lumped Element Methods and also for Direct Sound analysis.

See chapter Modes of Operation for an overview.

ABEC also provides a 3D viewer for the geometry and field-observations.

However, for input it expects scripts in form of text-files and, optionally data- and mesh-files. Results of spectral analysis are not rendered by ABEC but prepared for output with the help of another application.

In order to make it all work you may need to install further applications:

  • Examples
  • Text-Editor
  • VACS
  • Mesh-File-Tools (optional)

Examples

ABEC comes with a range of examples. It is advisable to experiment with these in order to get a feeling how ABEC ticks...

For new projects it is often helpful to make a copy of the whole folder of an example and to adjust and extend the files.

Examples are part of the installation.

Text-Editor

For comfortably editing scripts, we recommend to use a powerful text-editor, as explained in chapter Text-Editors.

VACS

Our software module VACS renders results of spectral analysis as curves or contour-plots and works seamlessly together with ABEC. VACS makes it convenient to import measurement-data and to compare these to curves from the simulation.

Mesh-File-Tools

ABEC allows to import external mesh-files, which can be combined with the geometry of the scripts. See chapter Mesh-Files.
