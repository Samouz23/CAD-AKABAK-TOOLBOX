Direct Sound Analysis calculates the sound pressure ignoring any boundaries. Typically calculation time is short but results can be very approximate. However, in some cases the Direct Sound Analysis is practical, for example, in room or free-field acoustics or in designing loudspeaker cross-over-filters with the help of the MeasRadiator.

For Direct Sound Analysis you need to provide a script at the associate section in the Project tree-list. Typically, the Direct Sound Script contains only a range of Pressure_Points and Pressure_Box sections. There is no solving stage, and you can directly proceed to observations. Therefore, you need to add also Observation Files to the project, which specify the "venue".


The Direct Sound-Analysis ignores reflections and diffraction, and, hence, there is no structure to cause such reflections and diffraction effects. The Direct Sound-Analysis calculates the sum-total of the sound pressure at observation points, which is generated by a range of Pressure_Points or Pressure_Box sections.


p(r1)  =   Σi G(ri, r1)· pi


G(ri, r1) is the point-source Green-function from point at ri to observation point at r1. p(r1) is the total sound pressure at the observation point at r1. The pi of the above formula includes the weight as given at Pressure_Point-section multiplied by the value specified at the Driving_Values-section or by the value, which is delivered by the Lumped Element Network via component MeasRadiator.


The specification for the Direct-Sound-Mode is relatively simple compared to the setup for a Boundary Element model.

First you need a Direct Sound Script, which specifies the location of Pressure_Points and Pressure_Box sections, for example:


  Nodes  "PressurePoints"
  //Name    x      y       z
    1000    16.0   40.0    0.5
    1001    16.0    0.0    0.5
    1002    16.0  -40.0    0.5

  Pressure_Points  "PressurePoints"
    RefNodes="PressurePoints"
    DrvGroup=1001
    100  1000  Weight=1.0  Delay=0ms
    101  1001  Weight=1.0  Delay=5ms
    102  1002  Weight=1.0  Delay=0ms


Further you need observation-scripts. For example, for field-analysis the observation-script could look like this:


  File='Driving.txt'

  Control_Field
    f1=20Hz;  f2=200Hz; NumFrequencies=10;  Abscissa=log
    Meshing=Bifu;  EdgeLength=5m

  MeshFile_Properties
    MeshFileAlias=M
    Scale=1mm;  MinAngle=2;  MinArea=2.0m2

  Field "Stage"
    BodeType=LeveldB; StepSize=1; Range=50
    101  MeshFileAlias=M  Include all

In field-observation of the Direct Sound Mode we need to specify a range of frequencies, which is the main purpose of the Control_Field section. This observation-script example includes another file (File=Driving.txt), which specifies Driving_Values:


  Driving_Values
    DrvType=Pressure
    Value=1.0
    101  DrvGroup=1001  Weight=1.0

The spectral analysis in Direct-Sound-Mode is similar and the script could look like this, for example:


  File='Driving.txt'

  Control_Spectrum
    Name="Direct Sound"
    f1=20Hz;  f2=200Hz;
    NumFrequencies=200; Abscissa=log;

  Nodes "Nodes"
    1000    100.0     0      5.0  // Center
    1001    100.0    50.0    5.0  // Off center

  BE_Spectrum
    RefNodes="Nodes"
    PlotType=Curves
    BodeType=LeveldB; StepSize=1; Range=50
    100   1000   ID=DS010
    101   1001   ID=DS011
