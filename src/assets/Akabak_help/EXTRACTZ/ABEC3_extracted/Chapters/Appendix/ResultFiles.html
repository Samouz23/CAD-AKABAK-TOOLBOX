Result Files

Home

Result Files store the solving stage of the Boundary Element Analysis immediately after solving is completed indicated by "Solved+Saved" on the bottom-left of the desktop. Next time the project in opened, ABEC will read the Result-File and mark the state Solved. Observations can commence directly.

Featuring Result Files dramatically improves efficiency of working because we do not have to wait for the solver each morning...

Demo vs Professional Version

Result File saving is enabled only for the commercial version. After purchasing download and replace the demo- by the professional version as described in the confirmation email. Further provide the Release Code.

Technical Issues

The Result File is saved automatically when the solver signals ready. For emergency it is possible to manually trigger saving of the Result File at menu Solving/Save Result File.

The Result File is stored in a dedicated sub-folder of the current project:

  /Results

The Result File has the dedicated name

  SolverResults.abecs

The Result File can be deleted with the help of menu Options/Delete Result Files...

The Result File stores also all solving-scripts. The command in menu Options/View Scripts in Result File will show all scripts as they were at the time of solving.

Disable saving the Result File can be specified at menu Options/Preferences at page Processing.

Note, Result Files can grow large, typically tens of mega-bytes, depending on the size of the mesh and number of frequencies.

The 32bit version of ABEC will prevent loading Result Files, which yield to exceed the 2G Byte limitation. Typically this happens for Result Files stored by the 64Bit version.
