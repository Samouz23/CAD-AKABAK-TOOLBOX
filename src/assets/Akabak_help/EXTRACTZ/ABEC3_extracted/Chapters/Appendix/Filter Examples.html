1) The rational transfer function forms a second order low-pass. Its result is used in the following formula system with the help of the reserved identifier "TF". Here TF is subtracted from a pure time delay as used for special cross-over designs.

  Filter  'F1'
    f0=1kHz
    {  b0=1;
       a2=1;  a1=sqrt(2);  a0=1; }  // BU lowpass 2nd order
    {  exp(-jf/500) - TF }          // Formula-system

Here, the red markers are reserved identifiers.


Alternatively and in this case, you can specify the rational transfer function with the help of specifiers of a standard alignment. Note, that we need to include a dummy { b0=1 } here.

  Filter  'F1'
    f0=1kHz
    Order=2  BU  Lowpass           // Butterworth 2rd order
    {  b0=1; }                     // Dummy
    {  exp(-jf/500) - TF }         // Formula-system

2) Second order Butterworth low pass. The filter frequency is f0 = 1000Hz. The value of the denominator coefficient a1 is being calculated.

  Filter  'F2'
    f0=1kHz
    { b0=1;
      a2=1;  a1=sqrt(2);  a0=1; }

3) The same function as above. In this case a constant is established, with the aid of which the filter can be scaled along the abscissa. With the entered value of sn=1.5, the filter frequency (in the case of Butterworth, the -3dB-Frequency, too) has been scaled to 1500Hz.

  Filter  'F3'
    f0=1kHz
    { sn=1.5;  // Frequency scaling factor
      b0=1;
      a2=1/sn^2;  a1=sqrt(2)/sn;  a0=1; }

4) The same as above, except that the rational transfer function is the associated high-pass. Note, the denominator coefficient a2 is assigned the value of the numerator coefficient b2.

  Filter  'F4'
    f0=1kHz
    { sn=1.5;      // Frequency scaling factor
      b2=1/sn^2;
      a2=b2;  a1=sqrt(2)/sn;  a0=1; }

5) Example of an integrator H(s) = 1/s

  Filter  'F5'
    f0=1kHz
    { b0=1;  a1=1 }

6) Example of a 1ms delay element.

  Filter  'F6'
    t0=1ms

Example of a delay element corresponding to an acoustic distance of 10ft.

  Filter  'F6'
    z0=10ft

7) Example of an inverting amplifier with a gain of 3.

  Filter  'F7'
    { b0=-3 }

8) Example of the use of the additional formula-system. Simple digital IIR-lowpass-filter. f is the abscissa frequency normalized to 10kHz. { b0=1 } is the residuum of the rational transfer function which always has to be entered if you want to make use of the general formula system. 

  Filter  'F8'
    { b0=1 }
    { z = exp(jf/10e3);  z1 = 0.6;
      G = (1 - abs(z1))/(z - z1); }

9) Example of the use of the additional formula-system. Same as before but with an (analog) anti-aliasing filter expressed by the rational transfer function. TF is a runtime variable, which carries the result of the rational transfer function into the formula system.

  Filter  'F9'
    f0=5kHz
    { b0=1;  a8=1;  a7=5.125831;  a6=13.137071;  a5=21.846151;
      a4=25.688356;  a3=21.846151; a2=13.137071; a1=5.125831; a0=1; }
    { z = exp(jf/10e3);  z1 = 0.6;
      G = TF*(1 - abs(z1))/(z - z1); }

10) Example of using standard filter alignment (Chebychev with 3dB ripple in passband, highpass)

  Filter 'F10'
    f0=1kHz
    Order=6  CH  Highpass  Ripple=3.0dB

11) Example of using standard filter alignment (Linkwitz-Riley highpass) 

  Filter 'F11'
    f0=1kHz
    Order=6  LR  Highpass

12) Example of using standard filter alignment (Butterworth-Thomson alignment family. Param=0.5 creates an alignment with poles half-way between Butterworth and Bessel poles).

  Filter 'F12'
    f0=1kHz
    Order=6  BT  Highpass   Param=0.5

13) Example of using standard filter alignment (2nd order block with damping factor d=2).

  Filter 'F13'
    f0=1kHz
    Order=2     Block   Highpass   d=2.0

14) Example of using standard filter alignment (Butterworth low-pass transformed to band-pass with relative bandwidth (f2 - f1)/f0).

  Filter 'F14'
    f0=1kHz
    Order=6  BU   Bandpass   Bandwidth=1
