Final results are rendered by the Observations Stage, either as a field or as a spectrum. Spectral observations can be of the acoustic field or of parameters inside a Lumped Element network.

All observations are transfer-functions, which can be weighted by Driving Values. Either driving is imprinted or comes via a Lumped Element network.

The acoustic field is calculated with the help of the Boundary Element Method (BEM) or approximated by the Direct Sound Analysis. BEM needs a solving-stage prior observation.

During observation the calculation accesses geometry information from the BEM- and the Direct Sound module. Also Lumped Element only analysis is possible.

If BEM is used together with multiple driving-channels then the observation takes place for each such channel. Finally all results are superimposed, which yields the total response. All this, of course, is done internally.

If BEM is used the observation module accesses solutions from the BEM-solving stage.

The Lumped Element network needs to be solved as well. However, this calculation is usually quick and is done on-the-fly. If BEM is used the network will access radiation impedance values from the solving stage. The solution of the Lumped Element network are voltages, forces and pressures (potentials). From these flow and motion is deduced, such as the electrical current and mechanical velocity. Having values for the velocity we can then use results from the BEM solving stage and calculate acoustic response functions.
