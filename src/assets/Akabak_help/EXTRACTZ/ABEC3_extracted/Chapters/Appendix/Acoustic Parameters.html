Acoustic Parameters control the mapping from spatial to temporal measures. ABEC uses the speed of sound, c and its density, ρ of the medium.

For example, the density of the medium is involved in the relation between the velocity potential, ϕ and the sound pressure: p = -jω·ρ·ϕ, by using the harmonic transform-convention exp(jωt).

In another example the speed of sound is part of the point source Green-function: G =  exp(-jk·d)/(4π·d) with free-field wave-number, k = ω/c and distance, d between source and receiver.

Another example is the radiation impedance of a plane wave: Z = ρ·c

By default ABEC calculates with

c = 343.32 m/s

ρ = 1.205 kg/m3

which are values for air at Temperature = 20C, Static Pressure = 101325Pa and zero altitude.

You can change the default values in the solving script at section Control_Solver. Either you would specify values directly for rho= (ρ) and c=, or you enter Temperature=, StaticPressure= or Altitude=, from which ρ and c are calculated internally.

The used values are reported on the desktop after loading of the solving script.

Examples:

  Control_Solver
    f1=20;  f2=500;  NumFrequs=70;  Absc=log;
    ...
    rho=998kg/m3;  c=1483m/s  // Water at 20C

or

  Control_Solver
    f1=20;  f2=500;  NumFrequs=70;  Absc=log;
    ...
    Altitude=500m;  Temperature=10C
