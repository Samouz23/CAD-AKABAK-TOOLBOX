Data Files - Spectrum - Driving_Values

Section Driving_Values is part of the Observation Scripts. By it a constant driving-value is imposed on a driving-group (DrvGroup=).

If parameter DataFileAlias= is specified in section Driving_Values then the file is assumed to be a frequency-response of a transfer-function.

For example

  Driving_Values
    DrvType=Pressure
    DataFileAlias="Hp"
    Value={ sqrt(0.5) }
    101    DrvGroup=1001   Weight=+1.0
    102    DrvGroup=1002   Weight=-1.0

Assuming "Hp" to be an alias to a file, which has been registered at Add Data-File then the driving value for DrvGroup=1001 will be

v = 0.707·(+1.0)·H(jω)

and the driving value for DrvGroup=1002

v = 0.707·(-1.0)·H(jω)

with H(jω) transfer-function as given by the data-file.



  Data_Domain=Frequency
  Data_Format=Complex
     2.0000000e+01  -1.1150935e-03   1.2923543e-04
     2.0138773e+01  -1.1660599e-03   1.6439579e-04
     2.0278508e+01  -1.2303389e-03   2.1322478e-04
     ...

Data_Domain=Frequency indicates a frequency abscissa, which forms the first column of numbers. Data_Format=Complex specifies that the second column is the real-part and the third column the imaginary part.
