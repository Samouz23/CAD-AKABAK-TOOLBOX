The direction of the normal is given by the order of the vertices of a boundary element. It is specified by the Right Hand Rule as sketched in the figures. If you form with your right hand a fist with thumb up then this indicates the order in which vertices should be specified. The starting vertex is arbitrary.

Example 1


  Elements "1"
  ...
  // Index  Node1  Node2  Node3  Node4
     101    1001   1002   1003   1004  |Quadrilateral
     102    2001   2002   2003         |Triangle
  ...

In the above example plane 101 shows the entry of a quadrilateral. The direction of the normal is fully described by the order of Node1 ... Node4. Plane number 102 shows the entry of a triangle. Here the normal direction is fixed by the order of node Node1, Node2 and Node3.

Example 2

  Elements "2"
  ...
  // Index  Node1  Node2  Node3  Node4
     101    1001   1004   1003   1002  |Quadrilateral
     102    2001   2003   2002         |Triangle
  ...

If we swap the order of node-indices then the normal would point into the opposite direction, as demonstrated in example 2. For a quadrilateral swap two opposite nodes. For a triangle swap two adjacent nodes.

Example 3

  Elements "3"
  ...
     SwapNormals
  // Index  Node1  Node2  Node3  Node4
     101    1001   1002   1003   1004  |Quadrilateral
     102    2001   2002   2003         |Triangle
  ...

If you want that the interpreter of the script is swapping normals for you, you can declare SwapNormals, as demonstrated in Example 3. In this example the order of the nodes is identical to Example 1 but the result is as if entered as in Example 2.

Normal of a Triangle

If P1, P2 and P3 are the three vectors of a triangle then the normal is

N = (P2 - P1) x (P3 - P1)

eventually N needs to be normalized.
