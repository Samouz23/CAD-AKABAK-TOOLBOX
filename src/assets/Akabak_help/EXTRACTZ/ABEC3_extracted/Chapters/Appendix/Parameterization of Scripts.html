Parameterization of Scripts

Home

See also Formula (syntax), Formula (section)

Parameterization of a script means that instead of constant values there are variables. In this way dimensions, positions and so on can be controlled from a central part in the script, making it easy to modify the whole structure.

Values of these variables are assigned at sections Formula and sub-sequentially used anywhere in the scripts where normally a floating point value is expected.

An effective way to use variables across scripts is to put the Formula-section into a file on its own, and then to embed this file in other scripts (see File=).

For example

Section Formula lists all variables, which values you want to assign at sub-sequent script parameters:

  Formula
    // Cabinet
    Hc = 2*0.45         // Cabinet height
    Wc = 0.43           // Cabinet width
    Dc = 2.436          // Cabinet depth
    tc = 0.022          // Cabinet wall thickness
    ...

Variables need to be enclosed by curly brackets if used as parameters:

  Nodes   "NF"
    // Front wall
    2001    0.0              0.0            {Hc + 2*tc}
    2002    0.0             {Wc/2 + tc}     {Hc + 2*tc}
    2003    0.0             {Wc/2 + tc}      0.0
    2004    0.0              0.0             0.0
    // Rear wall
    2201   {-Dc - 2*tc}      0.0            {Hc + 2*tc}
    2202   {-Dc - 2*tc}     {Wc/2 + tc}     {Hc + 2*tc}
    ...

Variables can be used at any place, which usually expects a floating point number. In the following example the variable "dD" transports the value from the Formula-section to the Diaphragm-section.

  Diaphragm  "Cone front"
    ...
    dD={dD}                      // Diameter of cone
    ...

Once a script has been set-up, it is possible to scale, for example, the structure with the help of a few parameters only. In the following example only the interior height and position of the diaphragm has been varied.

   Formula
     // Cabinet
     Hc = 0.7         // Cabinet height
     Pd = 0.4135      // Diaphragm position center
     ...
 
   Formula
     // Cabinet
     Hc = 0.9
     Pd = 0.6135
     ...
