Coordinates

Coordinates and directions form an important part of the Boundary Element and Direct Sound methods. In ABEC coordinates are typically specified in a coordinate-list of the Nodes-sections.

The default units of coordinates are meter. You can use sub-units such as mm (for example 20.5mm). Inch are also supported, for example 1.23in (see units).

3D Cartesian Coordinates

By default any specification of a 3D-point is always regarded as Cartesian coordinates.

A 3D-point in Cartesian coordinates is a vector with components [x, y, z]T. For example, specifications typically look like:

  Nodes "N"
    //      x        y        z
    1000    0.0     -12.5mm   0.1m
    1001    0.0     -42.5mm   0.1m
    ...

The 3D-mode is specified with the help of Dim=3D.

Circular Symmetric Coordinates

In the axis-symmetric case the specification of coordinates are marking the edges of concentric rings. These rings generate the surface-area of truncated cone sections. Each edge-coordinate can be regarded as a point with coordinates [Axial Radial]T.

A typical specification could be:

  Nodes "N"
    //      Axial    Radial
    1000    1in      0.0
    1001    0        0.5in
    ...

The circular symmetric-mode is specified with the help of Dim=CircSym.
