Note

ABEC provides a powerful feature, which allows to specify the actual driving-value at observations stage, as explained in chapter Driving Groups.

If a Lumped Element script is present then, by default, ABEC assumes that the structure, as specified in the Solving Script or in the Direct Sound Script, is driven via the Lumped Element network.

On the other hand, if you specify section Driving_Values in an observation script, then this will disable the driving via the Lumped Element for this observation-script. Instead it will use values given at section Driving_Values.
