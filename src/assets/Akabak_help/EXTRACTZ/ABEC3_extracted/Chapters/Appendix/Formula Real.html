Floating point values can also be assigned with the help of a formula. In this case the formula should be enclosed by curly brackets, for example:

  Nodes   "NF"
    ...
    2201   {-Dc - 2*tc}      0.0            {Hc + 2*tc}
    2202   {-Dc - 2*tc}     {Wc/2 + tc}     {Hc + 2*tc}
    ...
  Diaphragm  "D1"
    ...
    dD={dD}                        // Diameter of cone
    dD1={0.3*dD}                   // Diameter of dust cap
    ...

In these examples coordinates and diaphragm dimensions are assigned with the help of formulae. Variables from section Formula are used here.


Formulae need to be enclosed in curly brackets { ... } and generally consist of an identifier, an equal sign and a collection of expressions, for example:

    dD1={0.3*dD}

Spaces are permitted within the individual formula. More than one formula in a line are separated by ";" for example:

    dD1={ dD=0.3;  SD=pi*sqr(dD/2);  SD1=SD/3;  dD1=2*sqrt(SD1/pi) }

The result of the last formula (in this case dD1) is assigned to the result.

Identifiers

Identifiers are to the left of the equal sign and form constants after calculation, and therefore represent a numerical value.

    x = 1.0e3;   y = 5*x^2

Any characters may be used except for point, comma, |, and the operator characters: 

    +, -, *, /, ^, (, ), {, }   etc.

An identifier’s name must not start with 'j', but can start with 'J'. Neither should the name be the same as a function name nor the constant pi.

Numbers

Numerical values are entered as floating point numbers without thousand-separation. The decimal separator is a point and negative values are preceded by a minus sign (without a space). For very large or very small numerical values, the computer has its own exponential notation. "e" is an abbreviation for times ten to the power of, for example:

    1.26e3 = 1.26·103	(Scientific Format SCI)

The largest and smallest numbers that can be entered are: 1020 or 10-20, respectively. Double precision is used internally. Example

    b = sin(0.5);   a = -110.34*exp(b)

The identifier for the constant π=3.14159... is called pi. The growth constant e=2.718... is entered via the function Exp(1). For example

    SD = pi*sqr(dD)/4;  e = exp(1)

Units and sub-units are not supported within the formula-system.

Brackets

Within formulae, round brackets ( ) can be placed or nested according to the rules of arithmetic.

Operators

There are five binary operators:

      + Addition
      - Subtraction
      * Multiplication
      / Division
      ^ Exponential

Functions

    z = Name(Argument)
    z = Name(Argument1, Argument2, Argument3)

Name is the function name (case insensitive). The argument is another expression and is written in brackets. Multiple arguments should be separated by commas. Do not use function names as identifiers. Unitary operators - such as the minus sign the name.

See also build-in standard functions.

Examples

    z = arccos(cos(x))
    z = arctan4(Im(x), Re(x))
