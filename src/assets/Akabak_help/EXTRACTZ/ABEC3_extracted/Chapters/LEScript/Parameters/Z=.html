Identifier Z={ }
Format Formula
Purpose Impedance value vs frequency
Used in Impedance

Z={ ... } is the driving-point-function of the Impedance component in form of a complex valued formula. The formula-system is written in curly brackets and can go over several lines. The identifier is Z=, for example

  Impedance  'Imp1'
    Node=100=110
    Z={ Rms=1;   Mms=1e-3
        Zms = Rms + j*w*Mms }

The result of the last formula is assigned to the impedance. The value of the result is usually complex and frequency dependent. There are two more reserved identifiers:

    f
    w

with f frequency in Hz and w = ω = 2πf.

The formula-system is calculated for each frequency. The value of the abscissa frequency is copied into f or w, respectively. You can use f and w in a mixed fashion as often as you need them in a formula or in a formula-system.

Constants that have previously been computed in the definition Def_Const can also be assigned. The values of several Impedance or other elements can thus be changed centrally.
