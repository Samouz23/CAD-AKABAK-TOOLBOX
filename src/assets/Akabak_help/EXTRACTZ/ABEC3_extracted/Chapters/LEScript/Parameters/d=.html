Identifier d=
Format Floating-point number
Purpose Damping factor of second order filter block
Used in Filter
See also Q=

d= is the damping factor of a second order filter-block in section Filter.

d= belongs to the parameter-set of standard filter alignments.

For alignment type = Block and if Order=2 then d= controls the resonance.

For alignments of other type and different orders parameter d=is ignored.

The damping factor is the inverse of the quality factor Q=1/d


For example

  System 'S1'
    Filter
      f0=1kHz
      Order=2  Block  Highpass
      d=2

  System 'S2'
    Filter
      f0=1kHz
      Order=2  Block  Highpass
      d={ sqrt(2) }

  System 'S3'
    Filter
      f0=1kHz
      Order=2  Block  Highpass
      d=0.5
