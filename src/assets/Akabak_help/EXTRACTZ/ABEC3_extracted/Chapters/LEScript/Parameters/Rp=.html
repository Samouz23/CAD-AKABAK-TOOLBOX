Identifier Rp=
Units ohm
Format Floating point number
Purpose Parallel resistance
Used in Capacitor

Rp= is a loss resistance parallel to the capacitance of the Capacitor element. Units [Rp] = Ω

If not specified then 1/Rp = 0. With most modern components Rp can be neglected.

For example

  Capacitor  'C1'
    Node=10=20
    C=1uF  Rp=1e9ohm
