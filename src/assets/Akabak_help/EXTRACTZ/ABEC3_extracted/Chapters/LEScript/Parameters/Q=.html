Identifier Q=
Format Floating-point number
Purpose Quality factor of second order filter block
Used in Filter
See also d=

Q= is the quality-factor of a second order filter-block in section Filter.

Q= belongs to the parameter-set of standard filter alignments.

For alignment type = Block and if Order=2 then Q= controls the resonance.

For alignments of other type and different orders parameter Q= is ignored.

The quality factor is the inverse of the damping factor d=1/Q


For example

  System 'S1'
    Filter
      f0=1kHz
      Order=2  Block  Highpass
      Q=0.5

  System 'S2'
    Filter
      f0=1kHz
      Order=2  Block  Highpass
      Q={ 1/sqrt(2) }

  System 'S3'
    Filter
      f0=1kHz
      Order=2  Block  Highpass
      d=2
