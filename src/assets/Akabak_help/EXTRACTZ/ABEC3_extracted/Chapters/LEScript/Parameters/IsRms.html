Identifier IsRms
Format Simple key-word
Purpose Interpret as root-mean-square value
Used in Def_Driving, Def_MeasRadiator

If IsRms is present then the specified value is interpreted as a root-mean-square value. Assuming a sine crest factor, ABEC internally converts the input value to a peak value:

Upeak = √2·Urms


For example

  Def_Driving
    Value={ dB(-15)}
    IsRms
