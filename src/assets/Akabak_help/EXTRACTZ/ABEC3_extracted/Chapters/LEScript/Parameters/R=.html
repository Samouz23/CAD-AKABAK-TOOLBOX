Home » LE-Scripts

Identifier R=
Units ohm
Format Floating point number
Purpose Resistance or gyrator-factor
Used in Resistor, Gyrator

Resistor

R= is the resistance of a Resistor component. Units are [R] = Ω.

For example

  Resistor  'R1'
    Node=1=2
    R=1.234kohm

Gyrator

R= is the inverse of the Gyrator Conductance R = 1/G.

The unit of [R] = Ω.

For a Gyrator the default value of R = 1Ω, which makes it convenient if used for creating a flow-source.

See also chapter Gyrator.
