Identifier DataDistance=A=P
Units m
Format List of two floating point numbers
Purpose Normalization of SPL in amplitude and phase
Used in Def_MeasRadiator

Because ABEC calculates the response to any point in space due to the distance, measured data of the sound pressure need to be normalized. Otherwise, we would have the effect of sound-traveling twice.

DataDistance= can be used to manipulates sound pressure-data as used in Def_MeasRadiator. If the data-set of sound pressure is already normalized, say with the tools provided in VACS, then we do not need to specify DataDistance=.

Distance Normalization

Distance normalized sound pressure data are those which amplitude is realigned to 1m distance to the point of radiation. The phase should be the phase at the point of radiation (zero distance).

In VACS you can achieve this with the help of the Scaling Dialog, which allows both amplitude and phase scaling.

Alternatively, the normalization can be done with the help of DataDistance=. For example:

  Def_MeasRadiator  'Tweeter'
    DataFileAlias='Imp_Tweeter'
    DataFileAlias='SPL_Tweeter'
    DataDistance=1m,1m
    DataDriving=3.456  IsRms

Specification

DataDistance=A=P accepts two values with units meter or inch, see chapter Units.

"A" and "P" stand for distance-values at which the measurement has been performed. "A" affects the amplitude and "P" the phase of the response.

Often A=P and it is equal to the geometric distance to the acoustic center of the device. The acoustic center is the apparent radiation center of the far-field response, see [18]. However, in practice it is sometimes useful to be able to adjust the distance-values for level and phase separately.
