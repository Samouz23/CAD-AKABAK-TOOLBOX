DrvGroup=

Home » LE-Scripts

Identifier DrvGroup=A=B
Format Integer numbers
Purpose Reference to DrvGroup= of the solving script of the Boundary Element Part
Used in Driver, Speaker, Enclosure, RadImp
See also Driving Groups

DrvGroup= expects one or two integer values. Component Driver has two numbers, all other components expect only a single value. These values establish links to the solving and direct sound scripts as explained in chapter Driving Groups.

In LE-Scripts DrvGroup= makes sure that a component is supplied with diaphragm dimensions in order to calculate the mechano-acoustic transformations. Further, the LE-component is supplied with the radiation impedance at it cross-section area, which is linked to the boundary element part. Conversely, the Boundary Element part is supplied with the volume velocity in order to make calculations at the observation stage, see technical details in paper [9].

Driver

Because the Driver has two diaphragm sides it needs two links. In this case DrvGroup= has two numbers, for example:

  Driver  'Drv1'  Def='SP38'
    Node=2=0=10=20
    DrvGroup=1001,1002

In this example the first number of DrvGroup=1001=1002 links to a Diaphragm-section with DrvGroup=1001, and the second to another Diaphragm-section with DrvGroup=1002.

Note, that via DrvGroup= a Driver can have different membrane area for the front and the rear.

Note, that for a Driver, where only one side is modeled by the Boundary Element Method and the other by the Lumped Element Method the diaphragm area for the LE-part is identical to the other side (unless specified differently).
