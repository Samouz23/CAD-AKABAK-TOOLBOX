Identifier Value=
Units V
Format Floating point number
Purpose Driving voltage
Used in Def_Driving

Value= is the driving parameter. There is no unit. Value= is a potential. For an electrical source it means a voltage. For a mechanical network either force or mobility-velocity, respectively. For an acoustical network it means pressure.

By default Value= is a peak-value. Otherwise specify the keyword IsRms.


For example

  Def_Driving
    Value={ dB(-15) }
    IsRms

or

  Def_Driving
    Value={ dB(-15 + 3) }

or

  Def_Driving
    Value=0.251
