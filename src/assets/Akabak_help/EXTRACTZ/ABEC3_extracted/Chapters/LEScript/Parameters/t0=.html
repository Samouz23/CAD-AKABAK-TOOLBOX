Identifier t0=
Units s
Format Floating point number
Purpose Constant time delay
Used in Filter
See also z0=

t0= is a constant time-delay of the transfer function of the Filter.

Example

  System 'S1'
    Filter 'F1'
      t0=1ms

The associated observation script to investigate the transfer-function is

  Control_Spectrum
    Name="LE Filter"
    ID=Filter
    f1=100;  f2=10k;  NumFrequencies=200; Abscissa=log;

  LE_Spectrum "Voltage"
    GraphHeader="Voltage"
    AnalysisType=Voltage
    System="S1"
    ID=010

After issuing menu Spectrum/Start Calculation the curve will be rendered in VACS.

   

The left graph pictures the real part of the frequency response. The right graph is the associated time response obtained with the help of the Fourier transformation.
