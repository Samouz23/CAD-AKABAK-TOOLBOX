Identifier Rs=
Units ohm
Format Floating point number
Purpose Series resistance
Used in Capacitor, Coil

Rs= is a loss resistance in series with the capacitance of the Capacitor element or with the inductance of the Coil element. Units [Rs] = Ω

By default Rs = 0.

For example

  Capacitor  'C1'
    Node=10=20
    C=1uF  Ls=1uH  Rs=0.5ohm
