Transformation Types

Identifier [Allpass, Bandpass, Highpass]
Format Specifiers
Purpose Filter function transformation
Used in Filter

Transform Types belong to the parameter-set of standard filter alignments.

Lowpass and Highpass

Lowpass is the default. The lowpass transmits only low frequencies. For the Filter-element the lowpass is the generating function, which eventually can be transformed into a high-, band- or allpass.

Highpass transforms the lowpass into a highpass, which transmits only the upper frequency band.

In the following examples a Chebychev (CH) alignment with Ripple=3dB of Order=6 is used.

  System 'S1'
    Filter 'F1'
      f0=1kHz
      Order=6   CH  Highpass  Ripple=3.0dB

Bandpass

Bandpass transforms the lowpass into a bandpass, which transmits only a certain frequency band. This frequency band is symmetric about the filter-frequency f0= measured on a logarithmic frequency-axis. Note, that the bandpass-transformation doubles the order of the transfer-function in order to be able to satisfy specifications for the high- and low-pass sides.

For the bandpass transform a supplementary parameter becomes necessary, which is Bandwidth=.

  System 'S1'
    Filter 'F1'
      f0=1kHz
      Order=6   CH  Bandpass  Bandwidth=1   Ripple=3.0dB

Allpass

An allpass should have a constant amplitude but varying phase response. Such a filter typically is used to manipulate the delay of the signal. For example

  System 'S1'
    Filter 'F1'
      f0=1kHz
      Order=6   CH  Allpass  Ripple=3.0dB
