Identifier f0=
Units Hz
Format Floating point number
Purpose Filter frequency.
Used in Filter

Filter Frequency

Each filter-block has a so-called Filter-Frequency, f0, which is the normalization frequency of the transfer-function. The calculation of the polynomials is carried out with following substitution:

s = j·(f/f0)

In filter-theory common practice is to design a normalized transfer-function first, i.e. centered at 1. In a second step the frequency response is shifted to the designated frequency with the help of f0.

In the script f0 is entered in Hz or kHz, for example

    Filter  'F1'
      f0=1.2kHz
      v0=0.3
      { b3=1;
        a3=1;  a2=2;  a1=2;  a0=1; }

By default f0 = 1Hz.
