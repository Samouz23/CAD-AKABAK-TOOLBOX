Identifier Node=s=t=u=v=...
Format List of integer numbers
Purpose Node numbers for wiring components
Used in All network-components

Node Numbers

Node number entries in the lumped-element-networks have the form:

    Node=s=t=u=v=w=x

with s to x are the connection poles of the network element.

The number of connection poles depends on the type of the element. If the last pole is not entered, it is assumed to be zero.

You can enter any number in the range of 0... 32000. The node numbers need not to be ordered.

 
 

The node-number of smallest index is reserved for the network driving point.

Node number zero is the ground.

The specified sequence of node numbers determines the polarity of the potential difference between the nodes, and therefore the direction of the current arrow. If Us, Ut, Uv, Uu, Uw and Ux are the potentials at poles s, t, u, v, w and x, the potential differences across the poles of the element are then: Ust = Us - Ut, Uuv = Uu - Uv, Uwx = Uw - Ux etc.

The flow-arrow points in the direction of the alphabetic sequence of s, t, u, v, w and x. If the element is a two-pole the flow points from the first to the second node. If the element has more then two poles the simulated flow-direction points always into the element. The polarity results from the comparison with the potentials determined by the node numbers.

Example

For example: An electro-acoustic transducer with two voice-coils has six poles. Poles s and t are the terminals of the first voice-coil and poles u and v are those of the second voice-coil. Pole w represents the front-side of the diaphragm and pole x the rear of the diaphragm. Pole s is at node 1, and thus is the input of the network. The voltage U12 across the first voice-coil is the difference of the potentials U1 and U2. U20 = U2 - U0, where U0 = 0 is ground. The current-arrow of I1 points pole from node 1 to node 2. The current arrow of I2 points from from node 2 to ground. At the acoustic side, the potential is the sound pressure, p. The potential-difference is p1020 = p10 - p20. The flow-arrow of the volume-velocity V3 points from pole 10 to pole 20. Pole 10 represents the front side of the diaphragm and pole 20 the rear. The parameter of this network element is thus: Node=1=2=2=0=10=20

If the sequence of the node numbers is exchanged, for example: Node=2=1=2=0=10=20, then the voltage at poles of the first voice-coil would be U21 = U2 - U1= -U12. The polarity of the first voice-coil is thus reversed.
