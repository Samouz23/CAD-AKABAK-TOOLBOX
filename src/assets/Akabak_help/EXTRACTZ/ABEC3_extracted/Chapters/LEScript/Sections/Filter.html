Purpose Transfer function
Type Filter
Used in Definitions, System

Filter provides a transfer function, which parameters are defined in the frequency domain. These parameters can be polynomial coefficients, values of a standard alignment or of an arbitrary function.

The Filter element is not a network element, nor is it positioned by entering a node. Filter elements are switched in-between the global source and the driving point of the network, see chapter Network.

Filter elements can only be cascaded. The total transfer function is

H(s) = H1(s)·H2(s)·H3(s)·...

There can be an additional Filter-bank in front of all Systems.

The total transfer function can consist of four parts:

  1. Rational transfer function with arbitrary coefficients ai and bi specified.
  2. Rational transfer function with standard alignment specified, such as a Butterworth and Bessel function.
  3. Pure time delay with parameters t0= and z0=.
  4. General formula system (see below)

All these ways of specification can be mixed, see examples.

General formula-system

As mentioned above there is an optional and special kind of specification. It is possible to enter a complex function in form of a Formula System. The additional functions are enclosed in individual curly brackets, which follow the rational function(s).

If the additional function system is present it will form the transfer function of the Filter. The rational function system(s) are still active and, in fact, needs to be specified even if it is not used. The result of the rational function will be mapped to the runtime variable "TF" of the general function system. If the rational function system is not used then simply specify { b0=1 }.

The general function system has three reserved identifiers:

f abscissa frequency [f] = Hz
w 2πf [w] = s-1
wn w/(2πf0)
TF result of the transfer functions

See examples.
