Def_Driving is the potential source of the Lumped Element network. Typically, the voltage of an electrical source. But it could also mean force or mobility-velocity of a mechanical network or pressure of an acoustic network.

The driving value is the peak-value of the harmonic sinoidal, see at Value=.

The frequencies are specified at Control_Spectrum.

As pointed out in chapter Systems there is only a single driving source globally. Each network in a System is wired in parallel to the source, hence all networks are decoupled.

Each network is driven by the same driving value. However, it is possible to manipulate the driving with the help of filters. More on this topic see at chapter Systems.


For example (see example "Speaker Cabinet SP38")

  Def_Driver 'SP38'
    Re=5.82ohm
    Le=2.9mH  fre=1.1kHz  ExpoRe=0.824  ExpoLe=0.756
    Mms=70g Cms=81e-6m/N  Rms=1Ns/m  Bl=21N/A

  // Driving value of LE network (here using formula to convert dB to voltage)

  Def_Driving "Driving"
    Value={ dB(-25+20) } // -15dBV + 20dB
    IsRms

  // Lumped element network

  System 'S1'
    // Generator resistance of wires etc
    Resistor 'Rg' R=0.1ohm
      Node=1=2
    ...
