Def_Const

Home » LE-Scripts

Purpose Global formula-system
Used in Definition part
See also Formula

Def_Const lets you enter constants or entire formula-systems, which can be referenced in formulae within the subsequent script. Alternatively to Def_Const you can type Formula.

Def_Const or Formula allows you to parameterize the script versus, for example, temperature, filter coefficients, etc.

The syntax of the formulae is described in chapter Formula.

The keyword Def_Const is followed by an opening curly bracket. The formulae are separated by semicolons. The brace needs to be closed eventually.

Within Def_Const there is no conversion of units. For example, you cannot enter 1 mm. Best is to use SI-units. 1 mm may be entered as "1e-3". For example see at script of Electro Dyn Components.

There can be as many Formula sections as needed. Eventually all these sections will lumped to one big formula inside the program. For example you may want to specify part of the formula system in a separate file, which you included with the help of File=.

Note on Filter-Coefficients

The coefficients of the Filter-element are also evaluated with the aid of the formula-parser. The special thing here is that inside the formula the names of the coefficients are reserved identifiers (b0=, b1=, ... a0=, a1=,....). Hence, these coefficients cannot be assigned in Def_Const directly. If you want to use Def_Const in order to assign filter-coefficients globally you would need a construction similar to following example:

  Def_Const
    { a0=1.0;  a1=1.0;  a2=1.0;  }

  ...
  Filter  "F1"
    f0=1kHz
    { b0=1.0;  a0=a0;  a1=a1;  a2=a2;  }
