Def_OpAmp is the definition part of the network-component OpAmp. The definition helps specifying parameters for circuits with many Operational Amplifiers. Parameters, which are declared in section Def_OpAmp will function as default settings and can be over-written sub-sequentially.

See chapter OpAmp for detailed description of the parameters.

For example:

  Def_OpAmp  'Op1'
    v0=1e5  Rg=100ohm  Rin=100kohm  ft=3MHz

  System  'S1'
    ...
    OpAmp  'Op11'  Def='Op1'  Node=100=101=101
      ...
    OpAmp  'Op12'  Def='Op1'  Node=200=201=201
      ...
