The Enclosure-component can be a very simple acoustic compliance or a more complex rectangular enclosure with standing waves. It is also possible to specify a vent in order to create a Helmholtz-Resonator.

Sealed Enclosure

Vented Enclosure

In the script the Enclosure is always specified as a two-pole, where one pole is always grounded. Depending on the complexity of the Enclosure it becomes expanded to a multi-pole internally.

Sealed Enclosure

An enclosure without radiating vents is a Sealed Enclosure. This mode is the default and automatically available if there are no specifications for the vent.

Lumped Element Model

In the most simple case there is specified only a volume Vb=. For example

  Enclosure 'E1'
    Node=20
    Vb=100L

The associated lumped element network features the acoustic compliance Cab, mass Mab and the resistances Rab1 and Rab2.

Cab = Vb/(ρ·c2)

Rab2 = ρ·c/(η·Vb)

Mab = 1/3·ρ·Vb/Sb2

Rab1 = 1/3·η·ρ·c·Vb/Sb2

See chapter Ca= and Ra= for derivation. Rab1 abd Rab2 are obtained by using a complex wave-number k = k - jη with loss-factor eta= and effective cross-section of cabinet Sb=.

Wave Model

If you additionally specify an enclosure depth, Lb=, then Akabak models the cavity with the help of a closed duct. In this model it features the same acoustic compliance at low frequencies but includes standing waves between the driving wall and the rear wall at higher frequencies. This mode of operation is similar to the Duct-component with hard wall termination. For discussion of the various models see notes at Ca=. For example

  Enclosure 'E1'
    Node=20
    Vb=100L
    Lb=300mm

For example, in general and at higher frequencies there will be standing waves inside the enclosure. Enclosure with Lb= will model those between the speaker and the rear wall (first picture). Modes in the other directions are ignored.

Vented Enclosure

The vent forms an acoustic mass, which resonates with the acoustic compliance of the enclosure volume at the so-called Helmholtz Frequency, fb. The purpose of this construction is to amplify the low end of the transmission range by resonance-effects of low damping.

The Enclosure component of ABEC supports the model of the most common construction. More complicated devices, such as multiple coupled enclosures need to be modeled with the help of multiple Duct and Enclosure components or BEM.

In ABEC the enclosure-vent is a combination of duct and radiation-impedance. The duct gets implemented if parameter Len= is specified, which is the length of the vent. Hence, the Lumped Element Model of the vent takes into account standing waves. The cross-section shape is mostly ignored. Only the fundamental mode is considered. The perimeter/cross-section-area ratio determines the amount of viscosity. If Len=0 then the vent is a simple hole, and the vent is represented only by the radiation impedance of its cross-section.

The radiation-impedance is calculated with the help of the Boundary Element Method. Internally a RadImp component is added automatically. Hence, with respect to the radiation impedance, the exact cross-section shape is taken into account, which typically yield results of high precision. Also, If the Enclosure component is coupled to the Boundary Element part no cross-section parameters (dD=, SD=, etc) should be specified. The cross-section area for the duct is assigned automatically via parameter DrvGroup=.

Example

See ABEC Examples "Speaker Cabinet SP38 BEM+LEM".


BE-Script LE-Script 
  Elements "Vent-Radiator"
    SubDomain=1
    RefNodes="NF"
    101   2012  2011  2014  2013

  Driving
    RefElements="Vent-Radiator"
    DrvGroup=1002
 
  Enclosure 'E1'
    Node=20
    DrvGroup=1002
    Vb=116.9L
    etaB=0.05
    Lb=424mm
    Len=160mm
    etaD=0.2

The vented enclosure consists of two parts. The first part is defined in the BE-Script. Here we specify the geometry and mark the driving by assigning a DrvGroup= parameter. Note, we could have use here also the Diaphragm section for convenience.

In the LE-script we specify lumped parameters of the enclosure and of the vent, such as the volume, Vb= and the vent-length Len=. DrvGroup= should point to the associated DrvGroup= in the BE-Script. The DrvGroup= schema enables the exchange of radiation-impedance, radiation-area and velocity between the BE and LE parts.

This example displays the external field, which is calculated with the help of the Boundary Element Method. The BEM also calculates the radiation impedance at the diaphragm and the vent and the mutual radiation-impedances. The interior acoustics is calculated with the help of Lumped Elements.

Enclosure Configurations

(1) Basic lumped elements + duct
(2) Deep enclosure: 2 ducts parallel
(3) Long enclosure: 2 ducts in series

The vented enclosure comes in three flavors. Which configuration is used is controlled solely by parameter Lb= and the presence of keyword Long.

(1) The Basic Lumped Element model is selected if there is no depth Lb= of the enclosure specified. In this basic model the cabinet exhibits no standing waves. Only standing waves in the vent are taken into account. The cabinet acts as a simple acoustic compliance Cab. The values of the components are calculated with the same formulae as given at the sealed enclosure above.

  Enclosure 'E1'
    Node=20
    ...
    Len=160mm  // Length of vent

(2) If we specify the depth of the enclosure, Lb=, then the model for the vented enclosure consists of two ducts wired in parallel. The first duct stands for the cabinet. It is terminated, so we have zero velocity at its rear wall. In this configuration standing waves for the cabinet and for the vent are taken into account. This configuration is called Deep because we have a somewhat deep enclosure so that we can assume the same pressure at the terminals of the Enclosure-component and the vent - at least approximately.

  Enclosure 'E1'
    Node=20
    ...
    Lb=424mm   // Depth of enclosure
    Len=160mm  // Length of vent

(3) This configuration is called Long. It is similar to (2) but here we wire the ducts in series. The sound-wave passes first through the length of the cabinet and then through the vent. Hence, this configuration is for somewhat elongated enclosures where the vent is opposite to the point of driving. In order to enable this configuration you need to specify Lb= and the key word Long.

  Enclosure 'E1'
    Node=20
    ...
    Lb=424mm   // Depth of enclosure
    Long       // Its a long-configuration
    Len=160mm  // Length of vent
