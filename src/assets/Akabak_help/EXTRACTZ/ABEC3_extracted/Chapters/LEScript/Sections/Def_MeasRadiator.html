Def_MeasRadiator

Home » LE-Scripts

Purpose Radiator using measured data
Domain Any domain and acoustical
Used in Definition part
See also MeasRadiator 

  Def_MeasRadiator  "Any name"
    DataFileAlias=         // For impedance
    DataFileAlias=         // For sound pressure
    DataDistance=
    DataDriving=
    TransferFactor=
    ConstResistance=
    IsRms

The network-component MeasRadiator and its definition Def_MeasRadiator are used to create an element, which parameters are data-files. These data-files are the measured sound-pressure and the electrical impedance spectra.

The MeasRadiator is, for example, practical for designing cross-over filters for loudspeakers in Direct Sound Mode. As there is no modeling involved, the response of MeasRadiator performs like a snapshot of the device under test and can yield very precise results.

The MeasRadiator is linked to a section Pressure_Points or Pressure_Box of the Boundary Element or Direct Sound scripts. ...

The Def_MeasRadiator provides data for network-components MeasRadiator. Multiple MeasRadiator components can share a definition. The network-component relates to the Definition with the help of its parameter Def=.

For example

  Def_MeasRadiator  'Tweeter'
    DataFileAlias='Imp'
    DataFileAlias='SPL'
    DataDistance=1m,1m    DataDriving=1V   IsRms
    ...
  System 'S1'
    ...
    Capacitor 'C5'  Node=40=50  C=2.2uF
    Resistor  'R3'  Node=40=50  R=15ohm

    MeasRadiator  'Tweeter'
      Def='Tweeter'
      Node=50=0
      DrvGroup=1001

The Def_MeasRadiator has two specifications of DataFileAlias= because we need an impedance-file and a sound pressure-file. The distinction is made by Import Control Settings, which are assumed to be part of the file. VACS formats these files properly on export. Import Control Settings are documented in the help-system of VACS at Import Control Settings. Further examples see at chapter Add Data-File.
