Lumped Element Scripts are used at observation-stage as explained at Lumped Element Analysis.

Before a LE-Script can be used it should be registered with the project, see Add LE-Script.

The script-syntax is explained in chapter Syntax.

The script for Lumped Element Analysis has two parts:

  • Definitions
  • Systems

The Definition part lists sections of specification, which network components of the second part refer to. For example you can specify Def_Driver and use this set of parameters at multiple places in the network-systems.

The System part hosts any number of independent networks. These network are wired in parallel at the smallest node-number and are fed by an ideal voltage-source, which driving value is specified at section Def_Driving.

Additionally any number of Filter components can be placed between the common voltage-source and the individual network (System).

Coupling to the Boundary Element part is established with the help of parameter DrvGroup=, which exists on both sides, i.e. at the BE and at the LE part. DrvGroup= is used at network-components in order to exchange diaphragm-dimensions, radiation-impedance and driving-values with BE-scripts.


Example


  Def_Driving
    Value=1V    IsRms

  Def_Driver  'Drv1'
    dD=44mm       // Diaphragm diameter
    Mms=0.5g    Cms=10e-6m/N    Rms=4Ns/m
    Bl=5Tm     Re=6.7ohm   fre=50kHz       ExpoRe=1    Le=0.1mH    ExpoLe=0.618

  System 'S1'
    Driver
      Node=1=0=10=20   Def='Drv1'
    Enclosure  'Rear enclosure'
      Node=20      Vb=120cm3    Qb/fo=0.1
    Enclosure 'Compression chamber'
      Node=10    Vb={ dD=44e-3; H=0.5e-3; SD=pi*sqr(dD/2); Vb=SD*H }
    Waveguide  'Phase plug'
      Node=10=300    STh=3cm2  dMo=1in  Len=22mm  Conical
    Waveguide  'Horn-stub'
      Node=300=400   dTh=1in  dMo=2in  Len=76.5mm  Conical
    RadImp 'Throat'
      Node=400  DrvGroup=1001

Compatibility with Akabak 2.1

The LE-part inherits from Akabak v2.1 and is intentionally designed to be as compatible as possible to the workings and input-scripts of the legacy system. Because of this, the syntax in the LE-scripts slightly differs from the syntax in the ABEC input-scripts. See at chapter Syntax.

It is planned that ABEC + LE will eventually be hosted by an integrated simulation framework, which will form a new Akabak. This framework will provide also tools such as the filter analysis and synthesis and other tools as in version 2.1. The current LE analysis-extension of ABEC receives input via a script, i.e. there are no editing-dialogs and not design-tools. However, because of good compatibility you may use those of Akabak 2.1, which is available for free at http://www.randteam.de.

The radiation is solely provided by the Boundary Element analyser and is coupled with the help of the LE-element RadImp. This element provides a radiation-impedance at certain network nodes. The parameter DrvGroup= forms the link-handle of the two analysis schemas.

The element Radiator of Akabak 2.1 became obsolete and needs to be replaced by the new element RadImp. Diaphragm dimensions are specified on the BE-side if involved in coupling.

Because the LE analyser is void of radiation also Def_Reflector became obsolete. In the new system all acoustic effects such as diffraction, reflection and radiation are handled by the BE-system. However, the LE-analyser still handles acoustics, but only if modeled as lumped elements or with the help of one-dimensional waveguides (Waveguide or Duct element).
