The script for Lumped Element Analysis has two parts:

  • Definitions
  • Systems

The Definition part is like a little database of component specifications. Network components can take reference to a Definition.

The Definition is also the place where global items can be specified such as the global Filter-bank and the global source Def_Driving.

Example, see Direct Sound with MeasRadiators and Boundary Element with Def_Driver.
