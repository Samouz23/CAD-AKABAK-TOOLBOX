Control_Solver is a special section for controlling the Boundary Element solver. Preferably it is placed in the main solving-file. Specifications in Control_Solver are global for the solving stage. For example, the main solving-script could look like this: 

  File="Solving-Throat-Bottom-Elements.txt"
  ...
  Control_Solver
    f1=200Hz;  f2=5kHz;  NumFrequencies=10;  Abscissa=log
    MeshFrequency=5kHz
    Meshing=Delaunay
    Sym=x
    Dim=3D

Meshing

Meshing is the means by which the underlying Integral Equation is solved. Most important is the specification of the size of the finite elements, which can be specified directly with the help of EdgeLength= or indirectly with MeshFrequency=. The parameter Meshing= controls the type of mesh-generator used.

Meshing parameters of Control_Solver form default values and can be over-written in sections Subdomain_Properties, Elements, Diaphragm and Shell.

Frequency Abscissa

The acoustic field is solved for a range of frequencies, which needs to be specified by parameters: f1=, f2=, NumFrequencies=, Abscissa= or alternatively by a list of frequencies: Frequencies=.

See also discussion in chapter Interpolation.

Dimension and Symmetry

ABEC performs by default the Boundary Element Method in Dim=3D. However, certain special cases are also supported.

If the structure exhibits symmetry then calculation can be quicken by specifying the coordinate of symmetry, see parameters Sym=.

Non-Uniqueness Compensation (NUC)

Optional

The Non-Uniqueness Problem is tackled by a special treatment in order to avoid arte-facts in the exterior domain at high frequencies. The parameter NUC= can be used to control this application. If NUC= is not specified then the treatment is applied by default as set at the Preferences.

Coupling to Lumped Element Network

Optional

The parameter ImpedanceNumFrequencies= can be useful to improve spectral response curves for coupled Boundary and Lumped Element Methods.

Physical Parameters

Optional

rho=, c=, Altitude=, StaticPressure=, Temperature= allow to specify basic acoustical parameters.
