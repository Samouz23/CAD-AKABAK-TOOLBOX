This section controls the observation of acoustic-fields such as the sound pressure field. The display is in form of a field-plot, for example contours, which are colored-steps of identical pressure.

Field-plots are calculated for a range of frequencies, which need to be specified in the script but can be controlled with the help of the frequency-list on desktop-page Ob-Fields.

In Boundary Element Mode the frequency-list is generated by specifications given at section Control_Solver of the solving script. In Direct Sound Mode you need to add a Control_Field-section to the observation script in order to have a specification of frequencies.

After calculation and for display select a frequency and issue menu Fields/Show Field. Operation and options of Show Field are given in chapter Ob-Fields.

The field-plot is based on a distribution of spatial points. These points are created within field-planes. These planes need to be specified by a List of Field-Planes or by a List of Field Planes by Mesh-File. The density and distribution of points can be controlled. The way of specification is similar to the one used to specify the Boundary Element mesh. See also chapter Meshing. At each vertex of the mesh-triangles there is a calculation point. The mesh itself is necessary for creating the graphic presentation.

Domains

In many cases it is convenient to place an observation plane right through the structure to be observed. This is fine, because ABEC will sort out the various sub-domains for each point automatically.

To place an observation plane beyond the domain can be helpful in order check the accuracy of the calculations. The Helmholtz Integral should yield zero values outside a domain. Any leakage is either a sign of miss-aligned normals or too low mesh density, see also chapter Meshing.

If a triangle of the underlying mesh serves two sub-domains then this triangle might be rendered transparent. Expect also artefacts if points of the contour-grid are directly on the boundary or on an interface.
