Purpose Radiation condition
Used in BE-Script 
  Infinite_Baffle  "Any Name"
    Subdomain=
    Position=
    RefNodes=
    MeshFileAlias=
    Scale=
    Shift=
    Rotate=

Section Infinite_Baffle yields a special Radiation Condition, where we install a reflecting wall of infinite extend in the exterior. In ABEC you can specify even two Infinite Baffles, one for the front and one for the rear, and each can be displaced. The IB is related to a particular Subdomain= with ElType=Exterior.

The IB is a versatile object often applied in analytical acoustics and at measurements. This is so because, first, the special boundary condition of zero normal-velocity at the IB yields often more simple and elegant analytical solutions. Second, the IB hides away the rear of the radiator, which often is not of interest. See also chapter Infinite Baffle in General.


The normal of the Infinite Baffle matters, it should point into the domain, i.e. into the halve space where the radiation is, see chapter Normals and Volumes.

Position and direction is specified with the help of parameter Position=.

The 3D-viewer of ABEC displays the IB with the help of a large lucent plane. If you enable Views/Structure/Normals then you can see the normals of the IB at the corners of this large plane.

Single Infinite Baffle in 3D

  Infinite_Baffle
    Subdomain=1
    Position=x

In this example the IB is a plane of which one point is the origin and the normal of the plane is parallel to the x-axis. For the BEM the normal should always point into the domain.

Double Infinite Baffle in 3D

It is also possible to declare two Infinite Baffles, for example, if you want to investigate front and rear radiation of a speaker in a baffle. Such a specification could look like this:

  Subdomain_Properties "Front"
    Subdomain=1
    ElType=Exterior
    ...
  Subdomain_Properties "Rear"
    Subdomain=2
    ElType=Exterior
    ...
  Infinite_Baffle  "IB Front"
    Subdomain=1
    Position=x

  Infinite_Baffle  "IB Rear"
    Subdomain=2
    Position=-x  offset=-20mm

In this example the second baffle is displaced by Offset=-20mm in order to take into account the thickness of the baffle.

Infinite Baffle - Circular Symmetric

If we exploit circular symmetry then a specification for a forward Infinite Baffle is, for example

  Subdomain_Properties
    Subdomain=1
    ElType=Exterior
    ...
  Infinite_Baffle 
    Subdomain=1
    Position=Pos

"Pos" means "positive" and yields the normal of the Infinite Baffle plane to point to positive direction.

Arbitrary Positioning

If the Infinite Baffle needs to be positioned skewed then its direction can be specified with the help of three nodes as explained at parameter Position=.

  Nodes "N"
    1001  0   0    0
    1002  1   0    0.7
    1003  0   1    0.7

  Subdomain_Properties
    Subdomain=1
    ElType=Exterior
    ...
  Infinite_Baffle 
    Subdomain=1
    Position=1001,1002,1003  RefNodes=N

Alternatively, you can also use "Position, Theta, Phi" notation in order to position the Infinite Baffle, for example

  Nodes "N"
    1001  0   0    0
    1002  1   0    0.7
    1003  0   1    0.7

  Subdomain_Properties
    Subdomain=1
    ElType=Exterior
    ...
  Infinite_Baffle 
    Subdomain=1
    Position=1001 theta=-45  phi=45  RefNodes=N

Using Mesh-File

The direction of the Infinite Baffle can also be deduced from a mesh-file, as explained at parameter Position=, for example:

  Subdomain_Properties
    Subdomain=1
    ElType=Exterior
    ...
  Infinite_Baffle 
    Subdomain=1
    Position= MeshFileAlias=M  Include 10
