Driving_Values

Home » Scripts

Purpose Actual driving values for observation.
Used in Observation scripts 
  Driving_Values "Any name"
    DrvType=
    DrvDelay=
    Value=
    DataFileAlias=
    List of driving values

The Driving_Value-section enables fixed or static driving. It assigns physical values to specified driving-groups of the boundary element script or direct sound script, as explained in chapter Driving Groups.

If there is a section Driving_Values in an observation script then the Lumped Element script is ignored. This applies for an individual script. For example you can use Driving_Values in scripts for Field-analysis, and for spectral-analysis you may enable coupling to the LE-network.

Fixed Driving

This mode enables if there is a section Driving_Values in the observation script. Fixed driving means that the driven boundary element is enforced to have the specified motion regardless the sound-pressure it creates in return. Obviously this is an ideal condition but often useful for principal investigations or if the only thing you want to do is to observe the radiation impedance.

For static driving the Driving_Value-section is mandatory for each observation-script, otherwise all driving values would be zero or supplied by the Lumped Element script.

The driving-value can be specified as a single value at parameter Value=, which can be weighted by Weight= in the List of Driving Values. Further a time-delay can be specified at DrvDelay=.

Additionally, a transfer-function can be specified with the help of DataFileAlias=. The total driving value is

v = Value·Weight·H(jω)·exp(-jω·(DrvDelay + Delay))

H(jω) is the transfer-function given by a data-file as explained in Data Files - Spectrum.

Coupled

Coupled driving means that the sound pressure field affects the motion of the driven boundary element. This case is more natural, because any physical driving system has some kind of (electro-) mechanical feedback, for example a loudspeaker. Coupled driving is possible only for driven boundary elements, see at sections Driving and Diaphragm.

Coupling is established with the help of a Lumped Element Network. An observation script, which couples to a LE-Script, should be void of Driving_Value-sections. Further, the LE-Script needs to be registered with the project, see Add LE-Script.

See chapter Driving Groups for more details of the workings of coupling.
