LE_Spectrum

Home » Spectrum Observation Script

Purpose Spectrum of various lumped element parameter.
Used in Spectral observation scripts 
  LE_Spectrum  "Any Name"
    AnalysisType=
    DrvGroups=
    BodeType=
    Range=
    GraphHeader=
    ID=
    System=
    List of LE Spectrum Items

Section LE_Spectrum calculates power, impedance, flow and potentials of the lumped element network and its components.

AnalysisType= specifies, which parameter you want to observe.

Each item of List of LE Spectrum Items defines the component or node number and yields a curve in VACS.

If no List of LE Spectrum Items is specified then ABEC calculates a parameter of the total System= at its driving port. The driving node is the one, which has the smallest node-number. In this case specify only ID= and System=.


Examples

The total input power at node 1 is

  LE_Spectrum
    AnalysisType=Power
    System=S1
    ID=101

The driving voltage at node 1 to ground is

  LE_Spectrum
    AnalysisType=Voltage
    System=S1
    ID=201

The voltage-difference across nodes 1 and 4 is

  LE_Spectrum
    AnalysisType=Voltage
    System=S1
    101  Node=1=4  ID=301

The current I1 into Driver "Drv1" at node 3 is

  LE_Spectrum
    AnalysisType=Current
    System=S1
    101  ElName=Drv1  Port=1  ID=401

The volume-velocity V1 is either the negative of the flow into Driver "Drv1" at node 5 or the in-flux of RadImp "Rad1".

  LE_Spectrum
    AnalysisType=VolVelocity
    System=S1
    101  ElName=Rad1  ID=501

Excerpt of a Lumped Element Script:


  System  'S1'
    Coil      'L1'    Node=1=2      L=1mH
    Capacitor 'C1'    Node=2=3      C=1uF
    Coil      'L2'    Node=3=4      L=1mH
    Driver    'Drv1'  Node=3=4=5=6  Def=X1  DrvGroup=1001
    Driver    'Drv2'  Node=4=0=7=6  Def=X1  DrvGroup=2001
    Enclosure 'E1'    Node=6        Vb=100L fb=50Hz  DrvGroup=3001
    RadImp    'Rad1'  Node=5        DrvGroup=1001
    RadImp    'Rad2'  Node=7        DrvGroup=2001
