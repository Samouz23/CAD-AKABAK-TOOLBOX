Pressure_Box is similar to the workings of section Pressure_Points. However, Pressure_Box implements either only a single pressure point or a line-source with coordinates given by parameter Position=. Additionally, this element allows to provide directivity to its radiation. Pressure_Box provides graphical hints, which helps to see the direction of this directivity by drawing a simple box around the source. Its dimensions are given by parameter CabDim=. The actual pressure point is centered in the center of the front pane of the cabinet. The cabinet can be shifted up/down and left/right with the help of parameter CabPos=. Note, that the cabinet is only a graphical means and is not an acoustic boundary conditions.

Directivity

Directivity is the far-field radiation pattern of a point-source. If we imagine a large sphere centered at the point source then its pressure variations yield the directivity. Its pattern should not depend on the radius of this sphere. Of course, for many problems this is an approximation, for example if a boundary is close to the source then the directional properties of the source may be very different from its far-field pattern.

Concerning Pressure_Box there are two means for providing far-field radiation patterns: 1) Simulation and 2) Directivity Files. Both can be used.

In order to provide simulated directivity specify parameter DiaphShape= together with dimensions of the directivity forming shape, dD= or WD= HD=, respectively.

In order to use data-files for directivity specify DataFileAlias_Horiz= and/or DataFileAlias_Vert=. These files should contain directivity data for the (local) horizontal and vertical planes. For an example using directivity files, see chapter Data Files Pressure_Box.

If DataFileAlias_Horiz= and DataFileAlias_Vert= are specified then ABEC performs linear interpolation for points, which are not in the same plane than the data-points.

If DataFileAlias_Horiz= and DataFileAlias_Vert= and DiaphShape= are specified then the horizontal and vertical directivity data are weighted by the simulation in these planes prior interpolation.

It is also possible to use data and simulation in a mixed fashion. In this case either DataFileAlias_Horiz= or DataFileAlias_Vert= and DiaphShape= are specified. Again directivity data are weighted by the simulation in the horizontal and vertical planes prior interpolation.

If either DataFileAlias_Horiz= or DataFileAlias_Vert= is specified, but no DiaphShape=, then direcivity data are used for all angles.

Data files for horizontal and vertical planes 
    Pressure_Box
      ..
      CardioLevel=-30dB
      DataFileAlias_Horiz=Dir_Horiz
      DataFileAlias_Vert=Dir_Vert
 5.4 kHz - 50 dB
Data file for all angles 
    Pressure_Box
      ..
      CardioLevel=-30dB
      DataFileAlias_Horiz=Dir_Horiz
Data files for horizontal and simulation for vertical plane 
    Pressure_Box
      ..
      CardioLevel=-30dB
      DiaphShape=Rectangle; HD=100mm;
      DataFileAlias_Horiz=Dir_Horiz
Only simulation 
    Pressure_Box
      ..
      CardioLevel=-30dB
      DiaphShape=Rectangle; HD=100mm;  WD=50mm;

Line Source

If LineLength=, LineDir= and LineNumPoints= are specified then Pressure_Box creates a line-source.


Line source + data files for horizontal plane 
    Pressure_Box
      ..
      CardioLevel=-30dB
      DataFileAlias_Horiz=Dir_Horiz
      LineLength=100mm;
      LineDir=Vertical;
      LineNumPoints=10
 5.4 kHz - 50 dB

The above example creates a similar field-pattern as with DiaphShape=Rectangle; HD=100mm. Compared to the far-field formula the array of points simulate the field more realistically.
