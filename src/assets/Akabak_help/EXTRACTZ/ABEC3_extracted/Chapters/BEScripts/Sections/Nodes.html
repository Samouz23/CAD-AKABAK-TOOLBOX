Naming

Because of the Nodes and Elements approach, the key-word Nodes should always be followed by a unique name. Other sections will take reference to one of the Nodes sections via RefNodes=. There can be as many Nodes-sections as you like.

List of Nodes

The essential part of the Nodes-section is the List of Nodes, which should follow any other parameter. Each line represents a point in Dim=3D or a line in 2D simulations. For example:

  Nodes "N"
    Scale=1mm
    1000    0.0  -12.5   0.0
    1001    0.0  -42.5   0.0
    2001   -3.0  -12.0   0.0
    ...

Transformations

Optional controlling parameters can be placed between the keyword and the List of Nodes. These controlling parameters are coordinate transformations. Note, that the order of application matters here. There is a difference whether a point is first rotated and then translated versus the case where the point is translated first.

Note, that each coordinate can be entered with units otherwise meter is assumed.

Tip: Use Scale= if you want to enter all coordinates in different units, for example:

  Millimeter: Scale=1mm
  Inch:       Scale=1in      // 1in = 25.4mm
  Feet:       Scale=1ft      // 1ft = 12in

Tip: Spread-sheet applications are particular useful for the generation of nodal positions. This is also a simple way to parameterize the script.

Parameterization

ABEC allows to specify formulae for any floating-point parameter, which is particularly useful for parameterizing your coordinate-values. For example, you can specify global variables in section Formula and use these variables for coordinate specification of nodes. 

  Nodes   "NF"
    2201   {-Dc - 2*tc}      0.0           {Hc + 2*tc}
    2202   {-Dc - 2*tc}    {Wc/2 + tc}     {Hc + 2*tc}
    ...

In the above example x-, y- and z-coordinates are specified by expressions in curly brackets. The variables Dc, Hc and tc are specified in an embedded script, which contains only a Formula-section. For example:

   Formula
      Hc = 0.7            // Cabinet height 0.7
      Wc = 0.43           // Cabinet width 0.43
      Dc = 0.436          // Cabinet depth 0.436
      tc = 0.012          // Cabinet wall thickness 0.012
      ...
