Purpose Assignment of damping to boundary elements
Used in BE-Script 
  WallImpedance   "Any name"
    ImpType=
    Normalized=
    RefElements=
    Value=
    ft=
    DataFileAlias=
    Color=
    List of Impedance-Elements

The WallImpedance-section defines elements with an absorbent and/or reactive surface of impedance:

Zs  =  Z0·Zn

with Zs = p/vn is the specific impedance, p is the sound pressure and vn is the normal (particle) velocity at the surface of the element. Z0 = ρc is the plane-wave impedance and Zn is the normalized specific impedance.

For a rigid surface the normal velocity is zero and the wall-impedance is infinite. This case is the default (Neumann boundary conditions).

The impedance of a 100% damping surface is Zs = Z0, which is equivalent to the impedance of a free-traveling plane-wave.

If the impedance is purely imaginary then there is no damping but reaction.


By default all elements of an Elements-section are addressed. However, it is also possible to address individual elements with the help of the List of Impedance-Elements. For example:

  WallImpedance "I1"
    RefElements="Chamber"
    ImpType=Reflection
    100     100     Value=0.2
    101     101     Value=0.2
    102     102     Value=0.2

In the script you can define the impedance in a variety of ways as explained at ImpType=.

It is also possible to link the WallImpedance-section to a data-file, with the help of DataFileAlias=. In this case constant values are ignored here, see Value=.


For example:

  WallImpedance "I1"
    RefElements="Chamber"
    ImpType=Impedance
    Normized=true
    DataFileAlias=Z

The file should contain a spectrum of reflection- or damping-coefficients or impedance or admittance values depending on ImpType= and Normalized=.

The spectrum should cover the solving range, otherwise ABEC will continue with the first or last value of the spectrum. Intermediate values are interpolated automatically. The values can be complex valued (real and imaginary). The file-format is explained at Data-Files - Spectrum.


Note, with WallImpedance the static values in the link-list are ignored when a data-file is used, i.e. when DataFileAlias= is specified. This is contrary to the workings in the Driving_Values-section.
