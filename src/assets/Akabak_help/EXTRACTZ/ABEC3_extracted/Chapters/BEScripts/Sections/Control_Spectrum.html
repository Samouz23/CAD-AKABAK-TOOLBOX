Control_Spectrum

Home » Scripts

Purpose Output control of spectral analysis
Used in Spectral observation script 
  Control_Spectrum
    Name=
    ID=

    f1=
    f2=
    NumFrequencies=
    Abscissa=
    Frequencies=

    rho=
    c=
    Altitude=
    StaticPressure=

During observation any spectral curve is rendered with the help of the application VACS. ABEC sends its spectral data to VACS for display.

ID= provides the link between ABEC and VACS so that curves can be updated. Details see at chapter ID=.

Frequency Abscissa

Control_Spectrum is the place where to specify the frequency-abscissa of the observation-spectra of a script. There can be only one definition of Control_Spectrum in an observation-script. Hence all spectral simulations of a script share the same abscissa.

For observation scripts, which relate to solving scripts of the Boundary Element Method, basically, only frequencies for which the acoustic field has been solved for can be rendered in the observation-stage. However, an advance interpolation scheme makes it possible to render at a higher resolution as at the solving-stage. In order to avoid aliasing a certain density of solved frequency samples needs to be provided. More on this topic see Interpolation Technique.

For Direct Sound- and pure Lumped Element-Analysis the specification of frequency parameters is always necessary.

VACS Folder-Label

Control_Spectrum manages also the folder-label in VACS as can be seen in the tree-view of VACS, for example: 

  Control_Spectrum
    Name="ABEC-ABEC21"
    ID=ABEC21
    NumFrequencies=200;   Abscissa=log;

Acoustic Parameters

Acoustic parameters (ρ, c, etc) can be specified for the Direct Sound Analysis but are ignored if the script is used for the Boundary Element Method.
