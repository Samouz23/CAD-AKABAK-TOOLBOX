Driving

Home » Scripts

Purpose Assignment of velocity to boundary elements
Used in BE Solving Script 
  Driving "Any name"
     RefElements=
     RefNodes=
     MeshFileAlias=
     DrvGroup=
     Direction=
     DirIsAxial=
     DrvWeight=
     DrvDelay=
     Color=
     List of Driving Elements

In the Driving-section you specify driving-motion of the boundary elements. The motion of the boundary is typically associated with the movement of a diaphragm. The diaphragm can be a loudspeaker membrane, for example, but it can also be any virtual plane of definition, for example, the driving surface of a horn-throat and so on.

Any element can be assigned a driving but the Interface-elements.

The driving-motion is assumed to be constant across a plane.

It is possible to project motion in a certain direction.

At solving stage the driving is only marked, there are no driving-values yet. The actual driving-values are provided at observation-stage, as explained in Driving Groups.

There can be multiple Driving-sections. Each Driving-section takes reference to a single Elements-section. By default all planes of an Elements-section are addressed. However, it is also possible to address only certain planes with the help of a list which follows the parameter part.

For example for addressing all planes of Elements-section "Exterior":

  Driving  "Front"
    DrvGroup=1001
    RefElements="Exterior"
    Direction=101,102,103

For example addressing only planes with index 101, 102 and 103

  Driving  "Front"
    DrvGroup=1001
    RefElements="Exterior"
    Direction=101,102,103
    101    101    Weight=1.0
    102    102    Weight=1.0
    103    103    Weight=0.5
