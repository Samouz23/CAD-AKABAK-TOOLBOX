Control_Field is part of an observation script, which is mainly used for Direct Sound Analysis.

In Direct Sound mode we need to specify a set of observation frequencies for which field-plots can be calculated. The range of frequencies you specify here will be displayed in the frequency-list on page Ob-Field. Before starting the field-calculation is is possible to select only certain frequencies from this list.

For Boundary Element Analysis the frequencies for which a field can be calculated are identical to the solving frequencies. Hence in this mode all frequency related specifications in Control Field are ignored.

Like wise the acoustic parameters (ρ, c, etc). These can be specified for the Direct Sound Analysis but are ignored if the script is used for the Boundary Element Method.

However, specifications for meshing, i.e. distribution of observation points, can be specified with the help of Control_Field. These settings will then form default values for all Field-sections in this script.
