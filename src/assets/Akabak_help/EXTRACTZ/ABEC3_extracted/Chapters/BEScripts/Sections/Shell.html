Shell works as an element-factory, which conveniently creates boundary elements for a variety of shapes, depending on parameter Shelltype=.

HasBaffle=true creates a squared baffle around the circular shell, which size is identical to the outer-diameter of the shell. This helps modeling the transition between circular and rectangular environment.

If Simple=true is specified then a simpler shape is produced by the shell-factory, which often is sufficient especially at low frequencies.

If in low-resolution-mode (Simple=true) then only Meshing=Bifu is possible.

Example

  Shell  "Sphere1"
    Subdomain=1
    RefNodes="N"
    Position=2001,2002,2003
    Shelltype=Sphere
    NumRings=4
    dD=1in

Interface

Shell can also be used to create an Interface for sub-domain modeling. In this case provide two indices at parameter Subdomain=.

  SubDomain_Properties
    SubDomain=1
    ElType=Interior

  SubDomain_Properties
    SubDomain=2
    ElType=Exterior
    IBPlane=z


  VibFile "Vib"
    SubDomain=1
    VibFileAlias=Vib
    DrvGroup=1001
    NoBaffle
    NormType=PosPolar 12.8mm 0deg

  Shell "Interface"
    Subdomain=1,2
    ShellType=Dome
    dD=96mm;    hD1=10mm
    NoBaffle
    SwapNormals
    EdgeLength=5mm

This example demonstrates the use of Shell, which creates an interface for the cone-shaped laser-scan VibFile on an Infinite Baffle.
