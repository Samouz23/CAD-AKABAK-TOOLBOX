MeshFile_Properties

Home » Scripts

Purpose Scaling and control of mesh-files
Used in BE Solving Script, Field Observation Scripts 
  MeshFile_Properties  "Any Name"
    MeshFileAlias=
    Tags=
    MinAngle=
    MinArea=
    Scale=
    Shift=
    Rotate=
    Mirror=

The section MeshFile_Properties can be helpful if you work with mesh-files.

Each MeshFile_Properties-section manipulates a single mesh-file with alias given by MeshFileAlias=. For a script MeshFile_Properties works on a global level. This means mesh-file elements will be first modified by MeshFile_Properties and then the result will be handed to Elements-sections and Position=.

Tags= can be used to include only a range of mesh-elements.

MinAngle= and MinArea= allow to exclude tiny triangles.

Scale=, Shift= etc. are helpful to position the whole mesh-file.
