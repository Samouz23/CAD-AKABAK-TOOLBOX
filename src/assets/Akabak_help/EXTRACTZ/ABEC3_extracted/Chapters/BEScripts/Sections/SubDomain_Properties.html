Purpose Properties of a sub-domain
Used in BE-Script 
  Subdomain_Properies  "Any Name"
    Subdomain=
    ElType=
    MeshFrequency=
    EdgeLength=
    Meshing=
    RefNodes=
  

    Scale=
    Shift=
    Rotate=
    Mirror=
    Color=
    Set=

The specification of a section Subdomain_Properties helps structuring the script if multiple sub-domains are used, and to provide global parameters common to a particular sub-domain. There should be only one Subdomain_Properties-section per sub-domain.

For example

  ...
  Subdomain_Properties "Interior"
    Subdomain=1
    ElType=Interior
    Color=Yellow

  Subdomain_Properties "Exterior"
    Subdomain=2
    ElType=Exterior
  ...

There are two sub-domains in this script. The first sub-domain has index "1" and the second "2". All sections with the specification Subdomain=1 get assigned "ElType=Interior". All sections with Subdomain=2 will have "ElType=Exterior".
