Purpose Generating elements for a Transition
Used in BE-Script 
  Transition  "Any Name"
    Subdomain=
    ElType=
    RefElements=
    RefEdges=
    Meshing=
    MeshFrequency=
    EdgeLength=
    SwapNormals=
    Color=
    Set=

Transition creates Boundary Elements, which form the transition between two other components. These components need to be specified in the current script or in an embedded file.


Following components can be referenced: Baffle, Diaphragm, Duct, Shell and VibFile. The reference is done with the help of parameter RefElements=. Planes will go from the edge of the first referenced component to the second. The order may give different results.

If there is only a single entry then the transition-planes go to the center-point of the referenced component.


The transition is done between selected edges of each component. Use parameter RefEdges=. The first index refers to the first component and the second index belongs to the second component of RefElements=.


Use SwapNormals in order to invert the Normals.


Example

There are two Duct components, which are connected by Transition:

  Duct  "Duct-Inner"
    Position=x
    DuctType=Circ
    WD=60mm;  HD=100mm;  Len=100mm

  Duct  "Duct-Outer"
    Position=x
    DuctType=Rect
    WD=100mm;  HD=160mm;  Len=100mm
    SwapNormals

  Transition
    RefElements="Duct-Outer", "Duct-Inner"
    RefEdges=1,1

The planes of the Transition go from Duct-Outer to Duct-Inner. Of both components the first edge is used. In the upper picture the green edge belongs to the first edge of the Duct-Inner and the red edge to the first of Duct-Outer.


  ...
  Transition
    RefElements="Duct-Outer", "Duct-Inner"
    RefEdges=2,2
    SwapNormals

The lower pictures shows what happens if we use the second edge of the components.
