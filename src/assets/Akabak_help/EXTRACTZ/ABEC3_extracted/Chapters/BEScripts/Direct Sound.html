Direct Sound Script

Home » Scripts

Direct Sound-scripts are used for the Direct Sound Analysis only.

General properties are discussed in chapter Scripts and in chapter Syntax.

Direct Sound-scripts need to be registered with the Project, see Add Direct Sound Script. Registered scripts are monitored and re-loaded automatically if out-of-date, see Updating Files.

There can be only a single Direct Sound Script for each project, however the script can have embedded scripts using File=.


The purpose of the Direct Sound-script is to provide position and properties of pressure points, which can be declared with the help of Pressure_Points and Pressure_Box sections.

In Direct Sound Mode there is no solving stage and the calculation is performed during observation.
