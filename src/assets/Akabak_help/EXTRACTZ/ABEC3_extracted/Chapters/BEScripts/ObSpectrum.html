Spectrum Observation Scripts

Home » Scripts

For larger projects it is recommended to specify spectrum-observations in a dedicated script. In any case the following sections are relevant for spectral observations.

Driving Values - Coupling

Each observation-script should specify driving-values either by providing a section Driving_Values in the observation script or by coupling to a LE-Script as explained in chapter Observation Scripts.

Control_Spectrum

For Boundary Element Analysis the frequency abscissa is derived from the solving stage as defined in section Control_Solver of the Solving Script. An alternate abscissa for spectral observation curves can be defined with the help of section Control_Spectrum of an observation script.

For Direct Sound Analysis and Lumped Element Analysis only you need to specify Control_Spectrum in each observation script.

BE_Spectrum

Section BE_Spectrum can be used to observe the sound-pressure response at several spatial points.

Radiation_Impedance

Section Radiation_Impedance renders the spectral curves of the radiation impedance of vibrating surfaces as defined in the solving script. Radiation_Impedance works only in Boundary Element Mode.

LE_Spectrum

Section LE_Spectrum inspects parameters of the Lumped Element Network, such as the voltage-, current-, excursion-, etc. response.
