The input of ABEC are scripts. Scripts are used for all modes of ABEC: Boundary Element Method, Direct Sound and Lumped Element Method. Accordingly there need to be registered a Boundary Element-, a Direct Sound- and a Lumped Element Script.

The Lumped Element and Direct Sound scripts are calculated only at observation stage.

Further there are observation scripts, which specify where and how you want to observe.

Observation scripts are best formed in such a way that field- and spectrum-observations are in different scripts.


The script-syntax is explained in chapter Syntax.


ABEC does not provide an editor for these scripts. For convenience it is recommended to install a professional multi-document text-editor, see text-editor.


Scripts need to be registered with the Project, see Add Files. Registered scripts are monitored and re-loaded automatically if out-of-date, see Updating Files.


Each script can embed further scripts, as explained at File=. Embedded scripts should not be registered.


  File="Nodes.txt"

  Control_Solver
    f1=10Hz;  f2= 100Hz;  NumFrequencies=10;  Abscissa=lin
    Sym=x
    MeshFrequency=100Hz
    ...

Note, that currently there is a slight difference between the format of the Boundary Element Scripts and of Lumped Element Scripts because the latter is kept compatible with the legacy application Akabak 2.1. More on this topic, please see chapter Syntax.
