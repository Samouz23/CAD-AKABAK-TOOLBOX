Identifier MeshFileAlias=
Format String
Purpose Alias to a mesh-file
Used in Elements, Diaphragm, Shell, Field

MeshFileAlias= specifies an alias to a mesh-file, which has been registered with the project, see Add Mesh-File.

MeshFileAlias= belongs to a concept, where vertices, planes or positions are specified with the help of Mesh-Files (CAD).

MeshFileAlias= needs to be specified if you want to access planes of a certain mesh-file. Sections Elements and Field directly implement planes of the file. Section, which provide a Position= parameter, such as Diaphragm or Shell also need MeshFileAlias= if its positioning is deduced from planes of the mesh-file.
