rho= (ρ)

Home » Scripts

Identifier rho=
Units kg/m3
Format Floating-point number
Purpose Speed of sound
Used in Control_Solver (Boundary Element),
Control_Field, Control_Spectrum (Direct Sound)
See also Acoustic Parameters, StaticPressure=, c=, Temperature=, Altitude=

ρ= belongs to the set of Acoustic Parameters.

ρ= specifies the homogeneous density of the medium. Units are [ρ] = kg/m3.

ρ= depends on the temperature and on the static pressure:

ρ = ρ0·P/P0·T0/(T0 + T)

with

ρ0 = 1.293 kg/m3 at T = 0 and P = P0.

T0 = 273.15 C and T temperature in degree Celsius.

P0 = 101325 Pa and P static pressure in Pa.


By default ρ = 1.205 kg/m3, P = P0 and T = 20 C


For example

  Control_Solver
    f1=20;  f2=500;  NumFrequencies=20;  Abscissa=log;
    ...
    c=337.4m/s  rho=1.171kg/m3
