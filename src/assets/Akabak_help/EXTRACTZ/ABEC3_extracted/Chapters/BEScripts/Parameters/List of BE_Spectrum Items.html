Purpose List of BE_Spectrum observation points.
Used in BE_Spectrum

The list of observation points follows the parameter part of the BE_Spectrum-section. Each line represents a particular observation, either a single point or a range of points, depending on parameter PlotType=.

Each item of the line should be separated by a blank or tab.

PlotType = Curve

This format is for PlotType=Curve only:


    <Index>    <Node-index>   RefNodes=   DrvGroups=   ID=

Index

The first entry is an index, which becomes the "name" of the spectrum at the observation point.

Node-Index

The second index is a node-number from a list to which RefNodes= points. The spectrum will be calculated at this point in space.

RefNodes=

Optionally you can specify RefNodes= individually.

DrvGroups=

With DrvGroups= you can filter on driving groups.

ID=

ID= is an arbitrary and unique string which links an ABEC-data-set to a VACS curve..


Example

  Control_Spectrum
    Name="Horn H 400"

  Nodes  "Spectrum"
    Scale=1mm
    1001      0      0    -300   // Point on-axis
    1002      0    100    -300   // Point off-axis

  BE_Spectrum
    PlotType=Curves
    AnalysisType=Pressure
    RefNodes="Spectrum"
    GraphHeader="Sound pressure"
    BodeType=LeveldB; Range=50   
    101   1001   ID=5001
    102   1002   ID=5002

In the above example ABEC simulates two frequency response curves, the first at -300mm distance on the z-axis, the second at -300mm on the z-axis and 100mm on the y-axis. The parameters ID= are just some random identifiers.

PlotType = [Directivity, Arc]

The format for PlotType=[Directivity, Arc] is:


    <Index>    Inclination=   DrvGroups=    ID=

Index

The first entry is an index, which becomes the "name" of the frequency-directivity-plot.

Inclination=

The second parameter specifies the inclination angle in degree versus the BasePlane=. See chapter Inclination=.

DrvGroups=

With DrvGroups= you can filter on driving groups.

ID=

ID= is an arbitrary and unique string which links an ABEC-data-set to a VACS contour-plot..


For example

  BE_Spectrum
    PlotType=Directivity
    GraphHeader="Directivity"
    PolarRange=-90, 90, 37
    BasePlane=xy
    Distance=100
    101   Inclination=0.0   ID=56171
    102   Inclination=45.0  ID=56172

In this example two frequency-directivity plots are generated in VACS. The base-plane is spanned by the x- and y-axis, with the pole at the x-axis. The first directivity arc runs in the base-plane from negative y-axis (-90deg) to positive y-axis (+90deg). The second arc is inclined by 45deg.

PlotType = Line

The format for PlotType=Line is:


    <Index>  <Node1-index> <Node2-index>  RefNodes=  N=   DrvGroups=    ID=

Index

The first entry is an index, which becomes the "name" of the plot, where the x-axis is the frequency abscissa and the y-axis displays simple index numbers according to the points.

Node1- and Node2-Indices

The second and third indices are node-numbers from a list to which RefNodes= points. The line stretches from point with node-number Node1 to point with node-number Node2.

RefNodes=

Optionally you can specify RefNodes= individually.

N=

N specifies the number of points, which are generated between Node1 and Node2.

DrvGroups=

With DrvGroups= you can filter on driving groups.

ID=

ID= is an arbitrary and unique string which links an ABEC-data-set to a VACS contour-plot.


For example

  BE_Spectrum
    PlotType=Line
    GraphHeader="Sound pressure"
    RefNodes="Nodes"
    BodeType=LeveldB;  Range=50
  //Name  Node  Node   NumPoints
    101   3000  3001   N=61     ID=010
