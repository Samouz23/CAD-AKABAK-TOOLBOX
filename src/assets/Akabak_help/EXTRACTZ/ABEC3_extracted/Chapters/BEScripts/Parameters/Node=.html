Identifier Node=
Format Integer
Purpose Identification network node of Lumped Element Analysis
Used in LE_Spectrum
See also System=, ElName=, Port=, AnalysisType= 
  System  'S1'
    Driver    'Drv1'  Node=1=2=2=0=10=20  Def=X1  DrvGroup=1001
    Enclosure 'E1'    Node=20             Vb=100L
    RadImp    'Rad1'  Node=10             DrvGroup=1001

Node= identifies one or two particular nodes of a Lumped Element network for observation of spectra with LE_Spectrum.

Node= is necessary for inspecting potentials such as AnalysisType=[Voltage, Force, Pressure].

Node= can have one or two node-indices. If only one index is specified then the potential is always versus ground. If two indices are given then the potential is the difference between the two nodes, Node=s=t yields:

  pst = ps - pt

Example

If the Lumped Element script defines a loudspeaker-driver with two voice-coils and a sealed enclosure and you want to inspect the voltage-difference over the first voice-coil U12 = U1 - U2

  LE_Spectrum 'U12'
    AnalysisType=Voltage
    System=S1
    101  Node=1=2   ID=U12

Or, if you want to inspect the pressure-difference between the front and rear diaphragm p1020 = p10 - p20

  LE_Spectrum 'p1020'
    AnalysisType=Pressure
    System=S1
    101  Node=10=20   ID=U12

The associate LE-script looks like this:

  ...
  System  'S1'
    Driver    'Drv1'
      Def='Drv1'
      Node=1=2=2=0=10=20
      DrvGroup=1001
    RadImp 'Front'
      Node=10
      DrvGroup=1001
    Enclosure 'Rear'
      Node=20
      Vb=100L  Lb=300mm
