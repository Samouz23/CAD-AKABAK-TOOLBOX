Identifier NumBaffles=
Format Integer
Purpose Number of flanges
Used in Duct

NumBaffles=1 or NumBaffles=2 creates a rectangular baffle around the circular, elliptical or oval Duct, which size is identical to the outer-diameters of the Duct. NumBaffle= helps modeling the transition between a circular shape and an otherwise rectangular environment.

By default NumBaffles=0.
