Purpose List of pressure points.
Used in Pressure_Points

The list of pressure points follows the parameter part of the Pressure_Points-section. Each line represents a point-source. Each index should be separated by a blank, tab or comma. The format is

    <Index>    <Node-index1>   DrvGroup=   Weight=   Delay=   RefNodes=

Index

The first entry is an index, which becomes the "name" of a point.

Node-Indices

The second entry is a node-number from the list to which RefNodes= points.

DrvGroup=

Assigns a DrvGroup-index to this point individually.

RefNodes=

Optionally you can specify RefNodes= individually.
