Identifier hM=
Units m
Format Floating point number
Purpose Height of magnet.
Used in Diaphragm
See also Diaphragm shapes, dM=

hM= is the height or thickness of a simplified magnet. hM= should be specified together with dM=.

If not specified then the magnet is replaced by a non-vibrating disc of diameter dVC=.
