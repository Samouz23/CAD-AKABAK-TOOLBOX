List of Boundary Elements by Mesh-File

Home » Scripts

Purpose List of mesh-file items.
Used in Elements

The list of boundary elements follows the parameter part of the Elements-section. If a list-item shall represent planes of a mesh-file then following syntax should be used:

    <Index>    Mesh    MeshFileAlias=  Include <tags>   Exclude <tags>   SwapNormals

For example

  Elements "Mesh1"
    Subdomain=1
    MeshFileAlias=M
    101  Mesh  Include All   Exclude 1, 2, 3
    ...

Index

The first entry is an index, which becomes the "name" of all mesh-file elements.

Mesh

Indicator that this line is regarded as a mesh-file item (Note, Mesh can be omitted if also MeshFileAlias=, Include or Exclude is specified).

MeshFileAlias=

If you use a mesh-file you need to specify MeshFileAlias= in the parameter-part of the section. Alternatively it is also possible to provide MeshFileAlias= individually with each item of the Boundary Element List.

Include <tags> Exclude <tags>

With Include and Exclude you can filter triangles of the mesh-file as explained in Mesh-File-Tags.

SwapNormals

SwapNormals inverts all triangles of the mesh-file so that its normals point opposite, see also chapter on Normals and Volumes.
