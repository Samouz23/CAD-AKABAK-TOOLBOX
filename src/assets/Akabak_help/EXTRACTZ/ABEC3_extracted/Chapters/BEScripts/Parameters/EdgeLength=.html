EdgeLength=

Home » Scripts

Identifier EdgeLength=
Units m
Format 2 floating-point numbers (2nd optional)
Purpose Controlling meshing, max and min dimension of elements
Used in Control_Solver, Subdomain_Properties, Elements, Baffle, Diaphragm, Shell, Field
See also MeshFrequency=, Meshing=, Boundary Meshing

EdgeLength= is a distance-parameter controlling the mesh-generation. It is mainly used for Boundary-Meshing, however it is also used to control the distribution of observation field-points (Field).

Before solving, ABEC investigates the entered planes and eventually will cut-down these planes and create elements until specified criteria are met. EdgeLength= is the main criterion, which makes sure that all triangles have sides smaller than EdgeLength=:

Side < EdgeLength

Hence, the smaller the value of EdgeLength= the more triangles will be produced. MeshFrequency= can be used alternatively.

EdgeLength= can have two values. The second is applied only for certain types of meshing as explained at parameter Meshing=.


In the context of an observation Field EdgeLength= measures the maximum distance between calculation points. This is so because at observation values are calculated at the vertices of a mesh-triangle and not at the center.
