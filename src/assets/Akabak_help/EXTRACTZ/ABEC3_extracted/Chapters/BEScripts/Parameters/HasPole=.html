HasPole=

Home » Scripts

Identifier HasPole=
Format Boolean
Default HasPole=false
Purpose If true then inner part is not driven
Used in Diaphragm
See also dD1=

HasPole or HasPole=true makes the inner part of a Diaphragm a standard boundary, i.e. it becomes a non-vibrating part. HasPole has an effect only on the front side of a Diaphragm (Side=Front).

The pole diameter is given by the diameter of the voice coil, dVC=.

The pole can be shaped to a convex or concave dome with the help of parameter hD1=.

The pictures to the right demonstrate the difference between HasPole=false and HasPole=true. The dome is measured with the help of tD1= and dD1=. The pole is derived from dVC= and hD2=. However, we need a value for tD1= in both cases.

Note, for Side=Rear a non vibrating boundary is created. Either for a magnet (dM= and hM=), or for a flat plane if dVC > 0.

Example

  Diaphragm  "Front"
    DrvGroup=1001
    SubDomain=1
    EdgeLength=10mm 10mm
    Position=1001,1002,1003 RefNodes=N
    NoBaffle
    Side=front
    HasPole=true
    dD=120mm     // Cone diameter
    tD1=40mm     // Depth of cone
    ws=10mm      // Width of suspension
    hD1=10mm;    // Height of pole
    hD2=40mm;    // Height of cone
    dVC=20mm;    // Diameter of voice coil
