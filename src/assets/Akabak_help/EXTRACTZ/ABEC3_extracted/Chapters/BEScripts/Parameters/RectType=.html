Identifier RectType=
Format [Rectangle, Ellipse, Oval]
Purpose Type of rectangular diaphragm
Used in Diaphragm, Baffle
See also WD=; HD=, WB=; HB=, Diaphragm shapes

RectType= allows to specify details of a non-circular shape.

For example, if you specified the width and height of a Diaphragm or of a Baffle then ABEC needs to know what particular shape you want to model.

As sketched in chapter Diaphragm shapes ABEC offers a rectangular, elliptical or an oval shape. Accordingly you need to type RectType=Rectangle, RectType=Ellipse or RectType=Oval, respectively.

Note, that if WD=HD then ABEC creates a circular shape by default. In order to get a squared shape specify RectType=Rectangle, too.

For example

  Diaphragm  "D"
    DrvGroup=1001
    SubDomain=1
    EdgeLength=10mm 10mm
    Position=1001,1002,1003 RefNodes=N
    NoBaffle
    Side=front
    WD=200mm;  HD=100mm
    RectType=Oval
    hD1=10mm;   tD1=20mm;  dD1=50mm;
    Ws=10mm;
    tB=10mm;  t1=-10mm

...or, for the shape of the Baffle:

  Baffle
    Subdomain=1
    EdgeLength=25mm, 25mm
    Position=2001, 2002, 2003  "N"
    WB=400mm;  HB=640mm
    RectType=Rectangle;
    101  Ref="D1"   xl=0mm  yc=140mm  Rot=0
    102  Ref="D2"   xl=0mm  yc=-50mm  Rot=0
    103  Ref="Du1" xl=0mm  yc=-240mm Rot=0
    104  Ellipse  W=70mm  H=30mm  xr=50mm  yt=50mm Rot=40  EdgeLength=2mm
