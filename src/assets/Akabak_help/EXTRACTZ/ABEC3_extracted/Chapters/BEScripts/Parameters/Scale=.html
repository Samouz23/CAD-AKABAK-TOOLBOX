Scale=

Home » Scripts

Identifier Scale=
Format 1 Floating point number
Format 2 3 floating point numbers
Units m
Purpose Scaling of coordinate values
Used in Subdomain_Properties, MeshFile_Properties, Nodes, Elements, Baffle, Diaphragm, Shell, Field, BE_Spectrum
See also Rotate=, Shift=, Mirror=

Scale= performs stretching or shrinking of vectors as specified in section Nodes, parameter Position= and of mesh-files.

Format 1 scales isotropically and format 2 scales individually the x-, y- and z-component.

Note

Scale= does not alter dimensions of the Diaphragm, Shell and Baffle.

Scale= does not affect values entered for the Shift= parameter.

Entering Coordinates

For example, Scale= often used in section Nodes to provide entry in millimeters, Inches, etc.

  Nodes   "N1"
    Scale=1mm
    2001    0.0       0.0     712.0
    2002    0.0     227.0     712.0
    2003    0.0     227.0       0.0
    ...

In the above example xyz-coordinates are specified in millimeters. Scale=1mm converts these values into SI-units.


  Nodes   "N2"
    Scale=1in
    2001    0.0       0.0     180.8
    2002    0.0       57.66   180.8
    2003    0.0       57.66   0.0
    ...

Alternatively you can specify the xyz-coordinates in Inches. In this case use Scale=1in.

If you want to specify coordinates in feet then use Scale=1ft.


  Nodes   "N3"
    Scale = -1, 1.2, 0.8
    2001    0.0       0.0     0.0
    2002    1.0       0.0     0.0
    2003    1.0       1.0     0.0
    ...

The above example shows an un-isotropic scaling. The x-direction is mirrored. The y-direction gets magnified by the factor 1.2 and the z-direction shrinked by the factor 0.8.

Mesh-Files

Scale= is also helpful for rescaling mesh-files. For example

  Meshfile_Properties
    MeshfileAlias=M
    Scale= 1mm
    Shift= -100mm, 0, 0
    ...

In the above example mesh-file with MeshfileAlias=M is shrunk by Scale=1mm for the whole script where it is used. Alternatively, Scale= can be applied in section Elements or Field. In this case only this particular part of the mesh-file will be affected.
