Identifier tD1=
Units m
Format Floating point number
Purpose Depth of a cone.
Used in Diaphragm, Shell
See also Diaphragm shapes, hD2=

A non-zero value of tD1= creates a cone.

tD1 > 0 tD1 < 0

For the Diaphragm positive values create a concave cone otherwise it is convex. tD1 measures at the front side of the diaphragm and from the level of the suspension down to the base of the dust-cap.



tD1 > 0 tD1 < 0

For the Shell tD1 is the length of a cone if ShellType=Cone.
