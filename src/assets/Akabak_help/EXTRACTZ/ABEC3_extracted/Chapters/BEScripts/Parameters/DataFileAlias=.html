Identifier DataFileAlias=
Format String
Purpose Data-file with frequency-spectrum.
Used in WallImpedance, Driving_Values, Def_MeasRadiator
See also ImpType=, Normalized=, (WallImpedance)
DrvType= (Driving_Values)

DataFileAlias= expects an alias to a data-file, which has been registered with the project, see Add Data-File.

The expected format of the data-file is explained in Data Files-Spectrum.

WallImpedance and Driving_Values

The actual meaning of the data is resolved with the help of further parameters of sections WallImpedance and Driving_Values.

  WallImpedance:    ImpType=   Normalized=
  Driving_Values:   DrvType=

In general each value of a linked data-files is processed very much like the single value of the parameter Value=.

Def_MeasRadiator

The Def_MeasRadiator defines a radiating lumped element based on measurements. Here we have two specifications of DataFileAlias= because Def_MeasRadiator needs an impedance-file and a sound pressure-file. The distinction is made by Import Control Settings. These settings are part of the file as exported by VACS and are documented in the help-system of VACS at Import Control Settings. Examples see at chapter Data Files-Spectrum.
