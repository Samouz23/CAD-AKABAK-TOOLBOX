Identifier Set=
Format Integer number List of integer numbers
Purpose Controlling sets of enabled Element-sections
Used in Control_Solver, Subdomain_Properties, Elements, Baffle, Diaphragm, Shell, VibFile, Field

Set= allows to enable/disable complete sections with the help of numbers.

Set= is an alternative way to writing Off in front of a section name, see Script Syntax.


For example

Provide a set-number for sections you want to control. For example

  Element  "S1"
    Set=100
    ...
  Element  "S2"
    Set=200
    ...

The controller is at section Control_Solver, where you specify the set of numbers to be enabled. For example

  Control_Solver
    Set=100, 200
    ...

In the above example all sections with Set=100 and Set=200 will be enabled.
