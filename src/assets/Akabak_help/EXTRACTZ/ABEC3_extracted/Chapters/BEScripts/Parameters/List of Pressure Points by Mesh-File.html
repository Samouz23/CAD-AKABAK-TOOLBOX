List of Pressure Points by Mesh-File

Home » Scripts

Purpose List of mesh-file items.
Used in Pressure_Points

The list of Pressure Points follows the parameter part of the Pressure_Points-section. Each line yields one or more Pressure-Points at the center of at the mesh-file-shapes:

    <Index>    Mesh    MeshFileAlias=  Include <tags>   Exclude <tags>

For example

  Pressure_Points  "PP1"
    DrvGroup=1002
    MeshFileAlias=M
    MeshMode=Elements
    MeshMinDistance=0.2m
    101   Mesh Include "Right"
    ...

Index

The first entry is an index, which becomes the "name" of all mesh-file elements.

Mesh

Indicator that this line is regarded as a mesh-file item (Note, Mesh can be omitted if also MeshFileAlias=, Include or Exclude is specified).

MeshFileAlias=

If you use a mesh-file you need to specify MeshFileAlias= in the parameter-part of the section. Alternatively it is also possible to provide MeshFileAlias= individually with each item of the Pressure Point List.

Include <tags> Exclude <tags>

With Include and Exclude you can filter triangles of the mesh-file as explained in Mesh-File-Tags.


Note

Creating Pressure_Points with the help of a mesh-file needs some control over the way mesh-elements yield the positioning of the point-source. For example, included mesh-elements can yield the position of a single Pressure-Point (MeshMode=Center) or there can be Pressure-Points at the center of each mesh-element (MeshMode=Elements). See parameter MeshMode= for details.
