Identifier DrvType=
Format [Excursion, Velocity, Acceleration, Pressure]
Purpose Type of driving value
Used in Driving_Values

DrvType= is a parameter of section Driving_Values and only relevant for direct driving (i.e. not coupled to a Lumped Element Network).

DrvType= specifies the type of the physical driving-values. DrvType= relates to items in the List of Driving Values or to the character of a related data-file, ie if DataFileAlias= has been specified. DrvType= is either

  Excursion, Velocity, Acceleration or Pressure

With spectral excitation the three types of motion are related by: 

  Excursion       v = xconst·xfile·jω
  Velocity        v = vconst·vfile
  Acceleration    v = aconst·afile/jω

If there is no data-file assigned then xfile = vfile = afile = 1.


DrvType=Pressure is typically used if items of the List of Driving Values relate to Pressure_Points or Pressure_Box.

Example


  Driving_Values  "Point Sources"
    DrvType=Pressure
    Value=1Pa
    101   DrvGroup=1001  Weight=1.0  Delay=1ms
    102   DrvGroup=1002  Weight=1.0  Delay=0
    ...

  Driving_Values  "Membranes"
    DrvType=Acceleration
    Value=1m/s2
    DataFileAlias=A1
    101   DrvGroup=1001  Weight=1.0
    102   DrvGroup=1002  Weight=1.0
    ...
