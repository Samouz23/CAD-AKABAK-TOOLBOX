Identifier RefElements=
Format String
Purpose Reference to an Elements-section
Used in WallImpedance, Driving, Transition, Field

RefElements= refers to another section. See below at

WallImpedance and Driving

If used in WallImpedance or in Driving the reference is typically an Elements- or a Shell-section. Here the impedance of boundaries or driving-motion is specified for referenced elements.

For example

  Shell  "Dome"
    Meshing=Bifu
    RefNodes="N"
    SwapNormals
    ...

  WallImpedance
    RefElements="Dome"
    ImpType=Damping
    Value=0.5

Transition

The Transition section creates boundary elements between two other components. The names of the referenced sections form the values of RefElements=. The two strings should be separated by a blank, tab or comma. If the name contains a blank then it should be quoted, see example below.

The order matters. The planes are always formed from the first to the second component. Depending on the order and resolutions you may get different results.

For example

  Duct  "Duct_1"
    DuctType=Rectangle
    WD=150mm;  HD=50mm;  Len=200mm

  Duct  "Duct_2"
    DuctType=Oval
    WD=370mm;  HD=120mm;  Len=200mm
    t1=450mm

  Transition
    RefElements=Duct_2, Duct_1
    RefEdges=2,1

Field Observation

In section Field, RefElements= yields another purpose. If specified, as part of the List of Field Planes, then Field calculates and renders on the referenced surface. Referenced sections are from the solving script, typically

For example

  Field  "F2"
    AnalysisType=DrvVelocity
    BodeType=LeveldB;   StepSize=1;   Range=50dB
    Sym=xy
    101   RefElements="Vib"
    ...
