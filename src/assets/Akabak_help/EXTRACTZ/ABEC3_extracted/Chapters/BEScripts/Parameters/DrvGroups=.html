DrvGroups=

Home » Scripts

Identifier DrvGroups=
Format List of integer numbers
Purpose Set of driving groups
Used in Field, BE_Spectrum
See also Driving Groups

DrvGroups= is used in Observation Scripts for Field and Spectral analysis. If specified then DrvGroups= yields a response, which contributions are only from the set of driving groups specified.

DrvGroups= accepts a list of numbers, which are those of DrvGroup=. If a DrvGroup-number is part of the list then its response will be added to the final result.

There are alternative ways of specification:

    DrvGroups = <DrvGroup1>, <DrvGroup2>, <DrvGroup3>

or, using three dots for a range

    DrvGroups = <DrvGroup1> ... <DrvGroup3>

For including all driving groups of the project specify

    DrvGroups = all

For including only a single driving group

    DrvGroups = <DrvGroup1>

Example

A typical example comes from cross-over design. Here we want to see three curves: 1) Response of total, 2) Response of woofer only and 3) Response of tweeter only.

Such a specification could look like this

  BE_Spectrum "SPL"
    PlotType=Curves
    RefNodes="Spectrum"
    GraphHeader="SPL"
    BodeType=LeveldB;  Range=50
    101  1001  DrvGroups=1001...1004  ID=211
    102  1001  DrvGroups=2001         ID=212
    103  1001  DrvGroups=All          ID=213
