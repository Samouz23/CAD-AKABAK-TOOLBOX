Identifier c=
Units m/s
Format Floating-point number
Purpose Speed of sound
Used in Control_Solver (Boundary Element),
Control_Field, Control_Spectrum (Direct Sound)
See also Acoustic Parameters, StaticPressure=, rho=, Temperature=, Altitude=

c= belongs to the set of Acoustic Parameters.

c= specifies the homogeneous speed of sound of the medium. Units are [c] = m/c.

c= depends on the temperature:

c = c0·√(T/T0 + 1)

with

c0 = 331.4 m/s at T0.

T0 = 273.15 C and T temperature in degree Celsius.


By default c = 343.318 m/s and T = 20 C


For example

  Control_Solver
    f1=20;  f2=500;  NumFrequencies=20;  Abscissa=log;
    ...
    c=337.4m/s  rho=1.171kg/m3
