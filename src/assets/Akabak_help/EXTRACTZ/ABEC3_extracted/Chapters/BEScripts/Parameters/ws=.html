Identifier ws=
Units m
Format Floating point number
Purpose Width of the suspension.
Used in Diaphragm
See also Diaphragm shapes, dD=, WD=; HD=

ws= specifies the width of the outer suspension.

Elements, which are generated for the suspension, feature a velocity-gradient. The velocity weight factor is one for points close to the diaphragm and zero at the outside rim of the suspension.

As demonstrated in the picture the viewer displays the velocity gradient by a shade of grey after meshing.

If Simple=true then the value of ws= is ignored. In this case we assume the suspension is part of the diameter, dD= of the Diaphragm. Typically, half of the actual width of the suspension should be added to dD=.
