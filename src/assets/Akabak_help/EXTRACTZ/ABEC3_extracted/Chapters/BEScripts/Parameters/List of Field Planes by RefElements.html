List of Field Planes By RefElements

Home » Scripts

Purpose List of field planes.
Used in Field
See also List of Field Planes, List of Field Planes by Mesh-File

The list of field-planes follows the parameter part of the Field-section. If you want to calculate the field-plot on the boundary then you can take reference by following format:

    <Index>    RefElements=

Index

The first entry is an index, which becomes the "name" of a field-plane.

RefElements=

RefElements= indicates the name of a section of the solving file. RefElements= can point to the following sections:

Elements

Diaphragm

Shell

VibFile

Baffle

For example

This declaration calculates the velocity distribution of a VibFile in dB. It assumes a VibFile-section with name "Vib" in the solving script.

  Field  "Velocities"
    EdgeLength=2mm
    AnalysisType=DrvVelocity
    BodeType=LeveldB;   StepSize=1;   Range=50dB
    Sym=xy
    101   RefElements="Vib"
