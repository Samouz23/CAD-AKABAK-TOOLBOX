Identifier NormType=
Format [Lowest, Mean, Org, PosPolar, PosCartesian]
Purpose Type of normalization of imported data
Used in VibFile

NormType= is a parameter of section VibFile. NormType= specifies the type of normalization of vibrational data.

If you want to couple the VibFile-diaphragm to a Lumped Element Network the vibrational distribution should be normalized to the rigid body motion of the diaphragm. This is so because the lumped velocity shall be controlled by the lumped element network. In order to normalize the vibration data we specify NormType=. The point used for normalization is typically the one, where the driving force is attached. For an electro-dynamic speaker this is the connection of the voice coil. After normalization the frequency response of the velocity at the reference point is simply one for all frequencies. At any other point the frequency response of vibration relates to this reference point.

NormType=Lowest

NormType=Lowest normalizes the vibration-data to the vibration at the lowest point, i.e. the point with coordinates most recessed. This setting is particular helpful for scans of conical loudspeaker membranes with convex dust-cap. Here we assume that the lowest point coincides with the connection of the voice-coil.

NormType=Mean

NormType=Mean normalizes the data-set to the mean-value at each frequency. This setting makes that the frequency response of the mean-value is one for all frequencies. The frequency response of any particular point relates to this mean-value.

NormType=Org

NormType=Org does not perform a normalization. Hence, the vibrational-data are used as is. This means that the frequency response at any point may include the response of the driver. Obviously this setting makes only sense, if we observe with static value driving (no Lumped Element Coupling), see section Driving_Values.

NormType=PosPolar

NormType=PosPolar normalizes the data-set of vibration to a certain point, which needs to be specified additionally, for example

    VibFile "Vib"
      SubDomain=1
      VibFileAlias=Vib
      DrvGroup=1001
      NoBaffle
      NormType=PosPolar   12.8mm   0deg

NormType=PosPolar expects at least one additional parameter, which is the radius from the center of the VibFile-element, as indicated in the above sketch. A second additional parameter specifies the angle. By default this angle is zero. For circular symmetric data-sets this angle is ignored.

NormType=PosCartesian

NormType=PosCartesian is similar to the previous setting only that in this case the coordinates of the reference point is specified in Cartesian coordinates. For example

    VibFile "Vib"
      SubDomain=1
      VibFileAlias=Vib
      DrvGroup=1001
      NoBaffle
      NormType=PosCartesian   12.8mm   0mm
