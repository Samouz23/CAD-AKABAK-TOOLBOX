ElType=

Home » Scripts

Identifier ElType=
Format [Interior, Exterior]
Default ElType=Interior
Purpose Element type
Used in Subdomain_Properties, Elements, Baffle, Diaphragm, Shell, Duct, Transition
See also Normals and Volumes

ElType= is used within Boundary Element Scripts. It specifies the type of a Boundary Element, which can be:

  • Interior (default value)
  • Exterior

A Boundary Element with ElType=Interior belongs to a group, which enclosures a volume. Its normal should point into this volume as explained in chapter Normals and Volumes.

A Boundary Element with ElType=Exterior points into a special volume, namely the space between the surface and a hypothetical sphere, which is infinitely far away.

Typically, ElType= is specified at section Subdomain_Properties. This makes sense because ElType is a property of a subdomain. In this case all Elements of a subdomain (see Subdomain=) share the same type of ElType=. However, it is also possible to declare ElType= at Element-Level.

Interface-Elements belong to two subdomains and, hence, would not have parameter ElType= specified.
