Purpose List of field planes.
Used in Field
See also List of Field Planes by RefElements, List of Field Planes by RefElements

The list of field-planes follows the parameter part of the Field-section. Each line represents a plane, which is formed by nodes (vertices), as explained in chapter Nodes and Elements. Each index should be separated by blanks. The format is

    <Index>    <Node-index1>   <Node-index2>   <Node-index3>   <Node-index4>  RefNodes=

Index

The first entry is an index, which becomes the "name" of a field-plane.

Node-Indices

The second and subsequent entries are node-numbers from a list to which RefNodes= points.

RefNodes=

Optionally you can specify RefNodes= individually.

Dim=3D

With Dim=3D of Control_Solver or for Direct Sound mode there are either three of four entries, which describe a quadrilateral or a triangle, respectively. 

  Field
    RefNodes="Ob"
    BodeType=LeveldB;  StepSize=3;  Range=50
    101    2001  2002  2003  2004
    102    3001  3002  3003  3004
    ...

Dim=CircSym

The Boundary Element Mode supports also circular symmetry with Dim=CircSym of Control_Solver. In this case field-planes are defined by only two points, P1 and P2. Each point defines axial- and radial-coordinates. P1 and P2 are the outer vertices of a quadrilateral, which extends from the axis to P1 or P2, respectively. For example:

  Field  "Contour1"
    RefNodes="Contour"
    ...
    1     30   40
    2    100  110
    ...
