Identifier Len=
Units m
Format Floating point number
Purpose Length of Duct.
Used in Duct

Len= is the length of the waveguide-axis specified in section Duct.

For example

  Duct  "D1"
     DuctType=Circle
     dD=160mm
     Len=120mm
     Position=x
     NumBaffles=2

Direction

The value of Len= can be positive and negative.

Len= creates a duct, which starts at its first aperture as specified by parameter Position=.

A positive value extends the duct to the rear of the first aperture.

A negative value extends the duct into the front-direction.

Len > 0 Len < 0

For example

  ...
  Baffle "B1"
    ...
    101  Ref="Duct1"  xc=0mm  yc=0mm

  Duct  "Duct1"
    DuctType=Oval;  WD=150mm;  HD=50mm
    Len=120mm

The Duct is placed on a Baffle. With Len=120mm the Duct will extend to the rear of the Baffle.


  ...
  Duct  "Duct1"
    DuctType=Oval;  WD=150mm;  HD=50mm
    Len=-120mm

With a negative length-value the Duct extends now to the front of the Baffle.
