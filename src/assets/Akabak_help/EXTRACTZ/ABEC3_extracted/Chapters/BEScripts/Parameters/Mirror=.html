Identifier Mirror=
Format [x, y, z, xy, xz, yz, xyz]
Purpose Shifting of coordinate values
Used in Subdomain_Properties, MeshFile_Properties, Nodes, Elements, Baffle, Diaphragm, Shell, Field, BE_Spectrum
See also Scale=, Rotate=, Shift=

Mirror= translates and rotates along the axis specified.

The order of specification of Shift=, Rotate= and Mirror= matters.

For example

  Elements "Chamber3"
    Mirror=xy
    Shift= -1.2, 0.7, 0
    RefNodes="Chambers"
    SubDomain=3
    100   1000 1001 1002 1003  // Top
    101   2000 2001 2002 2003  // Bottom
    ...

In the above example coordinates of Elements are first mirrored along the x-axis and then along the y-axis. Finally, translated by Shift= -1.2, 0.7, 0.
