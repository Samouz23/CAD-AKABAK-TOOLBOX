Frequencies=

Home » Scripts

Identifier Frequencies=
Units Hz
Format List of floating-point numbers
Purpose List of frequencies for solving
Used in Control_Solver, Control_Field, Control_Spectrum
See also f1=; f2=, NumFrequencies=, Abscissa=

Frequencies= specifies a list of frequencies. It is an alternative way of specification of f1=, f2=, NumFrequencies and Abscissa.

For example

  Control_Solver
    Frequencies=500, 1kHz, 2kHz, 5kHz
    MeshFrequency=15kHz
    Sym=xy;  Dim=3D
    Meshing=Delaunay

Frequencies= accepts simple floating point numbers as well as units Hz in ENG-format. For example: 5000, 5000Hz or 5kHz.
