Identifier MinArea=
Format square meter, see Units/Area Units
Purpose Filtering mesh-file triangles below a certain area
Used in MeshFile_Properties
See also MinAngle=

MinArea= excludes all triangles of the mesh-file below a the specified area.

MinArea= can help to filter degenerated triangles. These are triangles where all vertices are on a line, or close to

Example

  Meshfile_Properties
    Meshfilealias=M
    MinArea=0.1in2
