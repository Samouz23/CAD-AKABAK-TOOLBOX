Identifier ImpType=
Format [Reflection, Damping, Impedance, Admittance]
Purpose Specification of wall-impedance
Used in WallImpedance
See also Normalized=

ImpType= relates to Value=, the items of the List of Impedance Values and to those from a spectrum hosted in a data-file as given by parameter DataFileAlias=.

Note, that if DataFileAlias= is specified then here any constant value is ignored.

ImpType=Reflection

For example

  WallImpedance "I1"
    ...
    ImpType=Reflection
    Value=0.2
    ...

In this case Value=0.2 means a reflection coefficient, R. From R the normalized specific impedance is calculated internally:

          1 + R
    Zn =  —————
          1 - R

ImpType=Damping

For example

  WallImpedance "I1"
    ...
    ImpType=Damping
    Value=0.8
    ...

In this case Value=0.8 means a damping coefficient, D = 1 - R. From D the normalized specific impedance calculates:

          2 - D
    Zn =  —————
            D

ImpType=Impedance

For example

  WallImpedance "I1"             WallImpedance "I1"
    ...                            ...
    ImpType=Impedance              ImpType=Impedance
    Normized=true                  Normized=false
    Value=1.5, -0.2                Value=617.4, -82.3
    ...                            ...

With ImpType=Impedance there can be specified two values. The first indicates the real part and the second the imaginary part of the specific impedance. The latter is optional and defaults to zero if not specified.

If Normalized=true then the values refer to the normalized specific impedance, Zn, otherwise the values are real and imaginary parts of Zs.


ImpType=Admittance

For example

  WallImpedance "I1"             WallImpedance "I1"
    ...                            ...
    ImpType=Admittance             ImpType=Admittance
    Normized=true                  Normized=false
    Value=0.655, 0.087             Value=0.0016, 0.000212
    ...                            ...

Similar to the above but the values specify now admittance values according to Y = 1/Z.
