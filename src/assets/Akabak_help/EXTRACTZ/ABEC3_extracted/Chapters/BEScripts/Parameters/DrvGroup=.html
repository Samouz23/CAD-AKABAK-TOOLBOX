Identifier DrvGroup=
Format Integer number
Purpose Index (name) of a driving group
Used in Diaphragm, Pressure_Points, Pressure_Box, VibFile, Driving, (Solving)
Driving_Values, Radiation_Impedance, (Observation)
RadImp, Driver, Speaker, Enclosure (LEScript)
See also Driving Groups

As explained in chapter Driving Groups there are no physical driving values at the Boundary Element solving-stage. The driving is only marked with the help of a handle, which we assign to DrvGroup=. The handle can be any integer number, for example DrvGroup=1001 or DrvGroup=10123 and so on. It should be unique.

For example

  Diaphragm  "Cone front"
    DrvGroup=1001
    Side=Front
    SubDomain=3
    ...

The physical driving value is specified in the observation script or in the Lumped Element script, respectively.

Example for fixed driving in observation script:

  Driving_Values
    DrvType=Acceleration
    Value=1.0
    101   DrvGroup=1001   Weight=1.0   Delay=0ms
    ...

Example for Lumped Element driving:

  Driver  'Drv1'  Def='SP38'
    Node=2=0=10=20
    DrvGroup=1001,1002
  RadImp 'Front'
    Node=10     DrvGroup=1001
  RadImp 'Rear'
    Node=20     DrvGroup=1002
