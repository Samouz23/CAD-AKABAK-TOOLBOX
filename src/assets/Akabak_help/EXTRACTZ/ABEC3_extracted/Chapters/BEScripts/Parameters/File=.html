File=

Home » Scripts

Identifier File= (Has no section)
Format String
Purpose Relative filename of embedded script
Used in Scripts

File= is used to embed another file in a script. This helps structuring a project. The main purpose is sharing information across several scripts, such as Node- and Formula-sections.

For example

  ...
  File="Nodes.txt"

  // Embed mutual exclusively script with elements
  // either for sealed or vented enclosure.

  off File="Elements - Sealed.txt"

  File="Elements - Vented.txt"

  Control_Solver
    f1=20;  f2=500;  NumFrequencies=30;  Abscissa=log;
    ImpedanceNumFrequencies=100
    Sym=y; Dim=3D
    MeshFrequency=1500Hz
    Meshing=Bifu
  ...

Embedded files are displayed on the desktop of ABEC, for example
