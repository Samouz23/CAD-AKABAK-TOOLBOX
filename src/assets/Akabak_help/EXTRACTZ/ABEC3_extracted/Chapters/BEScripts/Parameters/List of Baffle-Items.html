Purpose List of Baffle-Items.
Used in Baffle

A Baffle-Item describes a geometric feature within the Baffle-plane, such as a hole or an aperture for another component.

Each Baffle-Item is specified by an individual line, which typically starts with an index followed by a set of parameters. The list of Baffle-Items should follow the main-parameters of the Baffle.

In each line, parameters should be separated by a blank or a tab. Parameters should be within a single line (contrary to the following list).


  <Index>
     Ref="<Name of Component>"
     <Name of Shape>
     d=  W=  H=
     xc=  yc=   x=  y=   z=   rot=
     EdgeLength=
     SwapNormals

For example:

  Baffle  "B1"
    Subdomain=1
    EdgeLength=25mm, 25mm
    Position=2001, 2002, 2003  RefNodes="N"
    WB=400mm;  HB=640mm; RectType=Rect  
    101  Ref="D1"   x=0mm    y=140mm
    102  Ref="D2"   x=0mm    y=-50mm
    103  Ref="Du1"  x=0mm    y=-220mm
    104  Ellipse    x=150mm  y=280mm   Rot=40  W=70mm  H=30mm   EdgeLength=2mm

Parameters

Index

The first entry is an index, which becomes the "name" of a Baffle-Item.

Ref=

Ref= is the name of another component in the script. If specified then that component will be positioned on the Baffle, and a matching hole will be implemented. Currently, Ref= can reference following components: Diaphragm, VibFile, Shell and Duct.

Note, parameter Ref= is used only for positioning. A component can be referenced (positioned) only once.

Name of Shape

If specified then a simple hole will be implemented. The shape of the hole can be

Disc, Rectangle, Ellipse, Oval

Size of Shape (d= W= H=)

If the shape of the hole is specified then we need to enter also the size of the hole

d= is the diameter in units m.

W= H= are the width and height in units m.

Position

The global position and orientation of all Baffle-Items is given by the position of the Baffle plus local coordinates, x an y, assuming a flat surface.

There are two scenario: (1) Baffle is positioned with the help of parameter Position= plus size-parameters, such as WB=; HB=, or, (2) Baffle is positioned with the help of parameter Vertices=.

(1) Position= In this case the origin of local coordinates x= and y= is in the center of the Baffle-shape.

(2) Vertices= In this case there are two choices:

(2.1) Origin at the Center

xc= and yc= can be used to position Baffle-Items with regard to the point of gravity of the Baffle.

(2.2) Origin at the Vertex

x= and y= assume the origin to be at the first vertex (P1) of the Baffle.

Rotation

Each Baffle-Item can be rotated about its axis. The parameter is

Rot=

Units = deg

For example Rot=40 is used in the example above in order to rotate the Ellipse by 40 degree.

EdgeLength=

As elsewhere, EdgeLength= controls the meshing. Here, EdgeLength= is used only for holes as described at paragraph Name of Shapes. The single value of EdgeLength= is the length of elementary edges along the shape used for mesh-generation.

For referenced components, see parameter Ref=, EdgeLength is derived internally from the associated component.

Extrusion (z=)

Parameter z= allows the local extrusion of the baffle-item.

Units = m

SwapNormals

SwapNormals or SwapNormals=true inverts the normal of the generated boundary elements of the extrusion. If there is no extrusion (z=0) then SwapNormals is ignored.

For example, assuming Sym=xy:

  Baffle 'BR'
    Subdomain=1
    EdgeLength=40mm, 40mm
    Position=z;  WB=400mm;  HB=640mm; RectType=Oval;
    101   Disc  d=50mm   x=50mm  y=50mm  z=150mm  SwapNormals
SwapNormals=false SwapNormals=true
