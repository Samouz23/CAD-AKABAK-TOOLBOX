Identifier Dim=
Format [3D, 2D, CircSym]
Purpose Dimension of boundary elements
Used in Control_Solver
See also Sym=

Dim= specifies the dimension of the Helmholtz Integral of the Boundary Element Method.

By default Dim=3D. However, calculation time can be quicken if part of the integrations can be done analytically. In this case we make assumptions on the expected sound pressure distribution. For example, if the structure is circular- symmetric then we expect that the sound pressure is also circular-symmetric. Hence, physically it is still a 3D-problem but from the point of nummerical integration it is a quasi 2D-calculation.

Dim= is specified in section Control_Solver, for example

  Control_Solver
    f1=500;  f2=10000;  NumFrequencies=30;  Abscissa=log;
    MeshFrequency=10000Hz
    Dim=3D
    Sym=xy

Dim=3D is the default mode and enables full 3D-fields of sound pressure distribution. 3D-symmetries can be exploited with the help of parameter Sym=. In the far-field the sound pressure drops typically by 1/Distance.


Dim=CircSym assumes a field of a circular symmetry. This means pressures are identical along concentric rings. Because of this also boundaries should be of a circular symmetric design and need to be entered as described in chapter Coordinates. Under circular symmetry part of the analysis is carried out analytically, which accelerates the calculation. In the far-field the sound pressure drops by 1/Distance.


Dim=2D assumes that one dimension can be fully separated from the Helmholtz Equation and we assume wave-propagation only in the x- and y-plane. In the other plane we assume no excitation of waves. In the far-field the sound pressure drops only by 1/sqrt(Distance). This is an artefact, which stems from the assumption of infinite extension in the z-direction. Pressure is understood as per meter: "SPL/m"

Strange - yes - but useful in cases. First, the Dim=2D approach is quick in terms of calculation time. Further, geometry is easily specified because boundaries are line-segments. Dim=2D is mostly used to obtain an impression or a clue about the wave-field in a room or in the presence of scatteres. Absolute SPL-values need to be considered in practical applications because the Dim=2D assumes infinite long wakes of waves which in reality are spherical.
