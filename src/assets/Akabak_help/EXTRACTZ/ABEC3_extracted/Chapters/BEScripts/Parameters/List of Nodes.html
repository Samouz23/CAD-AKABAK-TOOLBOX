Units m
Purpose Coordinates of a node (vertex).
Used in Nodes

After the parameter part of the Nodes-section, a list of coordinates follows. Each line represents a point in space (node). Each value should be separated by a blank, tab or comma. The format is

    <Index>   <Coordinate1>   <Coordinate2>   <Coordinate3>

For example

  Nodes   "NF"
    Scale=1mm
    2001    0.0       0.0     712.0
    2002    0.0     227.0     712.0
    2003    0.0     227.0       0.0
    2004    0.0       0.0       0.0
    2005    0.0     227.0     175.0
     ...

Index

The first value is an arbitrary integer value and represents the "name" of this node. This index should be unique within a Node-section. Elements will take reference to this index.

Coordinates

Following the index-column there are coordinate-values. Three values for Dim=3D and two for Dim=CircSym.
