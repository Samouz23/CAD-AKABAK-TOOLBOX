Identifier ft=
Units Hz
Format Floating-point number
Purpose Frequency dependency of Value=
Used in WallImpedance
See also ImpType=, Normalized=, Value=

The parameter ft= allows to provide a simple schema of frequency dependency of Value=.


If ft > 0 then damping is applied above ft= according to:

  Z(f) = Z·(1 + ft2/f2)

If ft < 0 then damping is applied below ft= according to: 

  Z(f) = Z·(1 + f2/ft2)

Note, that a 100% reflecting boundary features Z → ∞ (Neumann), and a 100% damping boundary has Zs = ρc, which is equivalent to the impedance of a free-field plane-wave.

In the case DataFileAlias= is specified, ft= is ignored.
