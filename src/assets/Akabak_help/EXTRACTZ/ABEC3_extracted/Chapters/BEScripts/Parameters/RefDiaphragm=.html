Identifier RefDiaphragm=
Format String
Purpose Reference to other Diaphragm
Used in Diaphragm

RefDiaphragm= belongs to a mechanism, which facilitates entering parameters for a Diaphragm-section. It is possible to daisy chain Diaphragm-sections, where each linked Diaphragm inherits all parameters of its reference as default settings.

In this way it is easy to enter arrays of Diaphragm. Reference is also useful for speaker membranes where we use front and rear, see example at Side=

RefDiaphragm= is a string and relates to the name of another Diaphragm-section.


For example, there are four speakers. Only the fist diaphragm is fully specified, all the others take reference and over-write only the Position=, Subdomain= and DrvGroup=. 


  Diaphragm  "Woofer1"
    DrvGroup=1001
    SubDomain=3
    EdgeLength=20mm
    Position= MeshFileAlias=M Include 6
    NoBaffle
    Simple=true
    Side=Front
    dD=120mm
    tD1=20mm
    dD1=20mm
    hD1=5mm

  Diaphragm "Woofer2"
    RefDiaphragm="Woofer1"
    SubDomain=3
    DrvGroup=1002
    Position= MeshFileAlias=M Include 32

  Diaphragm "Woofer3"
    RefDiaphragm="Woofer1"
    SubDomain=3
    DrvGroup=1003
    Position= MeshFileAlias=M Include 2

  Diaphragm "Woofer4"
    RefDiaphragm="Woofer1"
    SubDomain=3
    DrvGroup=1004
    Position= MeshFileAlias=M Include 36
