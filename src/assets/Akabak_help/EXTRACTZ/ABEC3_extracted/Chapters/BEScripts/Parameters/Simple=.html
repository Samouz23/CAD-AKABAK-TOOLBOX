Identifier Simple=
Format Boolean
Purpose If true then a simplified meshing is applied
Used in Diaphragm, Shell

Simple= is used for Diaphragm and Shell element generators. By default Simple=false, otherwise ABEC creates a simplified version of the device, which might be sufficient for low-frequency analysis.

Simple=true

If Simple=true is specified then a simpler shape is produced by the Diaphragm- or Shell-factory, which often is sufficient, especially at low frequencies.

If in low-resolution-mode (Simple=true) then only Meshing=Bifu is possible. Also only circular shapes will be meshed.

If in low-resolution-mode (Simple=true) suspension specification of the Diaphragm, ws= is ignored and assumed to be part of the outer dimension of the diaphragm. It is common practice to add half of the suspension-width on both sides, or in other words dD = dD0 + ws

If in low-resolution-mode (Simple=true) a Diaphragm would not render the magnet-details for Side=Rear.

Simple=false

If in high resolution-mode (Simple=false) and if the width of the outer suspension, ws= is specified in the Diaphragm-section then a suspension is modeled. In this case the exact modeling also depends on the type of Meshing=. With Meshing=Delaunay the velocity distribution is linearly deceasing. With Meshing=BiFu the velocity profile of the suspension is mimicked with the help of two rings. The inner ring vibrates with the given value and the outer is not moving at all. The outer becomes an extension of the baffle, which is also indicated by the color.
