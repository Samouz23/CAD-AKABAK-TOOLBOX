f1=; f2=

Home » Scripts

Identifier f1=; f2=
Units Hz
Format Floating-point number
Purpose Frequency range from f1 to f2
Used in Control_Solver, Control_Field, Control_Spectrum
See also NumFrequencies=, Abscissa=, Frequencies=

f1= and f2= can be used to specify a range of frequencies. The range goes from f1 to f2 and includes both values. The actual grid depends of further parameters, such as NumFrequencies= and Abscissa=.

For Boundary Element Analysis it is possible to include f1=0. In this case Abscissa=lin. For f > 0 the Helmholtz Equation and for f1=0 the Poisson Equation is solved.

For example

  Control_Solver
    f1=200Hz;  f2=5kHz;  NumFrequencies=50;  Abscissa=log
    MeshFrequency=15kHz
    Sym=xy;  Dim=3D
    Meshing=Delaunay

f1= and f2= accepts simple floating point numbers as well as units Hz in ENG-format. For example: 5000, 5000Hz or 5kHz.
