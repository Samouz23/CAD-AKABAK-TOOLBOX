Identifier Offset=
Units m
Format Floating point number
Purpose Offset of arc.
Used in BE_Spectrum
See also BasePlane=

Offset= is a parameter of BE_Spectrum with PlotType=[Directivity,Arc].

It provides a shift of the arc in on-axis direction.

Note, Offset= works only if BasePlane= is used with symbols. For example

  BE_Spectrum
    PlotType=Directivity
    Distance=1m
    PolarRange=-90, 90, 19
    BasePlane=zx
    Offset=10mm
    101   0.0  ID=100
