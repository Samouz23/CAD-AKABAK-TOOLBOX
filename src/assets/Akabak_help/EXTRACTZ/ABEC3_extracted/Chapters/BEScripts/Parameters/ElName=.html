Identifier ElName=
Format String
Purpose Identification of a component of Lumped Element Analysis
Used in LE_Spectrum
See also System=, Port=, Node=, AnalysisType=

ElName= identifies a particular Lumped Element component for observation of spectra.

ElName= is only necessary for inspecting flow-parameters such as AnalysisType=[Current, Excursion, Velocity, Acceleration, VolVelocity] and AnalysisType=Power.


Example

If we want to inspect the current into the electrical port of a loudspeaker-Driver of name 'Drv' then the section of the observation script could look like this:

  LE_Spectrum
    AnalysisType=Current
    System='S1'
    101  ElName='Drv'  Port=1  ID=10001

The associate LE-script could look like this:

  System 'S1'
    Driver  'Drv'
      Def='Drv1'
      Node=1=0=10=20
    ...
