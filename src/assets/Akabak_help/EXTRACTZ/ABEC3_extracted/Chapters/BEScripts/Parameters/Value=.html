Identifier Value=
Format Floating point number
Purpose Constant for wall-impedance or driving values.
Used in WallImpedance, Driving_Values

Value= is a constant giving default values to WallImpedance and Driving_Values.

WallImpedance

As explained in section WallImpedance the meaning of Value= depends on parameter ImpType=. See at ImpType= for details, formulae and examples.

If WallImpedance is linked to a data-file, ie if DataFileAlias= is specified, then Value= is ignored.

ImpType=Reflection

Value= is a floating point value between 0...1.0.

Value=0 means no reflection, and boundary conditions equivalent to an impedance of a free traveling plane-wave: Zs = ρc.

Value=1 means 100% reflection and Neumann boundary conditions, which is the default in ABEC.

ImpType=Damping

Value= is a floating point value between 0...1.0.

Value=0 means no damping and Neumann boundary conditions, which is the default in ABEC.

Value=1 means 100% damping, which are boundary conditions equivalent to an impedance of a free traveling plane-wave: Zs = ρc.

ImpType=Impedance

Value= means an impedance-value. It expects one or two values. The first value is the real-part and the second is the imaginary part of the impedance. Both values are separated by a blank, tab or comma. For example Value=0.123, -0.01

If Normalized=true the values of Value= are assumed to be normalized to ρc, which is the specific impedance of a free travelling plane-wave.

If Normalized=false or not specified then the values of Value= are assumed to be a specific impedance Zs = p/v.

ImpType=Admittance

Value= means an admittance-value. An admittance is the inverse of an impedance: Y = 1/Z  The specification is similar to ImpType=Impedance.

If Normalized=true the values of Value= are assumed to be normalized to 1/ρc, which is the specific admittance of a free travelling plane-wave.

If Normalized=false or not specified then the values of Value= are assumed to be a specific admittance Ys = v/p.

Driving_Values

As explained in section Driving_Values physical values are assigned at observation-stage. Value= provides the static and physical driving value. Its meaning and units depend on DrvType=.

Weighing

Value= will weight imported values of the spectrum assigned by DataFileAlias=.

Value= will be modified by Weight= parameter of items of List of Driving Values.

Units

If no unit is given then SI-units are assumed otherwise the unit depends on DrvType=:

  Excursion       m             Value=1mm
  Velocity        m/s           Value=1e-3m/s
  Acceleration    m/s2          Value=1e-6m/s2
  Pressure        Pa            Value=0.1Pa

Examples

  Driving_Values  "Point Sources"
    DrvType=Pressure
    Value=1Pa
    101   DrvGroup=1001  Weight=1.0  Delay=1ms
    102   DrvGroup=1002  Weight=1.0  Delay=0
    ...

  Driving_Values  "Membranes"
    DrvType=Acceleration
    Value=1m/s2
    DataFileAlias=A1
    101   DrvGroup=1001  Weight=1.0
    102   DrvGroup=1002  Weight=1.0
    ...
