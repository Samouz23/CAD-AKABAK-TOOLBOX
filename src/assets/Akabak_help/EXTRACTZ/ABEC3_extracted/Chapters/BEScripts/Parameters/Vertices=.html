Identifier Vertices=
Purpose Vertices of Baffle
Used in Baffle

Use parameter Vertices= in order to define the geometry of the Baffle-component.

For example

  Baffle
    Subdomain=1
    EdgeLength=25mm, 25mm
    Vertices=1001, 1002, 1003, 1004  RefNodes="N"
    101  Ref="D1"   xl=0mm  yc=140mm  Rot=0
    102  Ref="D2"   xl=0mm  yc=-50mm  Rot=0
    103  Ref="Du1" xl=0mm  yc=-240mm Rot=0
    104  Ellipse  W=70mm  H=30mm  xr=50mm  yt=50mm Rot=40  EdgeLength=2mm

Vertices= expects a list of node-indices of coordinates specified in section RefNodes=. Each coordinate forms a vertex of the plane.

The first coordinate forms also the reference point for the local 2D-coordinate system of the Baffle-Items.
