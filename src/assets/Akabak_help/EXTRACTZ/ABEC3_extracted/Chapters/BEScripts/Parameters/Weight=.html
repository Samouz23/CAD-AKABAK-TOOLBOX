Identifier Weight=
Format Floating point number
Purpose Individual amplitude-weighing of item-values
Used in List of Driving Elements, List of Pressure Points, List of Driving Values
See also Delay=

Weight= can be used to modify the driving-value. Its default value is Weight=1.0.


Weight= is a parameter of list-items. for example

  Driving  "Front"
    DrvGroup=1001
    RefElements="Exterior"
    Direction=101,102,103
    101    101    Weight=1.0
    102    102    Weight=1.0
    103    103    Weight=0.5

Weight= is also used to weight the driving-value at observation-stage, for example:

  Driving_Values  "Point Sources"
    DrvType=Pressure
    Value=1Pa
    101   DrvGroup=1001  Weight=1.0  Delay=1ms
    102   DrvGroup=1002  Weight=1.0  Delay=0
    ...
