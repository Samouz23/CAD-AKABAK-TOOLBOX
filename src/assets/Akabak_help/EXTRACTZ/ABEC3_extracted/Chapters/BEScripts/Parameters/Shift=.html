Identifier Shift=
Format 3 floating point numbers
Units m
Purpose Translation
Used in Subdomain_Properties, MeshFile_Properties, Nodes, Elements, Baffle, Diaphragm, Shell, Field, BE_Spectrum
See also Scale=, Rotate=, Mirror=

Shift= translates coordinate definitions. There are three values. The first translates in x-direction, the second in y- and the third in z-direction.

You can use Units for each value.

Shift= values are not affected by Scale=.

The order of specification of Shift=, Rotate= and Mirror= matters.


For example

  Elements "Chamber1"
    Shift= 200mm, -700mm, 0
    RefNodes="Chambers"
    SubDomain=1
    100   1000 1001 1002 1003  // Top
    101   2000 2001 2002 2003  // Bottom
    ...
