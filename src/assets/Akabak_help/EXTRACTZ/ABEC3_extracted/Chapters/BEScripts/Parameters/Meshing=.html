Meshing=

Home » Scripts

Identifier Meshing=
Format [Bifu, Delaunay]
Purpose Type of mesh-generator
Used in Control_Solver, Subdomain_Properties, Elements, Diaphragm, Shell, Baffle, Control_Field, Field
See also Boundary Meshing, EdgeLength=, MeshFrequency=

Meshing= controls the way the auto-mesher produces triangles for given input elements. The auto-mesher tries to produce a most regular mesh. The size of the elements are controlled by sibling parameters EdgeLength= or MeshFrequency=, respectively.

Meshing=Bifu

Meshing=Bifu is the default setting. In this mode each quadrilateral and triangle is split into two new shapes. If certain criteria are not met, such as aspect-ratio and size a new cycle of splitting is performed.

Quadrilaterals

A quadrilateral is first split into smaller quadrilaterals and finally triangularized. The sub-dividing is only performed if the quadrilateral has a larger aspect ratio than specified. The default aspect ratio is A=3.

However, the aspect ratio criterion can be altered by appending the value of A to "Bifu". The allowed range is A ≥ 1. For example, with A=2 the above meshing is obtained and the specification is:

  Elements
     Meshing=Bifu, 2
     ...

Triangles

Triangles are split into smaller triangles if its longest side is larger than EdgeLength=, or larger than the size, which is derived from MeshFrequency=.

Meshing=Delaunay

Meshing=Delaunay typically yields high quality meshes and can handle complicated shapes. Delaunay calculations are involved and may take longer to mesh than Bifu.

Delaunay meshing runs through a loop in order to split boundaries and place new vertices. Normally, this loop is exited after some iterations only, but can fail if conditions cannot be matched. In this case an error message is output.

EdgeLength=

For Delaunay meshing the parameter EdgeLength= can have two values, for example:

  Elements  "Tri"
    Meshing=Delaunay
    EdgeLength=2m, 1m
    ...

The first value specifies the maximum size of a side of a triangle as usual. The purpose of the second value is to prevent the generation of edges of length smaller than this values. The second value is optional. If not specified then it is set to 10% of the first value internally.

For example, the top-triangle was meshed with the default setting. The bottom-triangle was meshed with the second value being set to 50% of the first value of EdgeLength=. In this case it prevents the generation of tiny triangles in the acute corner.

Maximum Number of Loops

Meshing=Delanauy can be supplemented with an integer-value, which controls the Delaunay main-loop. By default this loop is stopped after N=1000 iterations. In this case an error is raised. In special cases it may be helpful to increase this number, for example:

  Elements  "Tri"
    Meshing=Delaunay, 2000
    ...

Skinny Angle Limit

Meshing=Delanauy can be supplemented with an angle-value, which is the Skinny Angle Limit. By default its value is to 20°. The Delaunay algorithm tries to avoid creating triangles with minimum angles smaller than this value. In rare occasions it might be helpful to be able to alter this value, for example

  Elements  "Tri"
    Meshing=Delaunay, 1000, 10
    ...

Note, that in this case the interpreter also expects the loop number as the first supplement followed by the Skinny Angle Limit (10deg in the above example).
