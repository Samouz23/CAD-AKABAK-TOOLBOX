Identifier Position=
Purpose Position of shape
Used in Diaphragm, Shell, Duct, VibFile, Baffle

Boundary Element Components, such as the Diaphragm, Shell, Duct, VibFile and the Baffle need positioning. Position= specifies the mounting-point and the orientation of the device.

The mounting-point, P1, is always the center point of lateral extension. In the other dimension, the mounting point is in the plane of the outer rim. For example, the outer suspension of a loudspeaker-diaphragm, the aperture of the duct or the opening of the shell-component.

Position= can be specified in a various of ways.

  • Position Triangle
  • Direction-Specifiers
  • Mesh-File
  • Local Angular Parameters
  • Offset

Using the Positioning Triangle

Items can be positioned with the help of a positioning triangle. This technique appears a little bit abstract at first, is however practical in many cases because, often, the necessary coordinates are readily available. See also at chapter Planes.

P1 gives the absolute position and is the mounting point as described already.

P2 and P3 are there to provide orientation. The length of P2 and P3 can be arbitrary. The direction of the device-axis is identical to the normal of the triangle:

N ∝ P2 x P3

P2 controls axial rotation. The local x-axis of the device is aligned with the vector from P1 to P2.

P3 controls the inclination of the device-axis, together with P2.

Position= can be assigned three node-indices. The first is the index of P1, the second and third belong to P2 and P3. For example:

  Diaphragm  "D1"
    ...
    RefNodes="N"
    Position = 1001  1002  1003
    ...

Alternatively, RefNodes="N" can be also inline with the other parameters of Position=, no semi-colon needed. For example

  Diaphragm  "D1"
    ...
    Position = 1001  1002  1003   RefNodes="N"
    ...

Using Direction-Specifiers

If you want to align the orientation with one of the coordinate-axis then direction-specifiers are convenient:

x, y, z,   xy, xz, yz, yx, zx, zy   (Dim=3D)

pos, neg   (Dim=CircSym)

x, y, z are device-axis-directions, and xy ... zy are planes which normal becomes the device-axis. A negative-sign inverts the direction. Pos and Neg are used for Dim=CircSym and point along the axis.

For example

  Diaphragm
    ...
    Position= z   Offset=10cm

"z" means that the Diaphragm-axis points along the z-axis, and that there is an offset of 10cm.


  Nodes "N"
    1001  0  0  10cm

  Diaphragm
    ...
    Position= 1001   z   RefNodes="N"

The above yields the same result only that we make use of a coordinate entry in list "N".


  Diaphragm
    ...
    Position= x   Offset=10cm

"x" means alignment with the x-axis and an offset by 10cm in this direction.

Using a Mesh-File

Positions can also be based on mesh-file-planes. The schema is similar to Using Position Triangle, above. However, with mesh-files the orientation-triangle is constructed from the assigned mesh-triangles. P1 is the center-point of all included triangles. In case symmetry is exploited the shape gets expanded first. The normal is deduced from the first triangle of the set, assuming the control-plane is flat.

The syntax is similar to the one explained in List of Boundary Elements by Mesh-File, for example:

  Diaphragm  "D1"
    ...
    Position= MeshFileAlias=D Include 10  SwapNormals Rot=-57.9
    ...

Note, that in this context SwapNormals can be used to invert the normal of the control-plane, which yield the Diaphragm to point the other way.

Often, the control-plane may yield a wrong axial rotation. For a circular diaphragm or a duct the axial rotation can be arbitrary. However, for rectangular or oval shaped cross-sections we may need to adjust the axial rotation with the help of parameter Rot=, as explained below.

Local Angular Parameters

Unit: Degree

At positioning you have additionally available local rotation angles. In this case the component is first rotated locally and then translated to specified coordinates as described above.


Rot= is an angle in degree, which rotates the Diaphragm (or any other shape) about its main-axis.

theta= and phi= are spherical coordinate angles in degree and centered at point P1.

SwapNormals will add 180° to theta and, hence, the device will point to the inverted direction.

For example

  Diaphragm  "D1"
    ...
    Position= z theta=90  phi=70  rot=20
    ...

In the above example the basic position is so that the membrane-axis points along the z-axis. Theta=90 rotates about the y-axis, i.e. the membrane-axis points now along the x-axis. Then, Phi=70 rotates about the z-axis. Eventually, the membrane is rotated by Rot=20 about its device-axis.


Instead of the orientation-specifier "z" you can also use a node-index

  Diaphragm  "D1"
    ...
    RefNodes="N"
    Position= 1001 theta=90  phi=70  rot=20
    ...

SwapNormals and rotation-angles are particularly useful in connection with positions derived from mesh-file-planes. For example

  Diaphragm  "Horn"
    DrvGroup=1005
    SubDomain=2
    Side=Front
    dD=1in
    NoBaffle
    Position= MeshFileAlias=D Include 10   Rot=-57.9 SwapNormals

Offset=

Units: m

Position= parameter can be offset in direction of the device-axis with the help of inline-parameter Offset=

For example

  Diaphragm
    ...
    Position= x   Offset=10cm
