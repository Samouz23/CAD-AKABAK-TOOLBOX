Identifier DataFileAlias_Vert=
Format String
Purpose Data-file with frequency-spectra.
Used in Pressure_Box
See also DataFileAlias_Horiz=

DataFileAlias_Vert= expects an alias to a data-file, which has been registered with the project, see Add Data-File.

The associated file of DataFileAlias_Vert= weights the directivity in vertical direction.

The expected format of the data-file is explained in Data Files-Spectrum.
