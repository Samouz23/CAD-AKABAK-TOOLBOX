Identifier UseLineScan=
Format Boolean
Default UseLineScan=false
Purpose If true then line-scan is enforced.
Used in VibFile

As explained in chapter VibFile ABEC makes use of the whole 3D-data set of a VibFile if available and applicable, ie. if Dim=3D and Sym=no symmetry.

With the help of parameter UseLineScan= you can enforce the line-scan mode for any configuration. Line-scan means that VibFile data have been averaged in circumferential direction.
