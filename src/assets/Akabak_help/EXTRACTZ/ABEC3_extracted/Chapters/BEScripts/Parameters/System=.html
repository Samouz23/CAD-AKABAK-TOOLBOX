Identifier System=
Format String
Purpose Identification of network of Lumped Element Analysis
Used in LE_Spectrum
See also ElName=, Port=, Node=, AnalysisType=

System= identifies the hosting System of the Lumped Element Network for observation.

For example, if the Lumped Element script specifies a System named "S1", such as

  ...
  System 'S1'
    Driver
      Def='Drv1'
      Node=1=0=10=20
    Enclosure  'Eb'
      Node=20
      Vb=120cm3  Qb/fo=0.1
    ...

then the observation script for spectra should specify this system. For example:

  LE_Spectrum
    AnalysisType=Impedance
    System='S1'
    ID=110
