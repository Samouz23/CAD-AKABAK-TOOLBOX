Identifier Abscissa=
Format [lin, log]
Purpose Frequency distribution
Used in Control_Solver, Control_Field, Control_Spectrum
See also f1=; f2=, NumFrequencies=, Frequencies=

Abscissa= specifies the distribution-type of frequency points.

The default value is Abscissa=lin.

Abscissa=lin

With Abscissa=lin calculation points are distributed linearly with a constant spacing of

df = (f2 - f1)/(N - 1)

with N is the specified value of NumFrequencies= and f1 and f2 as specified by f1=; f2=

The generating formula is

fi = i*df + f1

with i running from i = 0 ... N-1

Abscissa=log

A logarithmic distribution has a high density at low frequencies and a low density at high frequencies (note, the points are distributed exponentially, the density is logarithmic).

On a log-paper the spacing of points appears constant with ratio of neighboring frequencies

r = e(ln(f2) - ln(f1))/(N - 1)

The generating formula is

fi = ri·f1

with i running from i = 0 ... N-1


Note, if you want to calculate f2= from points per octave (ppo) given f1= and NumFrequencies=

f2 = 2(N/ppo)·f1

For example

  Formula
    { f1= 200;  Nf=30;  ppo=6 }

  Control_Solver
    f1={ f1 }
    f2={ 2^(Nf/ppo)*f1 }
    NumFrequencies={ Nf }
    Abscissa=log
    MeshFrequency=15kHz
    Sym=xy;  Dim=3D
    Meshing=Delaunay

In the above example f2=6400Hz.
