Purpose List of LE_Spectrum observation points.
Used in LE_Spectrum

The list of observation points follows the parameter part of the LE_Spectrum-section. Each line represents a particular observation within the Lumped Element Network.

Each item of the line should be separated by a blank or tab.

This format depends on AnalysisType=. However some items are common to all types.

Common Parameters

    <Index>    ...    ID=

Index

The first entry is an index, which becomes the "name" of the spectrum at the observation point.

ID=

ID= is an arbitrary and unique string which links an ABEC-data-set to a VACS curve. See ID=.

AnalysisType = Power

For AnalysisType=Power the component is specified with the help of System=, ElName= and optionally Port=.

System= identifies the particular network hosting the component. It expects a string identical to the one of the targeted System= of the LE-Script.

ElName= identifies the component by name.

Port= is optional and it is useful if the component has more than two poles.

In order to calculate the total input-power of a System omit the List of LE-Spectrum Items and specify only System=.

For example

  LE_Spectrum
    AnalysisType=Power
    System=S1
    101   ElName=Drv1   Port=1   ID=01
    102   ElName=Drv1   Port=2   ID=02
    103   ElName=Drv1            ID=03

We seek to output the power of component ElName=Drv1. In this example "Drv1" is an electro-acoustic transducer with four poles, hence two ports. There will be rendered three curves. The first is the power into Port=1, which, in this case, are the electrical terminals. The second is the power into Port=2, which here is the acoustical port. The last curve lacks the Port= specification, which triggers the default. For the electro-dynamic Driver the default is the electric power in the voice-coil resistance Re.

AnalysisType = [Impedance, Admittance]

This AnalysisType= can only applied to the whole System. Hence there is no List of LE-Spectrum Items.

For example

  LE_Spectrum
    AnalysisType=Impedance
    System=S1
    ID=11

AnalysisType = [Voltage, Force, Pressure]

For this AnalysisType= the potential is specified with the help of

  • System= and Node=
  • System=, ElName= and Port=

The first specification allows to inspect any potential difference inside the network as explained in chapter Node=.

The second inspects the potential difference at the port of the component with name given by ElName=. For multi-poles Port= specifies the potential difference across a particular pair of terminals.

System= identifies the particular network hosting the component. It expects a string identical to the one of the targeted System= of the LE-Script.

For example

  LE_Spectrum
    AnalysisType=Voltage
    101  System=S1   ElName=Drv1   Port=1   ID=21

In order to calculate the total input-potential of a System omit the List of LE-Spectrum Items and specify only System=.

AnalysisType = Current

In order to calculate the total input-current to a System omit the List of LE-Spectrum Items and specify only System=.

AnalysisType = [Excursion, Velocity, Acceleration]

In order to calculate the total input-motion to a (mechanical) System omit the List of LE-Spectrum Items and specify only System=.

AnalysisType = VolVelocity

In order to calculate the total input-volume-velocity to a (acoustical) System omit the List of LE-Spectrum Items and specify only System=.
