List of Boundary Elements

Home » Scripts

Purpose List of node-indices.
Used in Elements

The list of boundary elements follows the parameter part of the Elements-section. Each line represents a plane, which is formed by nodes (vertices), see also Nodes and Elements. Each index should be separated by a blank, tab or comma. The format is

    <Index>    <Node-index1>   <Node-index2>   <Node-index3>   <Node-index4>  RefNodes=

Index

The first entry is an index, which becomes the "name" of an element.

Node-Indices

The second and subsequent entries are node-numbers from a list to which RefNodes= points.

RefNodes=

Optionally you can specify RefNodes= individually.

Dim=3D

With Dim=3D of Control_Solver there are either three of four entries, which describe a quadrilateral or a triangle, respectively. 

  Elements "Enclosure-Interior"
    RefNodes="N"
    ...
    101   2201  2204  2203  2202  | rear wall
    102   2001  2201  2202  2002  | top wall
    103   2004  2003  2203  2204  | bottom wall
    104   2002  2202  2203  2003  | side wall
    301   2001  2002  2131  2102  | baffle
    302   2102  2126  2119        | triangle
    ...

As described in chapter Normals and Volumes - 3D-Elements, the order of vertices controls the direction of the normal, which should point always into the domain. The domain is the volume enclosed by the boundary elements. For ElType=Interior the normals should point into the enclosed volume. For ElType=Exterior normals should point away from the body.

At solving stage all quadrilaterals are split into triangles, however currently there is no check on the "warpedness" of the quadrilateral. It is recommended to use approximately flat shapes.

Dim=CircSym

In the axis-symmetric case there are only two indices of points, P1 and P2, with P = (Axial, Radial)T. These points mark the edges of concentric rings. These rings generate the surface-area of truncated cone sections. For example:

  Elements "Cone"
    RefNodes="Nodes"
    Subdomain=1
    101   10  20    // Dust cap center
    102   20  30    // Dust cap outer
    103   30  40    // Cone first inner section
    104   40  50    // Cone and so on
    ...

As described in chapter Normals and Volumes - Circular Symmetric Elements, the order of vertices controls the direction of the normal, which should point always into the domain. The domain is the volume enclosed by the boundary elements. For ElType=Interior the normals should point into the enclosed volume. For ElType=Exterior normals should point away from the body.
