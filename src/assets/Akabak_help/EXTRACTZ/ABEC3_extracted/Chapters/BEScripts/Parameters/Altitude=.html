Identifier Altitude=
Units m
Format Floating-point number
Purpose Atmospheric altitude
Used in Control_Solver (Boundary Element),
Control_Field, Control_Spectrum (Direct Sound)
See also Acoustic Parameters,
c=, rho=, StaticPressure=, Temperature=

Altitude= belongs to the set of Acoustic Parameters.

Altitude= is measured above sea-level. The default value is Altitude=0.

Here Altitude calculates the static pressure approximately with the help of the Barometric Formula:

P = P0·(1 - 0.0065*H/(T0 + T))5.255

Formula taken from Wikipedia, with

H = Altitude in meter

P0 = 101325 Pa

T0 = 273.15 C and T temperature in degree Celsius.

For example

  Control_Solver
    f1=20;  f2=500;  NumFrequencies=20;  Abscissa=log;
    ...
    Altitude=500m;  Temperature=10C
