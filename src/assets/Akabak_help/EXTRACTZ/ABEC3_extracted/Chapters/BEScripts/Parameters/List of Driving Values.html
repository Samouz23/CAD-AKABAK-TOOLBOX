Purpose List of driving values.
Used in Driving_Values

The list of driven elements follows the parameter part of the Driving_Values-section. Each line represents an DrvGroup= which is driven. Each index should be separated by a blank, tab or comma. The format is

    <Index>    DrvGroup=          Weight=  Delay=  DataFileAlias=

or

    <Index>    <DrvGroup-index>   Weight=  Delay=  DataFileAlias=

Index

The first entry is an index, which becomes the "name" of a driving-value-item.

DrvGroup=

The second entry is the DrvGroup= of the solving-script, to which the value shall be assigned, see Driving Groups. Alternatively, you can omit "DrvGroup" and simply specify the DrvGroup-index.

Weight=

Weight= allows for weighing the amplitude of Value= of the parameter part.

Delay=

Delay= allows for adding delay to Delay= of the parameter part.

DataFileAlias=

DataFileAlias= allows to link an individual data-file to this driving-value item.



Example


  Driving_Values
    DrvType=Pressure
    Value=0.707
    101    DrvGroup=1001   Weight=+1.0
    102    DrvGroup=1002   Weight=-1.0

Alternatively you can omit "DrvGroup="

  Driving_Values
    DrvType=Pressure
    Value=0.707
    101    1001   Weight=+1.0
    102    1002   Weight=-1.0
