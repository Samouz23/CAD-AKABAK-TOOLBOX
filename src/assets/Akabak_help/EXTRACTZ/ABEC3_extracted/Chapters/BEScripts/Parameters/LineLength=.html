Identifier LineLength=
Units m
Format Floating point number
Purpose Length of distribution line.
Used in Pressure_Box
See also LineDir=, LineNumPoints=

If LineLength= is specified together with LineDir= and LineNumPoints=, Pressure_Box will distribute point sources along a line.

The length is measured from the first to the last point. The line is centered at the Position= point.

Note, with a line-source Pressure_Box ignores additional specified directivity-data in the direction specified by LineDir=. Linear interpolation is used with directivity data specified for the other direction.

For example

  Pressure_Box
    DrvGroup=1001
    Position= 1001 theta=90 phi=0   AxialRotate=0 RefNodes=P
    DrvWeight=1.0
    CabDim=50mm, 300mm, 30mm;  CabPos=0, -30mm, 0
    CardioLevel=-30dB
    DataFileAlias_Horiz=Dir_Horiz
    LineLength=200mm;
    LineDir=Vertical; LineNumPoints=10

In this example we have ten point-sources distributed along a line of LineLength=200mm. Each point is omni-directional in the (local) vertical plane and has a directivity given by the file DataFileAlias_Horiz=Dir_Horiz horizontally. In-between-points get interpolated linearly.
