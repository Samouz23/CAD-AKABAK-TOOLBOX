WD=; HD=

Home » Scripts

Identifier WD=; HD=
Units m
Format Floating point number
Purpose Width and Height of outer shape without the suspension.
Used in Diaphragm, Shell, Pressure_Box
See also Diaphragm shapes, RectType=, dD=, SD=, ws=

WD= and HD= are the outer dimensions of a rectangular diaphragm. WD= is the width and HD= is the height. See also sketches in Diaphragm shapes.

The particular shape can be selected with the help of parameter RectType=.

The width of the suspension is taken into account with the help of parameter ws=.

The width is along the local horizontal direction. Use AxialRotate= of the Position= parameter in order to rotate the diaphragm about its axis.
