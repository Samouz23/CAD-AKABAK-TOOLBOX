Identifier ID=
Format String
Purpose VACS-link to project or curve
Used in Control_Spectrum, BE_Spectrum, Radiation_Impedance, LE_Spectrum
See also VACS

ID= is a string forming a link-handle, so that curves in VACS can be updated.

The link-handle can be any string of literals, however it should be unique. If VACS cannot find a curve equal to the ID= then a new curve is created.

Each curve or directivity-plot should have a unique ID=. If the script does not specify an ID=, then ABEC creates one on the fly, which may alter if you delete a section in an observation script (Switching off a section with the help of Off maintains the automatic generated IDs, see Syntax).


The IDs of curves and directivities are concatenated to the ID= of Control_Spectrum. In this way it is easier to maintain uniqueness across several scripts and projects. The ID= at Control_Spectrum is created from parameter Name= but it is also possible to to specify it explicitly. This becomes practical if you work with several copies of a project. The way to get separate graph-sections in VACS, is to provide individual ID= in section Control_Spectrum.


Example


  Control_Spectrum
    Name="Simple_Horn"
    ID=Simple_Horn1


  Nodes  "Spectrum"
    1001   0   0   1.0

  BE_Spectrum
    RefNodes="Spectrum"
    GraphHeader="Sound pressure"
    BodeType=LeveldB;  Range=50
    101   1001    ID=1001

  BE_Spectrum
    PlotType=Directivity
    GraphHeader="Directivity"
    BodeType=LeveldB;  Range=50
    PolarRange=-90, 90, 37
    BasePlane=zx
    Distance=100
    101    Inclination=0.0    ID=2001
    102    Inclination=30.0   ID=2002

  Radiation_Impedance "Throat"
    GraphHeader="Throat Radiation Impedance"
    BodeType=Complex
    RadImpType=Normalized
    101   1001 1001   ID=3001
