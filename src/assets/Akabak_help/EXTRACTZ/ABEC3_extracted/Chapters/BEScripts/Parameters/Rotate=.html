Home » Scripts

Identifier Rotate=
Format 3 floating point numbers of Degree
Purpose Rotation of coordinate values
Used in Subdomain_Properties, MeshFile_Properties, Nodes, Elements, Baffle, Diaphragm, Shell, Field, BE_Spectrum
See also RotateX= RotateY= RotateZ=, Scale=, Shift=, Mirror=

Rotate= yields a combined rotation of the structure about xyz-axis. The structure is rotated anti-clockwise about the x-, y- and z-axis.

For example

  Nodes "N"
    Rotate = 90.0, 0.0, 45.0
    Scale=1in
    1001   0.0   0.0   0.0
    ...

In the above example all vectors (Nodes) of this section are first rotated by 90 deg about the x-axis, then by 45 deg about the z-axis.

Rotate= assumes a mathematical spherical coordinate system with poles on the z-axis.

The order of specification of Shift=, Rotate= and Mirror= matters.

Notes

If you need to change the order of rotation use the individual rotation parameters RotateX=; RotateY=; RotateZ=.

Parameter Position= is used at some components for orientation of the mounting point. This can be done by several means (triangle or mesh-file). This triangle gives position and direction of the, say, Diaphragm element. However, this orientation-triangle does not yield rotation about the axis of the component. If you need rotation of axis add RotateAxial=.

Rotation= replaces the the previously used parameter Rot=.
