Identifier ImpedanceNumFrequencies=
Format Integer number
Purpose Number of frequency points for Radiation Impedance
Used in Control_Solver
See also RadImp

ImpedanceNumFrequencies= can be declared in section Control_Solver, which specifies parameters for the Boundary Element Method.

ImpedanceNumFrequencies= is only used in rare cases on coupling the Boundary Element Acoustics to the Lumped Element Network. By default ImpedanceNumFrequencies=NumFrequencies.

ImpedanceNumFrequencies= specifies the number of frequencies points used for the abscissa of the coupling radiation impedance. Because, if specified, typically ImpedanceNumFrequencies > NumFrequencies ABEC interpolates impedance values of the solving stage.

The advantage is a higher frequency resolution for the coupling between the Boundary- and Lumped-Element domains. If results can be improved with ImpedanceNumFrequencies= should be found out experimentally. Typical applications are if the coupling is in a range of multiple acoustic modes.
