Identifier DiaphShape=
Format [Disc, Rectangle, Ellipse]
Purpose Shape of radiator
Used in Pressure_Box
See also dD=, WD= HD=

DiaphShape= specifies the radiating shape of a Pressure_Box. The shape can be DiaphShape=[Disc, Rectangle, Ellipse].

DiaphShape= simulates the far-field radiation pattern of the source.

Rectangle, Ellipse are aligned with the local coordinate system if Pressure_Box. The width is WD= and the height is HD=.
