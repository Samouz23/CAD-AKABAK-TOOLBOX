Identifier VibType=
Format [Excursion, Velocity, Acceleration]
Purpose Type of motion of imported data
Used in VibFile

VibType= is a parameter of section VibFile. VibType= specifies the type of the motion of the imported vibrational data. ABEC needs to convert these data into velocity. VibType= is either

  Excursion, Velocity, Acceleration

With linear spectral excitation the three types of motion are related by: 

  Excursion       v = x·jω
  Acceleration    v = a/jω

The default value is VibType=Velocity.

If the imported file of vibration-data already specifies the type of motion, then VibType is ignored (for example data from the Klippel Laser Scanner).
