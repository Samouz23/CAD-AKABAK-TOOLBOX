Identifier Sym=
Format [x, y, z, xy, xz, yz, xyz] [-xy, -xz, -yz, -xyz, -xzy, -yzx]
Purpose Symmetry of boundary elements or fields
Used in Control_Solver, Field
See also Dim=

Desktop/Views/Symmetries allows to toggle rendering of the mirrored symmetries.

Sym= specifies a symmetry for the Boundary Element Mode in order to speed-up calculation time. Sym= works only for the three dimensional mode (Dim=3D). For the Boundary Element Method, Sym should be specified at Control_Solver.

Sym= can also be used at observation of fields in order to create mirror images of the field without calculation. (see below).

The way of specification is by normals of the plane of symmetries. For example in case of Sym=x the x-axis is the normal of the plane of symmetry, which is the yz-plane. For two planes of symmetry use a specifier from the set [xy, xz, yz]. For example Sym=xy means that in the first step all coordinates are mirrored along the x-axis. In a second step all points are mirrored along the y-axis. Three planes of symmetry are rare and result in a symmetry in all 8 octants of a sphere.

Boundary Element Method

If Sym= is specified then ABEC expects only part of the model. It will then complete the structure by mirroring entries according to Sym=, which defines the axis along which to apply mirroring. For example, if you entered a point at x= 1.0, 0.0, 0.0 and Sym=x then the internal mirror-point would be at x'= -1.0, 0.0, 0.0.

This is also true for mesh-files. If you plan to exploit symmetry then create a copy of your CAD-drawing which shows only part of the whole structure.

The structure should be entered with the idea in mind that ABEC will complete the structure. For example, there should be no Boundary Elements in the plane of symmetry.

Note, that not only the field is mirrored but also all sources, such as Driven Elements, Diaphragm and Pressure_Points, etc.

Subdomains are mirrored as well. If a subdomain is complete in the original part of the structure then the whole sub-domain is copied. If the subdomain is across the plane of symmetry then it is made complete.

Sym= mirrors the structure only for the visual representation. Acoustically, we assume that also the pressure field is symmetric. For example, with Sym=x we assume that the field on the positive side of the x-axis is identical to the one on the negative side. The speed-advantage in calculation stems from the usage of special Green-functions. Not only integration is faster but also the size of the system-matrices to solve for are smaller. For one plane of symmetry this matrix is reduced to 1/4. For two planes it reduces to 1/8.

Sym= and Coupling to Lumped Element Network

If we have a source, which is not cut by the plane of symmetry then it will be duplicated. And because Sym= enforces symmetric fields this means that the mirrored source should be identical to the original. However, if we couple such sources to the Lumped Element Network we get a conflict here because the Lumped Element Network provides degrees of freedom, which may violate the symmetry.

For example, a speaker system with two drivers symmetrically spaced in a symmetric enclosure is a good candidate for exploiting symmetry. Basically, in this particular case, we have the choice between two planes of symmetry. If we cut horizontally we would duplicate the diaphragm. Hence we would have a single driver with two diaphragms... If we cut vertically, the two diaphragms would be halved, however, ABEC will take care of this situation and will provide the correct calculation. The second case allows to drive the diaphragm individually.

Observation Fields

Observation Fields are not automatically extended by the declaration of Sym= in Control_Solver.

The Field section provides its own Sym= parameter. If specified ABEC will display the field also for the opposite side of the plane of symmetry.

There are cases where the straight mirroring yields wrong results. For these cases Sym= provides also anti-symmetry. Use an identifier form the set [-xy, -xz, -yz, -xyz, -xzy, -yzx]. For Dim=CircSym use Sym=Radial.

No Sym Sym=x
Out of plane, Sym=x Out of plane, Sym=-xy

For example, in the above configuration we would get an error for Sym=x if the observation plane is not exactly in one of the principal planes.
