Identifier Temperature=
Units C (Celsius)
Format Floating-point number
Purpose Medium Temperature
Used in Control_Solver (Boundary Element),
Control_Field, Control_Spectrum (Direct Sound)
See also Acoustic Parameters, c=, rho=, StaticPressure=, Altitude=

Temperature= belongs to the set of Acoustic Parameters.

By default Temperature=20C.

Specify Temperature= in degree Celsius, for example

  Control_Solver
    f1=20;  f2=500;  NumFrequencies=20;  Abscissa=log;
    ...
    Altitude=500m;  Temperature=10C
