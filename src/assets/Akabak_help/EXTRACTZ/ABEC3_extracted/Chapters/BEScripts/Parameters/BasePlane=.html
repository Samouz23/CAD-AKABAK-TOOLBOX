Identifier BasePlane=
Format 1 [xy, xz, yz, yx, zx, zy, -xy, -xz, -yz, -yx, -zx, -zy, Pos, Neg]
Format 2 Node indices
Purpose Plane of the arc
Used in BE_Spectrum with PlotType=[Directivity,Arc]
See also Inclination=, PolarRange=

BaseBlane= is a parameter of section BE_Spectrum, which controls the localization of points for spectral analysis. With the help of parameter PlotType=Directivity or PlotType=Arc we can generate a range of points, which are distributed in a plane. The orientation of this plane and start and on-axis points needs to be specified. This can be done with the help of the two formats of BasePlane=:

Format 1 - Directional Specifiers

Format 1 is useful if BasePlane is aligned with the principal planes of the coordinate system. It provides a pair of symbols each stand for the name of an axis (x, y or z). The two axis named will span the plane. For example BasePlane=zx will create observation-points in the x-z-plane. Further, the first character - in our example the z-axis, will point into on-axis direction. The second character indicates the "-90 deg" point of the arc on which points are distributed - in our case the x-axis. A minus sign will invert the arc. For example:

  BE_Spectrum
    PlotType=Directivity
    BodeType=LeveldB;  Range=50
    Distance=1m
    PolarRange=-90, 90, 19
    BasePlane=zx
    101   Inclination=0.0    ID=TS_200

This example creates 19 points on an arc ranging from -90 deg to +90 deg at 1 m distance from the origin of the global coordinate system. The semi-circle is rendered in the x-z-plane. The first point is at -90 deg. The on-axis (0 deg) points along the z-axis.


Another example:

  BE_Spectrum
    PlotType=Directivity
    BodeType=LeveldB;  Range=50
    Distance=1m
    PolarRange=-70, 70, 19
    BasePlane=zx
    101   Inclination=0.0    ID=TS_200

This example demonstrates, what kind of role the "-90 deg"-point plays. The actual start point is at the first angle as specified at PolarRange=-70, 70, 19 i.e. at -70 deg. Hence, the second character of BasePlane=zx indicates the direction along the arc.


Another example:

  BE_Spectrum
    PlotType=Directivity
    BodeType=LeveldB;  Range=50
    Distance=1m
    PolarRange=-170, 170, 19
    BasePlane=zx
    101   Inclination=0.0    ID=TS_200

This example demonstrates how to specify a complete circle (only that we restricted the range here for demonstration purpose). For full circle you specify PolarRange=-180, 180, ... so that the arc ranges from -180 deg to +180 deg. The first character of BasePlane=xz specifies the on-axis point and the second where the arc has its -90 degree point.

Format 2 - Directional Vectors

The BasePlane can also be positioned with the help of node-indices.

There are three nodes defining point P1, P2 and P3.

P1 is the point of rotation.

P2 and P3 mark the BasePlane. The vector P2 - P1 is the on-axis direction (zero degree).

For example

  BE_Spectrum
    ...
    PlotType=Directivity
    Distance=100m
    PolarRange=-90, 90, 37
    BasePlane=1001  1002  1003   RefNodes=N
    101   Inclination=0.0   ID=ID101
    ...
