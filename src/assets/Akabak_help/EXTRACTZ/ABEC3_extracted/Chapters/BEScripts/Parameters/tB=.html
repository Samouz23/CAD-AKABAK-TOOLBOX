tB=

Identifier tB=
Units m
Format Floating point number
Purpose Baffle-extrusion or recess of local-baffle.
Used in Baffle
Used in Diaphragm, Shell, VibFile
See also HasBaffle=, t1=

Baffle

For component Baffle parameter tB= controls the size on an extrusion of the outer edge.

For example, one can use tB= for creating a band and then use section Transition for connecting it to another component.

Diaphragm, Shell and VibFile

           

tB= allows to create a tunnel or a step at the outer edge of following elements: Diaphragm, Shell or VibFile. If HasBaffle=false then still a tunnel or step is extruded but without the attached baffle.

Side=Front

If tB > 0 then the baffle is displaced forward, which creates a tunnel in front of the device. If tB < 0 then the baffle is displaced backwards, which creates a step with respect to the baffle.

Side=Rear

For the rear of a diaphragm it is the same from the view-point of the whole device. If tB > 0 then the baffle is displaced in direction of the front diaphragm, which creates a step for the rear. If tB < 0 then the baffle is displaced in direction of the rear-side, which creates a tunnel for the rear diaphragm.

Front and Rear

Often we have the case where a diaphragm is within a wall with a certain thickness. There are two Diaphragm-elements, one with Side=Front and one with Side=Rear. In this case we use tB= in combination with t1= (see also remarks there).

For example

  Diaphragm  "Front"
    DrvGroup=1001
    SubDomain=1
    EdgeLength=20mm
    Position=1001,1002,1003
    NoBaffle=false
    Simple=false
    Side=front
    dD=120mm;  tD1=20mm;  dD1=20mm; hD1=5mm
    Ws=5mm
    hD2=40mm;  dVC=20mm;  hVC=0mm;
    dM=80mm;   hM=20mm
    tB=10mm; t1=-10mm

  Diaphragm "Rear"
    RefDiaphragm="Front"
    SubDomain=2
    DrvGroup=1002
    Side=Rear

In the above example tB=10mm displaces the baffle 10mm upwards for both sides. However, in order that the baffle is in plane with the front wall of the cabinet, we displace both diaphragms down (in this view) by t1=-10mm. Note, that the second Diaphragm inherits parameters from Diaphragm "Front".
