Side=

Home » Scripts

Identifier Side=
Format [Front, Rear]
Purpose Side of diaphragm
Used in Diaphragm

A Diaphragm-section defines only one side of a membrane, which can be Side=Front or Side=Rear, respectively. The default-value is Side=Front.

Motion

For a Diaphragm mechanical motion is always in direction of its actual front side, typically axial, regardless of the specification of Side= (see Desktop-Views-Structure-Driving Directions).

Normals

Side= controls the direction of the normals (see Normals and Volumes). With Side=Front normals point to the front and with Side=Rear normals point towards the rear, depending also on the actual shape of the diaphragm. For example, if we specify for Diaphragm Side=Rear and check Desktop-Views-Structure-Driving Directions and Desktop-Views-Structure-Normals then we see that the normals point to the rear and the driving indicators are pointing to the front.

Cone Shapes

A cone-shaped loudspeaker diaphragm features different geometry for its two sides, which is also controlled with the help of Side=. If we want to use both sides of the membrane of a loudspeaker, we would have to use two Diaphragm-sections, one for the front and one for the rear.

In order to facilitate input, all parameters of the two Diaphragm-sections can be specified at one section. The other Diaphragm then takes reference with the help of parameter RefDiaphragm= and inherits all parameters in this way.

Of course we have to define Side=Front in the first Diaphragm- section and Side=Rear in the second section. Although both Diaphragm-sections have the complete specification, ABEC will render and use only relevant parts. For example, Side=Front will ignore magnet parameters. Also, the front membrane can be different from the rear as can be seen in chapter Diaphragm Shapes.


Example


  Diaphragm  "Cone front"
    Side=Front                   // Creates elements for the front side of the diaphragm
    DrvGroup=1001                // Driving group link to observation stage
    SubDomain=3                  // Front side belongs to sub-domain 3
    RefNodes="NF"
    EdgeLength=68mm
    Position=3000,3003,3004      // Triangle giving position
    dD=340mm                     // Diameter of cone
    tD1=70mm                     // Inner depth of cone to base of dust cap
    dD1=100mm                    // Diameter of dust cap
    hD1=30mm                     // Height of dust cap
    Ws=10mm                      // Width of outer suspension
    hD2=100mm                    // Height of total cone on the outside
    dVC=50mm                     // Diameter of voice coil
    hVC=5mm                      // Height of voice coil
    dM=200mm                     // Diameter of magnet
    hM=30mm                      // Height of magnet

  Diaphragm  "Cone rear"
    Side=Rear                    // This is the rear side of the diaphragm
    DrvGroup=1002                // Driving group link to observation stage
    SubDomain=1                  // This side belongs to sub-domain SubDomain=1
    RefDiaphragm="Cone front"    // Inherit from "Cone front"
    t1=-12mm                     // Offset to the rear
