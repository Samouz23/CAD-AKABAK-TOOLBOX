Identifier Distance=
Units m
Format Floating point number
Purpose Specifies the radius of the arc.
Used in BE_Spectrum

Distance= is used in observation scripts in section BE_Spectrum with PlotType=[Directivity,Arc].

It defines the distance of observation points on the arc.

If the distance is way larger than the dimensions of the object it is better to use PlotType=Directivity, which renders a symbol of the arc rather then the points itself. For the calculation both PlotType= are identical.
