Identifier RefNodes=
Format String
Purpose Reference to a Nodes-section
See also Nodes, Nodes and Elements

RefNodes= specifies a string, which is the name of a Nodes-section. If the name has blanks then the string should be placed in quotes.

RefNodes= is used to assign coordinates to sections such as Elements as explained in chapter Nodes and Elements. It is also used to provide coordinates at places where positions are required, see at parameter Position=.


For example

  Nodes "N"
    1001    0.0   0.0    0.0
    1002    1.0   0.0    0.0
    1003    0.0   1.0    0.0

  Subdomain_Properties
    Subdomain=1
    ElType=Exterior

  Infinite_Baffle
    Subdomain=1
    Position= 1001, 1002, 1003  RefNodes=N

  Diaphragm  "Disk front"
    Subdomain=1
    DrvGroup=1001
    RefNodes="N"
    Position= 1001, 1002, 1003
    NoBaffle
    dD=100mm
