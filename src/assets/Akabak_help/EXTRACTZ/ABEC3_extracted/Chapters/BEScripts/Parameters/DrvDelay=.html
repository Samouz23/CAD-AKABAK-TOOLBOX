DrvDelay=

Home » Scripts

Identifier DrvDelay=
Units s
Format Floating point number
Purpose Time delay of driving
Used in Diaphragm, Pressure_Points, Pressure_Box, VibFile, Driving
See also DrvWeight=, Delay=, Driving Groups

DrvDelay= allows to add time-delay to driven elements of the solving-stage, such as Diaphragm, Pressure_Points, Driving. For details see chapter Delay Example.

Example

  Diaphragm
    ...
    DrvWeight=1.0
    DrvDelay=2ms
    ...
