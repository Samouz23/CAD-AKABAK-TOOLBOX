Identifier Alpha=
Format Floating point number
Purpose Opaqueness.
Used in Field

Controls the opaqueness of contour colors. Range Alpha = 0 ... 1

Alpha=0.5 is semi transparent.

Alpha=1.0 is opaque (default value).


For example

  Field "Near"
    RefNodes="Contour"
    EdgeLength=2mm
    BodeType=LeveldB;
    StepSize=1;  Range=50;
    Sym=x
    Alpha=0.7
    101   1001  1002  1003  1004
