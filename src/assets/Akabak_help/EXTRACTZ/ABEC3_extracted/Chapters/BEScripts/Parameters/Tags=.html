Identifier Tags=
Format Mesh-File-Tags
Purpose Filtering mesh-file elements
Used in MeshFile_Properties

Tags= allow to include/exclude a specified set of triangles of the mesh-file.

Tags= can be specified with a range of parameters, which should all be in a single line and separated by spaces or tabs. The format is

    Tags = Include <tags>   Exclude <tags>   SwapNormals

Include <tags> Exclude <tags>

With Include and Exclude you can filter triangles of the mesh-file as explained in Mesh-File-Tags.

SwapNormals

SwapNormals inverts all triangles of the mesh-file so that its normals point opposite, see also chapter on Normals and Volumes.

Example

For this script and mesh-file with alias M we exclude all triangles with tags of index 13 and 20-28. Note, "include all" could be omitted here.

  Meshfile_Properties
    Meshfilealias=M
    Scale= 1mm
    Shift= -100mm ,0 ,0
    Tags= include all exclude 13 20...28
    MinAngle=5
