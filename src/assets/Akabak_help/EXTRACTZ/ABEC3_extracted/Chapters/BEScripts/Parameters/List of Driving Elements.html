Purpose List of indices of driven Elements.
Used in Driving

The list of driven elements follows the parameter part of the Driving-section. Each line represents an Element which is driven. Each index should be separated by a blank, tab or comma. The format is

    <Index>    <Element-index>   RefElements=  DrvGroup=  Weight=  Delay=

Index

The first entry is an index, which becomes the "name" of a driving-item.

Element-Index

The second entry is the index to an element of an Elements-section where RefElements= points.

RefElements=

Optionally you can specify RefElements= individually.

DrvGroup=

Optionally you can specify DrvGroup= of this driven plane.

Weight=

Weight= allows for weighing the amplitude of Value= of the parameter part.

Delay=

Delay= allows for adding delay to Delay= of the parameter part.
