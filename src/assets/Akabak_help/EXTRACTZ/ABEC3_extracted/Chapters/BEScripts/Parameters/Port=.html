Home » Spectrum-Observation-Scripts

Identifier Port=
Format Integer
Purpose Identification of port of Lumped Element Analysis
Used in LE_Spectrum
See also System=, ElName=, Node=, AnalysisType=

Port= identifies a particular port of a Lumped Element component for observation of spectra.

Port= is only necessary for components with more than two poles such as the Driver, Transformer, OpAmp, etc. For two-poles, such as the Resistor, Port= is ignored. However, some components appear only in the script as a two-pole, whereas internally they are expanded to multi-poles. Such components are the Duct, Waveguide, OpAmp and Transistor.

Port= is only necessary for inspecting flow-parameters such as AnalysisType=[Current, Excursion, Velocity, Acceleration, VolVelocity] and AnalysisType=Power. Otherwise, for inspecting potentials, LE_Spectrum expects the specification of a network-node with the help of Node=.


Port=0

Port=0 yields special inspection for some components:

For AnalysisType=Power the electrical power in the voice-coils resistance(s) Re= is calculated.

For AnalysisType=[Excursion, Velocity, Acceleration] the motion of the diaphragm is calculated for components Driver, Speaker and Diaphragm.


Example

If the Lumped Element script defines a Transformer and you want to inspect the current into the secondary coil then

  LE_Spectrum 'I into Tr1'
    AnalysisType=Current
    System=S1
    101  ElName='Tr'  Port=2   ID=Tr2

The associate LE-script could look like this:

  System  'S1'
    Resistor    'R1'
      Node=100=200
      R=5ohm
    Transformer 'Tr'
      Node=200=0=300=400
      L1=2mH  L2=5mH  R1=1.2ohm  R2=3ohm
    ...
