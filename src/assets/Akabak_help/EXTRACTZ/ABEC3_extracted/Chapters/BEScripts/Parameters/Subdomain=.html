Identifier Subdomain=
Format Integer number
Purpose Index (name) of a sub-domain
Used in Subdomain_Properties, Elements, Baffle, Diaphragm, Shell, Pressure_Points, Pressure_Box
See also Subdomain Modelling

Subdomain= is the "name" in form of a number of a certain subdomain. If Subdomain Modelling is enabled then each section of the Boundary Element Script should provide the parameter Subdomain=.

Subdomain Modelling is enabled if there are at least two different subdomains specified.

Typically each subdomain is headed by a section Subdomain_Properties, which allows to specify additional properties and default settings of a subdomain.


For example

  SubDomain_Properties 'Enclosure'
    SubDomain=1
    ElType=Interior
    Color=0.3,0.3,0.3

  SubDomain_Properties 'Vent'
    SubDomain=2
    ElType=Interior

  SubDomain_Properties 'Exterior'
    SubDomain=3
    ElType=Exterior
    IBPlane=z

  Elements "Enclosure-Interior"
    RefNodes="NF"
    SubDomain=1
    101   12201  12204  12203  12202
    ...

  Diaphragm  "Cone front"
    Side=Front
    DrvGroup=1001
    SubDomain=3
    ...

In this example from "Speaker Cabinet SP38" we have three subdomains. Subdomain=1 forms the interior of the loudspeaker cabinet. Subdomain=2 is the interior of the vent. Subdomain=3 is the exterior domain.
