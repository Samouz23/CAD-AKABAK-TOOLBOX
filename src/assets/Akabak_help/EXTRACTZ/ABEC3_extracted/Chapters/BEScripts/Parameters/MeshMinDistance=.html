Identifier MeshMinDistance=
Units m
Format Floating point
Purpose Bounding distance of Pressure_Points
Used in Pressure_Points
See also MeshMode=

MeshMinDistance= workes together with parameter MeshMode=Elements.

It controls the density of Pressure-Points so created. There is installed a Pressure-Point at the center of a mesh-element only if its distance to any other Pressure-Point is larger than MeshMinDistance=.

For example, at the top-sphere MeshMinDistance=0 and there is a Pressure-Point at the center of each triangle.

Conversely, the sphere at the bottom shows only a sparse set of Pressure-Points because here the parameter is MeshMinDistance=0.2m.
