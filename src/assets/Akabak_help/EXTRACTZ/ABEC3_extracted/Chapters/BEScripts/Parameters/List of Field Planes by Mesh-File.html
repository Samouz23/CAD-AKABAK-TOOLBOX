List of Field-Planes by Mesh-File

Home » Scripts

Purpose List of field planes.
Used in Field
See also List of Field Planes, List of Field Planes by RefElements

The list of field-planes follows the parameter part of the Field-section. If a list-item shall represent planes of a mesh-file then following syntax should be used:

    <Index>    Mesh    MeshFileAlias=  Include <tags>   Exclude <tags>

For example

  Field "F1"
    ...
    MeshFileAlias=M
    101  Mesh  Include 11 ... 39
    ...

Index

The first entry is an index, which becomes the "name" of the field-plane.

Mesh

Indicator that this line is regarded as a mesh-file item (Note, Mesh can be omitted if also MeshFileAlias=, Include= or Exclude= is specified).

MeshFileAlias=

If you use a mesh-file you need to specify MeshFileAlias= in the parameter-part of the section. Alternatively it is also possible to provide MeshFileAlias= individually with each item of the Field-Plane List.

Include <tags> Exclude <tags>

With Include and Exclude you can filter triangles of the mesh-file as explained in Mesh-File-Tags.
