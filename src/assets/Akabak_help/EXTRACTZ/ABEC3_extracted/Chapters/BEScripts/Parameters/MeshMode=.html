Identifier MeshMode=
Format [Center, Elements]
Purpose Distribution of Pressure_Points
Used in Pressure_Points
See also MeshMinDistance=

If Pressure_Points are distributed with the help of a mesh-file the parameter MeshMode= controls the way it is positioned.

MeshMode=Center creates a single Pressure-Point, which location is at the point of gravity of all mesh-elements involved.

MeshMode=Elements creates multiple Pressure-Points, which position is at the center of each triangle. The number of Pressure-Points created depends also on another parameter, which is called MeshMinDistance=.
