StaticPressure=

Home » Scripts

Identifier StaticPressure=
Units Pa
Format Floating-point number
Purpose Atmospheric Pressure
Used in Control_Solver (Boundary Element),
Control_Field, Control_Spectrum (Direct Sound)
See also Acoustic Parameters, c=, rho=, Temperature=, Altitude=

StaticPressure= belongs to the set of Acoustic Parameters.

By default StaticPressure=101325Pa (20C and see-level)

Specify StaticPressure= in Pascal, for example

  Control_Solver
    f1=20;  f2=500;  NumFrequencies=20;  Abscissa=log;
    ...
    StaticPressure=95178Pa
