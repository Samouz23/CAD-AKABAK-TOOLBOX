Identifier Name=
Format String
Purpose Name of the project
Used in Control_Spectrum

Name= assigns the the folder-label in VACS as can be seen in the tree-view of VACS.

For example: 

  Control_Spectrum
    Name="ABEC-ABEC21"
    ID=ABEC21
    NumFrequencies=200;   Abscissa=log;
