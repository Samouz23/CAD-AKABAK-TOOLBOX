Purpose List of element-references.
Used in WallImpedance

The list of wall-impedances follows the parameter-part of the WallImpedance-section. Each line represents a link to an element of an Elements-section, which is assigned an impedance value. If no list of wall-impedances is specified then all elements of the Elements-section where RefElements= points to are assigned the impedance.

Each index should be separated by a blank or tab. The format is

    <Index>    <Element-index>   RefElements=  DataFileAlias=  Value=

Index

The first entry is an index, which becomes the "name" of an impedance.

Element-Index

The second entry is the index to an element of an Elements-section where RefElements= points.

RefElements=

Optionally you can specify RefElements= individually.

DataFileAlias=

Optionally you can specify a data-file individually. See at DataFileAlias=. In this case Value= is ignored.

Value=

Optional an individual Value= can be specified. The meaning of Value= depends on ImpType= and Normalized=.

The total value is the product of Value= of the parameter-part times the value of the item of the list of wall-impedances.
