Observation Scripts

Home » Scripts

Observation scripts provide the input for the calculation of the observation stage.

If in Boundary Element Mode the observation stage is only enabled if the structure has been solved successfully. For Direct Sound Analysis or Lumped Element Analysis only there is only a single calculation stage.


For constant driving all observation scripts typically have two parts:

  • Driving_Values
  • Observation-sections

Otherwise we assume the presence of a Lumped Element Script, which provides driving values via DrvGroup= links. This means that if you couple to a LE-script then do not specify a Driving_Values-section in an observation script.

Driving_Values

Driving_Values-sections provide the physical values for driving-gropus as specified by the DrvGroup= parameters. If there is no Lumped Element Script the section Driving_Values is mandatory for an observation-script, because otherwise there would be no vibrating surfaces and no pressure-points active. Elements, which can be driven are

  • Driving (Elements)
  • Diaphragm
  • Pressure_Points, Pressure_Box

At Driving_Values you can specify constants or a file for driving. In any case this mode of driving is a "fixed" or "imprinted" kind of driving. This means there is no radiation-feedback on the source. Alternatively you can add a LE-Script to the project. In this case the driving lumped element network is fully coupled to the acoustics.


Observation Sections

It is recommended to split observation scripts into those, which perform field-calculations and those, which perform spectrum-calculations. This structure is also supported by ABECs application-layout, see

  • Field observations
  • Spectrum observations
