For larger projects it is recommended to specify Field-sections in a dedicated script. In any case the following sections are relevant for field observations.

Driving Values - Coupling

Each observation-script should specify driving-values either by providing a section Driving_Values in the observation script or by coupling to a LE-Script as explained in chapter Observation Scripts.

Control_Field

Section Control_Field can provide script-global settings for all field calculations, such as the mesh-generation parameters.

For observing Boundary Element Analysis field-frequencies are taken from the solving stage.

For observing Direct Sound fields section Control_Field needs to specify a frequency abscissa.

Field

Section Field generates a plane with regularly spaced observation points, which will be calculated for all checked frequencies. Eventually you can select a frequency or a range of frequencies in the frequency-list on page Ob_Fields. The result will be rendered as a field plot in the 3D-viewer on page Drawing.
