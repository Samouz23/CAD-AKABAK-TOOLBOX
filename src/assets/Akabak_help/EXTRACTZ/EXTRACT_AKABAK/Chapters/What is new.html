AKABAK 3.1.9


Convex polygon

Version 3.1.9 updates the mesh-file tag-filters. The new implementation should cope better with the updating of the CAD. Also the GUI has been reworked.

Version 3.1.8 stages scripting into Akabak. This goes step by step. First as a "beta" feature ever expanding to finally providing a means for remote control.
The lumped element Membrane received an update. It is now available for mobility and impedance notations. The Membrane component is practical for modeling woofer cabinets with passive membranes. Also new examples are added.
The in-build CAD-tool using Nodes and Elements has a new extrusion feature.

Version 3.1.7 implements the first incarnation of collision testing, which means the mesh generator of BEM tests each triangle whether it is too close to another one. If so a warning is output. See chapter Meshing. Meshing parameter EdgeLength can now be specified as a factor, see chapter Meshing-Form. VibFile is repaired (builds b84 to b90 rendered wrong results).

Version 3.1.6 provides a table of extrema and integrals of certain component parameters of the lumped element network.

Version 3.1.5 adds the lumped element component Bassunit, which implements the basic Benson/Thiele/Small model of the high-pass filtered vented loudspeaker.
The new Reference Table helps editing projects with large number of links.

Version 3.1.4 adds an Info Editor at the desktop which supports light formatting and embedded pictures.
A new paper is available explaining BEM and subdomains, see at [37].

Version 3.1.3 adds a new feature, which supports the specification of polygons as shape for boundaries and fields. The specification is straightforward as explained in chapter Nodes and Elements. Concave shapes should run for all cases. However the convex ones are those which are tricky to implement. For the Baffle component it might be that some convex polygon-configurations cannot be meshed at the moment.


AKABAK makes use of GUI-elements for specification of parameters, such as dialogs, lists and schematic-editor.

Currently AKABAK has almost the same feature-set as the previous version, which was called ABEC.
There are now some additional LE-components, which help modeling mechanical mobility-networks.
The calculation engine serves the whole stack, from meshing down to LE-observations. All stages are multi-threaded and asynchronous.

Compatibility with ABEC version 3

AKABAK is able to import ABEC 3-projects. See menu Tools/Import ABEC Projects.
