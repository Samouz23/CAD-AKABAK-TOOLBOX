The Radiator-component is an acoustic two-pole component and represents radiation.



Parameters

Caption Name of component
Application [BEM Boundaries, Pressure Source, Lumped Element]
Ref to BEM Link to vibrating BEM boundaries Application=[BEM Boundaries]
Ref to P-Source Link to BEM pressure sources Application=[Pressure Source, Lumped Element]
Ref to LE-cmp Link to other LE-component Application=[Lumped Element]

Application

Application means here the way we model.

BEM Boundaries installs a radiation impedance of vibrating boundaries of the BEM-part. The model is fully coupled. The BEM-part provides the radiation impedance for the Radiator. Eventually, after solving the LE-network, the Radiator provides volume velocity values for radiation observations. Within a network mutual coupling is taken care of. Technical details of the coupling are explained in [9]. In this mode of application we need to provide a link to a vibrating boundary, for example to a Diaphragm component.

Pressure Source means that Radiator is used as a simple measurement point of sound pressure inside the lumped element network. There is no radiation impedance. An example of application is the driving of a pressure source in a room. In this mode we need to provide a link to either Pressure-Points or Pressure Box.

Lumped Element indicates that Radiator is used to provide radiation impedance and radiation to a lumped element model without BEM. The radiation impedance is approximated with the help of the text-book function of a circular disc in an infinite baffle. In this mode of application we need to provide a link to another lumped element, which can provide the radiating area (Ref to LE-cmp). This can be a transducer or a waveguide component. If we want to observe radiation then we also need to provide a link to either Pressure-Points or Pressure Box.

Note

Radiator is similar to the component "RadImp" which is used in the LE-script of ABEC. On converting scripts to AKABAKs' schematic simply replace RadImp by Radiator components.
