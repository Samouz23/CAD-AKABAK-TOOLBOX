Arrow

Home LE-Part

Parameters

Caption String Name of component
Color [color-table]
Show GND Bar Boolean If true the arrow ends at a bar
Line width Line thickness in pixels

Arrow is for commenting the schematic.

The value of Line Thickness can be zero. In this case an internal default value is used.

The arrow can be rotated and flipped (see menu Schematic). The length of the arrow can be dragged with the help of the mouse on the little gray rectangle.
