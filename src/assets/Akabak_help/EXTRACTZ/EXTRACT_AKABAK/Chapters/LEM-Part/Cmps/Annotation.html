Annotation

Home LE-Part

Parameters

Caption String Name of component
Text String Text of annotation
Font size Size of characters in Points
Font bold Boolean If true text is rendered bold
Font italic Boolean If true text is rendered italic
Font underline Boolean If true text is rendered underlined
Auto size Boolean If true text gets wrapped to fit box.
Text alignment [Left, Center, Right]
Border type [No Border, Rectangle, Round Rectangle]
Border color [color-table]
Border distance Pixels between text and border
Border width Line thickness in pixels

Annotation provides a text box for commenting the schematic.

If Auto size = False the size of the box can be dragged with the help of the mouse on the little gray rectangle.
