Switch

Home LE-Part

Parameters

Caption String Name of component
Group String Name of switch-group
Positions Integer Quantity of switch positions
Position Integer Current position

The Switch-component can alter the wiring within a network. A network is comprised by all components which are somehow connected to a Source-component.

The switch can be configured with the help of parameter Positions.

  • Positions=1:
    On/off switch. Position=[0,1].
  • Positions=2:
    Alternating switch. Position=[0,1,2].
  • Positions>=3:
    1:N switch. Position=[0,1,2,...].

Optionally, multiple switches can be synchronized with the help of the Group-parameter. All switches of a group should share the same name. Un-coupled switches have a blank string here.
