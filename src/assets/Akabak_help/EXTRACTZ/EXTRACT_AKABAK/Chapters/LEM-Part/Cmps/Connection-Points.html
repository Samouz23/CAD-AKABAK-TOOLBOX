Connection-Points provide wiring across a schematic. Connection Points can be helpful if you want to loop a distant node in the network. They can be used only within a network. A network is comprised by all components which are somehow connected to a Source-component.

After you dropped a new Connection Point component, select another Connection Point, in order to establish the connection.
