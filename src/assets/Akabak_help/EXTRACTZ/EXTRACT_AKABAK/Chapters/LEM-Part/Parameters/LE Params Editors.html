LE Parameter - Editor

Home LE-Part

Parameters of components of the LE-Part are specified with the help of Parameter Editors. This editor is called from the Parameter Table which you find at page LEM on the left hand side of the desktop.

The Parameter Table displays values of the currently selected component. For selecting a component simply click on it inside the Schematic Editor.

If no component is selected then the table shows parameters of the underlying control.

Parameter Table

The Parameter Table lists the name of parameters and its value. The selected parameter can be edited with the help of the Editor by issuing menu Edit/Parameter, by clicking on the embedded button or by dbl-clicking.
You can select one or multiple parameters and use copy and paste to transport values to another component.

There is a little marker to the left which indicates whether this parameter is shown in the schematic. Use menu Schematic/Show in Label to toggle the display.


Editor - String

Caption, ...

This form edits the value in form of a string. An example for a string-parameter is the Caption of a component.

Editor - Floating Point

L, C, R, ...

This form supports editing of parameters of floating-point format. The expected input depends of the current settings of units.

Some components calculate mutual parameters. For example, the component Electro Dynamic Driver calculates the resonance frequency from Mms and Kms and vice versa.

Editor - Kms

Input-form and calculator for the transducer stiffness Kms, see chapter LE Mech Parameters.



Editor - Reference

Ref to Data, Ref to BEM, Ref to P-Source, Ref to LE-Cmp

This form supports selection of a reference. For example to a data-file object.



Editor - Diaphragm

Diaph Front, Diaph Rear, Diaph, Vent, Cross, Throat, Mouth, ...

Any lumped element component with mechano-acoustic transduction features a Diaphragm. Accordingly, we need to provide either a link to a vibrating boundary of the BE-Part or a value for the size of the diaphragm. See chapter LE Diaphragm Parameters for details.


Editor - Helmholtz

Input-form and calculator for the Helmholtz resonator of the vented enclosure.





Editor - Voice Coil

VC, VC1, VC2

Components, which feature an electro dynamic motor have a parameter called "VC", which stands for Voice Coil Parameters.



Editor - Formula

Formula

Any parameter of floating-point format can be assigned the result of a formula.
There is a special editor for formula. Results are assigned to parameters with the help of special Identifiers which each component provides. Here is a list of all Identifiers, however there is also a list at each component documentation. In the screen-shot-example to the right we see that there is a formula with name "Mms". Because parameter Mms has Identifier=Mms it receives the result of this formula.
