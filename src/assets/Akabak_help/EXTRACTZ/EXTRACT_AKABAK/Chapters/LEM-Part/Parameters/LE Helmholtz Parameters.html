If you click to edit on one of following parameters the Helmholtz-Form will open. It is a little calculator to evaluate the resonance or other parameters of the component Enclosure Vented. Details are explained at chapter Helmholtz.

Vb

Vb is the effective volume of the cavity of the enclosure which would yield a lumped acoustic compliance at low frequencies.

Len

Len specifies the length of the vent. If Add end-correction is checked Len should be regarded as the geometric length, otherwise, the effective length.

fb

fb is the Helmholtz-Frequency. It is a design parameter and introduced to help to specify the vented enclosure resonance.

Add end-correction

If checked the radiation impedance at the interior end of the vent is taken into account. This is of course an approximation because in the lumped element model the exact geometry of the acoustic boundaries is unknown.
If un-checked no end-correction is applied. This is practical if you want to add your own end-correction, typically by specification of an effective length of the vent.
Note, that for the exterior aperture the vent is always loaded with the radiation impedance. If in BEM-mode the radiation impedance stems from the Boundary Element Solution. If in Direct Sound Mode the radiation impedance comes from a text-book formula, which is the equivalent of a circular disc in an infinite baffle [22].

Vent Aperture

Parameter Vent Aperture specifies the cross-sectional area of the vent. The radiation of the vented enclosure component can operate in two ways:

  1. Coupled to boundary elements
  2. Direct Sound
Coupled to boundary elements

The vent aperture can be coupled to vibrational boundaries of the BEM-Part. The aperture acts as a "diaphragm". With the help of the Boundary Element Method a more accurate value for the lumped radiation impedance is available. Also, in this case, there would be mutual radiation between radiators. The BEM-mode of the vented enclosure component is activated automatically by specifying a reference to a driven boundary or to a Diaphragm component of the BE-part. Click button Vent Aperture which opens the Diaphragm Parameters-Form. Go to page Reference and select the driven boundary from the BEM-part.

Direct Sound

In Direct Sound mode the aperture would radiate directly with the help of a pressure source, for example the Pressure Box which needs to be referenced with the help of parameter Ref to P-Source of the vented enclosure component. It is possible to perform simulations also without this reference. However, in this case the vent would not take part in the radiation.
Button Vent Aperture lets you specify the value of the cross-section of the vent with the help of the Diaphragm Parameters-Form. Note, that eventually, for the vent we need only the cross-section area SD. Shape parameters, such as diameter and width and height, are there only for a convenient input but would be ignored during calculation.
The Direct Sound mode lacks the Boundary Element Method, which would otherwise calculate the radiation impedance. In this mode an approximate value for the radiation impedance is substituted. This comes from a text-book formula of a circular disc in an infinite baffle [22].
