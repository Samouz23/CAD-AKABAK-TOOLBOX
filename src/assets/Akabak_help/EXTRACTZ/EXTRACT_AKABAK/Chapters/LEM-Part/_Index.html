The LEM-Part of the desktop manages and displays components of the Lumped Element Analysis.

On page LEM at the center-part of the desktop the lumped element network can be drawn with the help of the schematic editor. A new component is created via the menu Edit/New Component form. There select page LEM and select the component to be created. Then click Apply. The new component appears at the top left corner from where we drag it to the desired position. Similarly we can use menu Edit/Paste or menu Edit/Duplicate. Alternatively you can drag the component from the New Component Form into the schematic editor to the desired position.

Parameters of the selected component are edited with the help of the Parameter Editor on page LEM at the side of the desktop. Each entry has a little Parameter Form which opens by clicking on the button with the ellipses.
