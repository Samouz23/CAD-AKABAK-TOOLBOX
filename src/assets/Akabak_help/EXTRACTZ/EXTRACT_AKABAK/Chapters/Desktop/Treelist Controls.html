Treelist Controls

Home » Desktop

On the side of the desktop you find tables which list components. Some tables have main-records and child-items.

You can navigate the selection (focus) with the help of the mouse or with UP and DOWN keys. Any clipboard operation, editing, moving or deletion is performed on the selected item.

Editing Parameters

Each component has an associated edit form (dialog). In order to open this form you need to first select the component in the table. Then issue menu Edit/Parameter... Alternatively you can dbl-click on the label of the component.

Editing Name

The name of a component can be changed with the help of menu Edit/Name on the selected component. A quick way is to click again on the caption of the component (second column).

Collapse and Expanding

Child-items can be shown or hidden by clicking on the +/- sign in front of the label. Also you can use menu Venue/Collapse all, Venue/Expand all and Venue/Expand selected. Expanding only the selected item is done by pressing CTRL-key + clicking on the label.

Move up, Move down

These commands will change the order of the list. The selected item will be moved up or down. Issue menu Venue/Move up or Venue/Move down. Also CTRL+UP or CTRL+DOWN key will move an items.

Components of the BEM-list can change the Subdomain or Interface only with the help of menu Venue/Subdomain...

Check-Box

The check-boxes are for controlling the visibility of the component and its parts.
BEM: Also invisible components take part in the calculation.
Observation: Here un-checking means disabling and hiding.

Colors

Subdomains are rendered blue. If Domain Type = Exterior the color is red.

Interfaces are colored purple.

Header-fonts are bold. The exception is when a component has inheritance.
