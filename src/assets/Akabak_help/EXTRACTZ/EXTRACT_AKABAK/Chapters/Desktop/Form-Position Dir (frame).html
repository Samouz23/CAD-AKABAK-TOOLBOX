At various places we need to specify an orientation or direction of a feature. For example we may need to specify the direction of a motion of driving, or the orientation of the infinite baffle.

Identifier

If the direction is aligned with one of the coordinate-axis then direction-specifiers are convenient:

Identifier of Direction

x, y, z Axis 3D
pos, neg Axis CircSym

x, y, z are directions - for example the normal of the Infinite Baffle. A negative-sign inverts the direction. Pos and Neg are used for Dim=CircSym.

Triangle

The direction can also be specified with the help of a triangle. This technique is practical if coordinates are readily available. See also at chapter Planes.

Reference to Nodes

First we need a reference to a database of Nodes.

P1, P2 and P3

For P1, P2 and P3 specify the Node-Index of the coordinate.

The direction of the component-axis is identical to the normal N of the triangle:

N ∝ (P2 - P1) x (P3 - P1)

The size of the triangle can be arbitrary.

Mesh-File

A direction can also be based on planes as provided by a Mesh File. The schema is similar to using a triangle as explained above. However, with mesh-files the triangle is constructed from the assigned mesh-planes. The normal is deduced from the first plane of the set, assuming the control-plane is flat.

Reference to Mesh File

First we need a reference to a Mesh File-object.

Mesh File Tags

Include. Here you specify, which planes shall be included. Because each plane of the mesh-file has one or multiple Tags, we can use these for selection.

Exclude. Tags specified here will be excluded from selection.

Scaling of Position

The Scaling sub-form provides a range of local and global rotation and translation parameters.
