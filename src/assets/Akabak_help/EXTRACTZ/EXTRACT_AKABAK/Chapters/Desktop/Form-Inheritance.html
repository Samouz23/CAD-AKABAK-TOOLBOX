Form - Inheritance

Home

Selects the ancestor for selected component. If a component has an ancestor then all its parameters are inherited from this related component.

An example is displayed to the above. There are two Diaphragm-components, one for the boundaries on the front side and one for the rear. All parameters are specified at Diaphragm "Front", which are eventually forwarded to Diaphragm "Rear". Only parameter Side of Diaphragm is different and changed to be Side=Rear.

The ancestor of a component can only be selected with the help of this form.

Inheritance is currently available only for following components: Diaphragm, Duct and Shell.
Also, it is possible to inherit only from the original component.

Position and Scaling parameters cannot be inherited and need to be specified individually.


In the component-list a component which has a link to another component is rendered with a thin stroke of font. Otherwise the stroke is bold.

At edit-forms any inherited parameter is indicated by a yellow background. You can over-write these values. For default values leave the edit-field blank.
In selection-lists the first entry is reserved for the ancestor. It is marked by a set of parenthesis.
