Acoustic Parameters control the mapping from spatial to temporal measures. AKABAK uses the speed of sound, c and its density, ρ of the medium.

Open this form at menu Global/Acoustic Parameters.

Note, values of ρ and c can be used inside formula. For example:

    rho = Density
    c = Speed
    Z = rho*c
    ...

Examples where acoustic parameters are used:

For example, the density of the medium is involved in the relation between the velocity potential ϕ and the sound pressure: p = -jω·ρ·ϕ by using the time-convention exp(jωt).

In another example the speed of sound is part of the point-source Green function: G =  exp(-jk·d)/(4π·d) with free-field wave-number, k = ω/c and distance d between source and receiver.

Another example is the radiation impedance of a plane wave: Z = ρ·c

Button - Default

By default AKABAK calculates with

  Speed of sound c   = 343.32 m/s
  Density        rho = 1.205 kg/m3
  Pressure       p0  = 101.33 kPa
  Temperatur     T   = 20 C

Button - Calc

Calculator for c and ρ of air. See chapter Sub-Form-Calculate Acoustic Parameters.

For other media we need to enter ρ and c directly. For example, water has the following acoustic parameters at T=20C:

c = 1483m m/s

ρ = 998 kg/m3
