Boundary Element Components, such as the Diaphragm, Shell, Duct, VibFile and the Baffle need positioning which specifies the mounting-point and the orientation of the device.

The mounting-point, P1, is always the center point of lateral extension of the component. In the other dimension, the mounting point is in the plane of the outer rim. For example, the outer suspension of a loudspeaker-diaphragm, the aperture of the duct or the opening of the shell-component.

Identifier

If the orientation of the component is aligned with one of the coordinate-axis then direction-specifiers are convenient:

Identifier of Direction

x, y, z Axis 3D
xy, xz, yz, yx, zx, zy Plane 3D
pos, neg Axis CircSym

x, y, z are directions of the main-axis of the component. xy ... zy can be used alternatively. These are planes which normal points the direction. A negative-sign inverts the direction. Pos and Neg are used for Dim=CircSym and point along the axial-axis.

For example the first dome-shaped Diaphragm in the picture on the right is specified with Identifier of Direction=z. The second with Identifier of Direction=x (The pictures of the example show an additional offset, which can be provided with the help of sub-form Scaling of Position).

Mounting Position P1

By default the mounting position is at the origin of the global coordinate system. You can pin the component to a coordinate from a database of Nodes. Specify here the Node-Index of the coordinate. Further you need to select the Nodes-database at list-box Reference to Nodes.

Reference to Nodes

Reference to database of Nodes. You would need this entry only if you want to use a coordinate from this database as specified at input-field Mounting Position P1.

Triangle

Items can also be positioned with the help of a positioning triangle. This technique is particular practical if coordinates are readily available. See also at chapter Planes.

Reference to Nodes

First we need a reference to a database of Nodes.

P1, P2 and P3

P1 gives the absolute position of the mounting point of the component. The mounting point is typically the center of the front edges of the component. Specify the Node-Index of the coordinate.

P2 and P3 are there to provide orientation. The length of P2 and P3 can be arbitrary. The direction of the component-axis is identical to the normal N of the triangle:

N ∝ (P2 - P1) x (P3 - P1)

P2 controls axial rotation. The local x-axis of the component is aligned with the vector from P1 to P2.

P3, together with P2, controls the inclination of the component-axis.

Mesh-File

Positions can also be based on planes as given by Mesh Files. The schema is similar to using a Position Triangle as explained above. However, with mesh-files the position triangle is constructed from the assigned mesh-planes. P1 is the center-point of all included triangles. In case symmetry is exploited the shape gets expanded first. The normal is deduced from the first plane of the set, assuming the control-plane is flat.

It can happen that the control-plane may yield an unexpected axial rotation. For a circular diaphragm or a duct the axial rotation may not matter. However, for rectangular or oval shaped cross-sections we may need to adjust the axial rotation with the help of the Scaling form, as explained below.

Reference to Mesh File

First we need a reference to a Mesh File-object.

Mesh File Tags

Include. Here you specify, which planes shall be included. Because each plane of the mesh-file has one or multiple Tags, we can use these for selection.

Exclude. Tags specified here will be excluded from selection.

Baffle

Some components can be positioned with the help of a Baffle-component. In this case all parameters of positioning would be ignored.

Scaling of Position

The Scaling sub-form provides a range of local and global rotation and translation parameters.

Note, Scaling-parameters are not inherited.

Inheritance

Position and Scaling parameters cannot be inherited. However, Button Get will retrieve these parameters from the ancestor.

This button is hidden if there is no inheritance specified.
