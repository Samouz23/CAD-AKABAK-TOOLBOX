Main Menu

Home Desktop

File

New project

Resets the application. All data will be deleted. The filename will be reset. Default values will be assigned as specified in Preferences.

Open project...

Opens an existing AKABAK-project, which is contained in a file with extension *.akp. Typically the file gets selected with the help of the Filename-Form. Prior to loading all data will be reset.

A quick way to open a project is via the Recent File list, which is accessible at the speed-button below the main-menu.

A project file can also be drag and dropped from Windows file-manager into the desktop of AKABAK.

Also AKABAK can be started with an application-parameter, which is the filename of the project.

Save project as...

Saves the current project into an AKABAK-file of extension *.akp. A filename needs to be provided at the Filename-Form.

Save project...

Saves the project by using current filename.

Printing...

Prints the current view on paper.

File Explorer...

Opens Windows file-manager at the folder of the current project.

Exit

Terminates the application. Alternatively press the keys ALT+F4 or click the cross at the top of AKABAKS main-window.

Edit

Delete, undo, use of clipboard, create new components and edit existing ones.

Undo

Undoes recent deletions. Undo depends whether the focus is on the LE-schematic or on one of the component lists.

Cut

Copies selected item(s) to the clipboard. Then the selected item(s) gets deleted.

Copy

Copies selected item(s) to the clipboard.

Paste

Inserts item(s) from the clipboard.

Delete

Deletes selected item(s) by moving these to the undo-list.

Select all

Selects all items.

Duplicate

Creates and inserts a clone of selected item.

New component...

Opens New Component Form where you can select the new component from various lists.

Edit Parameters...

Opens a form for editing parameters of the selected component.

Edit Name...

Lets you modify the caption string of a component without resetting calculations.

Venue

Specific commands for manipulating components of the BE-part.

See Drawing Controls for navigating the 3D-viewer.

See Treelist Controls for navigating the component-tables at the side of the desktop.

Change Inheritance...

Selects the ancestor for selected component. If a component has an ancestor then all its parameters are inherited from this related component. in the forms inherited parameters are indicated by blank edit-fields of orange background. You can over-write these values. For default values leave the edit-field blank.

Change Subdomain...

Select the Subdomain or Interface of the component of the BEM-Part.

Repository (to/from)

The table Repository is there for temporary storage of components. Components which are in the Repository are disabled, this means they are not taking part in the calculations.

Schematic

Specific commands for manipulating components of the LE-part.

Rotate

Rotates component of schematic-designer by 90 deg.

Flip

Flips component of schematic-designer (available only for some components).

Group

Compiles selected components of schematic-designer to a group. All components of a group translate in common.

Ungroup

Un-groups selected group in schematic-designer.

Show in Label

Selected parameter of lumped element is displayed in the schematic. See Parameter Editor.

Reference Table

Opens a table for editing links between LE- and BE-components. See at Table of LEM-BEM Links.

Global

Acoustic Parameters

Means to adjust the speed of sound and the density of air. See chapter Form - Acoustic Parameters.

BEM Parameters

Setting of the spatial dimension, symmetry and Non-Uniqueness-Compensator. See at Form - BEM Parameters.

Frequencies

Opens the Frequency Form for adjusting the frequency range and resolution.

Meshing

Opens the Meshing Form for controlling global parameters of the mesh-generator.

Formula

Opens the global Formula-Form for parameterization of the model.

Fixed Driving

Default driving values at observation stage. See Form-Fixed Driving.

Level of Driving

Scaling of the driving-value of the LE-Sources. Actually only the output level gets scaled, which is feasible because of the assumption of linearity. See Form-Level of Driving.

Processing

Calculate All/Individually

Processing means to calculate the total system response. Please, refer to chapter Processing for details.

Field Show

Renders results of Field calculations in the 3D-Viewer at selected frequency. See chapter Page - Frequencies for selecting the frequency.

Output Spectra

Sends results of spectra calculations to VACS, Clipboard or File.

Abort Calculations

Call for stopping any pending calculations. Note, that because of asynchronous processing, there might be a delay before the process is actually terminated.

Tools

Import ABEC Project

Importing an existing ABEC-project. See chapter Importing ABEC-Projects.

Export Mesh

Exports a BE-mesh to file(s). See chapter Form - Export Mesh.

Info Editor

The information file can be used to annotate your project with text and bitmaps.

Copy/Save as Picture

Copy to clipboard or save to file the current view of the 3D-Viewer or of the Schematic Designer. The file-format can be chosen at menu Options/Preference-Graphics.

Options

Result File

Manually save, load or delete the result file. The result-file does not contain essential project information. On file-transfers you can omit it. Also, it can be deleted.

Open VACS

Manually send the command to open the sibling application called VACS or VacsViewer.

Open ini-File

Opens the in-file of AKABAK, which is saved at "C:\Users\<user>\AppData\Local\RDTeam\Akabak.ini"

Units

Opens the Units-Form for changing the units of the input-fields of floating-point parameters.

Preferences

Opens the Form - Preferences which controls default parameters and other global settings.

Help

Help

Help invokes the user-manual. Pressing F1-Key in one of the dialogs calls for context-help.

Bug Reporter

Complex machinery such as AKABAK may have still bugs here and there. Please do not hesitate to make a report, see Bugs and Wishes.

Release Code

Here you provide/create the Release Code for the professional version of AKABAK.

Check for Updates

Opens a dialog for checking for new versions of the application.
