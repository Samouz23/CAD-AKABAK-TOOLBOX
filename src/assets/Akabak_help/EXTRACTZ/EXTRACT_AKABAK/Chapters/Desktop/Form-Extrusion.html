This dialog is a sub-form to Elements (Nodes) - Form and Elements (Mesh) - Form. It can be called via the sandwich-menu at Extrusion or a dbl-click on label "Extrusion...".

Please find principals explained in chapter Extrusions.


Swap Normals lets point the normal-vector of the generated boundary planes into the opposite direction. For more details see Normals and Volumes.

Type of Closing Cap. If the extrusion creates a body then the base and the top or the caps of a rotational body can be added or excluded.

Switched Off

No extrusion. Specified node-numbers are not used for extrusion. Node numbers should define planes, ie triangles, quadrilaterals or polygons.

Linear

Node numbers are assumed to define line-segments of the base-line or ground planes.

Height defines the height of the extrusion.

Direction specifies where the extrusion goes.
Normal is used if the base is a plane. Then the extrusion is performed into the direction of the normal of this plane.
x,y,z extrudes into the principal direction of the coordinate axis.

Circular

Node numbers are assumed to define line-segments of the contour. The first and last lines define the axis or rotation as explained in chapter Extrusions.

Angle defines the range of rotation. It always starts at the defined contour. This parameter is also useful when modeling with symmetry. With x, y, z-symmetry use Angle=180, with double symmetry (xy, xz, yz) use Angle=90.

N phi specifies the number of sections along the rotation.
