Each edit-form of a BE-component has a page named Boundaries. Here you specify the acoustic properties of the wall enclosing the boundary element domain.

Type of Boundaries

Neumann

Neumann boundary condition means the normal component of acoustic velocity-vector is zero at the walls. Or, in other words, the boundary is fully reflective. This is the default setting.

Wall Impedance

Wall Impedance indicates that a particular acoustic impedance should be applied as boundary condition. In this case it is assumed that there has been specified already an object of type Wall Impedance on page General. Once this object exists it can be referenced by one or multiple Elements components.

Driven

Driven means that the boundary is mechanically vibrating. The normal component of the acoustic velocity-vector is equal to this vibration.

If specified the associate component is selectable in the driving-lists at Form - Fixed Driving and at various LE-Components, such as the Radiator or the Enclosure Vented for example.

Button - Options if Boundary is Driven provides the specification of driving details, such as the direction of vibration and the weight of the signal.

Swap Normals of Boundary

Planes have an orientation, which is given by the normal of the plane. Use this check-box if you wish to see normals of all planes of this component to point into the opposite direction.

Note, this check-box may be hidden if there are other means to swap the normals.

Colors

Boundary specifies the color of boundaries of Type = Neumann. By default this color is gray.

Imp specifies the color of an impedance-boundary. The default color is green.

Driven specifies the color if the boundary is driven. The default color is red.

You can alter the settings at the Color-Form.
