The specifications on this page allow to edit size, position and direction of all coordinates of the associate component(s).

Note, this GUI-dialog is always a sub-form of other forms where you find it on page Scaling.

Scaling of Size

Scale factor

Isotropic scale-factor for all coordinate-directions.

The value should be larger than zero. There is no scaling with Scale=1. For example Scale=2 will double the size of the structure, whereas Scale=0.5 will render all coordinates diminished to 50%.

Note, the entry-field recognizes sub-units, such as mm, in and ft, for milli-meter, inch or feet, respectively. For example if an imported mesh is in inch then the specification of "1in" will convert the coordinate values to SI-units.

Scale factors in x,y,z

Individual scale-factor for each coordinate.

The value should be larger or smaller than zero. Leave the entry-field blank for no scaling.

Global Transformations

Rotation about x-, y- and z-axis

Rotations about axis of global coordinate system. Angles are expected to be in degree.

Shifting in x, y, z

Translations of mounting point in global coordinate system. Values are assumed to be specified in user-units.

Mirror

Inverting values of coordinate components, which yield a mirror position. For example, if the position was [1.5, 2.2, 3.05] then, after Mirror=x, the new coordinate would be [-1.5, 2.2, 3.05].

Order of Transformation

The order of application of above scaling-operations does matter. For example, there is a difference whether you first rotate the position and then apply shift or whether you do it vice versa.

AKABAK applies transformation in the same order as the input-fields are listed. For altering the list first select one of the input-fields so that the cursor blinks inside. Then click up-down-button. This will move the focused input-field inside the form up or down, respectively.
