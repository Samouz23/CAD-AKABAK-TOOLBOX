This form lets you scale the level of driving globally. No recalculation is necessary. The application simply scales the output-values which is feasible because we assume a linear system response.

In AKABAK all values are peak-values.
For convenience you can check Is rms. If checked the specified value will internally be multiplied by the crest factor of sinoidal signal √2 ≈ 1.4142.
