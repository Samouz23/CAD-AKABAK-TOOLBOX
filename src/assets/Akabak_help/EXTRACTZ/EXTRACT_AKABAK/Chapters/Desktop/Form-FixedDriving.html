The Fixed Driving - Form can be opened at menu Global/Fixed Driving.

Fixed Driving means that the driven boundary element is enforced to have the specified motion, or that a pressure source has a specified value.


The fixed driving is often useful for principal investigation, or if the only thing you want to do is to observe the radiation impedance, to study directivity patterns or room modes, for example.

The alternative to fixed driving would be coupled driving, which means that the sound pressure field affects the mechanic motion of the driven boundary element. Coupled driving is possible only for elements which are connected to a Lumped Element Network.

Pressure sources are always driven forward, i.e. there is no feedback from the acoustic field to the lumped element network.

Enabling

Initially, fixed driving is disabled. This is so because we assume that the project will feature a lumped element network as a means of driving. However, there are cases where it is more convenient to avoid setting up a lumped element network and to use fixed driving.

It is also possible to mix fixed driving and coupled driving. In this case the application checkes whether a BEM-source is connected to a lumped element network. If not it defaults to fixed driving. (Sometimes this can yield suprising results. If, for example, a source meant to be disabled by disconnecting it then is still driven by the "ghost" of fixed driving).

Weighing Features for All

If nothing is specified the driving value is a constant frequency spectrum of amplitude:

Vibrating boundaries v = 1 m/s
Pressure sources p = 1 Pa

Parameters in this section will modify this value for all driven boundaries and pressure sources which are not linked to a lumped element network.

Amplification

Value of amplification.

Delay

Value of signal delay τ in seconds: v2 = v1·exp(-j·ω·τ)

Weight(f)

Unchanged : This means the spectrum of the fixed value is constant.

Multiply by jω : in this case the driving spectrum is raising with frequency: v2 = v1·jω

Divide by jω : in this case the driving spectrum is falling with frequency: v2 = v1/jω. This case is often used to mimic the response of a direct radiating loudspeaker which is roughly proportional to the acceleration.

Reference Data File

Additionally the driving value can be weighted by a frequency response from a dataset. This dataset comes from a Curve File Object of the General-Part.

The reference points to the first curve. This curve is named in edit-field labeled Transfer-Function and has a red background.

Individual Features

The form always lists all vibrating boundaries and pressure sources.

Un-checking can be used to mute a vibrating boundary or a pressure source. If the boundary or the pressure source is actively coupled to a Radiator, Speaker or similar component of the lumped element part, the settings of the fixed driving are ignored.

Item

The name of the component.

LE

This flag indicates that this boundary or this pressure source is driven via the lumped element network. This is the case if the BEM component is referred to by one of the LE-components, for example by the Radiator.

Amplification, Delay, Weight(f), Data File

In this section each driving element can be controlled individually. The meaning of the parameters are identical to those of the global section above. Each set of parameters apply only to the selected element and not to the others.

Individual and global parameters are applied both.
