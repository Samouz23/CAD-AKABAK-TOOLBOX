Home

Akabak supports SI-units as well as User-Units for input of floating point value.

Go to menu Options/Units for selecting the input-mode.

Buttons - All...

The buttons All SI and All Milli are for convenience, alternatively you can select units individually.

Check-Box - Do Convert Current Values

Important is the check-box Do convert current values. If checked then already specified values are transformed into the new User Unit schema. For example if you have entered 0.01kg the same field will display 10g with User Unit set to gramms. If not checked then values are assumed to be already of the new schema. For example 0.01kg would become 0.01g.

Check-Box - For any New Project

Normally the setting of user-units is for the current project only. If you want your settings become the initial setting of new projects then set a check here.

OK

This command will switch all input-fields into the selected mode.

Note on Formula and Scripting

Note, that the output of the Formula-System should be in the selected form of user-units.

Within scripts specified units over-write user-units. If no unit is specified within a script then user-settings are applied.
