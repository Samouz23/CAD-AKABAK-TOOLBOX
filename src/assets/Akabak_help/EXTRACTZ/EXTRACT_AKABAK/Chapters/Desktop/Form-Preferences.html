Form - Preferences

Home

Preferences are default settings for new projects.

The Preference Form opens via menu Options/Preferences.

Page - Graphics

This page sets preferences of the 3D-graphic and the schematic designer.

Rotation of View. This setting arranges the initial view, when a project is opened or setup new. It also sets the polar rotation-axis for Euler-Mode.

Rotation Mode starts your Project with a particular rotation-mode.

View Port controls the size of the canvas of the 3D-viewer. Outside means the canvas is adjusted to the largest dimension of the window. Inside adjusts to the smaller side of the window (Inside mode can correct scaling problems of virtual operating systems).

Schematic editor: Securing moving... If checked, lumped elements cannot be moved within the schematic editor, unless you press the CTRL-key. This option helps to prevent accidental displacement of components.

Background of 3D-viewer and Background of schematic designer arranges for the color of the background. More colors opens the standard color-dialog of windows.

Format for Copy to Clipboard sets the picture-format, if you issue menu Tools/Copy as Picture, i.e. if you place the current drawing as a bitmap to the clipboard.

Page - Processing

Parallel Processing

Here you can set-up the calculation threads.

Number of Thread limits the number of CPU-Threads, which are used for meshing, solving and calculations.

Non-Uniqueness Compensation (NUC)

AKABAK treats the Non-Uniqueness Problem in order to avoid certain arte-facts in the exterior domain at high frequencies.

Specify here the default method, which gets applied to new projects. On project level NUC can be enabled and disabled with the help of Form - BEM-Parameters.

Page - VACS

This page gives information where to download the module for outputting the results of spectral observations, see chapter VACS and VacsViewer.

Page - Files

Saving of Result Files

Saving of results of the solving stage is explained in chapter Processing. Result-files have the same name as the project. However, the file-extension is *.akpbe  They are stored at the same folder as the project.

BEM Solving File

This feature is very convenient, however there may be circumstances where you dont want this saving. Here you can disable automatic saving. Note, you can still save the result file manually with the help of menu Options/Result File/Save.

Save to Tmp-Folder

If checked result files are initially saved to the local tmp-folder of the Operating System. Eventually, on saving the project, the result file is moved from the tmp-folder to the project-folder.

If un-checked result files are saved into the folder of the project.

If the BEM-project is solved and if no filename has been issued to the project so far, the result file will be saved to the tmp-folder. On saving the project the result file will be moved to the project folder.

Example Files

Here you can specify the path to your own copy of the example files which is used if you issue menu File/Open Example...
During installation the example files are copied to the global document folder of Windows, for example

    C:\Users\Public\Documents\RDTeam\AKABAK\AKABAK Examples\
