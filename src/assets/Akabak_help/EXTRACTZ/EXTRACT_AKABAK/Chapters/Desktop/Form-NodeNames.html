Form - New Node Numbers

Home Form Nodes

This tool helps in renumbering node names. It is called with Rename from the popup-menu of Form Nodes.

Before opening this form select in the first column a range of nodes, which you want to provide with new numbers. There are two modes of operation:

  1. Incremental
  2. Offset

Incremental In this case provide an integer number in the input-box First. This will be the first new number. The next node-name depends on the value of Delta:
NewName = First + i · Delta

Offset In this mode existing node numbers are offset by the value which is specified in input-box Delta. Leave input-box First blank or set to zero. The value of Delta can be positive or negative:
NewName = OldName + Delta.
