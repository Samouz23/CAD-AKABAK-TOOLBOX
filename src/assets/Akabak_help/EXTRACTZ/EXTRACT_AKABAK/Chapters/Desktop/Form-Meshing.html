Meshing sub-divides the input-planes of the acoustic boundary into triangles. The mesh forms the means by which the underlying Integral Equation is solved. Most important is the specification of the size of the finite element, which can be specified directly with the help of parameter Edge Length.

Meshing parameters specified at menu Global/Meshing provide default values and can be overwritten at subdomain-, interface- and boundary-components. Each subdomain-, interface- or component-form has a page Meshing. Here colored fields mean that the parent, ancestor or global value is used.

Spec Type

Parent means all Meshing parameter default to those of the subdomain or the interface the component belongs to.

Inherited means parameters are taken from the related ancestor if available.

If Parent or Inherited have no specifications (blank input-fields) then mesh-parameters default to the ones entered at the global-form. The global-form can be opened at menu Global/Meshing.

Meshing Type (3D)

The Meshing Type controls the way the auto-mesher produces triangles for given input planes. The meshing engine tries to produce a most regular mesh for finite element analysis.

Bifu stands for bifurcation. Here each triangle is split at its longest edge into two new triangles. If the longest edge is larger than Edge Length then a new cycle of splitting is performed.

Delaunay typically yields high quality meshes and can handle complicated shapes. Delaunay calculations are involved and may take longer to mesh than Bifu. Delaunay meshing runs through a loop in order to split boundaries and place new vertices. Normally, this loop is exited after few iterations only, but can fail if conditions cannot be matched. In this case an error message is output.

Mesh Density

Edge Length

Before solving, AKABAK investigates the entered planes and eventually will cut these planes to create triangular boundary elements. Edge Length makes sure that all triangles have sides smaller than given value. Hence, the smaller the value the more triangles will be produced as explained in chapter Meshing.

By Factor provides an alternative way of specification. The entered value is a factor by which Edge Length gets calculated from the parents value:

Edge Length = Factor·Parent

The reported frequency is a heuristic, which provides a value up to which the BEM-mesh might be useful. The value is equal to half of the temporal wave-length.

λm  =  c/Edge Length
Mesh Frequency  =  1/2 · λm

with c: speed of sound. Further experimentation should be performed. Experience shows that a good starting point is to adjust mesh-frequency to approximately the upper frequency of solving. Depending on the character of the boundaries, simulation may require a lower value of Edge Length or it turns out that a higher is sufficient.

Edge Length Min

The purpose of this value is to prevent the generation of triangles with edges of length smaller than this values. Edge Length Min is optional. If not specified then it is internally set to 10% of the first value.

By Factor provides an alternative way of specification. The entered value is a factor by which Min gets calculated:

Min = Factor·Edge Length

Inner Shapes

If specified this value controls the Edge Length of holes of the Baffle-component.

Quadrilaturals (3D)

Quad Ratio

Quadrilaturals of large aspect ratio are cut into two new and smaller quadrilaturals until Lmax/Lmin is less than Quad Ratio. If not specified Quad Ratio = 3 internally.

Delaunay (3D)

Min Points Distance

Controls the density of a Delaunay-mesh. During mesh-generation new triangles from additional points are created. A point is only added if the clearance to other vertices is larger than Min Points Distance. By default the value is zero.

Max Loops

Delanauy-meshing can be supplemented with an integer, which controls the generators main-loop. By default this loop is stopped after N=1000 iterations. In this case an error is raised. In special cases it may be helpful to increase this number.

Skinny Angle

The Delaunay algorithm tries to avoid creating triangles with minimum angles smaller than this value. In rare occasions it might be helpful to be able to alter this value. By default its value is to 20°.
