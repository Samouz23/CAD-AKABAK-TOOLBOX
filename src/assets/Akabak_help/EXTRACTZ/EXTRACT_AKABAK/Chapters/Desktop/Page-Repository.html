Home Desktop

The table Repository is there for temporary storage of components. Components which are in the Repository are disabled, this means they are not taking part in the calculations.

Select a component and issue menu Venue/Repository (to/from).

If the component is part of one of the active lists (General, BEM, Observation) it will be moved to the table Repository.

If the component is in the Repository it will be moved back to an active list.
