The specifications in this sub-form allow to alter position and direction of a component.

Local Transformations

Local rotation about mounting point.

Rot axial, horiz, vertical

Rotation about the main-axis of the device. Horiz alters the left/right direction. Vertical modifies the downwards or upwards direction. Angles are expected to be in degree.

Axial offset

Offset along the main-axis. The value is assumed to be specified in user-units.

Swap direction

Inverts the direction along the main-axis.

Global Transformations

Rotation about x-, y- and z-axis

Rotations about axis of global coordinate system. Angles are expected to be in degree.

Shifting in x,y,z

Translations of mounting point in global coordinate system. Values are assumed to be specified in user-units.

Mirror

Inverting values of coordinate components, which yield a mirror position. For example, if the position was [1.5, 2.2, 3.05] then, after Mirror=x, the new coordinate would be [-1.5, 2.2, 3.05].

Order of Transformation

The order of application of above scaling-operations does matter. For example, there is a difference whether you first rotate the position and then apply shift or whether you do it vice versa.

AKABAK applies transformation in the same order as the input-fields are listed. For altering the list first select one of the input-fields so that the cursor blinks in it. Then click up-down-button. This will move the focused input-field inside the form up or down, respectively.
