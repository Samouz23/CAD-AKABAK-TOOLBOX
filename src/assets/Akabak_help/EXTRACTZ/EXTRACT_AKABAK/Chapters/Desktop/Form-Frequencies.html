Form - Frequencies

Home

The model is calculated in the frequency domain. The range of frequencies is specified with the help of this form.

The Frequency - Form can be opened at menu Global/Frequencies.

The list of frequencies is displayed on the desktop at Page - Frequencies.

Range of Values

Frequency Band

The frequency-range goes from f1 to f2 and includes both values.

Abscissa

Abscissa specifies the distribution-type of frequency points. For details, see AES-paper [30].

With Abscissa=lin calculation points are distributed linearly with a constant spacing of df = (f2 - f1)/(N - 1). The generating formula is fi = i·df + f1 with i running from i = 0 ... N-1

With Abscissa=log a logarithmic distribution is generated. This grid has a high density at low frequencies and a low density at high frequencies. On a log-paper the spacing of points appears constant with ratio of neighboring frequencies r = exp((ln(f2) - ln(f1))/(N - 1)) The generating formula is fi = ri·f1 with i running from i = 0 ... N-1

With Abscissa=lig the area hyperbolic function or ArSinh-function combines the properties of the linear and logarithmic mapping. It behaves linearly for arguments close to zero and logarithmically further away. The generating formula is fi = 0.5·(r - 1/r) with r = R1·exp(i/(N-1)·ln(R2/R1)) and R1 = f1 + √(f12 + 1) and R2 = f2 + √(f22 + 1) with i running from i = 0 ... N-1

Number of Frequency Points

Points total specify the number of frequencies, which gets generated in the range between f1 and f2.

Points per octave specify the number of points based on an octave. The relation is: f2/f1 = 2(N/ppo)

You can specify N or ppo, respectively, whith mutual calulation. On entering f1 and f2 the mutual calulation depends on which parameter has had focus recently.

List of Values

The list is an alternative way of specifying the frequency-abscissa. You can type frequency values in any order separated by a blank or new line. Engineering format can be used, for example 10k for 1000.

Miscellaneous

Display list

Controls the list of frequencies on the desktop, see also chapter Page-Frequencies.

List of frequencies - Copy

Copies the list of frequencies to the clipboad.

For new projects - Save

The current settings will be used as default-values for new projects.

Notes

Note, for Boundary Element Analysis it is possible to include f1=0. In this case Abscissa=lin. For f > 0 the Helmholtz Equation and for f1=0 the Poisson Equation is solved.
