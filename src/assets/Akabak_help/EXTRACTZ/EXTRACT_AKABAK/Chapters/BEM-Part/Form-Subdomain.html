Form - Subdomain

Home BEM-Part

The Subdomain-component is the parent to a list of boundary and pressure-source components. Parameters specified at the Subdomain-component are forming the default settings for its child components.

Create a new Subdomain-component with the help of the New Component Form. The home of a Subdomain-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.


For multi-domain analysis we need several subdomain components. The boundaries and sources of one subdomain do not effect elements of other subdomains.

Subdomains can be coupled in two ways:

  1. with the help of Interface-components which form the base for Subdomain Modeling.
  2. via vibrating boundaries which are coupled to the lumped element network.

For radiation calculations there should be at least one subdomain specified.

If a subdomain hosts only pressure sources then there will be performed only Direct Sound Analysis.

Page - Name

On page Name provide the name of the component in form of a string. Further there is space for annotations.

Page - Parameters

Type of Domain

This parameter is essential for the Boundary Element Analysis. It is ignored for Direct Sound Analysis.

Interior means that all boundaries of the domain are specified. Hence, the enclosed volume is finite. Boundary normals are pointing into this volume.

Exterior is a specification which assumes an infinite domain. For example, the simplest radiation-setup would be a single pressure source radiating into the infinite domain. You can install an Infinite Baffle, which essentially halves the domain.

In both cases there can be exclusions to the domain. Each exclusion can have any shape but a thin shape. The exclusion should form a volume which surface provides acoustic boundaries.

See chapter Boundary Element Analysis.

Colors

Boundary specifies the color of boundaries of Type = Neumann. By default this color is gray.
Imp specifies the color of an impedance-boundary. The default color is green.
Driven specifies the color if the boundary is driven. The default color is red.

You can alter the settings at the Color-Form.

Scaling

Opens Form-Scaling, which provides scaling, shifting and rotation of coordinates or all components, which belong to this Subdomain.

Page - Meshing

On this page you can control the way the finite element mesh is generated for all components of this Subdomain. If not specified global meshing parameters are used, which should be specified at menu Global/Meshing....

Meshing Type and Edge Length and further parameters are described in chapter Form - Meshing.
