Form - Shell

Home BEM-Part

Shell creates boundary elements for a variety of shapes. Shell is typically used for passive boundaries, however it also can be specified to perform vibration. Further, it can be used for boundary elements of an Interface.

Create a new Shell-component with the help of the New Component Form. The home of a Shell-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

Page - Name

On page Name provide the name of the component in form of a string. Further there is space for annotations.

Page - Parameters

Modeling

Type of Shell: Select here the shape to be created:

Disc results in a flat circular plane.
Annulus gives a flat circular plane with an exclusion of diameter dD1.
Cone shapes a concave or convex cone of depth/height tD1.
Dome results in a convex or concave dome of height/depth hD1.
Sphere makes a sphere of diameter dD.

Model: Selection which controls the level of details taking into account for meshing of certain shapes. For details see chapter Diaphragm - Modeling.

Num Rings: This integer can refine the shape of a dome or a sphere. If left blank the default of Num Rings = 2 is used.

Baffle

The local baffle helps to embed circular shapes into an otherwise rectangular environment. See chapter Sub-Baffle for details of parameters Baffle Type and Offset.

Page - Dimensions

Shape

Specifies details of the outer shape such as the a circle, a rectangle, an ellipse or an oval, respectively.

dD, WD, HD

dD is the outer diameter of a circular shape.

WD and HD are the outer dimensions of a rectangle. WD is the width and HD is the height. The particular outline can be selected with the help of parameter Shape. The width is along the local horizontal direction. Use Rotate Axial of Scaling in order to rotate about its axis.

dD1

The Shell can have an exclusion or a dome at its center depending on the selection of Shell Type. The inner feature is always centered and of circular shape. dD1 specifies the diameter of the inner feature.

tD1

tD1 is used only for Shell Type = Cone. Positive values create a concave cone otherwise it is convex or flat. tD1 measures at the outer edge of the cone down to the base of the inner feature.

hD1

For Shell Type = Cone hD1 is the height of the inner dome.

For Shell Type = Dome hD1 is the height or depth of the dome.

If hD1 > zero then the feature is rendered convex, if hD1=0 flat and if hD1 < 0 its shape is concave.

Page - Boundaries

Here you specify the acoustic properties of the boundaries of Shell-elements. Details are given in chapter Frame - Boundaries.

Page - Meshing

On this page you can control the way the finite element mesh is generated for the Shell. If not specified Shell uses Meshing parameters of its Parent, which can be a Subdomain or an Interface. These in turn default to global settings (see menu Global/Meshing...).

Spec Type: For a Shell, which is linked to another Shell from which it inherits parameters, there is the option to select from where to receive default values.

Meshing Type and Edge Length and further parameters are described in chapter Form - Meshing.

Page - Position

A Shell is positioned by attaching it to a coordinate from a Node-database, by using mesh-file-planes or by using the Shift parameter of the Scaling feature. The mounting point is the center of the outer edge of the Shell.

Positioning and orientation is described in chapter Form - Position.

Inheritance

A Shell can inherit parameters from another Shell.

A Shell-component is linked to its ancestor with the help of the Inheritance-Form.
