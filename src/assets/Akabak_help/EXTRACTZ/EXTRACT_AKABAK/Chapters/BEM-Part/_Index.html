The BEM-Part of the desktop manages and displays components of radiation, either for the Boundary Element Analysis or Direct Sound Calculation.

The table at the side of the desktop lists all components which take part in the radiation. Chapter Lists Editors explains the navigation.

If you want to temporarily disable a component you have to move it to the Repository.

The check-boxes are for controlling the visibility of the component and its parts. Note, that also invisible components take part in the calculation. This is contrarily to page Observation where un-checking means disabling and hiding.

A new component is created by issuing menu Edit/New Component, by the desktop button, by dbl-clicking into the blank area of the list or via the right-click-menu.

For editing a component, first select its entry in the list then issue menu Edit/Parameter or dbl-click the entry.

Structure

There is a particular structure for the BEM-components. Mainly there are two levels. At the top level we have Subdomains and Interfaces. At the lower level there are components of acoustic boundaries and pressure-points. Hence each component belongs to either a Subdomain or to an Interface. This reflects the principal of subdomain-modeling.

You create a new component via menu Edit/New Component (or dbl-clicking in the white space of the table). This will open the New Component Form. There go to page BEM and select the component you wish to create. Eventually you will be asked to which Subdomain or to which Interface you want to assign the new component.

BEM settings

For applying the Boundary Element Method we need to create a mesh, which elements provide the actual boundary conditions. The mesh generation can be controlled globally at menu Global/Meshing. These are default values. You can over-write these settings at Subdomain or Interface level or at individual components.

There are also certain fundamental BEM-parameters, which we should set up before hand. See at chapter menu Global/BEM Parameters.

For a BEM model firstly we create the Subdomain and Interface sections. Eventually, we use components to create the geometry for the acoustic boundaries. There are basic components such as Elements (Nodes) and Elements (Mesh File). A set of particular shapes can be generated with the help of components Shell, Duct or others. All components provide a reflective, an impedance or a vibrating boundary condition. The components Diaphragm and Vib File conveniently create a set of boundaries of typical vibrating loudspeaker membranes.
A pressure source is not a boundary condition, rather an abstract concept of "something" creating sound at a point. For BEM pressure sources are practical for mimicking a loudspeaker inside a room, for example. Components such as Pressure Points and Pressure Box need to be assigned to one of the Subdomains.

Direct Sound Settings

A Subdomain can be made Direct Sound simply by omitting any component which otherwise would create an acoustic boundary. Hence, if a Subdomain hosts only Pressure Points and Pressure Box components then the BEM-solver is skipped and there would be left to do only the observation stage. The only boundary component allowed is the Infinite Baffle. For Direct Sound there is no meshing. However, symmetries are taken into account, see chapter menu Global/BEM Parameters.
