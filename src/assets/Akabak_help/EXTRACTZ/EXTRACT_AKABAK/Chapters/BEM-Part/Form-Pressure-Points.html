Form - Pressure Points

Home BEM-Part
   

The component Pressure Points implements a list of a single pressure point sources. Each radiating omni-directionally.

Create a new Pressure Points-component with the help of the New Component Form. The home of a Pressure Points-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

The Pressure Points are created for the specified Subdomain.
If the Subdomain also provides boundary elements it becomes a domain which needs to be solved with the help of the Boundary Element Method.
If the Subdomain only contains pressure sources and optionally an Infinite Baffle this domain is treated with the Direct Sound Analysis.

Alternatively you can use component Pressure Box, which would create a single point however with directivity.

Symmetry

In case of symmetry or the use of an Infinite Baffle mirror pressure points will be installed automatically.

Dimensions

Dim = 3D: Pressure Points resemble ideal point sources, which radiate omni directional. The sound pressure is

p = p0·exp(-jkd)/d

with d distance between source-point and observation point, k = ω/c wavenumber, c speed of sound and j imaginary unit and p0 some constant.


Dim = 2D: we have ideal pressure-lines, which radiate radially in the 2D-plane. The sound pressure is

p = p0·(Y0(kd) + j·J0(kd))

with Y0 Neumann-function and and J0 Bessel-function of zero order.


Dim = CircSym: Pressure Points resemble concentric rings of constant pressure. The directivity is given by the Bessel-function of zero order.

On this page the pressure sources are specified.

Buttons - New, Delete

Create a new pressure point, or delete the selected.

Reference to Nodes

Reference to the associated Nodes-database.

Table

List of all pressure points radiating. You can edit parameters directly inside the table. See chapter List-Editors.

Node

Node-Index of the coordinate as specified in database Nodes.

Amplitude, Delay

At solving stage the driving pressure is p = 1 Pa. This is the default value. At observation stage this value will be multiplied by the corresponding parameter of the lumped element network or of the fixed driving table.

Weight changes the amplitude and Delay τ in seconds performs: p2 = p1·exp(-j·ω·τ)

Comment

Each pressure point can be annotated.
