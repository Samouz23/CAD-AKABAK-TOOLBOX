Form - Elements (Nodes)

Home BEM-Part

Elements creates boundary elements of flat planes. Currently supported polygons are quadrilaterals and triangles. Each Elements component can host as many planes as you like. The vertices of the planes are node-indices from a Node-database. The component can make passive boundaries. It also can be specified to perform rigid-body vibration. Further, it can be used for boundary elements of an Interface.

Create a new Elements-component with the help of the New Component Form. The home of a Elements-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

Page - Name

On page Name provide the name of the component in form of a string. Further there is space for annotations.

Page - Planes

On this page we organize the database of planes.

New, Insert, Delete

Create a new record, or delete the selected records. You can use the menu, the buttons or the keyboard (Insert, Ctrl+Del).

Swap Normals

Inverts the direction of the selected planes. More on the normal of a plane see chapter Normals and Volumes.

Nodes

Reference to the associated Nodes-database.

Table

See also chapter List Editors.

The table lists all specified planes. Name is an arbitrary integer-number. Node-Indices are pointers to coordinates of the associated Nodes-database. Each node-index will form a vertex of the polygon of the plane. The order of specification matters and controls the direction of the plane. See chapter Nodes and Elements. Comment provides a place for annotation.

Node-indices are edited directly in the list. Separate each node-index by a blank.

Start edit-mode: Simply start typing numbers. Press keyboard F2. Mouse slow dbl-click.

Submit the new value: Press keyboard ENTER. Press keyboard up/down. Mouse click.

Cancel editing: Press keyboard ESC.

Extrusion

Extrusion expands specified line-segements or planes into planes or bodies, respecively. This feature can be called at the sandwitch-menu or by dbl-clicking on the label "Extrusion...". Opened is the Extrusion-Form.

Copy and Paste

Selected records or values can be copied to the clipboard. Eventually, these data can be pasted into the table. The datum is copied in text-format, which allows to paste the content also into the formula-editor or to any text-editor.
If a range of node-indices is selected the clipboard contains only these values. For pasting at the target table you can select more than available values.
If the plane-index is selected then the whole record gets copied to the clipboard. Eventually you can paste these records into the table or any Element- or Fields-Form. Here are two options available: over-writing existing coordinates or adding as new.

Moving and Sorting

Selected records can be moved up or down the list by issuing local menu Move up, Move down, ... or press CTRL+UP or CTRL + DOWN keys.
Records can be sorted with respect to the node-index. For this click on the header of the first column.

Undo

Operations can be undone with the local menu Undo or CTRL+Z key.

Page - Scaling

Page Scaling alters position of all coordinates. For details see sub-form Scaling.

Page - Boundaries

Here you specify the acoustic properties of the boundaries of Elements-elements. Details are given in chapter Frame - Boundaries.

Page - Meshing

On this page you can control the way the finite element mesh is generated for the Elements. If not specified Elements uses Meshing parameters of its Parent, which can be a Subdomain or an Interface. These in turn default to global settings (see menu Global/Meshing...).

Meshing Type and Edge Length and further parameters are described in chapter Form - Meshing.
