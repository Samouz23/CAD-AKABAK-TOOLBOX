The Interface-component is used for Subdomain Modeling. The Interface is the parent to a list of boundary components which connects two Subdomains.

Any boundary component can be assigned to an Interface, such as Elements (Nodes), Elements (Mesh), Baffle, Shell, Duct, Transition.

Parameters specified at the Interface-component are forming the default settings for its child components.

Create a new Interface-component with the help of the New Component Form. The home of a Interface-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.


The integrations over the finite elements of the interface make sure that sound pressure and velocity are continuous. Hence, the interface is acoustically transparent. We need the interface only for the mathematics. If a boundary component is assigned to an Interface its settings of boundary conditions are ignored.

For multi-domain analysis we need interfaces only if domains are coupled. If two domains are linked with the help of an interface, they "communicate" only through the mesh of the interface. See chapter Subdomain Modeling.

Page - Name

On page Name provide the name of the component in form of a string. Further there is space for annotations.

Page - Parameters

Subdomains

There are two list-boxes with references to existing Subdomains. Here we select which Subdomains are to be coupled with the help of the Interface, that means, with the help of its boundary components.

The order matters. Reference Subdomain 1 should reference a Subdomain where the normals of the boundaries of the Interface point to.
This setting is most important for the Interface to work properly. For example, the figure to the right displays a VibFile of concave shape mounted in an Infinite Baffle. The boundaries of the Interface are provided by a Shell-component. Its normals point into Subdomain "Interior". Hence, we have to set the first reference to Subdomain "Interior" and the second to "Exterior".

Colors

The default color is violet with a slight transparency. You can alter the settings at the Color-Form.

Scaling

Opens Form-Scaling, which provides scaling, shifting and rotation of coordinates or all components, which belong to this Interface.

Page - Meshing

On this page you can control the way the finite element mesh is generated for all components of this Interface. If not specified global meshing parameters are used, which should be specified at menu Global/Meshing....

Meshing Type and Edge Length and further parameters are described in chapter Form - Meshing.
