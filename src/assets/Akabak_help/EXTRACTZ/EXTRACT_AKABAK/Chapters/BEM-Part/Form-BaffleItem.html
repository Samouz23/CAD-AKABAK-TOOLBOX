Form - Baffle-Item

Sub-form BEM-Part
    
EdgeLength=25mm
EdgeLength=2mm

A Baffle-Item describes a geometric feature within the plane of the Baffle component, such as a hole or an aperture for another component.

Annotations

Index can be any number. It becomes the "name" of the Baffle-Item.

Comment provides room for an annotation.

Way of Specification

A Baffle-Item can be either defined by referencing a component, or by the dimension of a hole.

Component

Reference to Component means that an existing component shall be positioned on the baffle. Currently, following components can be referenced: Diaphragm, VibFile, Shell and Duct.

The Baffle receives information about the aperture from the referenced component. The number of line-segments which form the hole is derived from the referenced component. You can fine-tune the edge. Go to page Meshing of the referenced component and enter a value at Inner Shapes.

Hole

Shape of hole creates a hole of the selected shape. The size of the hole needs to be specified. The hole can be extruded with the help of parameter z at Position on the Baffle.
Edge Length controls the meshing of the hole. The value is the length of line-segments along the shape used for mesh-generation.

Position on the Baffle

All Baffle-Items are position with the help of the local coordinate system. The origin is either measured from the bottom-left vertex or from the center of the baffle. If Shape=Vertices then the first Node represents the origin of the local coordinate system.

x, y

x is the horizontal coordinate and y the vertical.

z

z is used as extrusion parameter. A positive value extrudes to the front. A negative makes a tunnel.

x- and y- Centered

If checked then coordinates are measured from center.

Axial Rotation

Each Baffle-Item can be rotated about its axis.

Formula

All parameters of format floating-point can be assigned a formula. Please check chapter Form - Formula for further details. Formula-identifiers for Baffle-Items parameters are:

Dimension of Exclusion
dHole<Index> Diameter
WHole<Index> Width
HHole<Index> Height
LenHole<Index> (not available, see ShiftZ<Index> below)
Meshing
EdgeLength<Index> Segmenting of exclusion
Position on the Baffle
RotateAxial <Index> Rotation axially
ShiftX<Index> Position x-direction
ShiftY<Index> Position y-direction
ShiftZ<Index> Extrusion

Example

Each identifier needs to be concatenated with the index of the Baffle-Item. For example

    dHole1 = 10 + @GlobalDiameter
    dHole2 = 10 + @GlobalDiameter

The diameter of the exclusion of Baffle-Item is 10 + the value of the global variable GlobalDiameter. Note, prefix "@" means that we access a global-formula.

Example

In another example, if we want the hole to be extruded specify in section Formula:

    // Dimension of hole
    WHole1=0.2
    HHole1=0.1

    // Local position
    ShiftX1=0.05
    ShiftY1=0.05
    RotateAxial1=30

    // Extrusion
    ShiftZ1=-0.03

Note, the extrusion of the Baffle-Item is controled by the shifting parameter "ShiftZ1=" (and not by "LenHole1=").
