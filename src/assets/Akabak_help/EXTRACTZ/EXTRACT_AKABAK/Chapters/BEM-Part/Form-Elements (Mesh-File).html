Elements (Mesh File)

Home BEM-Part

The component Elements creates boundary elements which originate from a Mesh File object. For any given component of type Elements one typically would use only a sub-set of mesh-elements. The selection is done with the help of specifying Tags. The component can create both, passive boundaries and boundaries of vibration. Further, it can be used for boundary elements of an Interface.

Create a new Elements-component with the help of the New Component Form. The home of a Elements-component is page BEM, either part of a Subdomain or of an Interface. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

Page - General

Name of Component

The name of the component in form of a string. Further there is space for annotations.

Mesh File

Reference to the associated Mesh File object.

Extrusion

Extrusion expands line-segements or planes into planes or bodies, respecively. This button opens the Extrusion-Form.

Page - Drawing

The page Drawing displays the currently used set of boundaries. The number of boundaries depends firstly on what is available from the associated Mesh File object. Secondly, it depends on the specification made in the Tag-list.

The operation is identical to Mesh File object - Page Drawing.

Page - Scaling

Page Scaling alters size, position and orientation of all dimensions. For details see sub-form Scaling.

On editing, a marker appears at page Drawing. This indicates a modification. On switching to page Drawing scaling parameter get applied and eventually displayed.

Page - Boundaries

Here you specify the acoustic properties of the boundaries of Elements-elements. Details are given in chapter Frame - Boundaries.

Page - Meshing

On this page you can control the way the finite element mesh is generated for the Elements. If not specified Elements uses Meshing parameters of its Parent, which can be a Subdomain or an Interface. These in turn default to global settings (see menu Global/Meshing...).

Meshing Type and Edge Length and further parameters are described in chapter Form - Meshing.

Note, with this component there are two meshes: The first mesh is the one which gets imported i.e. it was created by an external meshing application, for example GMSH.
The second mesh is the one which eventually will be generated by AKABAK. The latter one are the planes which are used for the boundary element method in order to solve the Helmholtz Integral. AKABAK can refine the mesh, however it cannot combine mesh-planes in order to simplify the mesh. Another point to keep in mind is that AKABAK refines the mesh assuming a flat structure. These two points yield the advice to have the initial mesh as coarse as possible, just so that any curvature is captured sufficiently. Then, we leave it to AKABAK to refine the mesh.
