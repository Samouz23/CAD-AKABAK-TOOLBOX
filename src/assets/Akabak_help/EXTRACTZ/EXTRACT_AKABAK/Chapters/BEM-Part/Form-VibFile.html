VibFile creates vibrating boundary elements from a Vib File object.

Create a new VibFile-component with the help of the New Component Form. The home of a VibFile-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

Page - General

Name of Component

The name of the component in form of a string. Further there is space for annotations.

Vib File

Reference to the associated Vib File object.

Page - Parameter

At solving stage the driving velocity is v = 1 m/s and modified by following parameters.
At observation stage this value will be multiplied by the corresponding parameter of the lumped element network or of the fixed driving table.

Weight

Value of amplification.

Delay

Value of signal delay τ in seconds: v2 = v1·exp(-j·ω·τ)

Weight(f)

Unchanged : This means the spectrum is constant.

Multiply by jω : in this case the driving spectrum is raising with frequency: v2 = v1·jω

Divide by jω : in this case the driving spectrum is falling with frequency: v2 = v1/jω. This case is often used to mimic the response of a direct radiating loudspeaker which is roughly proportional to the acceleration.

Normalization

If you want to couple the Vib File-diaphragm to a Lumped Element Network the vibrational distribution should be normalized to the rigid body motion of the diaphragm because the lumped velocity shall be controlled by the lumped element network.
The point for normalization is typically where the driving force is attached. For an electro-dynamic speaker this is the connection of the voice coil. After normalization the measured frequency response of the velocity at the reference point is one for all frequencies. At any other point the frequency response of vibration relates to this reference point.

Lowest normalizes the vibration-data to the vibration at the lowest point, i.e. the point with coordinates most recessed. This setting is particular helpful for scans of conical loudspeaker membranes with a convex dust cap. Here we assume that the lowest point coincides with the connection of the voice-coil.

Mean normalizes the data-set to the mean-value at each frequency. This setting makes that the frequency response of the mean-value is one for all frequencies.

Original does not perform a normalization. Hence, the vibrational-data are used as is. This means that the frequency response at any point may include the response of the measured driver. Obviously this setting makes only sense, if we observe with fixed driving (no coupling to a Lumped Element Network).

Pos Polar normalizes the data-set of vibration to a certain point, which needs to be specified additionally by Radius and Angle.

Pos Cartesian is similar to the previous setting only that in this case the coordinates of the reference point is specified in Cartesian coordinates.

Side

Optional parameter, which allows to specify the direction of vibration to be at the rear of the component.

Use Line Scan

If checked the line-scan mode is enforced even if Dim=3D.

Page - Drawing

The page Drawing displays the available set of boundaries from the associated Vib File object.

The operation is identical to the global 3D-Viewer.

Page - Scaling

Page Scaling alters size, position and orientation of all coordinates. For details see sub-form Scaling.

On editing, a marker appears at page Drawing. This indicates modification. On switching to page Drawing scaling parameter get applied and displayed.

Page - Meshing

On this page you can control the way the finite element mesh is generated for the Elements. If not specified Elements uses Meshing parameters of its Parent, which can be a Subdomain or an Interface. These in turn default to global settings (see menu Global/Meshing...).

Edge Length and further parameters are described in chapter Form - Meshing.
