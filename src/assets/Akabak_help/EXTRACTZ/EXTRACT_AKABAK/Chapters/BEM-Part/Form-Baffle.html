Form - Baffle

Home BEM-Part
       
     

The Baffle component creates Boundary Elements on a flat plane similar to component Elements.

Baffle also can arrange items on the Baffle using a local 2D-coordinate system. These items can be either simple zones of exclusion or components. If the item is a component it needs to exist already. The Baffle will position the component on its plane and also will cut out a hole for it. In this way boundary elements are not overlapping.

Create a new Baffle-component with the help of the New Component Form. The home of a Baffle-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

Page - Name

On page Name provide the name of the component in form of a string. Further there is space for annotations.

Page - Outer Edge

Shape

If you select Shape then the edge of the baffle is either a Circle, Rectangle, Ellipse or an Oval. If such a fixed shape is selected we need further information about its size (dB, WB, HB). Also the position needs to be specified.

dB is the diameter of the Baffle if Shape=Circle. WB and HB are the width and height, respectively, of a rectangular shape.

Position shifts and rotates the mounting point of the baffle which is thought to be in the center of the shape. The specification is similar to as described in Form-Position.

Vertices

With this selection the edge of the Baffle is assumed to be specified with the help of a list of coordinates. The associated node-indices need to be entered into the long input-field. The numbers should be separated by blanks. If there are three numbers a triangle is created. Four entries would yield a quadrilateral. More entries create a polygon, for example

1001 1002 1003 1004 1005 1006 1007 1008

for convenience it is also possible to type it in the form

1001 .. 1008

We also need a reference to a database of Nodes.

Side

Front means the plane(s) point forward as expected by the positioning parameters. This is the default.

Rear is a special setting, which proofs helpful if you are going to specify boundaries for a typical loudspeaker baffle. If you are modeling both the interior and the exterior for the BEM there would be necessary two Baffles - one for the inside and one for the outer side of the cabinet. Often the Baffle for the interior is similar to the one of the exterior domain. With Side=Rear you can specify the rear Baffle in the same way as the front Baffle. AKABAK will adjust positions and normals.

Extrusion

Extrusion of the outer shape of the Baffle. Positive values yield a concave shape, negative values makes a wall extending to the rear.
Extrusion is a convenient way of specifying the boundaries of the side walls. The drawback is that all planes of the Baffle receive the same meshing parameters. If you need individual parameters then it might be better to specify the side walls with the help of components Elements, Duct or Transition.

Scaling

Opens Form Scaling which alters position and orientation of all coordinates. If Shape=Vertices the scaling-factor would have an effect on the coordinates of the vertices, hence making Baffle smaller or larger. Otherwise the scaling-factor would be ignored.

Page - Items

A Baffle can be host to a range of items. Such a Baffle-Item can be a simple hole or an aperture for an existing component. The list allows for inline-editing. See Baffle-Item-Form for details.

Button - New

Opens the Baffle-Item-Form and eventually adds the new item to the Baffle.

Button - Delete

Removes the selected Baffle-Item. The referenced component is preserved. However, its position may need to be corrected.

Button - Edit

Opens the Baffle-Item-Form.

Page - Boundaries

Here you specify the acoustic properties of the boundaries of Baffle. Details are given in chapter Frame - Boundaries. Note, referenced components have their individual boundary specification.

Page - Meshing

On this page you can control the way the finite element mesh is generated for the Shell. If not specified Shell uses Meshing parameters of its Parent, which can be a Subdomain or an Interface. These in turn default to global settings (see menu Global/Meshing...).

Edge Length and further parameters are described in chapter Form - Meshing.

If the Baffle contains Items, i.e. holes or referenced components for positioning then the type of meshing should be specified as Delaunay.

Formula for Baffle-Items

Baffle-Items feature special identifiers in order to distinguish the records. The identifier is made-up from character Identifier + Item-Number. For example, "ShiftY1=" means that the result of its formula will be assigned to the y-component of the shift-parameter of the scaling of the Baffle-Item with index 1.

For example:

    ShiftY1 =  -640/2 + 460
    ShiftY2 =  -640/2 + 270
    ShiftY3 =  -640/2 + 80
