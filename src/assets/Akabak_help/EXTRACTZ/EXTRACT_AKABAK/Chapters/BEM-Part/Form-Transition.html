Form - Transition

Home BEM-Part

Transition creates Boundary Elements, which form the transition between two other components.

Create a new Transition-component with the help of the New Component Form. The home of a Transition-component is page BEM. Edit an existing component by dbl-click its entry on page BEM or issue menu Edit/Parameters or press CTRL+E.

Page - Name

On page Name provide the name of the component in form of a string. Further there is space for annotations.

Page Parameters

Reference

Following components can be referenced: Baffle, Diaphragm, Duct, Shell and VibFile. Planes will go from the edge of the first referenced component to the second.

If there is only a single entry then the transition-planes go to the center-point of the referenced component.

Type of Edge

Outer Edge means that transition planes originate at the principal rim of the component. For example at the suspension of the Diaphragm.
Extrusion Edge, here the planes start at the extrusion of a Baffle or a Diaphragm.
Base Baffle Edge If the Diaphragm, Shell or Duct has a local baffle then planes can be attached to the edge of this baffle.
Inner Edge, here the planes start from the inner feature of a Diaphragm or a Shell.

Page - Boundaries

Here you specify the acoustic properties of the boundaries of Transition-elements. Details are given in chapter Frame - Boundaries.

Page - Meshing

On this page you can control the way the finite element mesh is generated for the Transition. The Transition can only be meshed with the help of bifurcation (Meshing Type = Bifu). If not specified Transition uses Meshing parameters of its Parent, which can be a Subdomain or an Interface. These in turn default to global settings (see menu Global/Meshing...).

Spec Type: For a Transition, which is linked to another Transition from which it inherits parameters, there is the option to select from where to receive default values.

Edge Length and further parameters are described in chapter Form - Meshing.

Page - Formula

All parameters of format floating-point can be assigned a formula. Please check chapter Form - Formula for further details. Formula-identifiers for Transition parameters are:

Driving
Weight Signal amplification
Delay Signal delay
Meshing

SkinnyAngle Min angle at Delaunay
QuadRatio Aspect ratio of quads
