Form - Radiation Points

Home Observation

Radiation Points is an observation object, which yields the sound pressure spectrum at spatial points individually specified.

Create a new Radiation Points-component with the help of the New Component Form at page Observation. For editing dbl-click its entry on page Observation, press CTRL+E or issue menu Edit/Parameters

The result of the spectrum calculation is a frequency response which will be displayed with the help of VACS.

The frequency range is specified at menu Global/Frequencies.

Page - General

Name and Annotation

Provide the name of the component in form of a string.

There is also space for annotations.

Page - Positions

On this page we organize the database of observation points, which can be regarded as microphone positions.

Button - New, Delete

Create a new record, or delete the selected records.

Reference to Nodes

Reference to the associated Nodes-database.

Table

The table lists all specified observation points. Name is an arbitrary integer-number. Node-Indices are pointers to coordinates of the associated Nodes-database. Comment provides a place for annotation.

See also chapter List Editors.

Page - Range

On this page you find controls for the range of output as the ranging directly controls the contouring. Also sources can be selected which shall take part in the simulation. More see chapter Frame - Range.

Page - Formula
