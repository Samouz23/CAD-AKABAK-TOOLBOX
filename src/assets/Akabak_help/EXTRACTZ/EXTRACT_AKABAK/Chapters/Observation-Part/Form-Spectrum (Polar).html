Radiation Polar is an observation object, which yields the sound pressure spectrum at various spatial points along an arc.

Create a new Radiation Polar-component with the help of the New Component Form at page Observation. For editing dbl-click its entry on page Observation, press CTRL+E or issue menu Edit/Parameters

The result of the spectrum calculation is a frequency response which will be displayed with the help of VACS.

The frequency range is specified at menu Global/Frequencies.

Page - General

Name and Annotation

Provide the name of the component in form of a string.

There is also space for annotations.

Page - Parameters

Polar Range of Angles

These parameters control the distribution of points on an arc. The starting, end- and on-axis-points are on a plane, which position needs to be specified at page Position. Zero degree is assumed to be on-axis.

Min and Max specify the starting and end-angles, respectively. Number of Points controls the density of observation points. Most common are ranges for a front semi-circle and a full circle:

Arc Min Max
Semi circle -90 +90
Full circle -180 +180

In case the total range is <360 degree then ΔAngle = (Max - Min)/(N - 1). In case the total range is exactly 360 degree then ΔAngle = 360/N, with number of points N. In this case AKABAK automatically reduces the number of points by one. For example if you specify Min=-180, Max=180, N=30 then only 29 spectra will be produced, ranging from -168, -156, ... 180 with ΔAngle = 12 degree.

Distance

Distance is the radius of the circular arc on which observation points are distributed.

Far Field: if checked then the simulation is carried out at a large distance. Eventually the amplitude is scaled to specified Distance and the phase to zero-distance.

Far-Field Distance: here you can specify the "large" distance for approximating far-field conditions. If left empty 100 times the size of the radiator is used as far-field distance.

Normalized

Normalized: if checked all response curves will be normalized to the curve with angle specified at field Normalizing Angle. An example of the result is shown at the side.
Alternatively you can also perform normalization in VACS. There select menu Processing/Normalizing.

Display of Arc

This feature has no effect on the calculation. It controls the visual representation of the observation object inside the 3D-Viewer.

Rotation Hints is practical for large values of Distance. Start-, end- and on-axis-points are marked and the arc visualizes the positioning.

Points on Arc is practical if observation points are close to the radiator. In this mode there is a dot for each microphone.

Page - Position

Identifier

Identifier is most useful if the arc is aligned with the principal axis of the coordinate system. The list provides pairs of symbols each stand for the name of an axis (x, y or z). The two axis named will span the plane in which the arc is embedded. For example zx will create observation-points in the x-z-plane.
Further, the first character - in our example the z-axis, will point into the on-axis direction. The second character indicates the starting point of the arc on which points are distributed - in our case the x-axis. A minus sign will invert the arc.

Use sub-form Scaling Position in order translate and rotate the arc.

Point of Rotation can also be used to specify the point of rotation of the arc in terms of a node-index, which points into a Nodes-database. If you make use of Point of Rotation you also need to specify this database at list Reference to Nodes.

Triangle

The arc can also be positioned with the help of node-indices. There are three nodes defining point P1, P2 and P3.

P1 is the point of rotation.

P2 and P3 mark the plane in which the arc is embedded. The vector P2 - P1 is the on-axis direction (zero degree). The length of P2 and P3 can be arbitrary.

Page - Range

On this page you find controls for the range of output as the ranging directly controls the contouring. Also sources can be selected which shall take part in the simulation. More see chapter Frame - Range.
