Form - Fields (Nodes)

Home Observation

Field (Nodes) generates regularly spaced observation points on planes of quadrangle or triangular shape. These planes are defined by vertex-coordinates taken from an associated Nodes-database.

Create a new Field-component with the help of the New Component Form. The home of the component is page Observation. Edit an existing component by dbl-click its entry on page Observation or issue menu Edit/Parameters or press CTRL+E.

The result of the Field calculation is the frequency response of the sound pressure. It will be displayed as a contour-plot in the 3D-viewer.

The frequency range is specified at menu Global/Frequencies. After calculation select the frequency or frequency-range to plot at Desktop-Page - Frequencies.

The check-box of the list at the side of the desktop lets you show or hide the field. Un-checked Field-records will be skipped at next round of calculation.

Page - General

Name of Component

Provide the name of the component in form of a string.

Analysis Type

Pressure means the type of analysis is set to sound pressure response.

Meshing - Edge Length

Meshing is responsible for the distribution of observation points, which we can regard as microphones. Edge Length is a measure for the distance between two such points. The distance will not be exactly the same as Edge Length, but the distance will be guaranteed to be smaller. We need a sufficiently dense mesh of microphones in order to avoid aliasing artifacts.
Quad Ratio: Quadrilaturals of large aspect ratio are cut into two new and smaller quadrilaturals until Lmax/Lmin < Quad Ratio.

Page - Planes

On this page we organize the database of observation-planes.

Nodes

Reference to the associated Nodes-database.

New, Insert, Delete

Create a new record, or delete the selected records. You can use the menu, the buttons or the keyboard (Insert, Ctrl+Del).

Table

See also chapter List Editors.

The table lists all specified observation-planes. Name is an arbitrary integer-number. Node-Indices are pointers to coordinates of the associated Nodes-database. Each node-index will form a vertex of the polygon of the plane. See chapter Nodes and Elements. Comment provides a place for annotation.

Node-indices are edited directly in the list. Separate each node-index by a blank.

Start edit-mode: Simply start typing numbers. Press keyboard F2. Mouse slow dbl-click.

Submit the new value: Press keyboard ENTER. Press keyboard up/down. Mouse click.

Cancel editing: Press keyboard ESC.

Copy and Paste

Selected records or values can be copied to the clipboard. Eventually, these data can be pasted into the table. The datum is copied in text-format, which allows to paste the content also into the formula-editor or to any text-editor.
If a range of node-indices is selected the clipboard contains only these values. For pasting at the target table you can select more than available values.
If the plane-index is selected then the whole record gets copied to the clipboard. Eventually you can paste these records into the table or any Element- or Fields-Form. Here are two options available: over-writing existing coordinates or adding as new.

Moving and Sorting

Selected records can be moved up or down the list by issuing local menu Move up, Move down, ... or press CTRL+UP or CTRL + DOWN keys.
Records can be sorted with respect to the node-index. For this click on the header of the first column.

Undo

Operations can be undone with the local menu Undo or CTRL+Z key.
