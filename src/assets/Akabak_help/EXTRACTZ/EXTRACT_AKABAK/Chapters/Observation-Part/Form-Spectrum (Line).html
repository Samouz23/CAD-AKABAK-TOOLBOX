Form - Radiation Line

Home Observation

Radiation Line is an observation object, which yields the sound pressure spectrum at various spatial points along a line.

Create a new Radiation Line-component with the help of the New Component Form at page Observation. For editing dbl-click its entry on page Observation, press CTRL+E or issue menu Edit/Parameters

The result of the spectrum calculation is a frequency response which will be displayed with the help of VACS.

The frequency range is specified at menu Global/Frequencies.

Page - General

Name and Annotation

Provide the name of the component in form of a string.

There is also space for annotations.

Page - Positions

Reference to Nodes

Reference to the associated Nodes-database.

P1, P2, Number of Points

P1 and P2 are Node-Indices which are pointers to coordinates of the associated Nodes-database. P1 and P2 are the starting- and end-points of a line-segment. On this vector Number of Points of observation points are distributed.

Type of Plot

Curves yield a graph where each trace is the spectrum at one point along the line. The coordinates are copied to the Parameter section of each curve.

Contour yields a Contour plot. By default the y-axis is displaying the index of the point starting at P1 and ending at P2. Use VACS/Graph/Parameters for alternative mappings.

Page - Range

On this page you find controls for the range of output as the ranging directly controls the contouring. Also sources can be selected which shall take part in the simulation. More see chapter Frame - Range.
