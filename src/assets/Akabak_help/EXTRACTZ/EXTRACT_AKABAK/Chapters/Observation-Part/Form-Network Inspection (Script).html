Form - Network Inspection (Script)

Home Observation

Special Network Inspection object, which calculates the spectrum of parameters of the lumped element network which is specified in form of a LE-Script. Note, for inspecting networks of the schematic editor use Network Inspection instead.

Create a new Network Inspection (script)-component with the help of the New Component Form at page Observation. For editing dbl-click its entry on page Observation, press CTRL+E or issue menu Edit/Parameters

The result of the spectrum calculation is a frequency response which will be displayed with the help of VACS.

The frequency range is specified at menu Global/Frequencies.

Page - General

Name and Annotation

Provide the name of the component in form of a string.

There is also space for annotations.

Page - Observation

Component

Reference to the LE-Script which contains LE-components which parameters you want to observe.

New and Delete

Create or remove an observation.

Table

This table lists the parameters selected for observation. Each entry creates a curve in VACS.

Analysis selects the type of parameter such as Mechanic Excursion or Electric Current.

System is the name of the network of the component.

Component is the name of the component.

Port No specifies the port-number of multi-port components. For example a four-pole element has two ports. The first port has poles s and t. The second port is made of poles u and v. Observation points, which are not accessible have Port No = 0, such as the Mechanic Excursion of transducers.

Node s and Node t are used to mark observation of potentials.

Page - Range

On this page you find controls for the range of output as the ranging directly controls the contouring. Also sources can be selected which shall take part in the simulation. More see chapter Frame - Range.
