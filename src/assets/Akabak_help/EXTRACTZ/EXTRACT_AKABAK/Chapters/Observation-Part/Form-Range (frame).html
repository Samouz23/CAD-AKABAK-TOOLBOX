Home Observation

This sub-form is part of all forms of components of the Observation-Part. It gives control of output-parameters.

Range

For Field-calculations the ranging directly controls the contouring. For curves which are sent to VACS, specifications done here have only an effect at first creation of the curves and will be ignored for updates.

Bode Type

Bode Type selects the component of the complex-valued frequency response. In Field plots we can select only scalars such as Level dB or the real part. In curves for VACS we can select also combinations such as real and imaginary parts.
Level dB is naturally normalized. In AKABAK all dB-amplitudes are normalized to one unit peak. The sound pressure is normalized to
p0 = √2·20µPa.

Range

Range specifies the difference between Maximum - Minimum.
If Minimum is specified then Maximum = Minimum + Range.
If Maximum is specified then Minimum = Maximum - Range.
If Maximum and Minimum are specified then Range = Maximum - Minimum.
If not specified Range gets calculated.

Minimum

Minimum fixes the display range at the lower bound if specified.

Maximum

Maximum fixes the display range at the upper bound if specified.

Step Size of Contour

For Field plots only. Contour-plots are quantized. The value of Step Size specifies the difference between the contour levels.

Radiation Elements

Radiation simulations support the superposition technique, which enables to view the response of all or only a sub-set of sources.

List

Check-in which radiating boundaries or pressure sources shall take part in this observation.

Buttons

All will check all items. None un-checks them.

Output

Here the output can be selected individually. The default setting is done at menu Options/Preferences.

In case of Field-observations use menu Tools/Export Fields for saving results to file.

Way of Output

For output, there are various ways:

  • None (means use Preference)
  • Save to file
  • Copy to clipboard
  • Pipeline to VACS using COM

Folder

Specify here the folder-name where to store the files if Way of Output = Save to File. Click on the button with the ellipse to open the folder-form.

Text Format

Data are stored using the VACS Import Control Settings. The text-format-version is easier to parse, whereas the binary version is more compact. Both versions are documented.
