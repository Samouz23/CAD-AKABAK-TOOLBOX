Form - Fields (Mesh File)

Home Observation

Fields (Mesh File) calculates the field at the planes given by a Mesh File object. Most often the planes of observation are part of the CAD and sub-sequent external meshing. Hence, often we may want to make use only of a sub-set. Use Tags in order to extract wanted observation planes.

Create a new Field-component with the help of the New Component Form. The home of the component is page Observation. Edit an existing component by dbl-click its entry on page Observation or issue menu Edit/Parameters or press CTRL+E.

The result of the Field calculation is the frequency response of the sound pressure. It will be displayed as a contour-plot in the 3D-viewer.

The frequency range is specified at menu Global/Frequencies. After calculation select the frequency or frequency-range to plot at Desktop-Page - Frequencies.

The check-boxes in the list at the side of the desktop lets you show or hide the field. Un-checked Field-records will be skipped at next round of calculation.

The example to the right displays the direct sound response of an array of subs in an arena. The mesh-file of the venue was using the mesh-file format COLLADA (*.dae).

Page - Parameter

Analysis Type

Pressure means the type of analysis is set to sound pressure response.

(Note, currently Pressure is the only Analysis Type available. In the future there will be also a field of acoustic motion)

Meshing

Mesh File is a reference to the associated Mesh File object.

View Symmetry. This setting applies only in connection with BEM-Parameters of symmetry. If View Symmetry is checked then the Field is rendered also with symmetric parts if available. Otherwise the field is rendered always only at the positive octant(s).

Edge Length controls the distance between the observation points (microphones). Edge Length also controls the meshing algorithm which is used to display the contours and its colors.

Please note that Edge Length should to be smaller than spatial variations of the physical Field in order to avoid aliasing effects. Below the input-box of Edge Length is displayed a value of Mesh Frequency. The acoustical wave-length of this frequency corresponds to half the value of Edge Length. Hence, we get a hint up to which frequency the field plot would work in the worst case. Beyond this frequency the plot may miss out certain variations of the field.

Meshing of Quads can be used to fine tune the way quadrilaterals (rectangles, squares, etc) are subdivided. Grid produces a regular pattern by dividing the edges in to sections of length Edge Length. Bifu performs directly a triangulization by bifurcation until the longest side of a triangle is smaller than Edge Length. None does not do a sub-division into smaller planes. The quadrilateral will be divided into two triangles only.

Quad Ratio: Quadrilaturals of large aspect ratio are cut into two new and smaller quadrilaturals until Lmax/Lmin < Quad Ratio.

Page - Range

On this page you find controls for the range of output as the ranging directly controls the contouring. Also sources can be selected which shall take part in the simulation. More see chapter Frame - Range.

Page - Drawing

The page Drawing displays the currently used set of planes for observation. The number of planes depends first on what is available from the associated Mesh File object. Secondly it depends on the selection made in the Tag-list.

The operation is identical to Mesh File object - Page Drawing.

Page - Scaling

Page Scaling alters size, position and orientation of all coordinates. For details see sub-form Scaling.

On editing, a marker appears at page Drawing. This indicates modification. On switching to page Drawing scaling parameter get applied and displayed.
