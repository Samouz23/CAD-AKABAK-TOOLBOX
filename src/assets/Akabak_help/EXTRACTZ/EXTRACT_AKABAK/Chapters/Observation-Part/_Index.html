The Observation-Part of the desktop manages and displays components of observation. The table at the side of the desktop lists all components which provide an observation.

An observation is active if checked. A checked observation-item will take part at next round of calculation.
If you uncheck an observation-item its graphic representation gets hidden. An unchecked item will also be skipped during next round of calculation.
You can also move an observation component to the Repository.

A new component is created by issuing menu Edit/New Component, by clicking the desktop button or by dbl-clicking into the blank area of the list.

For editing a component, first select its entry in the list then issue menu Edit/Parameter or dbl-click the entry.


Observations are falling into four categories:

  1. Fields
  2. Radiation points or polar
  3. Radiation impedance
  4. Network parameters

All calculations are performed in the frequency domain for frequency-points specified at menu Global/Frequencies. A reflection of these settings are given at the desktop at Page - Frequencies.

Simulations involving the Boundary Element Method make necessary a special solving stage as discussed in chapter Processing.

Range, Superposition, Output

For all observations the output-parameter can be specified in detail, such as the Bode Type and the range of values.

Radiation simulations support the superposition technique, which enables to view the response of only a sub-set of sources.

For output, there are various ways:

  1. Field plot in 3D-Viewer
  2. Save to file
  3. Copy to clipboard
  4. Pipeline to VACS

For all these settings there is a dedicated Page, which all observation-forms feature. For details see Frame - Range.

Fields

Fields are the calculation of many frequency responses at various spatial points. These points are distributed on a plane automatically. Fields are output as a colored contour plots inside the 3D-Viewer of AKABAK. Calculated Fields can be exported. See chapter Export Fields. The various types of Fields-components differ in the way the generating planes are specified.

Fields (Nodes) Fields on planes given by Nodes
Fields (Mesh File) Fields on planes given by a Mesh File
Fields (Balloon) Fields on surface of a balloon
Fields (BE-Ref) Fields on surface of boundaries

Radiation Spectrum

Radiation Spectra are frequency responses at a single spatial point or on a distribution of points. The difference to Fields is that the output goes to VACS for display.

Radiation Points Sound pressure at spatial points
Radiation Line Sound pressure at spatial points on a line
Radiation Polar Sound pressure at spatial points on an arc

Radiation Impedance

The Radiation Impedance is the lumped acoustic driving point impedance of a vibrating boundary. The output is sent to VACS, where typically the real and the imaginary parts are viewed.

Radiation Impedance

Network Inspection

Network Inspection means the frequency response of network-parameters or parameters inside LE-components.
You can issue this observation in an alternative way. Select the lumped element component of observation and issue Add to Inspection or Add to Powers from the popup-menu.
The output is a spectrum which values are sent to VACS for display.

Network parameters Response of network or components
Network powers Power response inside network

Network Extrema and Integrals

The result of this calculation are single values of the maximum or the integral of a spectrum. The output is send to the input-form and displayed as table.
