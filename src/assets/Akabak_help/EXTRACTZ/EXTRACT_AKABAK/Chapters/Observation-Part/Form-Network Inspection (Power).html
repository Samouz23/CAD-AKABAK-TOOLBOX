Form - Network Inspection of Powers

Home Observation

Network Inspection of Powers calculates the spectrum of the power response inside the lumped element network.

Create a new Network Inspection (Power)-component with the help of the New Component Form at page Observation. Alternatively, select the component of observation and issue Add to Powers from popup-menu.
For editing dbl-click its entry on page Observation, press CTRL+E or issue menu Edit/Parameters.

The result of the calculation is a frequency response which will be displayed with the help of VACS.

The frequency range is specified at menu Global/Frequencies.

Page - General

Name and Annotation

Provide the name of the component in form of a string.

There is also space for annotations.

Page - Observation

Component

The power-response is always linked to a lumped element, which you select here. You can pre-select the component prior creating the observation object.

This table lists all available power-responses to observe of the selected component.

Page - Range

On this page you find controls for the range of output as the ranging directly controls the contouring. Also sources can be selected which shall take part in the simulation. More see chapter Frame - Range.
