LE-Parameter - Formula at Run-Time

Home Formula

At certain places formula can be entered in complex form, for example at runtime formula for lumped elements, such as Filter, Coupler or Impedance.

Results

For each frequency the run-formula system will be calculated. In this process the result of the last formula gets assigned to the associated parameter of the component.

Variables

Imaginary unit

Results can be complex if you specify the imaginary unit or provide out of range arguments (for example √(-5)).

The imaginary unit is identified by the letter j, with

j·j = -1.

If j comes before a number (for example between the minus sign and the value) or before the name of a constant or function or before a bracket, this is equal to multiplying the following value by the imaginary unit. The syntax is thus similar to that of a minus sign. For example:

    h = -jSin(j - -j5);  k = -j(5 + j^(Sin(3)) + h
