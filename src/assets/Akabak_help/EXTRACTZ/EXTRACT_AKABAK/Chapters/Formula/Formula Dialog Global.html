Formula Dialog - Global

Home Formula

The global formula can be referenced from any formula at component-level.

You can invoke the global formula-editor with the help of menu Global/Formula.


A reference to a global formula system is established by prefixing an identifier with the symbol "@", for example:

    dD = 2*sqrt(@SD/pi)

In this example the identifier "SD" refers to a global formula because it is prefixed by "@".


There are multiple global formula systems. If you modify global formula then all referencing formula are modified as well. Of course, this is practical for the purpose of parameterizing. However, there are often scenario where we want this depedency to be more refined. For example, if you have parameterized the geometry of the BEM part, and if the global script also contains formula for describing the observation field, then any change would trigger also a re-solving of the BEM, which can be time consuming.


There are four global formula editors:

  • Global. Results of this script can be referenced by any other formula system. It is suited for global formula of the BEM-Part and the General-Part. Also the other global formula can take reference to this section.
  • LEM. Results can be referenced only from components of the LEM-Part. Hence, if you modify this formula-script only the LE-components get changed. The BEM-solving state is preserved. Observations need to be re-evaluated.
  • Observation. These two scripts contain any global formula, which result you want to assign to a Field- or Spectrum-Observation.
    Note, that Nodes from General-Part can be used for the BEM-Part as well as for the Observation-Part, or both. For this reason there is a switch at page Formula of the Nodes-Dialog, which directs the referencing of the formula.
