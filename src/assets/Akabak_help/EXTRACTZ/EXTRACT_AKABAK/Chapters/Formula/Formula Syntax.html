Formula Syntax

Home Formula

Formula can be used to parameterize floating point values. Formula can be entered globally, at BEM-Dialogs and at the LE-parameter editor, as explained in chapter Formula Form - Operation. The syntax follows the typical mathematic convention. For example:

    w = 0.01
    R = 0.1 + w
    dD = 2*R

There can be multiple formula. Each formula is assumed to be in one line. If there are more formula for one line then use ";" as separator. For example

    w = 0.01;    R = 0.1 + w;    dD = 2*R

The name of a formula becomes an Identifier, which can be used in sub-sequent formula. In the example above "w", "R" and "dD" are identifiers.

Results

Each formula yields a result, which gets displayed on the right hand side of the formula-dialog.

Further, results can be assigned to component-parameters, such as the diameter dD of the Diaphragm or coordinate of Node 1001. On how this is to be operated is explained in chapter Formula Dialog - Operation.

The list of special identifiers depends on the component and is reported at the Formula-page of the component.

Units and sub-units are not supported within the formula-system. However, results are assumed to be of the current User-Units.

Reference

As explained in chapter Formula Dialog - Global there is a hierarchy of formula systems. If you want to address a constant of another formula system you would use the @-sign for prefix. The referenced formula must be in one of the global formula systems.

For example, if the following formula are specified globally:

    w = 0.01
    R = 0.1 + w

Then, at component level, we can take reference to "R" by typing "@R":

    dD = 2*@R

Comments

The text of the formula can contain blank lines and lines of comment. A comment is signalled with the help of "//". Any characters behind "//" get ignored. The comment stops at the end of line. For example:

    w = 0.01      // Width of suspension
    R = 0.1 + w   // Total radius
    dD = 2*R      // Result assigned

Identifiers

Identifiers are to the left of the equal sign and form constants after calculation, and therefore represent a numerical value.

    x = 1.0e3;   y = 5*x^2

Any characters may be used except for point, comma, |, and the operator characters: 

    +, -, *, /, ^, (, ), {, }   etc.

An identifier’s name must not start with 'j', but can start with 'J'. Neither should the name be the same as a function name nor the constant pi.

Numbers

Numerical values are entered as floating point numbers without thousand-separation. The decimal separator is a point and negative values are preceded by a minus sign (without a space). For very large or very small numerical values, the computer has its own exponential notation. "e" is an abbreviation for times ten to the power of, for example:

    1.26e3 = 1.26·103	(Scientific Format SCI)

The largest and smallest numbers that can be entered are: 1020 or 10-20, respectively. Double precision is used internally. Example

    b = sin(0.5);   a = -110.34*exp(b)

The identifier for the constant π=3.14159... is called pi. The growth constant e=2.718... is entered via the function Exp(1). For example

    SD = pi*sqr(dD)/4;  e = exp(1)

Brackets

Within formulae, round brackets ( ) can be placed or nested according to the rules of arithmetic.

Operators

There are five binary operators:

+  Addition

-  Subtraction

*  Multiplication

/  Division

^  Exponential

Functions

    z = Name(Argument)
    z = Name(Argument1, Argument2, Argument3)

Name is the function name (case insensitive). The argument is another expression and is written in brackets. Multiple arguments should be separated by commas. Do not use function names as identifiers. Unitary operators - such as the minus sign the name.

See also build-in standard functions.

Examples

    z = arccos(cos(x))
    z = arctan4(Im(x), Re(x))
