Formula Dialog - Operation

Home Formula

There is a special formula-editor, which opens at menu Global/Formula, is part of the Form of BEM-components and opens at LE-components at parameter Formula.

The formula-edit-form provides at text-editor to the left, a list of results to the right and a control-button.

Editor

The editor is on the left hand side. Formula are entered as text, following the Formula Syntax. You can use multiple formula. Each formula gets a name (identifier), which can be used sub-sequentially. Some names are reserved. Reserved are either the names of build-in functions, or the identifiers of parameters of the associate component. If you name a formula with the identifier of a parameter then this parameter will receive the result of the formula.

Results

To the right you find a list of results. You can use Copy for copying a value to the clipboard.

Button Calculate

Clicking or using the keyboard with CTRL+ENTER evaluates all formula and renders results to the Result-List.

Right-Click on the button opens a menu of service-functions. Save, Save as and Open will stream the text to a file or retrieve it from there.

Button OK

Assigns the formula to the component. This command also evaluates the formula system and assigns results to parameters. The input-field of the associated parameter should display a yellow background.
