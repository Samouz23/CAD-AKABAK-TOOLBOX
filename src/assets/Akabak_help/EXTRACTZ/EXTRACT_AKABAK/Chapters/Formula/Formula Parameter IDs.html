Identifiers with an Index

At places there are list of items. Here, each record has typically a name in form of an index. In this case we type the name of the identifier directly followed by the index:

<Identifier><Index>

For example

    X2202 = -@Dc - 2*@tc;   Y2202 = @Wc/2 + @tc;    Z2202 = @Hc + 2*@tc
    Width1000 = @Width;    Height1000 = 1.618*@Width;

Following components feature Identifiers with an Index:

  • Nodes
  • Baffle
  • Pressure Points
