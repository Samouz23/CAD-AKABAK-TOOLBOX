Floating point values can also be assigned with the help of a formula for parameterization. Each component-dialog has a page with a text-editor for editing the formula system.

Identifiers

The assignment is established with the help of identifiers. Each parameter owns a unique name, which serves as an identifier. For example the diameter of the Diaphragm is called "dD". Global Formula

You can access formula, which are specified at menu Global/Formula.

A reference to a global formula system is established if you prefix an identifier with the symbol "@", for example:

    dD = 2*sqrt(@SD/pi)

In this example "SD" is the identifier of a global formula because it is prefixed by "@".
