In BEM-scripts units are optional and typically are applicable at parameters, which expect a floating point value. Unit-specification is case-sensitive. There should be no blank between the number and the unit.

If no unit is specified then units of current desktop setting are applied. See chapter Units.

For example

    Diaphragm "D1"
      dD = 350mm
      ...
    Diaphragm "D2"
      dD = 350
      ...

The above example should yield the same diameter for D1 and D2 if the current user-unit of distance is set to millimeter.

Units of Distance

In this case enter the full unit such as "mm" for millimeter, "cm" for centimeter and "m" for meter. It is also possible to specify inch and foot. For example:

    0.0254m      2.54cm
    25.4mm       25400um
    1in          0.0833ft

Units of Area

Also here enter the full unit such as "mm2" for square millimeter, "cm2" for square centimeter and "m2" for square meter. It is also possible to specify square inch and square foot. For example:

    0.00064516m2      6.4516cm2
    645.16mm2         645160000um2
    1in2              0.00693889ft2

Units of Time

Time values can be entered in SCI- or ENG-format or with the unit attached. Hence Delay=1m is identical to Delay=1ms.

Units of Frequency

Frequency values can be entered in SCI- or ENG-format or with the unit.

For example: Frequencies=10Hz, 200Hz, 1kHz, 2kHz

Or Alternatively: Frequencies=10, 200, 1k, 2k
