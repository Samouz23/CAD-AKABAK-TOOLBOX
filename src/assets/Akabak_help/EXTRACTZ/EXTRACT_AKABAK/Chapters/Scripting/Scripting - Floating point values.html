Scripts - Floating Point Values

Home Scripting

The mantissa of floating point values is indicated by a dot. No thousand separations are supported. Examples are

  dD=10.3mm
  f1=20.5Hz
  Delay=1ms
  Value=1.234e-2

Many floating point parameters of the BEM-scripts allow also the specification of units.

Scientific Format (SCI)

Use "e" or "E" directly following the number to indicate magnitudes. For example:

  1200 = 1.2e3
  0.0015 = 1.5e-3

Engineering Format (ENG)

Use "p, n, u, m, k, M, G" directly following the number to indicate pico, nano, micro, milli, kilo, Mega and Giga. For example: 10k = 1e3, 1u = 1e-6 etc.
