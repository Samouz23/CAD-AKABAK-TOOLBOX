The General Page of the desktop holds a range of databases for global access.

A new component is created by issuing menu Edit/New Component, by the desktop button or by dbl-clicking into the blank area of the list.

For editing a component, first select its entry in the list then issue menu Edit/Parameter or dbl-click the entry.

Nodes Database of coordinates
Mesh File Object of mesh file
Vib File Object of structural vibration file
Wall Impedance Object of boundary properties for BEM
Curve File Object of frequency response curves
Contour File Object of Frequency Directivity data-set
