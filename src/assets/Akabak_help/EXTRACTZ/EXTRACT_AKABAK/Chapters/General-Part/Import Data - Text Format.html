For importing datasets in text-format it is most convenient to use Import Control Settings of VACS. In this case the import would be fully automatic, for example:

  Data_Format=Complex
  Data_Domain=Frequency
  Data_LevelType=Impedance10
         500        11.01502        1.141454
    601.0638        11.02708        1.466311
    702.1277        11.06961        1.925395
    803.1915        11.79239        2.834777
     ...

However, you also can import text-files of other formats. The only assumption is that the first column is the abscissa. The second is the first and the third part is the second component of the ordinate value. For example a complex valued impedance curve could look like this

         500        11.01502        1.141454
    601.0638        11.02708        1.466311
    702.1277        11.06961        1.925395
    803.1915        11.79239        2.834777
     ...

In the above example the the import engine is not clear about the format. In this case it would open the Import Data Control Form.


Below you find information about the general format of the text-format. More features and information you find at VACS - Importing Data.

Data Separation

Data-values should be separated by Blanks, Tabs or Commas.

Line Separation

Datasets of text-format are organized in lines. Each line is separated from the next line by a combination of characters called "Carriage Return" and "Line Feed" (13+10).

A semi-colon (;) indicates also a new data-line. However, a semi-colon (;) at the start of the line marks the line as a comment and gets ignored subsequently.

A line, which starts with a character from the set (; | /) is regarded as a comment and as such ignored.

The import engine also reads files where the "lines" are concatenated and separated by commas. In such a file each "line" is encapsulated by commas. Internally the single-line-file is converted to a multiple line-file. For example

  "xxxx...","yyyy...","zzzz...",...

will be converted to:

  xxxx...
  yyyy...
  zzzz...
  ...

Floating Point Numbers

Floating point numbers are assumed to be in SI-units. The decimal separator is a point (.) or a comma (,). Thousand separators are not supported. SCI-computer notation is fine, for example 1e3 for 103. The mantissa can have up to 15 digits, i.e. double precision. The minimum and maximum absolutes are 10–300 and 10300.

If there are data-lines with "NaN" or "INF" (case insensitive) then the associated line is skipped.
