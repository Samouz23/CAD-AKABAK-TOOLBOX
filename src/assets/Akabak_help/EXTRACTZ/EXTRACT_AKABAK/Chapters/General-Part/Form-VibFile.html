A VibFile is used as driving boundary of the BEM-part. VibFile comes as a combo. There is a file-object at page General called VibFile. This object can be referenced by one or multiple BEM-components also called VibFile.

Eventually VibFile creates boundary elements automatically. These are derived from a special file with geometric and vibrational data. Currently, VibFile supports files, which are exported by the Klippel laser-scanner software.

Create a new Vib-File-object with the help of the New Component Form. The home of a Vib-File is in page General. Edit an existing object by dbl-click its entry in page General or issue menu Edit/Parameters or press CTRL+E.

Best is if the vibrational data are available for the whole frequency range of analysis. Outside this range, AKABAK will substitute vibration-values of the nearest available frequency point. Within the range, vibration values are interpolated.

Note, in AKABAK there is no feedback on the structural vibration due to acoustic pressure. The velocity profile stays the same, regardless whether the speaker is built in a waveguide or is radiating freely. Even, if you change the acoustic properties, say to water, it will still be the same distribution. In reality, of course, the vibration of a body will change due to acoustic pressure. This is especially true for a dense medium such as water. However, in air, this alteration may be small enough to yield a good approximation, hopefully better than to assume a piston movement.

The coupling to the lumped element network is via the radiation-impedance, which in turn is based on the acoustic power on the diaphragm. If a diaphragm has a velocity-distribution then this is taken into account during integrations. For details, see [9].

Try to make the vibrational scan as course as possible. For example, the Klippel scanner software can help you to identify dominant radiating modes (although this depends very much on the radiation condition). For example, for low frequency analysis we may need only a very course scan. Detailed scans may yield superb simulation results at higher frequencies, however on the cost of calculation time.

Dimension

By bringing together mechanical vibrational data and the acoustic simulation, naturally, there are several modes of operation:

Case Vibrational data Acoustic simulation Symmetry UseLineScan= Results in
1) Full 3D scan Dim=3D No symmetry false 3D-scan
2) Full 3D scan Dim=3D Sym=any sym false Line-scan
3) Full 3D scan Dim=CircSym - false Line-scan
4) Full 3D scan Dim=all modes Sym=all sym true Line-scan
5) Line-scan Dim=all modes Sym=all sym - Line-scan

During import of a 3D-vibrational data-set AKABAK directly creates both, a 3D representation and a line-scan. The latter is created by forming a mean-value in circumferential direction of the vibrational data. The mean-forming is performed complex-valued so that symmetric modes cancel by interference.

As the above table demonstrates, only case 1) results in the application of the original 3D data-set. In any other case AKABAK makes use of the circumferential mean-value (line-scan), automatically.

Page - File

Button - Open

Opens the file-dialog where you can select the file, which contains data of geometry and structural vibration.

Klippel. The data-file is created by the Klippel Laser Scanner. Use the asc-format (*.asc). Note, at the Klippel Scanner System software the file-type can be selected at the File Dialog.

Page - Scaling

VibFile coordinates are assumed to be in SI-units, regardless what User-Units has been selected. Use Scaling in order to convert mesh-coordinates to SI-units.

See sub-form Scaling for scaling, shifting and rotating the mesh-coordinates.

On editing, a marker appears at page Drawing. This indicates modification. On switching to page Drawing scaling parameter get applied and displayed.
