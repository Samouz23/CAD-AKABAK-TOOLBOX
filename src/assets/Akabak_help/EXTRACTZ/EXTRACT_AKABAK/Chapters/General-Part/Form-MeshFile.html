The home of a Mesh-File object is page General of the desktop. The data of the Mesh-File object originate typically from CAD-applications as explained in detail in chapter Mesh-Files. There can be multiple Mesh-File-objects.

Once there is a Mesh-File object other components of page BEM and page Observation can make use of its planes. See components Elements (mesh-file) and Fields (mesh-file). Mesh-files can also be used to position components, see chapter Form-Position.

A new Mesh-File-object is created with the help of the Form - New Components. You can edit an existing Mesh-File object with the help of the associated form starting at menu Edit/Parameters.

Page - General

Name of component

Text string which identifies the component. This name will be displayed at sub-sequent reference lists.

Info

Place for comments.

Page - File

Open

Opens the file-dialog and reads the mesh-file. The button with the arrow down provides a recent file list.

Re-Open

This button starts the import process directly by using the current file-name.
Note, re-open maintains the current stack of Tag-Filters, which means that the specification of mesh-file elements may still be valid or may need only a slight modification. See also chapter Tag Picking Tool.

Compatibility

The Tag machinery of previous versions of Akabak worked similar. If you want to apply your current Tag-Filters to a newly to be imported mesh-file, then check the compatibility check-box. This setting will create certain strings which your old Tag-Filters can specify.

Report

After import this box will display the format, date and time stamps of the mesh-file. There are also reports of the number of elements and the overall dimension.

Note, the size-parameter gives a hint whether the structure needs to be scaled. For example, if the CAD was using millimeter as units, in Akabak a small device would come out way too large and needs scaling (see below).

Page - Entities

The rendering of the mesh-file depends on the current setting of the Dimension as can be set in form BEM Parameters:

  • 3D: Reading of planes such as triangles and quadrilaterals.
  • Circular symmetric: Reading of line-segments which Akabak completes to circular symmetric bodies.
  • 2D: Reading of planes in 2D.

Filter

The purpose of the Filter-parameter is to exclude degenerated elements, such as elements of where the inner angle is smaller than Min Angle. Or, where the area of the element is smaller than Min Area. Or, where one of edges is shorter than Min Length.

Note, Min Length and Area are applied to the un-scaled data-set. In the example to the right a scaling of 0.001 is applied because the original CAD was drawn in milimeter which height came out nearly 1km after import. Hence, if you were to exclude tiny planes you may enter for Min Length = 10e3 or so.

After editing, a marker appears at page Drawing. This indicates modification. On switching to page Drawing the Filter gets applied and the mesh is displayed.

Page - Scaling

The dimensions of the imported mesh-file are assumed to be in SI-units, regardless of the setting at User-Units. If the drawing comes out too large then use Scaling in order to convert mesh-dimensions to SI-units. How can one determine the size of the object? Firstly, there is a report of overall size given on page File. Alternatively, one can select an element inside the drawing, which in turn outputs its location and size.

Details on how to specify parameters of scaling are given here: Form-Scaling. One can not only scale the dimensions but also shift and rotate the mesh.
Note, shift-parameters are expected in user-units.

On editing, a marker appears at page Drawing. This indicates modification. On switching to page Drawing scaling parameter get applied and the mesh is displayed.

Page - Drawing

Tags

Tags are used to specify elements. Only a specified plane will be available to the system, otherwise it would be hidden and not accessible for further operation. Specified elements are those which are listed in the box on the right hand side. Specified planes can also be inverted, that is, its Normal swapped. Details of the operation are given in chapter Tag Picking Tool.

Control

The 3D-viewer displays the mesh-file as imported, filtered and scaled. The operation of the viewer is similar to the 3D-viewer of the main-desktop.

Messages

Report on available and specified elements.

Page - Formula

All parameters of format floating-point can be assigned a formula. Please check chapter Form - Formula for further details. Formula-identifiers for Elements are:

Filter
MinAngle Exclude all triangles of angles smaller than MinAngle
MinLength Exclude all triangles of sides smaller than MinLength (in units of file)
MinArea Exclude all triangles of area smaller than MinArea (dito)
Scaling
Scale Isotropic scaling
ScaleX Scaling in x-direction
ScaleY Scaling in y-direction
ScaleZ Scaling in z-direction
RotateX Rotation about x-axis (in degree)
RotateY Rotation about y-axis (dito)
RotateZ Rotation about z-axis (dito)
ShiftX Shift in x-direction (in user-units)
ShiftY Shift in y-direction (dito)
ShiftZ Shift in z-direction (dito)
