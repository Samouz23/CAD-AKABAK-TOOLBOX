Each curve of a data-set of a data-file can be attached a so-called Parameter. For example, with the help of this Parameter a Frequency Response can be assigned to a spatial coordinate. In VACS this concept of Parameters is held more general. In AKABAK however Parameters are currently only used for directivity data. Here the Parameter is typically a spherical coordinate. For the purpose of display and for the processing one of the components of the Parameter-vector needs to be mapped to the y-axis of the plot. This component is the varying angular abscissa and displayed with a yellow background. Click on the header for editing the mapping and range.

Menu - File

Open...

Importing of parameters from a text-file. In the following it is possible to choose whether to import only to the selected column, or to over-write all parameters. The source can be either a previously exported set or any data-set with Import Control Settings with a Param-Section. Alternatively, the file may contain only a simple column of values.

Save...

Save parameters as text using the Import Control Setting format of VACS.

Menu - Edit

Perpetuate value

Command to assign the value of the selected cell to all cells of the column.

Edit range...

Opens a dialog for creating a range of values and to assign the y-axis of contours.

Menu - Control

Assign to y-axis

Assigning the column of the selected cell to the y-axis of the contour plot. The table is sorted automatically to this parameter. However, this sorting is just visual and keeps the assignment.

Change coordinate system

Change of the coordinate system for values of the first three columns. Please select subsequently if you want to transform existing values or to just switch the notation.

Sort ascending, descending

Sorting of the data set (curves) according to the legend text, whilst keeping the parameter-list. Note, this would yields a new assignment of curves and parameters.

If more than one legend is selected then sorting takes place only within this selection. This function is practical in the case where only part of the data set needs to be reversed in order, for example swapping the scan-direction of directivity measurements.

Move up, down

Move (multiple) selected data-sets (curves) up and down the list. Alternatively you may use the "+, -" keys. Note, that this operation yields a new assignment, similar to the sorting function (see above).

Table

For editing floating point values press F2 or Enter. Click on header to open Edit Parameter Range.

Curve

Read-only. Legend-name of data-set. Is used as a sorting criterion for Menu > Control > Sort.

Column 1, 2 and 3

Components of position parameters of a 3D-vector pointing from the origin to the location of the receiving point.


Column Parameter Cartesian Spherical Cylindrical
1 Param_Coord_x1 x-axis Distance from the origin Distance from axis
2 Param_Coord_x2 y-axis Polar angle θ (theta) axial (azimuthal) angle ϕ (phi)
3 Param_Coord_x3 z-axis Axial angle ϕ (phi) z-axis

This setting corresponds to Param_Coord_x1=, Param_Coord_x2= and Param_Coord_x3= of the Import Control Settings.

Driving

Specification of driving point values, such as voltage, currents, forces, etc. By default peak values are assumed, otherwise check Driving is rms. This value correspond to the Import Control Setting parameter Param_Drv=.

Parameter

Omni-purpose parameterization, such as temperature, etc. This value correspond to the Import Control Setting parameter Param_Param=.

Driving is rms

Check if the values in column Driver are rms-values, otherwise peak values are assumed. This setting corresponds Import Control Setting parameter Param_DrvIsRms=.
