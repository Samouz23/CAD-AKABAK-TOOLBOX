This tool helps in creating a linear distributed set of values for the associated parameter.

The associated parameter is the one containing the current selected cell or at which column the click occurred when opening the dialog.

Auto range

Enable

Enables the number generator. Disable if you want to prevent over-writing existing values after pressing OK.

Min, max

Range bounds. The step size is automatically calculated and depends on the number of data-sets.

Note the special issues when handling circular periodical parameters, say 0...360 or -180 ... 180 degree. For convenience you may just enter the nominal range, even if the range should be one step less. The hosting Parameter Dialog will eventually raise a query when it detects an ambivalent range definition, and then you can leave it to AKABAK for correction.

Speed buttons

Creates range limits for some frequently used ranges.

Invert

If checked then the direction of order is reversed.

Mapping

If checked then the associated parameter will be used to create the y-axis of a contour plot. Subsequently this state is indicated in the parameter table as a colored column.
