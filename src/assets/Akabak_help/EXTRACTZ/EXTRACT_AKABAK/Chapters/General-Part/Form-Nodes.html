Form - Nodes Database

Home General

Nodes provides a database of coordinates. Each record consists of a name, coordinate values and a comment. Other components take reference to Nodes as explained in chapter Nodes and and Elements. A node-record can be referenced by multiple components.

Create a new Nodes-database with the help of the New Component Form. The home of a Nodes-database is in page General. Edit an existing database by dbl-click its entry in page General or issue menu Edit/Parameters or press CTRL+E.

Name

On page Name provide the name of the database in form of a string. Further there is space for annotations.

Points

Points are individual records of coordinates. Each record consists of a name, values and a comment.

Name

Each coordinate has a name in form of an index. This number is called node-index. Other components take reference with the help of this number.

AKABAK suggest a unique number when a new point is added. However, you can alter this to any value larger than zero.

The node-index should be larger than zero. It should be unique.

If you alter a node-index, which other components use for reference, these references are automatically updated accordingly.

Coordinate Values

We assume Cartesian coordinates. In 3D we have values for the x-, y- and z-components. In 2D only values for x and y need to be specified. With Circular Symmetry there are only two values, the Axial- and the Radial- component, respectively. The dimension needs to be specified prior opening the dialog. By default SI-units of distance are assumed. However, you can alter User Units at menu Options/Units. If a value is calculated from a formula this is indicated by a yellow background color. More on formula for nodes see below.

New, Insert, Delete

New: Command to add a new coordinate record to the database. Insert: Inserts a new record above current selection. Delete: Deletes selected record.

Editing

Coordinates are edited directly in the list.

There are several ways to start the edit-mode of an entry-field.

  • Simply start typing numbers.
  • Keyboard F2.
  • Mouse slow dbl-click.

Submit the new value:

  • Keyboard ENTER.
  • Keyboard up/down.
  • Mouse click.

Cancel editing

  • Keyboard ESC.
Swap Values

A range of selected values can be swapped with its neighbors values. Issue local menu Swap Values or press keys CTRL+SHIFT+LEFT or CTRL+SHIFT+RIGHT.

Copy and Paste

Selected records or values can be copied to the clipboard. Eventually, these data can be pasted into the table. The datum is copied in text-format, which allows to paste the content also into the formula-editor or any text-editor.

If a range of values is selected the clipboard contains only these values. For pasting at the target table you can select more than available values. This would yield a repetition of values. For example, select a single value, say the x-component of the coordinate. Then issue Copy. You can then assign this single value to multiple other coordinates. In order to do so select a range of existing values. then issue Paste.

If the node-index is selected then the whole record gets copied to the clipboard. Eventually you can paste these records into the table or any Node-Form. Here are two options available: over-writing existing coordinates or adding as new.

Renaming

This tool can provide new node numbers to a selected range of nodes. Select a range of nodes in the first column (Click with Shift). Then issue Rename of the popup-menu. The New Node Name-Form opens.

Moving and Sorting

Selected records can be moved up or down the list by issuing local menu Move up, Move down, ... or press CTRL+UP or CTRL + DOWN keys.
Records can be sorted with respect to the node-index. For this click on the header of the first column.

Undo

New, Delete, Editing, Paste and Sorting can be undone with the local menu Undo or CTRL+Z key.
Note, after assigning node-numbers to the system (pressing Apply) Undo still works. However, node-numbers cannot be synchronized anymore.

Groups

Groups is a convenience-feature. It creates groups of coordinates based on specification of size and position of a fictional shape such as a rectangle.

A Group has individual node-indices. However, it also has a main-index. A component can take reference to all coordinates of a group by simply specifying the main-index.

In the above example there is a group with main-index 1000. It controls a group of four nodes, which are the vertices of a fictional rectangle. In this example will the Fields-component create the actual rectangle by referencing the main-index 1000.

New, Edit, Delete

New: Command to add a new group record to the database.

Edit: Editing of a record by calling the Nodes-Group-Sub-Form.

Delete: Deletes selected record.

Copy and Paste

Selected Groups can be copied to the clipboard. Eventually, these data can be pasted into the table. The datum is copied in text-format, which allows to paste the content also into the formula-editor or any text-editor.

Moving

Selected records can be moved up or down the list by issuing local menu Move up, Move down, ... or press CTRL+UP or CTRL + DOWN keys.

Undo

New, Delete, Editing, Paste and Sorting can be undone with the local menu Undo or CTRL+Z key.
Note, after assigning node-numbers to the system (pressing Apply) Undo still works. However, node-numbers cannot be synchronized anymore.

Scaling

Page Scaling alters size, position and orientation of all coordinates. For details see sub-form Scaling.

Formula

All parameters of format floating-point can be assigned a formula. Please check chapter Form - Formula for further details. Formula-identifiers for Nodes are:

Scaling
Scale Isotropic scaling
ScaleX Scaling in x-direction
ScaleY Scaling in y-direction
ScaleZ Scaling in z-direction
RotateX Rotation about x-axis
RotateY Rotation about y-axis
RotateZ Rotation about z-axis
ShiftX Shift in x-direction
ShiftY Shift in y-direction
ShiftZ Shift in z-direction

If you switch to page Scaling the associated input-fields should be highlighted.

Formula for Points and Groups

Points and Groups feature special identifiers in order to distinguish the records. The identifier is made-up from character "X"+node-number, "Y"+node-number or "Z"+node-number. For example, "Z2001=" means that the result of its formula will be assigned to the z-component of point "2001".

For example:

                                                   Z2001 = @Hc + 2*@tc
                           Y2002 = @Wc/2 + @tc;    Z2002 = @Hc + 2*@tc
                           Y2003 = @Wc/2 + @tc
    X2201 = -@Dc - 2*@tc;                          Z2201 = @Hc + 2*@tc
    X2202 = -@Dc - 2*@tc;  Y2202 = @Wc/2 + @tc;    Z2202 = @Hc + 2*@tc

If you select page Points then you should see marked entry fields:


Likewise, if you want to assign a formula to a record of a Group you would type the identifier as "Width"+group-number or "Height"+group-number.

For example:

    Width1000 = @Width;    Height1000 = 1.618*@Width;

This would assign the record with Group-Number "1000" the result of formula "Width" or "1.618*Width", respectively. Note, prefix "@" means that we access a global-formula.
