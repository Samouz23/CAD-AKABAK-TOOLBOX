The Contour-File object contains an ordered set of frequency response curves, which is typically used by components to create a directivity, such as in component Pressure Box.

Create a new Contour-File-object with the help of the New Component Form. The home of a Contour-File is in page General. Edit an existing object by dbl-click its entry in page General or issue menu Edit/Parameters or press CTRL+E.

At the referring component simply select the Contour-File object. Then it will use the data-set.

Importing Data

Most convenient it is if the file format is using the Import Control Settings of VACS. In this case the import is automatic.

In VACS you can prepare the frequency response curves all at once. Eventually issue VACS-menu IO/Export Data.

You should see a form as displayed to the bottom-right. Select File Format = VACS Text Format or File Format = VACS Binary Format. Check Export of parameters. If your data-set is complex-valued then Bode Type should be set to Bode Type = Real + Imaginary, Bode Type = Amplitude + Phase or Bode Type = Level dB + Phase, respectively.

Parameter

Each dataset should have Parameters. For directivity curves these are typically spherical coordinates. Either θ or φ are mapped to the y-axis as explained in chapter Graph - Parameter Dialog. For example, a matrix of data may follow Import Control Settings of the Parameter section:

    ...
    Param_Coord_x1=1
    Param_Coord_x2='-180,-175,-170, ... 155,160,165,170,175'
    Param_Coord_x3=90
    Param_Coord_Type=Spherical
    ...

Note, the dots in "Param_Coord_x2=" are an abbreviation only for this document.

Page - Graph

Data are visualized with the help of a contour-plot. This plot displays the ordinate as contour levels. There are two abscissa. The frequency is aligned with the horizontal x-axis and the angular distribution is aligned with the vertical y-axis. The operation is similar to the Contour-Plot in VACS.

Button - Open

Opens the file-dialog where you can select the data-file(s). The new dataset will replace the existing one.

Button - Projections

The sibling graphs display the projections. There are two cursors in the contour plot. One controls the mapping of the x-projection and the other of the y-projection.

Alternatively you can open the Projection dialog. Here you can specify the frequency and angular position of the projected curves and enable the Level Marker in order to show the beam-width traces. For more details, please refer to the VACS-manual.

Button - Contour

Opens a menu of tools for adjusting the contour-plot. For details see VACS-manual.

Button - Graph

Opens a menu of tools for adjusting the sibling graphs. For details see VACS-manual.

Button - Curves

Opens a menu of tools for adjusting selected curves. For details see VACS-manual.
