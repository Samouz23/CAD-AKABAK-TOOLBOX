If a data-file contains an Import Control Setting from the name-space "Data_..." then the import-engine can proceed automatically. If it is not part of the data-file, then the Import Data Control Dialog would open. Syntax and workings are identical to the Import control Settings of VACS. Please find below an extraction from the VACS-manual.

Converting Stage

The converter of the import-engine converts the incoming data-set into values of a physical unit, say SPL to Pascal. Eventually, AKABAK stores these physical data as curves.

On import of dB-levels AKABAK will typically de-normalize the level and convert the original data-values into linear values of physical units. For physical values peak values are assumed. For more advanced features, please refer to the VACS manual at Import Control Settings.

Data_Format = (Real, Real_Rms, LeveldB, Complex, Complex_Rms, Ampl_Phase, Ampl_Rms_Phase, LeveldB_Phase)

Data_Format is essential for interpreting incoming values. By learning the number-format we know whether we deal with scalar or vector data (real or complex), respectively, we know the notation of complex valued data and whether the numbers are given in physical units or as a level in dB. The rms-versions will cause AKABAK to multiply the incoming data by the crest-factor sqrt(2) in order to convert rms- to peak-values.

Real is used for all general scalar values. Real_Rms additionally converts rms- to peak-values. LeveldB converts dB-values to values in physical units as explained at manual of VACS - Appendix/Level Types. Complex is used if two successive numbers form real and imaginary parts of a complex number. Complex_Rms converts real and imaginary parts from rms- to peak-values. Ampl_Phase is used if two successive numbers form amplitude and phase, i.e. the polar notation of a complex number. For the phase angle degree-units are assumed, otherwise specify also Data_PhaseFormat=. If the phase is continuous (unwrapped) then specify also Data_IsContPhase=true. Ampl_Rms_Phase is similar but additionally converts rms- to peak-values. LeveldB_Phase is used if two successive numbers form level-dB and phase (see LeveldB and Ampl_Phase).

Data_LevelType = (Peak, Rms, Power, SoundPressure, SoundPower, Intensity1m, Impedance10, Impedance20)

Data_LevelType controls the de-normalization during import from dB to values in physical units as explained in manual of VACS - Appendix/Level Types. For example, SPL data get converted to peak sound pressure values in Pascal.

Data_LevelType is forwarded to the curve as scaling-parameter, and can be altered with the help of the Scaling-Dialog (see VACS manual). Because of this Data_LevelType can control the way AKABAK normalizes your data when displaying as dB-Level.

Data_IsContPhase = (false, true)

If true then data are kept as amplitude and continuous phase during import, otherwise they will be converted to real and imaginary parts. This setting prevents unnecessary processing if the phase is already unwrapped. If your data are not unwrapped or of other format this setting is ignored. See also Continuous Phase Technique in the manual of VACS.

Data_Phase_AngularFormat = (degree, radiant, cycles)

Angular format of imported phase-values, with the default value Data_Phase_AngularFormat = Degree.

Curve Properties

It is of advantage to attach certain properties to the data-set, in order to help subsequent processing and annotation.

Data_Domain = (Time, Frequency, Other)

Data_Domain specifies the Fourier-domain of the imported data. In AKABAK the default is Data_Domain=Frequency. Data_Domain is saved with the curve and can be modified with the help of the Scaling-Dialog (see VACS manual).


Note, there is no direct import of the y-axis for contour-plots. Rather the y-axis is generated from one of the Parameters as specified in the Parameter Dialog. Hence, either the data-file already contains Parameters, or these can be generated with the help of the above mentioned dialog.


Example

We are importing a file with values of sound power level in dB. The first column are frequencies and the second levels in dB.

       0  -89.12
   18.43   65.31
   36.85   62.62
   55.28   59.16
   ...

After selecting this file the Import Control Dialog opens because there are no Import Control Settings.

Select Data_Format = LeveldB because we import dB values. Level Type = SoundPower tells the level-converter of AKABAK the kind of dB-conversion to be used for de-normalization at import and re-normalization during display of curves in dB. Domain = Frequency helps in annotation and selecting default settings for the graph.

After import the curve is produced. As you can see in the screen-shot it is possible to alter the Level Type with the help of the Scaling-Dialog (see VACS-manual).
