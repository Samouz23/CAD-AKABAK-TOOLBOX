VACS

The Curve-File object contains Frequency Response curves, which are used by components. For example a curve can weight the driving such as as in Fixed Driving, LE-Source or LE-Filter. Curves can be the Response and Impedance of a LE-Measured Radiator component. It can also be the frequency impedance curve of Wall Impedance.

Create a new Curve-File-object with the help of the New Component Form. The home of a Curve-File is in page General. Edit an existing object by dbl-click its entry in page General or issue menu Edit/Parameters or press CTRL+E.

The graph can contain as many curves as you like. However, you need to specify which curve shall be used by components. This is done with the help of the curve-name which you need to enter at the appropriate fields.

Importing Data

Most convenient it is if the file format is using the Import Control Settings of VACS. In this case the import is automatic.

However, you can also import other formats. Here is a short-hand documentation: Import Text Formats, Import Control Dialog. For example, you may want to enter a frequency response curve. Take a text-editor and enter for example:

      20   0.2
      50   0.5
     100   0.7
     200   0.8
    1000   1.0
    2000   1.0

Copy this sequence to the clipboard and and issue Button - Paste of this form. The Import Control Dialog opens where you can make adjustments. Eventually, the curve appears in the plot.

Using VACS

In VACS you can prepare the frequency response. In VACS select the curve you want to use. Then issue VACS-menu IO/Export Data.

Eventually you should see a form as displayed to the right. Select File Format = VACS Text Format or File Format = VACS Binary Format. For single curve-data most of the check boxes may not apply. If your data-set is complex-valued then Bode Type should be set to Bode Type = Real + Imaginary, Bode Type = Amplitude + Phase or Bode Type = Level dB + Phase, respectively.

Page - Graph

Button - Open

Opens the file-dialog where you can select the data-file. The new dataset will be added as a curve to the existing curves.

Button - Paste

This command assumes a filename or data are available at the clipboard. If its a filename then the associated file will be imported. A filename is copied to the clipboard with the help of the File-Manager of the operating system. There you would select a file and then issue menu Start/Copy or press CTRL+C. You can also drag the filename from the File-Manager into the Curve File Form. If the clipboard contains data then these will be imported directly. Eventually, the new dataset will be added as a curve to the existing curves.

Button - Swap Axis

Moves selected curves to the other ordinate axis.

Button - Graph

Opens a menu of tools for adjusting the whole graph. For details see VACS-manual.

Button - Curves

Opens a menu of tools for adjusting selected curves. For details see VACS-manual.

Name of curves to be used

Enter here the "name" of the curve to be used during calculations. All other curves will be ignored for calculations. Unspecified curves will still be saved with the project.
