Import Data - Control Form

Home General Import Text Formats Import Control - Data

During importing datasets in text-format the Import Control Dialog would open if the file-format is unknown.

The Control Form would be skipped if there is sufficient information given by Import Control Settings.

Columns of the table

Filename

Name of data-file containing one or multiple data-sets.

Data set

Index of data-set within data-file. A data-set is a group comprising one or multiple curves of identical settings.

Data format

Number-format of incoming data. This Import Control Setting is essential for conversion to physical units.

Level Type

Level Type controls the de-normalization during import from Level-dB to values in physical units.

This settings also controls the display of Level-dB.

Domain

Select either Frequency, Time or Other. Currently, only data-sets of Domain=Frequency are used in AKABAK.

Skip

If checked then this data-set is not imported.

Graph

Type of hosting graph. Different data-sets are assigned first to the left and then to the right ordinate.

Warnings

Outputs a list of warnings for this data-set.

Buttons

View file

Opens the file, which is associated with the selected row. This feature is helpful for identifying the data structure. You can also modify and save the file, however, for re-importing you would need to go back and import the file again.

To all

Assigns the setting of the selected data-set to all others (see Of this file).

Of this file

If checked To all applies only to those data-sets, which belong to the same file.

Apply

Rendering the imported data into graphs. The dialog is not closed yet, so you might want to change some settings.

Close

Closes the dialog and terminates the import engine.
