Home

Processing means to calculate the total system response. The source is specified by the Lumped Element Part. If this is not available the source defaults to Fixed Driving. If there are acoustic boundary conditions to satisfy the Boundary Element Part gets involved. Otherwise we have a Direct Sound Analysis. Eventually the sound pressure response can be rendered as a Field plot or as a Frequency Response Curve. Further Radiation Impedance and Network Parameter can be calculated. The latter are forwarded to the sibling application VACS.

Calculations make use of parallel processing. You can specify the number threads used for calculation at menu Options/Preferences.

Superposition

Processing involving the Boundary Element Method feature superposition. This feature allows to sub-sequentially alter the driving conditions of the acoustic sources without the need to resolve the BEM-domains. Superposition it is called because the BEM is solved for each source individually and kept separated. Only at observation-stage solutions are 'collapsing' to the final result.
For the practice this means as long as we do not change the acoustic boundary condition the BEM-part does not need to be re-solved. The driving can be via the Lumped Element Part or by values from the Fixed Driving Table. If we only modified the networks or its parameters we simply re-calculate the observations.

Calculate All

See menu Processing/Calculate All. This command starts the calculation stack. If the BEM is involved then the system of Integral Equation is solved first. This step is usually time consuming. When ready AKABAK saves the results in the result-file. This result file has the same filename as the project however the file extension is *.akpbe commences with the calculation of specified observations - first the Fields then Spectra.

Calculate Individually

BEM Meshing only performs the meshing and the calculation of the Free Terms and the Volume.
BEM Solving performs the meshing and the solving of the Helmholtz Integral.
Field Meshing is only "meshing" the planes for Field observations.
Field Calculation performs "meshing" the planes and calculation for Field observations.
Spectrum All performs calculations of radiation, radiation impedance and network-parameters and sending results to VACS, Clipboard or File.
Spectrum Radiation dito however radiation only.
Spectrum Radiation Impedance dito however radiation impedance only.
Spectrum LE dito however lumped element network parameters only.

Result File

When ready AKABAK saves the solving stage in the result-file. This result-file has the same filename as the project however the file extension is:

*.akpbe

The saving is asynchronous and runs in the background.

The result-file gets loaded after a project has been opened. In this case BEM-projects can be directly observed without the need for solving the BEM-system.

Menu Options/Result File can be used to manually save, load or delete the result file. The result-file does not contain essential project information. On file-transfers you can omit it. Also, it can be deleted.

Note, that the result-file can become large, say, several mega-bytes. You can disable this feature at menu Options/Preferences-Files.

Note, the demo-version does not have the result-file feature. In this case you have to re-solve BEM-systems after opening the the project.
