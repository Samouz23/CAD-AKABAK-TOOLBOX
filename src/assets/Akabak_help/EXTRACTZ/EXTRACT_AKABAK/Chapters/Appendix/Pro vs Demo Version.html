Professional vs Demo Version

Home

There are two versions of AKABAK:

  1. Professional
  2. Demo

Professional Version

For the Professional Version a user licence can be purchased. The Professional Version allows to store results from the solving stage of the Boundary Element Analysis. This feature dramatically increases working efficiency because solving typically is the most time consuming step. See chapter Processing.

The Professional Version is protected by a Release Code, which will be provided after sells.

Demo Version

The Demo Version provides the same functionality but the feature of saving results of the solving stage. This means that after opening a project the first step would be the solving when working in Boundary Element Mode.

Note

The Demo Version does not allow for entering the Release Code. After purchase, please download and install the Professional Version as indicated in the email.
