Integration points and receiving point

For applying the Boundary Element Method (BEM) the surface surrounding the field needs to be divided into finite elements. In AKABAK constant pressure elements of triangular shape are used for solving the Helmholtz Integral. Any other shape specified is transformed into triangular patches. During solving-stage the receiving point is the point of gravity of a triangle. The solver calculates unknown surface-velocities and pressures according to the standard way of solving Integral Equations. Hence, for the solver the structure "looks" like a cloud of points, each a center of a triangle.

At the subsequent observation stage, i.e. when the sound field is calculated, the Green-function of each triangle is integrated again and then weighted by the normal surface-velocity and pressure as calculated at the solving stage.

AKABAK mesh-generator starts with a given polygon by sub-dividing its flat plane into triangular shapes. If you use an external mesh-generator, such as GMSH, you would firstly import the mesh with the help of the Mesh-File Object. Secondly use the component Elements (mesh-file) in order to create the acoustic boundaries.

Type of Mesh

AKABAK offers two types of mesh-generation: Bifurcation and Delaunay. Bifurcation is a technique where each specified quadrilateral and triangle is split into two new items in an attempt to yield a regular shape and simultaneously satisfy the specified mesh-criteria. Delaunay is an advanced schema [8], which triangulizes any shape directly in a most regular way. For most elements in AKABAK the mesh-type can be selected and there are optional control parameters, as explained at dialog Meshing.

Mesh Density

Before solving, AKABAK investigates the boundary-planes as specified and will cut these planes until specified criteria are met. Main criterion is the side-length of the mesh-triangle, which can be specified with the help of parameter Edge Length of dialog Meshing.

High Frequencies

At high temporal frequencies the wave-field is typically formed more complex due to interferences. For example, the acoustic field may show stronger variations at diffraction edges or at high modal density, whereas the field may be more regular across larger flat structures.

Basically each finite element should be small enough so that pressure-variations across the element can be regarded small. Here, we are in a dilemma because there is no reliable measure a priory.

Low Frequencies

For low frequency analysis the frequency-criterion may yield too a coarse mesh. The BE-mesh should sufficiently represent the acoustic boundary.

For checking whether the mesh is reliably representing the acoustic boundary there is this "FE-wisdom":

  1. Run a simulation with given mesh-density.
  2. Repeat simulation with increased mesh-density.
  3. If result is different repeat check with increased density.

Opposite Walls and Thin Shapes

Close to the surface of a boundary element the sound field can be only approximate because of finite number of integration points. Picture a small halo over each triangle having a radius of the inscribed circle. In general, the model can be considered good if there is little intersection of these semi-spheres.

BEM works best if the acoustic boundaries enclose a compact volume as demonstrated in paper [37]. Thin shapes and narrow ducts need to be meshed with a higher resolution. For example, elements of opposite walls of a duct should have a size which ensures that its halos do not intersect. Halos in the left sketch intersect. This means the size of the finite element is too large. After adjusting parameter EdgeLength the mesh generator yields triangles of smaller size and the halos appear apart as shown in the right drawing. Similar problems occur with thin plates or elongated triangles where the distance of the center points is much smaller then the length of the sides.

Overlapping Elements

One of the most encountered pitfalls is the overlapping of elements. If two elements occupy the same spot in space and belong to the same sub-domain then the solver cannot yield exact results because of ambiguity.

The mesh generator performs a simple test on whether there are boundary elements which center points are close. A warning will be issued and close triangles will be rendered colored as demonstrated by the mesh on the right. There are two rectangles of width 200mm and height 120mm apart only by 10mm. If meshed with EdgeLength 50mm AKABAK issues a warning and renders close triangles violet. Setting EdgeLength to 25mm removes the warning because the gap is modeled by sufficient small boundary elements as described in the last chapter.

There is one exception where boundary elements are allowed to be very close or to overlap. This case is if the two boundary planes belong to different subdomains.

Holes and Gaps

The Boundary Element Method assumes a complete boundary, and the subdomain should enclose a valid volume. The exterior domain forms only an apparent exception because here the domain is "closed" analytically by assuming Sommerfeld radiation condition at infinity.

However, one of the advantages of the Boundary Element Method is that the boundary-mesh does not need to be "water-tight". The BEM, as implemented in AKABAK, can still give satisfactory results if the mesh shows small holes and gaps. The reason for this is that for a subdomain all elements are inter-connected by integrated Green-functions, i.e. the method can be regarded a holistic approach.

Subdomains

AKABAK allows subdomain modeling. With respect to meshing, each subdomain should be regarded independently, i.e. it should form a volume surrounded by the boundary. Any triangle generated should be uniquely belong to a single subdomain. Here, the only exception are the interfaces, which triangles belong to exactly two subdomains.
