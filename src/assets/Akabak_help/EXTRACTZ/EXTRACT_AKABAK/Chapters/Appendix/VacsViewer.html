VACS stands for Visualising Acoustics, a software package that has been developed to simplify visualising, processing and storing acoustical data, notably of transfer-functions.

With VACS it is easy to compare measurements, simulations and calculations from different origins. Once imported, a variety of processing tools allows for transformations and calculations.



AKABAKs calculation of spectrum-curves makes use of the interface of VACS, which allows for receiving and displaying data. After the calculation results are send to VACS which performs the rendering.

On recalculation, curves will be updated in VACS.

Transmission of Data

By default AKABAK transmits spectral data to VACS automatically using Windows COM technology. In this scenario VACS plays the role of the COM-server. If there is an Observation specified, which involves spectral output then VACS should start automatically if not already open. Alternatively you can start VACS from Windows Start menu as usually, or you can issue menu Options/Open VACS in AKABAK.

However, it is possible to select alternative ways of output. This can be practical if there are several instances of AKABAK and VACS involved and it becomes unclear where curves will come out. Also, an alternative becomes necessary if the underlying operating system does not support the COM-transfer technique, such as on LINUX for example.

You can select the Clipboard or Files for data-transfer as an alternative to COM. If globally selected the way of output becomes the default (see menu Options/Preferences-VACS). It can also be specified at individual observations at Form-Page Range.

With Clipboard or Files selected the format of the dataset is conform with the VACS - Import Control Setting schema, which is documented in the help-files of VACS. There are also public papers available at the R&D Team website.
The curves will be output after the calculation has finished. Also these datasets are output if menu Processing/Output Spectra is issued.

Clipboard will copy curves to the clipboard. Nothing else is happening. If you want to paste, first select the target application then issue menu Edit/Paste of the target application. In VACS it is of advantage to create also a blank graph-form before the pasting. On updating you simple call paste. VACS will then search for to-be-updated curves.

Files will save the datasets to files. Of course we need a target folder and filenames. The latter are generated automatically. The folder-name can be specified globally or individually otherwise the folder of the current Project is used. In VACS issue menu IO/Import Data which will import one or multiple data-files. Here also, the update-mechanism applies.

VACS for Preparing Datasets

VACS can also be used to create datasets, which can be used at various components of the General Part.

VacsViewer

Typically AKABAK & VACS licenses are purchased as a bundle. However, both packages need to be downloaded and installed individually.

If you work with the demo-version of AKABAK then download and install VacsViewer.

VacsViewer is essentially the same application as VACS but does not allow for saving VACS-project-files. VacsViewer is free of charge and readily available from our web-site: www.randteam.de
