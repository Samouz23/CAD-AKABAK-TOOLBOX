The Boundary Element Analysis calculates the acoustic field satisfying the linear wave-equation and given boundary conditions, which includes reflection and diffraction. We assume linearity and isotropic properties of the medium. Interior and exterior radiation problems can be solved [1,2,4,5].

The basic setup is displayed in the figure to the right. We want to calculate the sound field in volume V1 given acoustic boundaries of volumes V2 and V3. The boundaries can be reflective, can provide an impedance or can vibrate with velocity v0. There can be sound sources inside V1. There can be as many "exclusions" or "islands" like V2 which cause scattering. However, there is typically only one enveloping boundary such as V3 which dominates the forming of modes. V3 can be made analytic in a way that we can formulate the BEM for an infinite large V3. We call this radiation condition Exterior. In AKABAK you specify this at component Subdomain.

The acoustic boundary gets segmented into triangles for 3D, into truncated cones for Circular Symmetry and lines for 2D. Such a segment is called Finite Element. The name stem from a mathematical trick for solving the integral equations. For this trick to work each element needs to be small enough compared to the wavelength so that we can assume approximately a constant pressure over its surface. The creation of the finite elements is called meshing.

Inside the Helmholtz Integral there are vectors, hence not only the value of a parameter is important also its direction. The reference here is the normal of a finite element, and this is deduced from the specified planes of the component. In AKABAK normals should point always into the domain. Only at Interfaces we are free to select the direction.

The BEM needs a volume to function properly. Thin shapes cause a problem. However, one way to tackle this problem is the use of multiple and coupled subdomains. These can be of type Interior and Exterior. See also dedicated paper [37].

The BEM of the exterior domain fails to solve at certain eigen-frequencies of the "exclusions" or "islands" like V2. However, there are workarounds, which are called NUC.


The Boundary Element solver is used in order to calculate the acoustic field. Only boundary condition of motion are taken into account. Potential boundary conditions are not supported. The integral is solved by decomposing the structure into triangles assuming constant pressure on each finite element.

We need to specify the acoustic boundary and a range of sources, which can be vibrating parts of the boundary or point-sources. The Boundary Element Analysis solves for certain unknowns. Therefore, the analysis always goes through two steps:

  1. Solving stage
  2. Observation stage

AKABAK switches automatically a subdomain into Boundary Element Mode as soon as there are specified boundaries. If there are only sections of Pressure Points or Pressure Box this subdomain goes into mode for Direct Sound Analysis.


The Boundary Element part can be fully coupled to the Lumped Element Analysis Analysis [9]. The coupling is specified at observation stage by specification of a lumped element network.

If no lumped element network is present acoustic sources are driven by fixed values, which can be edited at menu Global/Fixed Driving.
