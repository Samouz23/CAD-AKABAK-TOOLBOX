Planes can be specified with the help of vertices by following components: Elements (Nodes), Elements (Mesh-File), Baffle, Fields (Nodes) and Fields (Mesh-File).

Planes are also used to position components in 3D, such as the Diaphragm, Shell, Duct, VibFile, Baffle and the Infinite Baffle.

Planes are also used for generating observation points for fields or for positioning directivity plots.


There are two ways of inputting planes

  1. Nodes and Elements
  2. CAD and Mesh-Files

Nodes and Elements

At the various dialogs we typically specify a plane with the help of an ordered list of indices, which are pointers to vertex-coordinates of the plane. These indices are called Nodes and are references to a database of coordinates.

The order of specification should be such that the normal points according to the right hand rule. For example the node-indices of the above plane should be specified in the following order:

1001  1002  1003  1004

For the Boundary Element Method the normal should point into the domain as explained in chapter Normals and Volumes.

Triangular planes are also used to give position and direction. In this case the first point of the list is the position and the other two form a triangle. The size of this triangle can be arbitrary. The normal of the triangle is the direction of the component. See also at sub-form Position.

CAD and Mesh-Files

See also chapter Mesh-files.

Planes for BEM, positioning and for fields can be imported from 3D-CAD-applications. Best results are obtained if an intermediate meshing-tool is used. A meshing-tool can read typical CAD-files, performs meshing and eventually exports so-called mesh-files. The content and structure of these mesh-files are similar to the above Nodes & Element approach.

The CAD drawing should be as simple as possible. It should contain only faces relevant to the acoustic problem. For the BEM this means only and strictly the boundary conditions.

The meshing-tool should create a mesh as coarse as possible. Just complex enough that the boundaries are represented. Note, that AKABAK will mesh further based on the imported mesh and according to the frequency criterion, see chapter Meshing. In general, AKABAK can refine the mesh but cannot simplify the mesh.

The meshing-tool generates so called Tags, which are names of planes in form of integer-numbers or strings. Tags can group clusters of planes, which makes selection easier. With the help of Tags we can organize mesh-file-elements. See chapter Mesh-File-Tags.

Example Positioning

Planes are also used to provide positioning and direction for components, such as Diaphragm.

In the CAD-program we provide these control-planes as part of the drawing. These planes are typically little boxes or surfaces as shown in the draft on the right hand side. Eventually one of the planes of the box will form the control-plane.

On page Position we select Mesh-File where we select the reference to a Mesh-File object. From the mesh-file we type into field Include all Tag-numbers or Tag-strings which associated elements we want to be the control-plane for positioning. In this example, the control-plane will be assembled from all mesh-file elements with Tag=28. The mounting point P1 is the center-point of this plane. The first triangle of this set will provide P2 and P3. In this example, we had to manually adjust axial rotation by -22.5 deg and to offset it by -10 mm.
