Initialization-files (ini-file)

Home


Please note that it is not necessary to edit the ini-files and is generally not recommended.


Note: If installed on a removable medium, such as a memory-stick, settings are stored into the folder of the executable instead of storing them to the standard locations.

The ini-file is a text-file and can be edited with the help of a text-editor. Changes take affect only with the next start of the application. Make sure the application is terminated before starting editing. Comments start with a ";".

Personal settings

The application stores all settings in its associated "ini" file (initialization-file), say AKABAK.ini. Personal settings are non-roaming, that means settings are available only on the local computer and are not send across the network.

Under MS-Windows the ini-file is located in your personal Profile in the local section. The physical location depends on the version.

In Win7 you can find AKABAK.ini at

    C:\Users\«User»\AppData\Local\RDTeam\AKABAK.ini

Global settings

The Professional Version stores another ini-file common to all users. This ini-file stores installation relevant parameters, such as the Release Code.

For example

    C:\ProgramData\RDTeam\AKABAK.ini
