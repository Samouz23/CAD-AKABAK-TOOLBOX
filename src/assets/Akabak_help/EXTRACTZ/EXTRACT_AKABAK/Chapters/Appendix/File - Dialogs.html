The File-Dialog-Form

Home

The File dialogs is used to load or save a file from or into memory. In Windows filenames are structured into a path, the filename and the extension. The dialog-from is structured accordingly.

The path gives the location of the file and can be selected typically at the top of the dialog with help of a tree-list. Clicking on a folder maneuvers into this folder and displays files in the file-list.

Selecting a file in the file-list and clicking on the Open or Save button will close the dialog and eventually start the loading or saving, respectively. Dbl-clicking on a file-name is identical to selecting + button-click.

Files of type provides a file-filter. Common File filters can also be entered into the input-field of the file-name. For example, *.* means view all files, *.txt means all text-files and so on.
