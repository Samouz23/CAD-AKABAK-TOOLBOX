Hardware Requirement

In general AKABAK assumes modern PC-hardware, fit for a standard MS-Windows system.

Recommended is an amply equipped computer with many CPUs and lots of memory, because AKABAK makes extensively use of parallel processing. However, with each used thread also the memory allocation goes up. The maximum number of supported threads are 64.

On 32bit-systems memory is limited to a maximum of 2GByte per process. If you simulate large structures on multiple CPUs it is recommended to run the 64bit version of AKABAK. Of course, this assumes a 64bit OS-system.

It is hard to give reliable prediction of memory consumption. In fact the best measurement-tool is AKABAK itself. Run AKABAK with different mesh-distributions and frequency ranges and observe Windows' Task-Manager/Performance board. Note, regarding memory consumption the free and commercial version of AKABAK are identical. To give a number, most projects run well on a laptop with 4 CPUs, 8 threads and 16 GByte of memory.

AKABAK 3D-viewer runs OpenGL. Make sure your graphic-card is up-to-date.

OS Requirements

AKABAK should run on all versions of MS-Windows 11, 10, 8 and 7. There is available a 32bit and a 64bit version. The installation is organized automatically by the installer.

Other Software

For spectral output you need to install also the application VACS which is typically part of the license which you have purchased.

Installing

Installing is straightforward. Open the install application and follow the instructions. The installer automatically installs the correct bit-version of AKABAK (32/64bit). Examples are very important, and are part of the installation.

User Documentation

The basic user documentation is available as Help. If you are new to AKABAK, simply press F1 and enjoy the reading!
