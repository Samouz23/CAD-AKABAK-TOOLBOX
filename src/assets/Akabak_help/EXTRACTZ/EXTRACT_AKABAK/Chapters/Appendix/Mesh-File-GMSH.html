GMSH is a mesh generator for three-dimensional finite element analysis. It provides built-in pre- and post-processing facilities. GMESH is open-source provided by C. Geuzaine and J.-F. Remacle. By the time of this writing GMSH was at version 4.11. Here is the download link:

Download GMESH

GMSH creates firstly a surface-mesh, and subsequently from this the volume is discretized by fundamental 3D-bodies. In AKABAK we make use only of the surface mesh of GMSH (2D). This is so because AKABAK calculates the radiation with the help of the Boundary Element Method. The other application of where we can make use of a mesh is the display of sound pressure fields. Here, too, we only need the surface meshing capability of GMSH.

CAD

For meshing we need a technical drawing in digital form, which we call "CAD". There are basically two ways of generating the CAD:

(1) GMSH has on board its own CAD drawing tool. It is similar to AKABAKs, however features more functionality. The specification is script based and can be parameterized with the help of variables and formula. Further there is a API available, which can be called from your Python or C application. Please refer to the extensive documentation provided at the web-site of GMSH.

(2) The CAD-drawing can be generated graphically with the help of plattfoms such as Solidworks, Inventor, Rhino, FreeCAD etc. GMSH can read a host of common CAD file-formats. Typically you would save your CAD into a file of the transfer-formats such as STEP, IGES, DXF etc. In GMSH you load this file and start with the meshing. There is a 3D-viewer similar to the one in AKABAK.

You can mix the CAD-import with GMSH-scripting (and, of course, also with AKABAK drawing facilities).

Note, GMSH can create different versions of the format of its mesh-file. AKABAK supports mesh-files of version 2.2 in text format. See below where the work-flow is explained.

Work-flow Graphical CAD

In the following there is given a 1-2-3 description of the work-flow when you have a CAD drawing to begin with and aim to have a mesh-file for AKABAK at the end.
Note, each step of the work-flow involves usually complex processing. Often a task can be performed in different ways. Also, errors or missing parts are common place. Experimentation is necessary here to find the best possible type of file-format and adjustment.

(1) In the CAD application, firstly you draw the CAD. Cut it in such a way that only the principal part is left if you later want to exploit symmetry in AKABAK (see BEM Parameters).

(2) Then export the CAD drawing using a transitional file-format which can be read by GMSH, for example STEP, IGES, etc.

(3) Open GMSH, go to menu/Open and load the the transitional file. Initially, it is displayed only by shape-lines.

(4) In GMSH in the tree-list on the left hand side click on Modules/Mesh/2D. This will create a surface mesh. No parameters to adjust? Well, yes, later, if necessary. Usually the initial settings are well-adjusted.

(5) In GMSH is the next step to adjust the mesh-density. The easiest way to do this is to issue point Modules/Mesh/Refine by splitting of the tree-list.
Note, there are two stages of meshing. The first happens at GMSH. The second is performed by AKABAK, eventually. Please, note that AKABAK can only refine the mesh within the GMSH-mesh. The refinement of AKABAK is always flat. Usually this stage needs some experimental iterations. As a rule of thumb, try to make the GMSH-mesh as coarse as possible - just so that any curvature is preserved. Eventually, in AKABAK the mesh-density is controlled with the help of parameter Edge Length, see menu/Meshing.

(6) In GMSH the final step is to export the mesh to a mesh-file of version 2.2 in text-format. This works as follows:

  • Issue menu/File/Export.
  • There select File Type = Mesh-GMSH (*.msh).
  • Click OK.
  • In the following form MSH Options select Version 2 ASCII.
  • Click OK, which saves the msh-file.

The mesh-file of GMSH has a structure similar to Nodes and Elements of AKABAK. It is a text-file which can be viewed (and edited) with the help of a text-editor.

(7) Finally the mesh-file can be imported into AKABAK. In order to do so create a Mesh-File object on page General. There simply issue button/Open on page File as explained in chapter Form Mesh-File.
Firstly you would check the dimensions as reported on page File at parameter Size. If necessary you can scale, shift and rotate the drawing with the help of page Scaling.
On page Drawing you will find listed all Tags which GMSH has attached to the elements. Also AKABAK adds its own Tags. The Tags help in selecting groups of elements in order to distribute these elements to various Subdomains, Interfaces or Fields. Please refer to chapter Mesh-File-Tags.

Work-flow GMSH Geo-Files

GMSH brings with it an extensible CAD drawing facility. It is text-based. Each line forms a command. Step-by-step the script builds the structure starting with points, then lines, surfaces and eventually bodies. The script is stored as a text-file with extension *.geo. Below is a view into an example of GMSH called "transfinite.geo". The transfinite mesh is different from the Delaunay mesh as it provides a linear rectangular grid:


    l = 1;
    r1 = 2;
    r2 = 0.5;
    n = 10;
    n2 = n;
    progr = 2;
    // exterior cube
    Point(1) = {0,0,0,l};
    Point(2) = {r1,r1,-r1,l};
    Point(3) = {-r1,r1,-r1,l};
    Point(4) = {-r1,-r1,-r1,l};
    Point(5) = {r1,-r1,-r1,l};
    Line(1) = {2,3};
    Line(2) = {3,4};
    Line(3) = {4,5};
    Line(4) = {5,2};
    Curve Loop(5) = {4,1,2,3};
    Plane Surface(6) = {5};
    Extrude {0.0,0.0,2*r1}{ Surface {6}; }
    Delete { Volume{1}; }
    ...

The working with the geo-file of GMSH is well documented by GMSH manuals, examples and various video-tutorials. Please refer there.
Here we can say that you can use GMSH as a CAD-drawing tool with the advantage of integrated meshing. You have full control about the mesh-density down to node-level. As for the tagging, the Geo-script allows to assign Physical Names to Tags, which in turn, facilitates the setup of AKABAKs subdomain structure.
Using GMSH Geo-scripts has further the advantage that Tags are maintained and the whole meshing and saving process can be automated.

Once the mesh-file is stored we proceed in the same way as explained above for Graphical CAD at points (6) and (7).
