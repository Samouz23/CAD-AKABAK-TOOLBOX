Rotation Modes

Home

Rotation is for navigating objects in the 3D-Viewer. Click the mouse and drag it. Also you can use the navigating-keys. Select the 3D-viewer, press "R" and then the left, right, up or down key.

AKABAK offers two rotation modes. You can toggle the modes at any time at menu/Venue. Use menu Options/Preferences-Graphics in order to set your preferred mode for new projects.

Euler

If the rotation mode is Euler then rotation is about one coordinate axis. In this case the horizontal movement rotates about the vertical axis. The vertical axis can be selected in the menu Venue/ZYX-Axis Upwards, respectively.

ArcBall

If the rotation mode is ArcBall then the mouse movement in the 3D-viewer is mapped on the surface of a virtual sphere, which rotates.
