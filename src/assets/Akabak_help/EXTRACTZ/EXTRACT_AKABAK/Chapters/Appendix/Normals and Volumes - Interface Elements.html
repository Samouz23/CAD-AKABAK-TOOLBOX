Normals and Volumes - Interface Elements

Home » Normals and Volumes

Interfaces are part of Subdomain Modeling. In general an interface couples two subdomains. This is done by solving the Boundary Element System in such a way that at each triangle of the interface we have continuity and compatibility of pressure and normal velocity, respectively.

Operational wise, we assign all BEM-components which belong to the interface to a special parent-component called Interface.


Also with interfaces, the orientation of the normals is of importance. The normal of all planes of an interface should point into the same direction. The direction can be arbitrary but needs to be specified at the Interface-Component.

The normals of all elements belonging to interface "Interior-Vent" should point into the volume of the cabinet because parameter Subdomain 1 = "Interior".

The normals of all elements belonging to interface "Exterior-Vent" should point into the exterior because parameter Subdomain 1 = "Exterior".

Note, that normals should point into the direction, where parameter Subdomain 1 is referencing to.
