Floating Point Values

Many parameters are in the form of floating point values. The mantissa of floating point values is indicated by a dot. No thousand separations are supported. Examples for the general format are

    1000.3
    0.01234

For large or small values the Scientific Format (SCI) format can be convenient. Use "e" or "E" directly following the number to indicate magnitudes. For example:

  1200 = 1.2e3
  0.0015 = 1.5e-3

You can select the unit-system of AKABAK at menu Option/Units.

SI-Units

If SI-units are used you can specify also with the help of the Engineering Format (ENG). Magnitudes are given by "p, n, u, m, k, M, G" directly following the number to indicate pico, nano, micro, milli, kilo, Mega and Giga. For example: 10k = 1e3, 1u = 1e-6 etc.

If SI-units are used then values of distance can be entered:

  • m: 0.0254
  • mm: 25.4mm
  • cm: 2.54cm
  • in: 1in
  • ft: 0.0833ft

User-Units

If a User Unit is selected then the floating-point number should be entered in general or scientific format. No units are supported.

Formula

Floating point parameters can be assigned a value with the help of a formula.
