Purpose Creates a rectangular baffle
Used in Diaphragm, Shell, Duct, Vib-File

Baffle Type

Components Diaphragm, Shell, Duct, Vib-File feature a local baffle which helps to embed circular shapes into an otherwise rectangular environment. In the associate edit-forms the Baffle Type can be selected with the help of a list. For example at Diaphragm - Page Parameter.

With Baffle creates a rectangular baffle around the circular, elliptical or oval Diaphragm, Shell, Duct, Vib-File.

If the component has a rectangular shape no baffle is created. However, parameter Offset can still be used.

The size of this baffle is always identical to the outer-diameters of the component.

No Baffle disables the baffle.

Only Recess disables the baffle. However, extrusion walls are created if parameter Offset is specified (see below).

Offset

           

Offset allows to create a tunnel or a step at the outer edge of following elements:

Diaphragm, Shell, Vib-File

If Baffle Type = Only Recess then a tunnel or step is extruded but without the attached baffle.

If Baffle Type = No Baffle then Offset is ignored.

Side=Front

If Offset > 0 then the baffle is displaced forward, which creates a tunnel in front of the device. If Offset < 0 then the baffle is displaced backwards, which creates a step with respect to the baffle.

Side=Rear

For the rear of a diaphragm it is the same from the view-point of the whole device. If Offset > 0 then the baffle is displaced in direction of the front diaphragm, which creates a step for the rear. If Offset < 0 then the baffle is displaced in direction of the rear-side, which creates a tunnel for the rear diaphragm.

Front and Rear

Often we have the case where a diaphragm is within a wall with a certain thickness. There are two Diaphragm-elements, one with Side=Front and one with Side=Rear. In this case we use Offset in combination with axial offset of the Scaling Form.
